# v52.30 변경내용

## 중점위험요인 관리 UI
공지사항 관리와 동일한 관리 바 패턴을 적용했습니다.

- 추가
- 선택 삭제
- 위로 이동
- 아래로 이동
- 선택 개수 표시
- 전체 체크박스
- 행 체크박스
- 순번 컬럼

## 기존 기능 유지
- 담당자: 배정 현장 전파
- 안전관리자/관리자/최고관리자: 기존 권한에 따른 공통/현장 전파
- 전파 종료
- 근로자 앱 중점위험요인 표시
- 기존 작성자/등록일/대상 표시

## 순서 정책
중점위험요인은 공지와 달리 `공통`과 `현장별` 범위가 섞입니다.
다른 현장의 순서를 건드리지 않도록:

- 공통끼리 순서 변경
- 각 현장끼리 순서 변경

으로 처리했습니다.

작업자 앱에서는 공통 중점위험요인을 먼저 표시하고,
이후 해당 작업자의 소속현장 중점위험요인을 각 순번대로 표시합니다.

## 삭제
선택 삭제 시 DB에서 실제 삭제됩니다.
전파중 항목을 삭제하면 작업자 앱에서도 다음 조회부터 즉시 사라집니다.
