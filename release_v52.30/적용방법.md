# v52.30 적용방법

## 1. 먼저 Supabase SQL 실행

Supabase SQL Editor에서 아래 파일 **전체**를 실행합니다.

```text
release_v52.30\Supabase에서_실행\00_v52.30_중점위험요인_공지형관리바_순서삭제.sql
```

SQL에서 추가되는 핵심:
- `attendance_risk_broadcasts.sort_order`
- 신규 등록 시 자동 순번
- 중점위험요인 관리 조회 v52.30
- 선택 위/아래 이동 RPC
- 선택 삭제 RPC
- 작업자 앱 risk_broadcasts 순번 반영

기존 공통/현장 권한 함수와 기존 전파 종료 기능은 유지합니다.

## 2. 프로그램 적용

프로젝트 최상위에서:

```powershell
node .\release_v52.30\apply-v52.30-risk-toolbar-order-delete.cjs
```

정상 메시지:

```text
[v52.30 적용 완료]
```

## 3. 빌드

```powershell
npm run build
```

## 4. Git

변경 파일은 프로그램 기준 1개입니다.

```powershell
git add src/page/RiskBroadcastManagement.jsx
git status
git commit -m "v52.30 add risk management toolbar and ordering"
git push origin main
```

`git add .`은 사용하지 않습니다.

## 5. 화면 확인

근태관리 > 중점위험요인 관리:

- 상단 제목/설명/새로고침
- `+` 추가
- `−` 선택 삭제
- `↑` 위로 이동
- `↓` 아래로 이동
- `선택 N개`
- 전체/행 체크박스
- 순번
- 기존 공통/담당 배지
- 기존 전파 종료

순서 변경은 안전하게:
- 공통 전파는 공통끼리
- 특정 현장 전파는 같은 현장끼리
이동합니다.

## 6. SQL 롤백

필요한 경우:

```text
release_v52.30\Supabase에서_실행\99_v52.30_롤백.sql
```

단, `attendance_worker_me_v52_21` 원복은 기존 v52.21 SQL을 다시 실행해야 합니다.
