# v52.14.3 근태 QR 카메라 무한대기 보완

- iPhone에서 `후면 카메라를 준비하고 있습니다`가 계속 표시되던 문제 수정
- 촬영창의 비디오 요소가 실제로 생성된 뒤 카메라 연결을 시작하도록 변경
- 카메라 첫 영상 프레임이 확인되는 즉시 준비 화면 제거
- QR 판독기 초기화와 카메라 미리보기 표시를 분리
- ZXing 내부 영상 재생 대기에 의존하지 않고 직접 프레임을 판독하도록 변경
- 카메라 준비 이벤트가 누락되는 브라우저를 위해 0.1초 간격 상태 확인 추가
- 8초 안에 영상이 시작되지 않으면 무한대기 대신 원인 안내 표시
- Supabase SQL 및 출·퇴근 토큰 처리 규칙 변경 없음
