# v52.48.5.44.60 적용방법

현재 v52.48.5.44.59 적용 상태의 프로젝트 최상위에서 실행합니다.

```powershell
node .\release_v52.48.5.44.60\apply-v52.48.5.44.60-guide-image-stage.cjs
npm run build
git add .
git commit -m "v52.48.5.44.60 가이드 이미지/주석 stage 일치 보정"
git push origin main
```

`main` Push와 Vercel Production이 자동 연동되어 있으면 자동배포를 확인합니다.
자동배포가 시작되지 않을 때만 아래를 추가 실행합니다.

```powershell
npx vercel --prod
```

추가 Supabase SQL은 없습니다.
