# v52.48.5.44.60 변경내용

## 가이드 편집/표시 불일치 원인 수정

기존 .59까지는 번호 원/설명박스의 확대비율 자체는 이미지 폭에 맞추었지만, 실제 미리보기/공개 가이드에서 **주석이 배치되는 stage 박스의 크기와 실제로 렌더링된 이미지의 크기가 서로 달라질 수 있었습니다.**

특히 원본 이미지가 `maxHeight` 또는 부모 컨테이너 폭에 의해 축소되면 이미지 자체는 작아지는데 stage는 원본/최대 콘텐츠 폭을 유지할 수 있어, 같은 퍼센트 좌표를 사용해도 표시 위치와 크기가 편집화면과 달라졌습니다.

### 수정
- `GuideAnnotatedImage.jsx`
  - 원본 이미지 비율 + 실제 사용 가능한 폭 + maxHeight를 기준으로 표시 폭/높이를 직접 계산
  - 주석 stage의 폭/높이를 계산된 **실제 이미지 표시 크기와 완전히 동일하게 고정**
  - 번호/박스/설명박스의 퍼센트 좌표가 실제 이미지 영역을 기준으로 적용
- `systemGuidePopup.js`
  - 공개 가이드에서도 동일하게 원본 크기/가용 폭/최대 높이로 이미지 실표시 크기를 계산
  - stage와 이미지 크기를 1:1로 맞춘 후 주석 비율 계산

기존에 저장한 좌표, 번호, 점선박스, 동그라미, 화살표, 설명박스 데이터는 변경하지 않습니다.
