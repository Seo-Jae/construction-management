# v52.48.5.19 변경내용

## 상단 영역

- `현재 현장` 표시 옆에 붙어 있던 실행 아이콘을 화면 최우측에 고정했습니다.
- 새 작성, 저장, 출력/PDF, Excel, 새로고침 순서는 그대로 유지했습니다.

## 규격 선택 영역

- 대분류, 중분류, 세부규격, 문서명, 저장상태의 글자 크기와 박스 높이를 줄였습니다.
- 각 선택값은 좁은 박스 안에서 말줄임 처리할 수 있도록 구성했습니다.
- 내부 여백과 항목 사이 간격도 함께 축소했습니다.

## 구성표 작업 바

- `1㎡당 구성 항목` 제목과 기존 개수 칩을 제거했습니다.
- `노임관리 > 공정별 노임작성`과 동일한 바 형태로 변경했습니다.
- 바의 좌측에 추가, 삭제, 위로 이동, 아래로 이동 아이콘을 배치했습니다.
- 구분선 다음에 현재 선택된 항목 개수를 표시합니다.
- `자재 마스터에서 추가`는 기존 기능 유지를 위해 바 우측에 배치했습니다.
- `구분`, `품명`, `규격` 표 머리글을 가운데 정렬했습니다.

## 데이터 영향

- 데이터베이스, 계산식, 저장 형식은 변경하지 않았습니다.
- SQL 실행이 필요하지 않습니다.
