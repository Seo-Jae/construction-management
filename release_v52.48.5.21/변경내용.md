# v52.48.5.21 변경내용

## 구성표

- 단위 입력값을 가운데 정렬했습니다.
- 정미금액과 제출금액의 우측에 여백을 추가해 셀 경계선에 붙지 않게 했습니다.
- 단가 입력값에 천 단위 쉼표가 즉시 표시됩니다.
- 단가는 화면에 `1,150`처럼 표시되지만 저장과 계산에는 기존처럼 숫자값을 사용합니다.

## 노무비 단위

- 추가 버튼으로 만든 항목의 구분을 `노무비`로 변경하면 단위가 자동으로 `인`으로 입력됩니다.
- 노무비에서 재료비로 다시 변경하고 단위가 `인`인 경우 `M`으로 복원됩니다.
- 기준정보의 규격별 기본 구성값에서도 같은 규칙을 적용합니다.

## 금액 요약

- 재료비·노무비·경비별 정미와 제출 항목 사이에 고정 간격을 적용했습니다.
- 금액을 우측 정렬하고 글자 크기를 줄였습니다.
- 하단 총 일위대가의 정미·제출 금액도 동일한 열 구조로 정리했습니다.
- 과도하게 크던 제출 합계 글자 크기를 축소했습니다.

## 데이터 영향

- 데이터베이스와 저장 형식은 변경하지 않았습니다.
- SQL 실행이 필요하지 않습니다.
