# v52.48.5.44.46 변경내용

## 1. 시스템 가이드 메뉴 기본 구조
좌측 시스템 메뉴 하단에 `가이드`를 추가했습니다. 가이드 화면은 실제 시스템의 현재 메뉴 구성을 기준으로 동일한 대분류/하위 메뉴 구조를 제공합니다.

현재 가이드 내용은 아직 작성하지 않았으므로 모든 항목을 `준비중`으로 표시합니다. 이후 메뉴별 가이드를 완성할 때 해당 항목만 완료 상태와 실제 설명 콘텐츠로 전환할 수 있도록 분리했습니다.

## 2. 실제 기능 준비중 메뉴 구분
가이드 작성 상태와 실제 시스템 기능 상태를 혼동하지 않도록, 현재 Sidebar에서 비활성화된 아래 메뉴는 `기능 준비중` 배지도 함께 표시합니다.

- 자재관리 > 자재발주작성
- 기성관리 > 매입매출현황
- 노임관리 > 노임서류작성
- 업무 보고 관리 > 외주 품의 보고
- 업무 보고 관리 > 사고 경위 보고

## 3. 향후 가이드 확장 구조
가이드 화면 우측은 각 메뉴별로 다음 내용을 순차적으로 넣을 수 있게 구성했습니다.

- 화면 목적
- 사용 순서
- 클릭 위치 및 버튼 설명
- 입력/수정 방법
- 주의사항
