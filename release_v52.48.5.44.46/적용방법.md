# 적용 및 운영 배포

프로젝트 최상위 폴더에 `release_v52.48.5.44.46` 폴더를 넣고 PowerShell에서 아래 명령을 순서대로 실행합니다.

```powershell
node .\release_v52.48.5.44.46\apply-v52.48.5.44.46-guide-menu.cjs
npm run build
git add .
git commit -m "v52.48.5.44.46 시스템 가이드 메뉴 기본 구조 추가"
git push origin main
```

`main` 브랜치가 Vercel Production에 연결되어 있으면 마지막 push 후 운영 배포가 자동 진행됩니다.

## 적용 후 확인
1. 좌측 메뉴 최하단에 `가이드`가 표시되는지 확인합니다.
2. 가이드 진입 후 실제 시스템 메뉴 구조가 가이드 메뉴에 동일하게 표시되는지 확인합니다.
3. 모든 미작성 가이드가 `준비중`으로 표시되는지 확인합니다.
4. 실제 기능 준비중 메뉴에는 `기능 준비중` 배지가 함께 표시되는지 확인합니다.
