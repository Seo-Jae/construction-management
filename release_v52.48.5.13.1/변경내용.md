# v52.48.5.13.1 변경내용

## 적용 스크립트 보완

- Windows에서 체크아웃된 `CRLF` 줄바꿈과 배포파일의 `LF` 줄바꿈을 같은 코드로 인식합니다.
- 줄바꿈 외에 실제 코드 내용이 달라진 경우에는 기존처럼 자동 적용을 중단하여 사용자 변경을 보호합니다.

## 완료 세대 작업자 표시

- `공정별 현황 입력` 골구도의 파란 완료 세대에 마우스 커서를 올리면 해당 동·층·호와 작업자명이 표시됩니다.
- 예: `104동 701호` / `작업자: A`
- 공동작업이면 그 세대를 실제로 제출한 작업자만 쉼표로 함께 표시됩니다.
- 다른 세대나 화면 전체에 작업자명이 계속 노출되지 않고, 확인하려는 세대에서만 표시됩니다.
- 휴대폰·태블릿에서는 완료 세대를 터치하여 확인할 수 있습니다.

## 승인자료 연결 규칙

- v52.48.5.13.1 적용 이후 최종승인부터 세대별 참여 작업자 ID와 이름을 함께 저장합니다.
- v52.48.5.12에서 이미 공동승인한 자료도 승인 원본이 남아 있고 현재 완료일과 일치하면 SQL 실행 시 자동 연결합니다.
- 이전 버전에서 승인 원본이 남지 않은 오래된 완료 세대와 관리자가 직접 입력한 세대에는 작업자명이 표시되지 않습니다.
- 관리자가 골구도에서 상태를 직접 변경하면 이전 근태 작업자 연결정보를 제거하여 잘못된 이름이 남지 않게 합니다.
- 테스트계정 근태 초기화 시 해당 작업자명도 공동작업 원본에 맞게 다시 계산합니다.
