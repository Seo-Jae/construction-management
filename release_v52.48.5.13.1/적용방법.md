# v52.48.5.13.1 적용방법

적용 기준은 `v52.48.5.12`입니다.

## 1. Supabase SQL 먼저 실행

Supabase SQL Editor에서 아래 파일의 전체 내용을 실행합니다.

`Supabase에서_실행/00_v52.48.5.13_완료세대_작업자표시.sql`

SQL은 `unit_progress`에 작업자 표시용 열을 추가하고, 신규 승인 RPC와 기존 공동승인 자료 자동 연결을 생성합니다.

## 2. 코드 적용

프로젝트 최상위 폴더에서 압축을 해제한 뒤 PowerShell에서 실행합니다.

```powershell
node .\release_v52.48.5.13.1\apply-v52.48.5.13.1-completion-workers.cjs
npm run build
git add src/BuildingGrid.jsx src/Dashboard.jsx src/page/AttendanceManagement.jsx
git status
git commit -m "v52.48.5.13.1 show completion workers"
git push origin main
```

적용 스크립트는 Windows `CRLF`와 배포파일의 `LF` 줄바꿈 차이를 허용한 상태에서 기존 파일이 `v52.48.5.12`인지 검사합니다. 실제 코드 내용이 다르면 자동으로 덮어쓰지 않습니다. 적용 전 원본은 프로젝트의 백업 폴더에 저장되며, 같은 스크립트를 다시 실행해도 중복 수정되지 않습니다.

## 3. 확인 방법

1. 작업자가 퇴근 진척 세대를 제출합니다.
2. 담당자가 근태관리에서 최종승인을 합니다.
3. `공정별 현황 입력`에서 동일 공정을 선택합니다.
4. 파란 완료 세대에 마우스 커서를 올립니다.
5. 정확한 동·층·호와 `작업자: 이름`이 나타나는지 확인합니다.
6. 공동작업 세대에는 해당 세대를 제출한 작업자들이 함께 나오는지 확인합니다.

앱 재설치는 필요하지 않습니다. 배포 후 브라우저 새로고침 또는 앱 종료 후 재실행으로 적용됩니다.
