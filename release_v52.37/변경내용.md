# v52.37 변경내용

## Excel 생성 준비

월별 노임작성 상단에 `Excel 생성 준비` 버튼을 추가합니다.

저장되지 않은 변경이 있으면 먼저 저장하도록 안내합니다.

## 서버 사전검증

신규 RPC:
`labor_monthly_export_readiness_v52_37`

검사:
- 주민/외국인번호 등록여부
- 전체 연락처 등록여부
- 주소 등록여부
- 계좌번호 등록여부
- 은행 등록여부
- 월별 공종
- 일급
- 출역

## 보안

근로자 보호정보 암호문을 복호화하지 않습니다.

기존 안전 상태값만 사용합니다:
- has_resident_no
- has_foreign_no
- has_private_phone
- has_address
- has_account
- bank_name_hint

반환하지 않는 값:
- 주민등록번호 원문
- 외국인등록번호 원문
- 전체 전화번호
- 주소 원문
- 계좌번호 원문

## 결과창

표시:
- 전체 근로자
- 준비 완료
- 보완 필요
- 총 누락항목

근로자별:
- 순번
- 성명
- 생년월일
- 휴대폰 뒤4자리
- 보완 필요 항목

`준비 완료`는 실제 다운로드 가능 상태가 아니라
회사 Excel 셀 매핑을 시작할 기본 데이터가 준비됐다는 의미입니다.
