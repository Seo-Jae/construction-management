# v52.37 적용방법

## 1. Supabase SQL 먼저 실행

Supabase SQL Editor에서:

`release_v52.37/Supabase에서_실행/00_v52.37_노임Excel_생성사전검증.sql`

필수 선행:
- v52.34 근로자 보호정보
- v52.35 월별 명단
- v52.36 출역/노임값

## 2. 프로그램 적용

```powershell
node .\release_v52.37\apply-v52.37-labor-excel-readiness.cjs
npm run build
```

## 3. Git

```powershell
git add src/page/MonthlyLaborManagement.jsx
git status
git commit -m "v52.37 add labor excel readiness check"
git push origin main
```

`git add .`은 사용하지 않습니다.

## 4. 확인

`노임관리 > 월별 노임작성`

1. 해당 월 명단 저장
2. `Excel 생성 준비` 클릭
3. 전체/준비완료/보완필요/누락항목 확인
4. 근로자별 보완 항목 확인

검사항목:
- 주민등록번호 또는 외국인등록번호 등록여부
- 전체 연락처
- 주소
- 계좌번호
- 은행
- 공종
- 일급
- 출역

## 보안
