# v52.48.5.44.84 건의·오류 제보 V1

## 사용자 기능
- 상단 `가이드` 옆에 `건의·오류` 상시 버튼 추가
- 어느 메뉴에서든 바로 제보 팝업 실행
- 구분: 오류/버그, 기능개선, 사용문의, 기타
- 제목 / 내용 / 이미지·파일 첨부
- 최대 첨부 5개, 파일당 10MB
- 현재 현장, 현재 메뉴, 작성자, 화면배율, 브라우저 환경 자동 기록
- 사이드 메뉴 `건의·오류 제보`
- 본인이 등록한 제보와 처리상태, 관리자 답변, 반영 버전 확인

## 최고관리자 기능
- 사이드 메뉴는 `건의·오류 관리`로 표시
- `전체 제보 관리` / `내 제보` 탭
- 전체 현장 제보 검색
- 구분/상태 필터
- 처리상태: 접수 / 확인중 / 반영예정 / 처리완료 / 보류
- 관리자 답변
- 반영 예정 버전 / 처리 완료 버전 기록
- 비공개 첨부파일 열람

## DB
- `public.system_feedback` 신규 테이블
- RLS:
  - 일반 사용자: 본인 제보만 조회, 본인 계정으로 신규 등록
  - 최고관리자: 전체 조회·수정·삭제
- `feedback-attachments` private Storage bucket
- 첨부파일은 사용자 UID 폴더 아래 저장
- 일반 사용자는 자기 첨부만, 최고관리자는 전체 첨부 열람
