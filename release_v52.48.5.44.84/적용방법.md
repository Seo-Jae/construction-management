# 적용방법

1. 프로젝트 최상위에서 패치 적용

```powershell
node .\release_v52.48.5.44.84\apply-v52.48.5.44.84-system-feedback-v1.cjs
```

2. Supabase SQL Editor에서 아래 파일 전체 실행

```text
supabase/v52.48.5.44.84_system_feedback.sql
```

정상 실행 후 마지막 검증값 3개가 모두 `true`인지 확인합니다.

3. 빌드 및 운영 반영

```powershell
npm run build
git add .
git commit -m "v52.48.5.44.84 건의 오류 제보 V1"
git push origin main
```

GitHub main push 후 Vercel 자동배포가 시작되면 별도 수동 배포는 필요 없습니다.
