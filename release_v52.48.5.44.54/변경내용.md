# v52.48.5.44.54 변경내용

## 가이드 팝업
- 좌측 목차의 현재 위치 표시 로직을 개선했습니다.
  - 기존 IntersectionObserver 방식에서 실제 스크롤 기준선 방식으로 변경했습니다.
  - `2. 출력일보 작성` 영역을 보고 있을 때 `1. 화면 구성`이 계속 선택되는 문제를 수정했습니다.
- 팝업 바깥/카드 사이의 배경을 상단 `시스템 가이드` 영역과 동일한 네이비(`#0f172a`)로 통일했습니다.
- 좌측 목차 글씨 크기를 키우고 행간과 번호 영역을 확대했습니다.
- 목차 항목의 수동 줄바꿈을 그대로 표시합니다.
- 상세 가이드의 간단 안내 문구와 이미지 하단 대표 안내 문구 글씨를 크게 조정했습니다.
  - 섹션 제목보다는 작지만 한눈에 읽을 수 있는 크기로 조정했습니다.
- 한눈에 보기의 화면 제목도 수동 줄바꿈을 반영합니다.

## 가이드 설정
- `화면/순서 제목`을 1~3줄 입력 가능한 형태로 변경했습니다.
- `Shift + Enter`로 줄바꿈할 수 있습니다.
- 일반 Enter는 실수로 줄바꿈되지 않도록 막고, Shift+Enter만 줄바꿈으로 사용합니다.

## DB
- 추가 Supabase SQL 없음.
- 기존 가이드 JSON 구조를 그대로 사용합니다.
