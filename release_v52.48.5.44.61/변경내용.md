# v52.48.5.44.61 변경내용

## 공정진척관리 > 공종별 현황 입력 > 타입별 세대 현황

- 패널이 이전에 저장된 좌측 위치로 계속 로딩되던 문제를 수정했습니다.
- 위치 저장 키를 `type-summary-panel-v4`로 변경하여 기존 잘못된 v3 좌표를 자동으로 무시합니다.
- 신규 기본 위치는 상단 우측 목표설정 영역의 `펼치기/최소화` 버튼을 기준으로 잡습니다.
  - 패널 오른쪽 끝 = 펼치기/최소화 버튼 오른쪽 끝
  - 패널 상단 = 버튼 하단 + 8px
- 화면 크기가 변해도 기본 도킹 상태에서는 해당 버튼 하단 위치를 다시 따라갑니다.
- 패널을 사용자가 직접 드래그하면 자동 도킹이 해제되고, 이후에는 사용자가 옮긴 위치를 저장합니다.
- 수동 이동 시 우측 제한을 화면 끝 4px까지 완화하여 우측으로 더 이상 움직이지 못하던 체감을 개선했습니다.
