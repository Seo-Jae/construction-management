v52.48.5.31 - 일위대가 기술자료 이미지 "새 창 보기"

[기준]
- v52.48.5.30이 정상 적용된 상태에서만 사용합니다.
- 과거 기능을 되돌리거나 다른 기능을 덮어쓰지 않습니다.
- 대상 파일: src/page/UnitPriceAnalysis.jsx 1개
- Supabase SQL 변경 없음

[변경]
1. 기술자료 이미지 클릭 시 현재 화면 위 Dialog를 띄우지 않습니다.
2. 실제 별도 브라우저 창(window.open)에서 기술자료를 크게 표시합니다.
3. 기술자료 창을 열어둔 채 기존 일위대가 작성 화면을 계속 보고 수정할 수 있습니다.
4. 기술자료 창에는 "화면 맞춤" / "원본 크기" 기능을 제공합니다.
5. 이미지 업로드·교체·삭제 권한은 v52.48.5.29 기준을 그대로 유지합니다.
   - 최고관리자: 항상 관리 가능
   - 최고관리자가 권한을 부여한 사용자: 관리 가능
   - 그 외 사용자: 이미지 조회만 가능, 업로드 UI 미표시

[적용]
new 폴더에서:
node release_v52.48.5.31/apply-v52.48.5.31-technical-image-new-window.cjs

그 다음:
npm.cmd run build
npm.cmd run dev

[주의]
- 브라우저에서 팝업이 차단되면 화면 하단 안내가 표시됩니다.
  해당 사이트의 팝업을 허용한 뒤 다시 이미지를 클릭하면 됩니다.
- 적용 스크립트는 예상 코드가 다르면 아무 파일도 수정하지 않고 중단합니다.
- 실제 수정 직전 기존 UnitPriceAnalysis.jsx를 backup_v52.48.5.31_... 폴더에 자동 백업합니다.
