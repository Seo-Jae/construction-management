## Chrome URL 복사 알림
저장소에서 `navigator.clipboard`, `writeText`, `clipboard` 호출을 검색했으나
작업자 앱 실행 시 URL을 자동 복사하는 코드는 발견되지 않았습니다.

Chromium의 WebappActionsNotificationManager는 standalone Web App 실행 중
Chrome 자체 알림을 만들며, 알림을 탭하는 경우 Chrome이 URL을 복사합니다.
따라서 웹페이지 JavaScript에서 해당 Chrome 시스템 알림 자체를 강제로
취소하는 방식은 사용하지 않습니다.

대신 Android 설치 흐름을 `앱 설치`로 통일하여
홈 화면 바로가기형 설치를 피하도록 수정합니다.
