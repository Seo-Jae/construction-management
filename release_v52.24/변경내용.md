# v52.24 변경내용

## 공지사항 관리
기존:
- 순번: `fontWeight: 900`
- 공지내용: `fontWeight: 700`
- 공지내용: 별도 `0.76rem`

변경:
- 순번: `fontWeight: 400`
- 공지내용: `fontWeight: 400`
- `fontFamily: inherit`
- 공지내용 `fontSize: inherit`

따라서 다른 일반 표 데이터와 같은 글꼴/두께/크기 계열로 표시됩니다.

## 공통 글씨체
전역 `theme.js`의 UI_FONT_FAMILY 설정은 변경하지 않습니다.
기존 통일 폰트 설정을 그대로 사용합니다.

## 작업자 Android 설치
기존 도움말:
- `앱 설치` 또는 `홈 화면에 추가`

변경:
- Android는 `앱 설치`만 안내
- `홈 화면에 추가`는 사용하지 않도록 안내
- 기존 바로가기 설치폰은 제거 후 재설치 안내

## 티커 속도
v52.23의 1.4배 속도를 누적 보장합니다.
이미 v52.23이 적용되어 있으면 그대로 유지합니다.

## DB
SQL 변경 없음.
