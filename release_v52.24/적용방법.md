# v52.24 적용방법

## 변경내용
1. 공지사항 관리 목록의 `순번`과 `공지내용`을 일반 글씨로 변경
2. 공지 행 글꼴을 기존 통일 UI 글꼴에 명시적으로 상속
3. 공지내용 크기도 표의 다른 셀과 동일하게 상속
4. v52.23 티커 1.4배 속도가 아직 적용되지 않은 경우 함께 누적 적용
5. Android 작업자 앱 설치 안내를 `앱 설치` 방식으로 통일

## SQL
SQL 변경 없음.

```powershell
node .\release_v52.24\apply-v52.24-notice-font-android-install.cjs
```

## Git

실제 프로그램 변경 파일은 2개입니다.

```powershell
git add src/page/AttendanceManagement.jsx
git add src/page/AttendanceWorkerPortal.jsx
git status
git commit -m "v52.24 normalize notice font and android install"
git push origin main
```

`git add .`은 사용하지 않습니다.

## Android URL 복사 알림 — 기존 설치폰

Chrome의 “이 앱의 URL 복사하기” 알림은 웹사이트가 만든 알림이 아니라
Chrome이 홈 화면 바로가기형 standalone 웹앱에 표시하는 시스템 알림입니다.

기존 설치폰은 다음을 1회 수행합니다.

1. 기존 `욱림건설 근태시스템` 홈 화면 아이콘 제거
2. Chrome에서 작업자 앱 URL 접속
3. 화면의 `근태앱 설치` 또는 Chrome 메뉴의 `앱 설치` 선택
4. Android에서는 `홈 화면에 추가` 방식은 사용하지 않음
5. 새로 설치한 앱 실행 후 Chrome URL 복사 알림 여부 확인

단순 홈 화면 바로가기 대신 브라우저의 정식 앱 설치 흐름을 사용해야 합니다.
