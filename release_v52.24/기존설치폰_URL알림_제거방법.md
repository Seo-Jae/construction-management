# 기존 설치폰의 Chrome URL 복사 알림

증상 예:
- `욱림건설 근태시스템`
- `탭하여 이 앱의 URL 복사하기`

이 문구는 작업자 앱의 자체 알림이 아니라 Chrome이 표시하는 Web App 시스템 알림입니다.

## 기존 폰 처리
1. 현재 홈 화면의 `욱림건설 근태시스템` 아이콘을 제거합니다.
2. Chrome에서 작업자 앱 주소로 접속합니다.
3. 화면 하단의 `근태앱 설치`를 누릅니다.
4. Chrome 설치창이 뜨면 설치합니다.
5. 메뉴를 직접 사용하는 경우 `앱 설치`를 선택합니다.
6. Android에서는 `홈 화면에 추가` 방식은 사용하지 않습니다.

## 참고
Chrome/기기 설치 방식에 따라 설치 결과가 달라질 수 있습니다.
브라우저 자체 시스템 알림은 웹페이지 코드에서 임의로 끌 수 없습니다.
