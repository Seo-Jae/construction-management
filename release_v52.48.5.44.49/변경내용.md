# v52.48.5.44.49 변경내용

## 가이드 표시 방식 수정
- 1·2·3 각 표시의 안내 제목/상세 설명을 이미지 아래 카드 목록으로 반복 노출하지 않습니다.
- 각 표시의 안내 문구는 실제 화면 이미지 위의 `설명박스`로 표시합니다.
- 설명박스는 표시 도형/번호와 별도로 드래그하여 원하는 위치에 배치할 수 있습니다.
- `이미지 하단 설명`은 `하단 대표 안내 문구`로 변경했습니다. 화면 전체를 대표하는 짧은 문구만 입력합니다.

## 번호 위치 자유 이동
- 동그라미/점선박스/설명 화살표의 번호 원을 도형과 별도로 드래그할 수 있습니다.
- 예: 기존 우측에 붙어 있던 2번 번호를 왼쪽으로 이동해 3번과 자연스럽게 연결할 수 있습니다.

## 번호 연결 화살표
- 기존 `설명 화살표`와 별개로 `번호 연결 화살표`를 추가했습니다.
- 시작 번호 원 → 도착 번호 원을 차례로 클릭하면 두 번호 중심을 정확하게 연결합니다.
- 연결 화살표 자체에는 번호가 추가되지 않습니다.
- 번호 원을 이동하면 연결 화살표의 시작/도착점도 자동으로 따라갑니다.
- 선택 후 우측에서 시작 번호/도착 번호를 변경할 수 있습니다.

## 선 두께
- 동그라미, 점선박스, 설명 화살표, 번호 연결 화살표에 `선 두께(1~10)` 설정을 추가했습니다.
- 기본보다 굵게 만들어 실제 화면에서 강조 표시가 눈에 잘 띄도록 조정할 수 있습니다.

## 데이터
- 기존 v52.48.5.44.48에 저장된 가이드 데이터는 그대로 사용합니다.
- 기존 표시의 번호/설명은 자동 보정되어 화면 내 설명박스로 표시됩니다.
- 추가 Supabase SQL은 없습니다.
