# v52.48.5.44.49 적용방법

기준 버전: `v52.48.5.44.48`

프로젝트 최상위 폴더에 `release_v52.48.5.44.49` 폴더를 넣고 PowerShell에서 실행합니다.

```powershell
node .\release_v52.48.5.44.49\apply-v52.48.5.44.49-guide-callouts-connectors.cjs
npm run build
git add .
git commit -m "v52.48.5.44.49 가이드 설명박스 및 연결 화살표 개선"
git push origin main
```

`main` 브랜치가 Vercel Production에 연결되어 있으므로 push 후 자동 운영 배포를 확인합니다.

자동 배포가 시작되지 않을 때만 다음을 별도로 실행합니다.

```powershell
npx vercel --prod
```
