# 지출결의서 작성 v51.92 적용방법

## 적용 기준

- 기준 버전: v51.91
- v51.91의 좌우 폭 조절과 동적 미리보기 열을 유지합니다.
- v51.90의 엑셀 날짜 형식과 상세내역 색상 수정을 유지합니다.
- 통행료 도착시간, 유류비 분리, 셀 직접수정을 추가합니다.
- DB 변경은 없으므로 Supabase SQL을 실행하지 않습니다.

## 1. 압축 해제

ZIP 파일을 프로젝트 최상위 폴더에 압축 해제합니다.

```text
C:\Users\서재형\Desktop\new
├─ package.json
├─ src
├─ public
└─ release_v51.92
```

## 2. 소스 적용

PowerShell에서 프로젝트 최상위 폴더로 이동한 후 실행합니다.

```powershell
node .\release_v51.92\apply-v51.92-expense-resolution.cjs
```

적용 파일:

- `src/page/ExpenseResolution.jsx`
- `src/utils/expenseResolutionExcel.js`
- `src/utils/highpassReceiptPdf.js`

기존 대상 파일은 적용 전에 자동 백업됩니다. `pdfjs-dist`가 없다면 `5.7.284` 버전을 `--legacy-peer-deps` 옵션으로 자동 설치합니다.

## 3. 빌드 확인

```powershell
npm run build
```

`Some chunks are larger than 500 kB`는 용량 경고입니다. 마지막에 `built in`이 표시되면 정상입니다.

`@mui/material`을 찾지 못한다는 오류가 발생하면 아래 명령을 먼저 실행합니다.

```powershell
npm install @mui/material @mui/icons-material @emotion/react @emotion/styled --legacy-peer-deps
npm run build
```

## 4. 화면 확인

1. `업무보고관리 > 지출결의서 작성`에서 신규 문서를 엽니다.
2. 통행료 PDF 업로드 창에서 출발지·km·유류비를 일괄 입력합니다.
3. 갑지 유류대 내용칸에 `서울→용인 59km`가 표시되는지 확인합니다.
4. 갑지 통행료 내용칸에 `용인 14:00`이 표시되는지 확인합니다.
5. 유류비와 통행료 금액이 각각의 금액칸에 표시되는지 확인합니다.
6. 좌측 사용내역에서 각 입력 셀을 바로 수정할 수 있는지 확인합니다.
7. 가운데 조절선과 동적 열 표시가 유지되는지 확인합니다.
8. 엑셀 다운로드 후 같은 내용·금액 구분, 날짜 형식, 상세내역 색상을 확인합니다.

## 저장 및 DB

- 이동거리(km)와 PDF 행의 유류비는 기존 `description` 필드에 호환 형식으로 저장합니다.
- 기존에 숫자 km만 저장된 문서도 그대로 불러옵니다.
- 새로운 DB 컬럼이나 Supabase SQL은 없습니다.
