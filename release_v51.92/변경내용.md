# 지출결의서 작성 v51.92 변경내용

## 1. 통행료 내용에 도착시간 표시

- PDF에서 읽은 도착영업소를 정리해 `용인 14:00` 형식으로 표시합니다.
- 갑지와 엑셀 모두 통행료 내용칸에 도착지와 도착시간을 표시합니다.
- 유류대 내용칸의 `서울→용인 59km` 표시는 그대로 유지합니다.

## 2. 유류비와 통행료 금액 분리

- 갑지 미리보기의 금액 머리글을 `금액(유류비)`와 `금액(통행료)`로 구분합니다.
- PDF 업로드 창에서 유류비를 건별로 입력할 수 있습니다.
- 출발지·km와 함께 유류비도 선택 항목에 일괄 적용할 수 있습니다.
- PDF 한 건은 목록에서 한 행만 사용하며 유류비와 통행료를 함께 보관합니다.
- 합계와 엑셀 다운로드에는 유류비와 통행료가 모두 반영됩니다.

## 3. 사용내역 셀 직접수정

- 행 클릭이나 수정 팝업 없이 사용일·항목·사용내용·금액을 표 안에서 바로 수정합니다.
- 이동 항목은 출발지·도착지·km·도착시간을 각각 직접 수정합니다.
- 통행료 행은 유류비와 통행료를 각각 직접 수정합니다.
- 삭제만 아이콘으로 유지합니다.

## 4. 기존 기능 유지

- v51.91 좌우 폭 조절 및 동적 미리보기 열 유지
- v51.90 엑셀 날짜 `yyyy-mm-dd aaa` 및 상세내역 RGB 색상 유지
- 예전의 km 저장 자료와 호환
- 새 DB 컬럼 및 Supabase SQL 없음
