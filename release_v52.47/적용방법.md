# v52.47 적용방법

## 이번 단계

기존에 Excel로 관리하던 회사 근로자 자료를
`근로자 정보관리`에 이관할 수 있게 합니다.

업로드가 끝나면 데이터는 기존 `labor_worker_master`에 들어가므로
`월별 노임작성 > 근로자 조회`에서 바로 사용할 수 있습니다.

## 1. Supabase SQL 먼저

SQL Editor에서:

`release_v52.47/Supabase에서_실행/00_v52.47_근로자Excel_AH_이관.sql`

전체 실행합니다.

## 2. 프로그램 적용

```powershell
node .\release_v52.47\apply-v52.47-worker-excel-import.cjs
npm run build
```

## 3. 화면

`노임관리 > 근로자 정보관리`

상단에:
- EXCEL 업로드
- 근로자 등록

두 버튼이 표시됩니다.

`EXCEL 업로드`를 누르고 회사 노무비명세서 Excel을 선택합니다.

## 4. 업로드 흐름

1. 파일 선택
2. 브라우저에서 A:H만 분석
3. 서버 사전검증
4. 신규 / 기존 업데이트 / 보완 필요 / 충돌 분류
5. 외국인은 국적 선택
6. 필요없는 행은 `제외됨`으로 전환 가능
7. `최종 등록`
8. 암호화 근로자 마스터 저장
9. 월별 노임작성 근로자 조회에서 즉시 사용

## 5. 기존 근로자 중복처리

주민번호/등록번호 13자리를 그대로 DB 검색키로 저장하지 않습니다.

기존 암호화 비밀키를 이용한 SHA-256 fingerprint만 별도 저장해
동일인 여부를 판단합니다.

- fingerprint 동일 + 성명 동일 → 기존 정보 업데이트
- fingerprint 동일 + 성명 다름 → 충돌, 자동등록 차단
- fingerprint 없음 → 신규 등록

## 6. 외국인

A:H에는 `외국인` 여부와 체류자격은 있지만 정확한 국적은 없습니다.

따라서 외국인 행은 미리보기에서 국적을 선택해야 최종 등록할 수 있습니다.

외국인 필수 추가정보:
- 영문 성명
- 체류자격

영문 예금주는 선택정보입니다.

## 7. I:AV

시스템은 업로드 시에도 I:AV를 읽지 않습니다.

향후 SENS 인증 후 Excel 다운로드를 만들 때도
시스템 작성범위는 A:H로 한정하고 I:AV는 원본 양식을 그대로 유지하는 방향입니다.
