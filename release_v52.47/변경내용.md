# v52.47 변경내용

## 1. 회사 Excel 이관

회사 노무비명세서의 A:H를 근로자 정보관리로 가져옵니다.

원본 Excel 파일 자체를 Supabase Storage에 올리지 않습니다.
브라우저에서 읽은 뒤 구조화된 근로자 정보만 보안 RPC로 전달합니다.

## 2. 미리보기

바로 DB에 저장하지 않습니다.

상태:
- 신규 등록
- 기존 업데이트
- 보완 필요
- 충돌

을 먼저 확인합니다.

## 3. 외국인

회사 Excel에서 새로 확보되는 필드:
- 영문 성명
- 체류자격
- 영문 예금주

세 필드는 기존 `labor_worker_private` 암호화 payload에 저장합니다.

국적은 A:H에 없으므로 외국인만 미리보기에서 선택합니다.

## 4. 주민번호 중복검사

주민번호 원문을 평문 검색컬럼으로 만들지 않습니다.

Vault 비밀키 + 주민번호로 keyed fingerprint를 만들어
`labor_worker_master.identity_fingerprint`에 저장합니다.

이를 이용해 과거 Excel을 여러 번 업로드해도 동일 근로자를 중복 생성하지 않습니다.

## 5. 생년월일

Excel에는 별도 생년월일 열이 없으므로 13자리 주민번호/등록번호에서 서버가 생년월일을 계산합니다.

7번째 코드:
- 1/2/5/6 → 1900년대
- 3/4/7/8 → 2000년대
- 9/0 → 1800년대

형식이 잘못되면 `보완 필요`로 처리합니다.

## 6. 월별 노임작성 연결

별도의 복사 작업이 없습니다.

최종 등록은 기존 근로자 마스터에 저장되므로 월별 노임작성 `근로자 조회`가 동일 테이블을 즉시 조회합니다.
