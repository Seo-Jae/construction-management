# 욱림건설 노무비명세서 A:H 매핑

업로드 기준 파일: `노무비명세서양식(업로드용).xlsx`

근로자 1명은 2개 행을 사용합니다.

| Excel | 시스템 저장 |
|---|---|
| A 첫행 | 순서 - 업로드 식별용 |
| B 첫행 | 최근 공종 |
| C 첫행 | 성명 |
| C 둘째행 | 영문 성명(외국인용) |
| D 첫행 | 내국인 / 외국인 |
| D 둘째행 | 체류자격 |
| E 첫행 | 주민등록번호/등록번호 13자리 |
| E 둘째행 | 전체 휴대폰번호 |
| F 첫행 | 은행명 |
| G 첫행 | 예금주 |
| G 둘째행 | 영문 예금주 |
| H 첫행 | 계좌번호 |

`I:AV`는 시스템에서 읽지 않고 담당자가 다운로드 후 직접 작성하는 영역으로 유지합니다.

## 국적

회사 양식 A:H에는 외국인의 정확한 국가가 없습니다.

따라서:
- 내국인 → 자동 `대한민국`
- 외국인 → 업로드 미리보기에서 국적 선택

으로 처리합니다.
