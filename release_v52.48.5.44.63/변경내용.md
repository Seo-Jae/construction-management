# v52.48.5.44.63 변경내용

## 가이드 표시 편집 - 번호 없는 설명박스
- 상단 도구에 `▤ 설명박스`를 추가했습니다.
- 설명박스는 번호 원을 생성하지 않습니다.
- 도구 선택 후 이미지의 원하는 위치를 한 번 클릭하면 설명박스가 생성됩니다.
- 생성된 설명박스는 직접 드래그하여 이동할 수 있습니다.
- 우측 설정에서 박스 색상, 설명 제목, 상세 설명, X/Y 위치를 수정할 수 있습니다.
- 번호 재정렬 시 설명박스는 번호 순서에 포함되지 않습니다.
- 번호 연결 화살표의 시작/도착 번호 선택 대상에도 포함되지 않습니다.
- 가이드 설정 미리보기와 실제 사용자 가이드에서도 번호 없이 동일한 설명박스로 표시됩니다.
- 기존 번호/점선박스/화살표/설명 데이터에는 변경이 없습니다.
- Supabase SQL 변경은 없습니다.
