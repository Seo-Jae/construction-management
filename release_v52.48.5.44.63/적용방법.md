# v52.48.5.44.63 적용방법

프로젝트 최상위 폴더에서 실행합니다.

```powershell
node .\release_v52.48.5.44.63\apply-v52.48.5.44.63-guide-note-box.cjs
npm run build
git add .
git commit -m "v52.48.5.44.63 가이드 번호 없는 설명박스 추가"
git push origin main
```

`main` push가 Vercel Production 자동배포로 연결되어 있으면 자동 배포를 확인합니다.
자동배포가 시작되지 않을 때만 아래를 실행합니다.

```powershell
npx vercel --prod
```
