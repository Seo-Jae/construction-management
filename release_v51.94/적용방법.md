# 지출결의서 작성 v51.94 적용방법

## 적용 순서

1. 받은 ZIP 파일을 프로젝트 최상위 폴더에 압축 해제합니다.
2. PowerShell에서 프로젝트 최상위 폴더로 이동합니다.
3. 아래 명령을 실행합니다.

```powershell
node .\release_v51.94\apply-v51.94-expense-resolution.cjs
```

4. 적용 완료 메시지를 확인한 뒤 빌드합니다.

```powershell
npm run build
```

5. 정상 빌드 후 배포합니다.

## 확인할 내용

- 엑셀 다운로드 완료·실패 알림이 상단 중앙 토스트로 표시되는지 확인합니다.
- 통행료 PDF 업로드 완료·오류 알림이 토스트로 표시되는지 확인합니다.
- 저장 후 목록으로 이동한 뒤 저장 완료 토스트가 유지되는지 확인합니다.
- 목록 총금액에 PDF 행의 유류비와 통행료가 모두 포함되는지 확인합니다.

## 참고

- 적용 전 기존 3개 파일은 `.bak-v51.94-날짜시간` 이름으로 자동 백업됩니다.
- 이번 버전은 Supabase SQL 실행이 필요하지 않습니다.
