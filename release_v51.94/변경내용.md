# 지출결의서 작성 v51.94 변경내용

## 1. 알림 토스트 전환

- 엑셀 다운로드, 지출결의서 저장, 통행료 PDF 업로드 과정의 결과 알림을 화면 상단 중앙 토스트로 표시합니다.
- 성공·안내·경고·오류 상태를 색상으로 구분합니다.
- 토스트는 기본 3초 후 자동으로 닫히며 사용자가 직접 닫을 수도 있습니다.
- 저장 완료 알림은 작성 화면에서 목록 화면으로 전환된 뒤에도 유지됩니다.

## 2. 목록 총금액 수정

- 목록을 불러올 때 각 지출결의서의 저장된 사용내역을 다시 합산합니다.
- PDF 통행료 행에 연결해 저장한 유류비와 통행료를 모두 총금액에 포함합니다.
- 일반 유류대·접대비·숙박비·잡자재·우편·택배비·기타 금액도 함께 합산합니다.
- 저장 후 목록을 즉시 다시 불러와 수정된 총금액을 표시합니다.
- 기존에 저장된 지출결의서도 목록을 열면 같은 계산 기준이 적용됩니다.

## 유지 기능

- v51.92 도착시간·유류비·셀 직접수정·좌우 폭 조절
- v51.93 상세내역 `서울→용인(유류비)` 문구 및 셀 색상 수정
