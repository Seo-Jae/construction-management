# v52.48.5.44.24 변경내용

- 대시보드의 최초 기본 화면 배율을 90%로 적용했습니다.
- 상단 우측에 `화면 90%` 배율 선택 메뉴를 추가했습니다.
- 사용자는 90% 또는 100% 중 원하는 배율을 선택할 수 있습니다.
- 선택한 배율은 로그인 사용자와 브라우저 기준으로 저장되어 다음 접속에도 유지됩니다.
- 대시보드의 팝업, 메뉴, 토스트를 포함한 전체 화면에 같은 배율이 적용됩니다.
- 로그아웃 후 나타나는 로그인 화면과 근태 작업자·QR 전용 화면에는 배율을 적용하지 않습니다.
- 인쇄 전에는 화면 배율을 자동 해제하고 100%로 출력한 뒤 기존 배율로 복원합니다.
- 데이터베이스 구조 변경은 없습니다.
