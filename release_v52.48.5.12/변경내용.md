# v52.48.5.12 변경내용

## 공동작업 중복 처리 규칙

- 같은 현장·작업일·공정의 퇴근 진척 제출을 담당자 화면에서 하나의 공동작업 묶음으로 표시합니다.
- 여러 작업자가 같은 세대를 선택해도 세대 진척은 한 번만 반영합니다.
- 참여 작업자와 각 작업자의 원본 제출 기록은 모두 보존합니다.
- 담당자는 작업자별 중복 요청을 각각 승인하지 않고 통합 묶음을 한 번 승인합니다.
- 담당자가 화면에서 확인하지 않은 새 제출은 통합 승인에 몰래 포함되지 않습니다. 새 제출은 새로고침 후 별도로 확인합니다.
- 이미 같은 공정으로 완료된 세대는 작업자 퇴근 화면에서 선택할 수 없고, 서버에서도 다시 제출하지 못하도록 차단합니다.

## 전체 골구도 승인 화면

- 기존의 층별 가로 카드 대신 해당 동의 전체 층·호수를 한 화면에 세로 골구도로 표시합니다.
- 회색: 해당 공정에서 이미 승인 완료된 세대
- 초록색: 이번 통합 승인 대상인 금일 작업 세대
- 진한 테두리와 숫자 배지: 두 명 이상이 함께 제출한 공동작업 세대와 참여 인원 수
- 회색 바탕과 붉은 테두리: 기존 완료와 겹쳐 자동 제외되는 세대
- 금일 제출이 있는 층은 행 배경을 연한 초록색으로 강조합니다.

## 테스트계정 초기화 보완

- 공동작업 그룹 중 테스트계정 한 명만 초기화할 때 다른 작업자의 승인 진척은 유지합니다.
- 공동작업 그룹의 마지막 작업자까지 초기화할 때만 승인 전 진척 상태로 되돌립니다.

## 데이터베이스 추가 항목

- 공동 승인 그룹, 그룹별 제출, 그룹별 세대 기준상태를 보존하는 테이블 3개
- 통합 목록 조회, 통합 승인·반려, 테스트계정 초기화 RPC 3개
