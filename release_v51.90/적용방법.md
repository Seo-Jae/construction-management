# 지출결의서 작성 v51.90 적용방법

## 적용 기준

- 기준 버전: v51.89
- 이번 버전은 지출결의서 엑셀 다운로드의 날짜 형식과 상세내역 색상만 수정합니다.
- DB 변경은 없으므로 Supabase SQL을 실행하지 않습니다.
- 수정 파일은 `src/utils/expenseResolutionExcel.js` 1개입니다.

## 1. 압축 해제

ZIP 파일을 프로젝트 최상위 폴더에 압축 해제합니다.

```text
C:\Users\서재형\Desktop\new
├─ package.json
├─ src
└─ release_v51.90
```

## 2. 소스 적용

PowerShell에서 프로젝트 최상위 폴더로 이동한 후 실행합니다.

```powershell
node .\release_v51.90\apply-v51.90-expense-excel.cjs
```

적용 스크립트는 기존 `src/utils/expenseResolutionExcel.js`를 자동 백업한 뒤 새 파일로 교체합니다.

## 3. 빌드 확인

```powershell
npm run build
```

`Some chunks are larger than 500 kB` 문구는 용량 경고입니다. 마지막에 `built in`이 표시되면 정상입니다.

## 4. 엑셀 다운로드 확인

1. `업무보고관리 > 지출결의서 작성`에서 사용내역이 있는 문서를 엽니다.
2. 엑셀 다운로드를 실행합니다.
3. 갑지의 사용일이 `2026-06-01 월`처럼 `yyyy-mm-dd aaa` 형식으로 보이는지 확인합니다.
4. 상세내역의 제목·요일 헤더가 진한 남색인지 확인합니다.
5. 평일은 흰색, 일요일·토요일은 연한 크림색인지 확인합니다.
6. 작성월에 포함되지 않는 달력 칸은 회색인지 확인합니다.

## 색상 기준

| 구분 | 색상 |
|---|---|
| 제목·요일 헤더 | `#12346C` |
| 평일 | `#FFFFFF` |
| 일요일·토요일 | `#F9F9E1` |
| 작성월 바깥 칸 | `#D9D9D9` |
| 날짜 글자 | `#000080` |

색상 인덱스를 사용하지 않고 실제 RGB 값을 적용하므로 시트 복사나 브라우저 생성 과정에서도 색이 달라지지 않습니다.
