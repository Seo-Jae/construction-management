# 지출결의서 작성 v51.90 변경내용

## 1. 갑지 날짜 형식

- 기존 `mm-dd` 표시를 `yyyy-mm-dd aaa`로 변경했습니다.
- 날짜 값은 문자열이 아니라 기존과 동일한 Excel 날짜 값으로 유지합니다.

## 2. 상세내역 색상 복원

- 원본 이미지의 실제 RGB 색상을 적용했습니다.
- 제목·요일 헤더는 진한 남색으로 표시합니다.
- 평일은 흰색, 일요일·토요일은 연한 크림색으로 표시합니다.
- 작성월에 포함되지 않는 칸은 회색으로 표시합니다.
- 달력 배치에 따라 색상이 자동 적용되므로 월 시작 요일과 마지막 날짜가 달라도 정상 표시됩니다.
- 시트 복사 과정에서 색이 달라지지 않도록 색상 인덱스 대신 RGB 값을 사용합니다.

## 3. 적용 범위

- 기준 버전: v51.89
- 수정 파일: `src/utils/expenseResolutionExcel.js`
- DB 변경 없음
- Supabase SQL 없음
- 적용 스크립트: `release_v51.90/apply-v51.90-expense-excel.cjs`
