# v52.48.5.24 변경내용

## 항목할증률 계산 기준 수정

- 항목할증률은 수량이 아니라 해당 항목의 제출단가·제출금액에 적용합니다.
- 기본 계산식은 `제출금액 = 정미수량 × 단가 × (1 + 항목할증률 / 100)`입니다.
- 항목할증률을 입력해도 제출수량은 정미수량과 동일하게 유지합니다.
- 제출수량을 직접 수정한 경우에는 사용자가 입력한 수량을 유지합니다.
- 지급자재로 체크한 재료비는 할증 여부와 관계없이 정미·제출금액 모두 0원입니다.

## 기존 저장 문서 호환

- 이전 계산 방식으로 자동 저장된 할증 제출수량은 문서를 불러올 때 정미수량 기준으로 보정합니다.
- 사용자가 직접 수정해 저장한 제출수량은 그대로 보존합니다.
- 저장, 화면 금액 요약, Excel, 출력/PDF에 동일한 계산 기준을 적용합니다.

## 화면 정리

- 하단의 재료비·노무비·경비 기본 할증률 입력란을 삭제했습니다.
- 하단의 문서 비고 입력란을 삭제했습니다.
- 항목할증률 안내 문구를 `할증 없음` 또는 `금액에 적용`으로 변경했습니다.
- 제출수량 안내 문구를 `정미수량 적용` 또는 `직접 수정`으로 변경했습니다.

## 데이터 영향

- 데이터베이스 구조는 변경하지 않았습니다.
- 새로 저장하는 문서의 분류별 기본 할증률과 문서 비고는 빈 값으로 정리됩니다.
- SQL 실행이 필요하지 않습니다.
