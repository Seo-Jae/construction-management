# v52.48.5.24 적용방법

적용 기준은 `v52.48.5.23`입니다. 이번 버전은 일위대가 할증 계산과 화면만 수정하며 SQL 실행은 필요하지 않습니다.

## 1. 코드 적용

프로젝트 최상위 폴더에서 압축을 해제한 뒤 PowerShell에서 실행합니다.

```powershell
node .\release_v52.48.5.24\apply-v52.48.5.24-markup-calculation.cjs
npm run build
```

## 2. Git 반영

```powershell
git add src/page/UnitPriceAnalysis.jsx
git status
git commit -m "v52.48.5.24 fix unit price markup calculation"
git push origin main
```

배포 후 항목할증률을 입력해도 제출수량은 정미수량과 동일하고, 제출금액에만 할증이 반영되는지 확인합니다.
