# v52.17.1 적용방법

기준: v52.17 배포 완료 상태

## 1. ZIP 압축 해제
프로젝트 최상위 폴더에 `release_v52.17.1` 폴더가 보이도록 압축을 풉니다.

## 2. 프로그램 적용
PowerShell에서 프로젝트 최상위 폴더 기준으로 실행합니다.

```powershell
node .\release_v52.17.1\apply-v52.17.1-attendance-ui-tuning.cjs
```

적용 전 기존 파일은 `backup_v52.17.1_날짜시간` 폴더에 자동 백업됩니다.

## 3. 빌드
```powershell
npm run build
```

## 4. Git 반영
이번 버전의 실제 변경 파일은 2개입니다.

```powershell
git add src/page/AttendanceManagement.jsx
git add src/page/AttendanceWorkerPortal.jsx
git status
git commit -m "v52.17.1 attendance app UI tuning"
git push origin main
```

`git add .`은 사용하지 않습니다.

## 5. Vercel 확인
`wooklim-construction-management`의 Production 배포가 `Ready`가 되면 실제 갤럭시 근태앱에서 확인합니다.

## SQL
SQL 변경은 없습니다. v52.17 SQL을 다시 실행할 필요가 없습니다.
