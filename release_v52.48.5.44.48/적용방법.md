# v52.48.5.44.48 적용방법

## 기준
- `v52.48.5.44.47` 적용 상태에서 실행합니다.
- `.47`의 Supabase 가이드 SQL을 아직 실행하지 않았다면 먼저 `.47` SQL을 실행해야 합니다.
- `.47` SQL이 이미 적용되어 있다면 이번 버전의 추가 SQL은 없습니다.

## 적용 → 빌드 → Git → 운영배포
프로젝트 최상위 폴더에 `release_v52.48.5.44.48` 폴더를 넣고 PowerShell에서 실행합니다.

```powershell
node .\release_v52.48.5.44.48\apply-v52.48.5.44.48-guide-visual-annotations.cjs
npm run build
git add .
git commit -m "v52.48.5.44.48 이미지 주석형 시스템 가이드"
git push origin main
```

Vercel Production이 Git `main`에 연결되어 있다면 push 후 운영배포가 자동 진행됩니다.

## 확인 순서
1. 최고관리자 계정 → `가이드 설정` 진입
2. 메뉴 하나 선택 → 실제 화면 캡처 이미지 등록
3. `표시 편집` → 번호/동그라미/점선박스/화살표 추가
4. 표시별 제목/설명 입력 → 편집 창 저장
5. 가이드 설정 화면에서 `저장`
6. `작성 미리보기`로 화면 구성 확인
7. `공개`
8. 해당 실제 메뉴 상단 `가이드` 버튼으로 사용자 화면 확인
