# v52.48.5.44.48 변경내용

## 가이드 작성 방식 전환
- 단순 설명/이미지 나열 방식에서 **실제 시스템 화면 이미지 기반 안내 방식**으로 전환했습니다.
- 최고관리자는 가이드 화면별 실제 캡처 이미지를 등록하고 이미지 위에 안내 표시를 배치할 수 있습니다.
- 지원 표시: **번호, 동그라미, 점선 박스, 화살표**.
- 각 표시는 번호, 안내 제목, 상세 설명, 색상을 갖습니다.
- 표시 위치/크기는 이미지 비율에 대한 퍼센트 좌표로 저장되어 화면 크기가 달라도 같은 위치에 표시됩니다.

## 최고관리자 가이드 설정
- `가이드 화면 추가`로 실제 작업 순서별 화면을 구성합니다.
- 화면 이미지 등록 후 `표시 편집`을 눌러 별도 편집 창을 엽니다.
- 편집 창에서 표시를 직접 그리거나 이동하고 각 번호에 맞는 안내 문구를 작성합니다.
- 작성 미리보기에서 일반 사용자가 보게 될 최종 구성을 확인할 수 있습니다.
- 초안 저장과 공개본은 기존처럼 분리됩니다.

## 일반 사용자 가이드 팝업
- 상단: `사용 순서 한눈에 보기`를 화면 썸네일 형태로 자동 구성합니다.
- 하단: `상세 이용가이드`에서 실제 화면을 크게 보여주고 번호/원/박스/화살표를 그대로 표시합니다.
- 각 화면 아래에는 이미지 표시 번호와 연결된 설명이 표시됩니다.

## DB
- 신규 테이블/컬럼 변경은 없습니다.
- `.47`에서 생성한 `system_guides` JSONB 컬럼과 `system-guide-images` Storage를 그대로 사용합니다.
