# v52.48 적용방법

## 기능 1. 근태앱 관리자 모드

근태앱의 `근로자 로그인` 화면에서:

`처음 이용하시나요? 가입 신청`

바로 아래에:

`관리자 모드`

버튼이 추가됩니다.

관리자 모드는 통합관리시스템에서 사용하는 동일한:
- 아이디(이메일)
- 비밀번호

로 인증합니다.

추가로 QR을 표시할 현장을 선택합니다.

## 관리자 QR 흐름

1. 근태앱 실행
2. `관리자 모드`
3. 통합관리시스템 이메일/비밀번호 입력
4. 현장 선택
5. `출·퇴근 QR 실행`
6. Supabase 관리자 로그인 인증
7. 계정 활성상태 확인
8. 기존 `attendance_start_qr_display_v52_14_1` 서버 권한검사
9. 보안 QR 표시 세션 발급
10. 현재 탭의 관리자 인증세션 자동 종료
11. 휴대폰에 5초 동적 출·퇴근 QR 표시
12. 근로자가 자신의 휴대폰으로 촬영

기존 PC 근태관리 QR과 같은 서버 보안방식을 재사용합니다.

## 기능 2. 근로자 로그인 폭 확대

일반 브라우저에서 로그인 화면 최대폭을:

`520px → 1040px`

로 약 2배 확대합니다.

휴대폰에서는 `width: 100%` 제약이 먼저 적용되므로 화면 밖으로 넘치지 않습니다.

가입신청 화면은 너무 넓어지지 않도록 720px로 유지합니다.

설치앱(appMode)은 기존처럼 휴대폰 전체폭을 사용합니다.

## 확인

### 근로자 로그인
- 로그인 화면 폭 확대
- 가입신청 버튼 아래 `관리자 모드`

### 관리자 모드
- 통합관리시스템 이메일 입력
- 비밀번호 입력
- 현장 선택
- QR 실행

권한 없는 현장을 선택하면 기존 서버 권한검사에 의해 QR 발급이 차단되어야 합니다.

### QR
- 관리자 휴대폰에 큰 QR 표시
- 5초마다 자동 변경
- 근로자 휴대폰에서 기존 `출·퇴근 QR 촬영`으로 인식
