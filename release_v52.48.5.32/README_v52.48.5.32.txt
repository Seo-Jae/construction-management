v52.48.5.32 - 일위대가 기술자료 편집기 v1

[기준]
- 현재 배포 완료된 v52.48.5.31에서 앞으로 이어지는 패치입니다.
- 기존 일위대가 계산/저장/버전관리/기술자료 이미지 업로드/권한 기능을 되돌리거나 덮어쓰지 않습니다.
- 수정 대상은 src/page/UnitPriceAnalysis.jsx 1개이며, 새 유틸 파일과 SQL 파일을 추가합니다.
- 적용 전 UnitPriceAnalysis.jsx를 backup_v52.48.5.32_날짜시간 폴더에 자동 백업합니다.
- 예상 기준 코드가 다르면 자동 적용을 중단합니다.

[추가 기능]
1. 기술자료 편집 권한
- 기존 기술자료 이미지 관리 권한(material.unit_price.tech_image.manage)을 그대로 사용합니다.
- 최고관리자: 항상 편집 가능
- 최고관리자가 권한을 부여한 사용자: 편집 가능
- 그 외 사용자: 편집 버튼이 보이지 않고 완성된 기술자료만 조회

2. 기술자료 편집기 v1
- 기술자료 우측 상단의 "지시선 편집" 버튼으로 별도 브라우저 편집 창 실행
- "+ 지시선 추가" 클릭
- 이미지에서 실제 부재 위치 1회 클릭
- 번호/명칭을 표시할 위치 1회 클릭
- 생성 후 부재 위치 점과 번호/명칭 위치를 각각 드래그하여 이동
- 번호/기호 입력
- 명칭 입력
- 명칭에 대한 설명 입력
- 표시 색상 선택
- 항목 삭제
- 항목 순서 위/아래 변경
- 저장 시 원본 이미지는 수정하지 않고 좌표/명칭 데이터만 Supabase에 저장

3. 기술자료 조회 개선
- 기존처럼 별도 브라우저 창에서 이미지 확인
- 저장된 지시선/번호/명칭을 이미지 위에 표시
- 하단에 기술자료 항목 목록 표시
- 하단 항목에 마우스를 올리면 해당 지시선과 실제 부재 위치를 같은 색으로 강조
- 이미지 위 번호/명칭에 마우스를 올려도 같은 항목 강조
- 화면 맞춤 / 원본 크기 유지

[적용 순서]
1. 이 release_v52.48.5.32 폴더를 프로젝트 new 폴더 안에 둡니다.
2. VS Code 터미널에서 new 폴더 위치 확인 후 실행:
   node release_v52.48.5.32/apply-v52.48.5.32-technical-annotation-editor.cjs
3. 적용 완료 후 Supabase SQL Editor에서 다음 파일 전체 실행:
   supabase/v52.48.5.32_unit_price_annotation_editor.sql
4. 빌드 확인:
   npm.cmd run build
5. 로컬 실행:
   npm.cmd run dev

[테스트]
- 자재관리 > 일위대가작성
- 기술자료 이미지가 있는 규격 선택
- 최고관리자 또는 기술자료 이미지 관리 권한 계정: "지시선 편집" 버튼 표시 확인
- 일반 계정: "지시선 편집" 버튼 미표시 확인
- 편집창에서 지시선 1개 추가 후 번호/명칭/설명 입력 및 저장
- 기술자료 이미지를 클릭하여 새 조회 창 실행
- 하단 항목에 마우스를 올렸을 때 해당 지시선/부재 위치가 강조되는지 확인

[DB]
신규 테이블:
- public.unit_price_technical_annotations

신규 RPC:
- public.can_manage_unit_price_technical_annotations()
- public.save_unit_price_technical_annotations(text, jsonb)

image_key 단위로 저장하므로 같은 기술자료 이미지를 공유하는 세부 규격은 동일한 지시선/명칭 정보도 공유합니다.
