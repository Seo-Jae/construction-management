# v52.48.5.26 변경내용

## 재료비(단수정리)로 정정

- `경비(단수정리)`를 `재료비(단수정리)`로 변경했습니다.
- 단수정리 금액은 우측 금액 요약, Excel 및 출력/PDF에서 재료비 제출금액으로 합산합니다.
- 단수정리 선택 시 품명과 규격을 자동 입력하지 않고 빈칸으로 유지합니다.
- 품명과 규격은 작성자가 직접 입력해야 합니다.
- v52.48.5.25에서 자동 생성된 `경비 단수정리`와 기본 규격 문구는 SQL 실행 시 빈칸으로 정리합니다.
- 작성자가 직접 변경한 품명과 규격은 그대로 보존합니다.

## 노무비 입력 방식 개선

- 표의 정미수량 칸에는 ㎡당 금액이 아니라 계산된 실제 수량을 `0.036인` 형태로 표시합니다.
- 노무비 정미수량 칸을 클릭하면 폭 176px의 작은 `1㎡당 노무비` 입력 팝업이 열립니다.
- 팝업에 ㎡당 금액을 입력하고 Enter 또는 적용 버튼을 누르면 정미수량을 자동 계산합니다.
- 계산식은 `㎡당 노무비 ÷ 노무 기준단가`입니다.
- 노무 기준단가가 0원인 경우 계산하지 않고 기준단가 입력을 안내합니다.
- 규격별 기본값 관리 화면에도 같은 팝업 입력 방식을 적용했습니다.

## 데이터베이스

- 기존 `expense_rounding` 값을 `material_rounding`으로 전환합니다.
- 기존 일반 재료비·노무비·경비와 저장 문서는 삭제하지 않습니다.
