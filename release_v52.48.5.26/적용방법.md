# v52.48.5.26 적용방법

적용 기준은 `v52.48.5.25`입니다. 기존 경비(단수정리) 데이터를 재료비(단수정리)로 전환하기 위해 SQL을 반드시 실행해야 합니다.

## 1. 코드 적용

프로젝트 최상위 폴더에서 압축을 해제한 뒤 PowerShell에서 실행합니다.

```powershell
node .\release_v52.48.5.26\apply-v52.48.5.26-material-rounding-labor-popup.cjs
npm run build
```

## 2. Supabase SQL 실행

Supabase Dashboard의 `SQL Editor`에서 아래 파일을 열어 전체 내용을 한 번 실행합니다.

```text
supabase/v52.48.5.26_unit_price_material_rounding.sql
```

기존 문서와 기본 구성값은 삭제하지 않습니다. v52.48.5.25 SQL을 이미 실행했거나 아직 실행하지 않은 경우 모두 적용할 수 있으며, 다시 실행해도 안전합니다.

## 3. Git 반영

```powershell
git add src/page/UnitPriceAnalysis.jsx supabase/v52.48.5.26_unit_price_material_rounding.sql
git status
git commit -m "v52.48.5.26 correct material rounding and labor popup"
git push origin main
```

배포 후 재료비(단수정리)를 선택했을 때 품명·규격이 비어 있는지 확인합니다. 노무비 정미수량 칸을 클릭하여 ㎡당 금액을 입력하고 Enter 또는 적용 버튼으로 계산값이 반영되는지도 확인합니다.
