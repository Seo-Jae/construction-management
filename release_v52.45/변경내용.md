# v52.45 변경내용

## 공종 일괄변경

월별 노임작성 상단의 공종 일괄변경 기능을 제거했습니다.

제거:
- bulkTrade state
- setBulkTrade
- applyBulkTrade
- 공종 일괄변경 Autocomplete
- 적용 버튼
- 해당 영역 앞 Divider

유지:
- 각 근로자 행의 공종 입력
- 근로자 추가/삭제
- ↑↓ 순서변경
- 근로자 조회

## 작성월 이동

작성월 필드 좌우에 이전월/다음월 IconButton을 추가합니다.

아이콘:
- ChevronLeftRoundedIcon
- ChevronRightRoundedIcon

`changeMonthBy(offset)` 함수가 현재 YYYY-MM을 한 달 단위로 계산합니다.

연도 경계도 자동 처리합니다.

예:
- 2026-01 - 1개월 = 2025-12
- 2026-12 + 1개월 = 2027-01

## 데이터 보호

이전월/다음월 이동도 기존 `handleMonthChange()`를 호출합니다.

따라서 dirty 상태의 저장 경고를 우회하지 않습니다.
