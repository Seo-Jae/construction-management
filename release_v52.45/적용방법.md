# v52.45 적용방법

## 선행조건

v52.44가 먼저 적용되어 있어야 합니다.

v52.44:
- 근로자 조회 전체목록
- 성명 / 공종 조회 필터
- 목록 클릭 추가

v52.45 적용스크립트는 `labor_worker_master_browse_v52_44` 연결 여부를 확인한 뒤 진행합니다.

## 변경내용

### 1. 공종 일괄변경 제거

상단의:
- 공종 일괄변경 입력칸
- 적용 버튼

을 제거합니다.

개별 근로자 행의 `공종` 입력/수정 기능은 그대로 유지합니다.

### 2. 작성월 이전/다음 이동

기존:

`[ 2026년 08월 ]`

변경:

`[ < ] [ 2026년 08월 ] [ > ]`

- `<` : 이전월
- `>` : 다음월
- 기존 달력/월 직접선택도 그대로 사용 가능

예:
- 2026-08에서 `<` → 2026-07
- 2026-08에서 `>` → 2026-09
- 2026-01에서 `<` → 2025-12
- 2026-12에서 `>` → 2027-01

## 저장되지 않은 내용

기존 `handleMonthChange()`를 그대로 사용합니다.

따라서 명단을 수정하고 저장하지 않은 상태에서
`<` 또는 `>`를 누르면 기존과 동일하게:

`저장하지 않은 변경사항이 있습니다. 작성월을 변경하시겠습니까?`

확인창이 표시됩니다.
