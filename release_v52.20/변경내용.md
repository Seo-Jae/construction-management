# v52.20 변경내용

## 작업자 앱 로그인 상태 유지

### 기존
- 프론트 세션 토큰: localStorage 저장
- 서버 `attendance_worker_sessions.expires_at`: 로그인/가입 시 30일
- 세션 확인 RPC 오류 발생: 오류 종류와 상관없이 localStorage 토큰 즉시 삭제
- 첫 세션 확인이 실패하고 worker가 없으면 자동 재연결 루프도 동작하지 않음

### v52.20
- 서버 작업자 세션 자동 만료 제거
- 기존 세션도 영구 세션으로 전환
- 신규 세션은 DB trigger가 `expires_at = infinity`로 보정
- 명시적 로그아웃은 기존 RPC의 세션 DELETE를 그대로 사용
- 토큰/등록기기가 실제 무효한 경우에만 localStorage 세션 삭제
- 네트워크/RPC 일시 오류는 로그인 상태 유지
- 저장된 세션 토큰이 있으면 worker 데이터가 아직 없어도 60초 주기 재연결
- 창 focus 시 재연결
- 인터넷 online 복귀 시 즉시 재연결
