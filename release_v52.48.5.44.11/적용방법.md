# v52.48.5.44.11 적용방법

기준은 `v52.48.5.44.10` 반영 완료본입니다.

1. ZIP을 프로젝트 루트(`package.json`, `src` 폴더가 있는 위치)에 풉니다.
2. PowerShell에서 실행합니다.

```powershell
node release_v52.48.5.44.11/apply-v52.48.5.44.11-labor-quantity-excel.cjs
npm run build
git add .
git commit -m "feat: enable labor quantity excel v52.48.5.44.11"
git push
```

새 Supabase SQL은 없습니다.

## 확인방법

1. `노임관리 > 공정별 노임작성 > 2. 세대별 물량 입력`으로 이동합니다.
2. 공정을 선택하면 `엑셀 다운로드`와 `엑셀 업로드`가 모든 현장에서 활성화되는지 확인합니다.
3. 화면의 타입 열이 `현장관리`에서 입력한 동별 기본타입과 층별·호별 예외타입으로 표시되는지 확인합니다.
4. `엑셀 다운로드`를 눌러 파일이 생성되는지 확인합니다.
5. 내려받은 파일의 `타입(자동)` 열에 해당 세대 타입이 표시되는지 확인합니다.

9층 이하 세대번호는 기존과 같이 `101901`, `1010901` 형식을 모두 인식합니다.
