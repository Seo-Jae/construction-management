- 직전 v52.48.5.37.3 적용 스크립트는 로컬 파일이 반드시 v52.48.5.37.2라고 가정했습니다.

- Git blob SHA 확인:
  v37.1 / 현재 main : dcc8b3e3e2c167cb9694e06fd9edefbe80757e21

- 따라서 기능 문제가 아니라 적용 스크립트의 기준선 판정이 너무 엄격해 중단된 것입니다.

이번 패키지
- 완성된 technicalImageSheetEditor.js 교체파일 포함
- v37.1 또는 v37.2 둘 중 어느 기준이어도 안전하게 적용
- 그 외 알 수 없는 파일이면 자동 중단
- 적용 전 원본 자동 백업
- 적용 후 파일 해시 재검증

포함 기능
1. v37.2 번호/하단 명칭 클릭 안정화
2. 번호/명칭 선택 시 연결 부속자재 즉시 표시
3. 선택항목 상세 미리보기 250px 높이 제한 제거
4. 세로 상세이미지를 우측 패널 폭 전체로 표시
5. 가능하면 이미지 바깥 흰 여백을 VIEW에서만 자동 최소화
6. 전체보기는 목록 + compact 작은 미리보기 유지
7. 편집기/부속자재 연결/지시선/DB 기존 기능 유지
