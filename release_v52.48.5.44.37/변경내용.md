# v52.48.5.44.37 변경내용

- `다중 공종 진척 현황 > 공종 선택`과 `자재투입현황 > 해당 기간 입고업체` 목록의 기준 좌표를 현재 시스템 화면배율로 환산합니다.
- 목록 폭 때문에 MUI가 팝업을 왼쪽으로 밀어내던 문제를 막고 입력칸의 시작점에 맞춥니다.
- 세대물량관리 `타입별 기본물량` 열을 `기본물량 / 단위 / 소계 / 공제물량 / 자동 합계`로 확장했습니다.
- 소계는 `기본물량 × 해당 세대`, 자동 합계는 `소계 - 공제물량`로 계산합니다.
- 공제물량을 세대물량 문서와 Excel 숨김 연결정보에 저장합니다.
- 기존 v2 세대물량 Excel에는 공제물량 0을 적용하여 계속 업로드할 수 있습니다.
- 수량·물량·합계는 우측, 텍스트는 가운데 정렬합니다.

Supabase SQL 변경은 없습니다.
