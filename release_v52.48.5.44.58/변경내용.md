# v52.48.5.44.58 변경내용

## 가이드 표시 크기 기준 수정
- v52.48.5.44.57에서 **표시 편집기 크기를 기준으로 실제 가이드를 축소하던 방식**을 되돌렸습니다.
- 사용자가 실제로 보는 **공개 가이드의 표시 크기**를 기준으로 삼습니다.
- 기존에 작성한 번호 원/설명박스가 .57 적용 후 지나치게 작아 보이던 현상을 복원합니다.

## 표시 편집기
- 실제 가이드 팝업의 상세 이미지 영역 폭을 기준값으로 계산합니다.
- 편집 이미지가 더 크게 표시되는 경우 번호 원/설명박스도 같은 비율로 확대되어, 저장 후 실제 가이드에서 보일 상대 크기를 편집 중 확인할 수 있습니다.
- 확대/축소 및 화면 이동 기능은 그대로 유지합니다.
- 리사이즈 핸들은 조작성을 위해 기존처럼 화면에서 일정한 크기로 유지합니다.

## 가이드 설정 미리보기
- 실제 가이드 팝업 상세 이미지 영역을 기준으로 번호/설명박스 비율을 표시합니다.
- 편집기 기준 자연폭(최대 2200px)을 사용해 표시를 축소하던 .57 방식은 제거했습니다.

## 공개 가이드
- .56까지 사용하던 가독성 좋은 번호 원/설명박스 크기로 복원했습니다.
- .56의 최하단 목차 활성 표시 수정은 유지됩니다.

## DB
- 추가 Supabase SQL 없음
- 기존 작성 데이터/좌표/화살표/번호 데이터 변경 없음
