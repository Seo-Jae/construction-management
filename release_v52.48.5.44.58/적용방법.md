# v52.48.5.44.58 적용방법

v52.48.5.44.57이 적용된 프로젝트 최상위 폴더에서 실행합니다.

```powershell
node .\release_v52.48.5.44.58\apply-v52.48.5.44.58-guide-output-reference.cjs
npm run build
git add .
git commit -m "v52.48.5.44.58 가이드 출력 기준 WYSIWYG 보정"
git push origin main
```

Vercel이 main 브랜치 Push 자동배포로 연결되어 있으면 배포 완료만 확인합니다.
자동배포가 시작되지 않는 경우에만 다음을 실행합니다.

```powershell
npx vercel --prod
```

추가 Supabase SQL은 없습니다.
