# v52.48.5.44.66 변경내용

- 가이드 설정 > 화면 이미지 `교체` 시 기존 표시를 초기화하던 로직을 제거했습니다.
- 새 이미지 업로드 후 `imagePath`와 미리보기 URL만 변경합니다.
- 기존 번호, 동그라미, 점선박스, 설명/지점/번호 연결 화살표, 설명박스, 표시 색상/두께/위치/번호 숨김 설정을 그대로 유지합니다.
- 교체 완료 메시지에 유지된 표시 개수를 안내합니다.
- `초안에서 이미지 제거`는 명시적인 삭제 기능이므로 기존처럼 이미지와 표시를 함께 제거합니다.
- 이미지 레이아웃이 크게 달라진 경우 기존 좌표는 그대로 유지되므로 `표시 편집`에서 위치만 미세 조정할 수 있습니다.
- Supabase SQL 변경은 없습니다.
