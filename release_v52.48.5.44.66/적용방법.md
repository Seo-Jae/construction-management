# 적용방법

현재 v52.48.5.44.65 적용 상태의 프로젝트 최상위 폴더에 `release_v52.48.5.44.66` 폴더를 넣고 실행합니다.

```powershell
node .\release_v52.48.5.44.66\apply-v52.48.5.44.66-guide-image-replace-preserve-annotations.cjs
npm run build
git add .
git commit -m "v52.48.5.44.66 가이드 이미지 교체 시 기존 표시 유지"
git push origin main
```

Vercel이 `main` push 자동배포에 연결돼 있으면 운영배포가 자동으로 시작됩니다.
자동배포가 시작되지 않는 경우에만 `npx vercel --prod`를 실행합니다.

추가 Supabase SQL은 없습니다.
