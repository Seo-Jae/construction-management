# v52.48.5.44.51 적용방법

프로젝트 최상위 폴더에 `release_v52.48.5.44.51` 폴더를 넣은 뒤 실행합니다.

```powershell
node .\release_v52.48.5.44.51\apply-v52.48.5.44.51-guide-overview-thumbnails.cjs
npm run build
git add .
git commit -m "v52.48.5.44.51 가이드 한눈에 보기 썸네일 개선"
git push origin main
```

Vercel이 `main` 브랜치 자동 배포로 연결돼 있으면 push 후 Production 배포 상태를 확인합니다. 자동 배포가 시작되지 않을 때만 `npx vercel --prod`를 별도로 실행합니다.

추가 Supabase SQL은 없습니다.
