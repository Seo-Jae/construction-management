# v52.32 적용방법

## 목적
노임관리의 신규 `월별 노임작성` 1차 골격을 추가합니다.

이번 단계에서는 개인정보 DB, 근로자 마스터 DB, SMS 인증, Excel 생성은 연결하지 않습니다.
먼저 실제 업무에 사용할 명단 조작 방식부터 확인합니다.

## 변경 파일
- `src/Dashboard.jsx`
- `src/components/Sidebar.jsx`
- 신규 `src/page/MonthlyLaborManagement.jsx`

## SQL
없음.

## 적용
프로젝트 최상위에서:

```powershell
node .\release_v52.32\apply-v52.32-monthly-labor-foundation.cjs
npm run build
```

## Git
빌드 성공 후:

```powershell
git add src/Dashboard.jsx
git add src/components/Sidebar.jsx
git add src/page/MonthlyLaborManagement.jsx
git status
git commit -m "v52.32 add monthly labor management foundation"
git push origin main
```

`git add .`은 사용하지 않습니다.

## 화면 확인
1. 좌측 `노임관리` 펼치기
2. 최상단에 `월별 노임작성` 메뉴 확인
3. 현장 선택 후 메뉴 진입
4. `신규 근로자 추가`
5. 공종 입력
6. 여러 명 체크 후 ↑ / ↓
7. 선택 삭제
8. 선택 후 공종 일괄변경
9. `근로자 조회` 팝업 확인
   - 현재는 근로자 마스터 DB 연결 전이므로 실제 기존 근로자 데이터는 표시되지 않음
   - DB 연결 후 같은 팝업에서 검색 → 추가 → 다시 검색 → 추가를 반복하도록 이미 구조를 준비함

## 기존 기능
기존 `근로계약서작성`, `공정별 노임작성`은 삭제/변경하지 않습니다.
`월별 노임작성`의 임시 접근권한은 현재 `labor.cost.view`를 재사용합니다.
별도 노임 개인정보 권한은 근로자 마스터 개발 단계에서 분리합니다.
