# v52.32 변경내용

## 노임관리 메뉴
신규:
- 월별 노임작성

기존 유지:
- 근로계약서작성
- 공정별 노임작성
- 노임서류작성(준비중)

## 월별 노임작성 1차 기능
- 현장명 표시
- 작성월 선택
- 근로자 조회 버튼
- 조회 팝업을 닫지 않고 반복 검색/추가 가능한 구조
- 신규 근로자 직접 추가
- 명단 체크박스 선택
- 선택 삭제
- 선택 근로자 ↑ / ↓ 한 단계 순서 이동
- 여러 명 선택 시 상대순서를 보존한 상태로 이동
- 공종 개별 입력
- 공종 목록 선택 + 직접입력
- 선택 근로자 공종 일괄변경
- 명단 총원 / 선택 인원 표시

## 아직 연결하지 않은 기능
- 근로자 마스터 DB
- 개인정보 암호화 DB
- SMS 인증
- 노임 Excel 생성/다운로드
- 서버 저장

위 기능은 화면 조작방식을 먼저 확인한 다음 순차 연결합니다.
