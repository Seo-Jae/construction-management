# v52.48.5.17 적용방법

적용 기준은 `v52.48.5.16`입니다.

## 1. 코드 적용

프로젝트 최상위 폴더에서 압축을 해제한 뒤 PowerShell에서 실행합니다.

```powershell
node .\release_v52.48.5.17\apply-v52.48.5.17-unit-price-analysis.cjs
npm run build
```

## 2. Supabase SQL 실행

Supabase Dashboard의 `SQL Editor`에서 아래 파일을 열어 전체 내용을 한 번 실행합니다.

```text
supabase/v52.48.5.17_unit_price_analysis.sql
```

성공 시 하단 결과에 `Success. No rows returned`가 표시됩니다. SQL은 다시 실행해도 기존에 등록된 규격과 사용자가 수정한 기준값을 덮어쓰지 않습니다.

## 3. Git 반영

```powershell
git add src/Dashboard.jsx src/components/Sidebar.jsx src/page/UnitPriceAnalysis.jsx supabase/v52.48.5.17_unit_price_analysis.sql
git status
git commit -m "v52.48.5.17 add unit price analysis"
git push origin main
```

배포 후 `자재관리 > 일위대가작성`에서 화면을 확인합니다. 기술자료 이미지는 현재 안내 박스로 표시되며, 추후 이미지가 준비되면 규격별로 연결합니다.
