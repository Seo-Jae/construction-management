# v52.48.5.17 변경내용

## 신규 메뉴

- `자재관리 > 일위대가작성` 추가
- 기존 `자재발주작성` 기능과 데이터는 이번 개발에서 제외
- 기존 자재투입현황 조회 권한을 사용하므로 현재 자재관리 권한 체계와 충돌하지 않음

## 일위대가 작성

- 벽체/천정 → 중분류 → 세부규격 3단계 선택
- Excel에서 추출한 69개 규격과 256개 규격 구성항목 초기 등록
- 마감자재를 포함한 259개 자재 마스터 초기 등록
- 1㎡당 정미수량, 단가, 정미금액 자동 계산
- 재료비·노무비·경비 구분 및 항목 추가/삭제/순서변경
- 기본 수량·단가·품명·규격·단위·비고 자유 수정
- 자재 마스터에서 마감재 등 원하는 항목 검색·추가

## 정미값과 제출용 할증

- 재료비·노무비·경비별 기본 할증률 설정
- 특정 항목에만 개별 할증률 적용
- 자동 계산된 제출수량을 항목별로 직접 수정 가능
- 정미금액과 제출금액을 화면에서 동시에 비교
- 정미 일위대가와 제출용 일위대가를 각각 출력/PDF 처리
- Excel 다운로드 시 `정미값`, `제출용` 2개 시트 생성

## 저장·공유

- 현장별 문서 저장
- 저장할 때마다 버전 번호 증가 및 전체 스냅샷 보관
- 작성중/제출본/보관 상태 구분
- 저장본 다시 불러오기 및 수정
- 다른 현장 문서 조회와 대상 현장으로 복사
- 원본 문서는 유지하고 대상 현장에 새 작성중 문서 생성

## 자재 단가와 기준정보

- 자재별 현재 단가와 적용일 관리
- 단가 변경 전/후 금액과 적용일, 사유 이력 저장
- Excel 단가양식 다운로드 및 월별·분기별 일괄 반영
- 신규 자재 등록
- 규격별 기본 구성항목 및 정미수량 관리
- Excel 원본에서 단가가 비어 있던 2개 자재는 0원으로 표시하여 추후 입력 가능

## 이미지 준비

- 규격 테이블과 화면에 기술자료 이미지 연결 구조를 미리 반영
- 이미지가 없는 현재 상태에서는 규격명이 포함된 안내 박스 표시
- 추후 제공 이미지 작업 시 계산·저장 기능을 변경하지 않고 연결 가능
