# 사내시스템 v52.07 누적배포 적용방법

## 기준

현재 운영 최신 버전은 **v52.00.2 회원권한 2~5단계 및 관리 화면 개선**입니다.
이 패키지는 v52.01부터 v52.06까지의 최종 파일을 한 번에 적용합니다.

## 1. Supabase SQL 먼저 실행

Supabase Dashboard > SQL Editor에서 아래 파일을 처음부터 끝까지 전체 실행합니다.

```text
release_v52.07\Supabase에서_실행\00_v52.00.2부터_v52.06_누적실행.sql
```

이 파일에는 다음 두 DB 변경이 순서대로 포함되어 있습니다.

1. v52.03.1 회원계정 영구삭제/FK 보존 처리
2. v52.04 Main 주요일정 및 전체현장 공유권한

기존 v52.03 SQL은 따로 실행하지 않습니다.

## 2. 프런트 누적 적용

ZIP을 프로젝트 최상위 폴더(package.json과 src가 있는 위치)에 압축 해제한 뒤 PowerShell에서 실행합니다.

```powershell
node .\release_v52.07\apply-v52.07-cumulative-v52.00.2-to-v52.06.cjs
npm run build
```

적용 전에 기존 대상 파일은 `backup_v52.07_...` 폴더에 자동 백업됩니다.

## 3. 우선 확인할 화면

- 회원관리: 직급 최고관리자 전용 수정 유지, 계정 영구삭제 버튼/보호규칙
- 전체 UI: 일반 화면 글꼴 통일 및 기존 출력/서명 전용 글꼴 유지
- Main: 공지사항 1/3 + 캘린더 영역 2/3
- Main 캘린더 내부: 캘린더 2/3 + 주요일정 1/3
- 주요일정: 등록/수정/삭제, 빨간 점, 상세 팝업, 전체현장 공유
- 캘린더/주요일정 사이 연한 세로 경계선이 데이터 유무와 무관하게 아래까지 유지
- 날짜 입력: `yy-mm-dd`, 한글 캘린더
- 월 선택: `yyyy년 m월`, 한글 월 선택판
- 기존 출력일보/공정/기성/지출결의서 저장 기능 정상

## 4. Git 반영

`npm run build`와 화면 확인이 끝난 뒤 아래 파일만 반영합니다. **git add . 사용 금지**.

```powershell
git status
git add src/Dashboard.jsx
git add src/theme.js
git add src/main.jsx
git add src/components/KoreanDatePicker.jsx
git add src/components/KoreanMonthSelect.jsx
git add src/page/DailyReport.jsx
git add src/page/DrawingQuantityAnalysis.jsx
git add src/page/ExpenseResolution.jsx
git add src/page/LaborContractManagement.jsx
git add src/page/LaborCostManagement.jsx
git add src/page/MainDashboard.jsx
git add src/page/MaterialInputStatus.jsx
git add src/page/OrganizationChart.jsx
git add src/page/ProgressClaimManagement.jsx
git add src/page/ProgressInput.jsx
git add src/page/ProposalReportEditor.jsx
git add src/page/UserManagement.jsx
git add src/page/WeeklyOverviewArchive.jsx
git commit -m "deploy: v52.01 through v52.06 cumulative"
git push origin main
```

그 뒤 Vercel Production이 새 커밋을 가져와 `Ready`가 되는지 확인하고 실제 운영 화면을 검증합니다.
