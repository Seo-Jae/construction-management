# v52.19 변경내용

## 1. App 전체 remount 방지

### 확인된 원인
기존 `App.jsx`는 `supabase.auth.onAuthStateChange()`가 실행될 때마다
`fetchProfile()`을 일반 로딩 방식으로 호출했습니다.

`fetchProfile()`은 `profileLoading=true`를 만들고,
App은 `profileLoading` 동안 `<LoadingScreen />`만 반환했습니다.

따라서:
1. Dashboard unmount
2. 모든 하위 업무 컴포넌트 unmount
3. 프로필 조회 완료
4. Dashboard 재생성
5. React 메모리 state 초기값 복원

순서가 발생할 수 있었습니다.

### v52.19
- 정상 프로필이 이미 있으면 프로필 재조회는 silent
- TOKEN_REFRESHED + 기존 프로필이면 불필요한 프로필 조회 생략
- silent 조회의 일시적 네트워크 오류는 기존 정상 프로필 유지
- `profileLoading && !userProfile`일 때만 전체 LoadingScreen 사용
- 계정이 실제 비활성/삭제된 경우의 차단 로직은 유지
