# v52.48.5.44.33 변경내용

## 세대물량관리

- 선택된 공정 탭의 파란 밑줄을 탭 자체 하단 테두리로 변경했습니다.
  - 브라우저 및 Windows 화면 배율 조합에서 밑줄이 옆으로 밀려 보이는 현상을 방지합니다.
- 화면의 `단열 기준` 열 제목을 `기본옵션`으로 변경했습니다.
  - 단열 공정은 실제 단열 옵션명을 표시합니다.
  - 단열 이외 공정은 `-`를 표시합니다.
- 내려받는 세대물량 Excel의 `단열 기준` 열 제목도 `기본옵션`으로 통일했습니다.
  - 단열 공정은 실제 단열 옵션명을 기록합니다.
  - 단열 이외 공정은 `-`를 기록합니다.

## 데이터베이스

- 새로 실행할 Supabase SQL은 없습니다.
