# v52.11 변경내용

## 1. 역할과 메뉴 표시 분리

기존에는 `담당자 / 관리자 / 최고관리자` 역할이 Sidebar 메뉴 표시와 강하게 결합되어 있었습니다.
특히 Dashboard는 `관리자 이상`이라는 하드코딩 때문에 회원관리에서 Dashboard 조회권한을 추가해도 화면에 나타나지 않았습니다.

v52.11부터 메뉴의 `조회` 여부는 다음 순서로 결정합니다.

1. 회원의 권한 템플릿 기본값
2. 모든 접근현장 공통 `추가 / 차단`
3. 현장별 `추가 / 차단`
4. 최고관리자는 기존처럼 전체 허용

따라서 담당자 역할을 그대로 유지한 상태에서 필요한 메뉴만 추가할 수 있습니다.

## 2. Dashboard 권한

- 현장 담당자 계열 템플릿은 기존 화면처럼 Dashboard가 기본 숨김입니다.
- 최고관리자가 회원관리에서 `공사일보·공정 > Dashboard > 조회 > 추가`를 선택하면 담당자에게도 Dashboard가 표시됩니다.
- 현장별로 추가한 경우 Dashboard에는 해당 권한이 허용된 접근현장만 표시합니다.

## 3. 관리자 = 전체현장 문제 수정

기존 Dashboard.jsx는 역할이 `관리자`이면 `building_settings`에서 모든 현장을 읽어 현장 선택목록에 넣었습니다.

v52.11부터 현장 목록은 역할이 아니라 회원관리의 `접근현장` 설정을 사용합니다.

- 소속현장: 해당 현장만
- 선택현장: 선택된 현장만
- 전체현장: 전체현장으로 지정된 계정만

따라서 메뉴 하나를 보기 위해 역할을 관리자로 올려도 자동으로 모든 현장이 보이는 구조를 제거했습니다.

## 4. 회원관리 세부권한 UI

기존에는 `결재 / 기성관리 / 공통·조직 / 공사일보·공정 ...` 권한이 한 번에 길게 펼쳐졌습니다.

v52.11부터:
- 각 권한 그룹 기본 접힘
- 우측 `펼치기 / 접기` 버튼
- 그룹별 메뉴 개수 표시
- 현재 선택 범위에서 개별 추가/차단 설정이 있으면 건수 표시
- 펼친 그룹에서 기존 상속/추가/차단 기능 그대로 사용

## 5. 기존 기능 보존

- 최고관리자 전용 회원관리 유지
- 역할/직급/조직구분 저장 유지
- 접근현장/기간 설정 유지
- 권한 템플릿 유지
- 세부권한 공통/현장별 추가·차단 유지
- 특수권한 유지
- 권한 변경이력 유지
- 메신저 v52.10.2 기능 변경 없음

## 범위 주의

이번 버전은 `조회(view)` 권한을 실제 메뉴 노출과 화면 진입에 연결하는 단계입니다.
작성/수정/삭제/다운로드 같은 세부 동작권한은 기존 DB 설정을 그대로 보존하지만, 모든 개별 페이지 버튼을 전부 세부권한에 연결하는 작업은 별도 단계입니다.
