# v52.11 적용방법

기준: Production/로컬 소스 v52.10.2

## 1. Supabase SQL 먼저 실행

Supabase SQL Editor에서 아래 파일을 처음부터 끝까지 전체 실행합니다.

`release_v52.11/Supabase에서_실행/00_v52.11_권한런타임_메뉴현장분리.sql`

이 SQL은 기존 회원권한 데이터를 삭제하지 않습니다.

추가 내용:
- 현재 로그인 사용자의 실제 권한 템플릿/추가·차단/접근현장을 읽는 `get_my_runtime_access_v2()` RPC
- 현장 담당자 계열 템플릿의 Dashboard 기본 노출을 기존 화면 기준으로 유지(기본 숨김)
- 필요한 담당자는 회원관리에서 Dashboard > 조회를 `추가`로 지정 가능

## 2. 프로그램 적용

ZIP을 `package.json`이 있는 프로젝트 최상위에 풉니다.

```powershell
node .\release_v52.11\apply-v52.11-permission-runtime.cjs
npm run build
```

적용 파일:
- `src/Dashboard.jsx`
- `src/components/Sidebar.jsx`
- `src/page/UserManagement.jsx`

적용 전 현재 3개 파일의 SHA256을 검사합니다. 예상 버전과 다르면 기존 기능 보호를 위해 적용을 중단합니다.

## 3. 우선 테스트

1. 최고관리자로 회원관리 진입
2. 담당자 계정 선택
3. 세부권한 > `공사일보·공정` 펼치기
4. Dashboard > 조회를 `추가`로 지정
5. 저장
6. 해당 담당자 계정에서 새로고침 또는 창 포커스 후 Dashboard 메뉴 표시 확인
7. Dashboard에서 그 회원에게 허용된 현장만 표시되는지 확인
8. 담당자를 관리자 역할로 바꾸더라도 `접근현장` 설정이 1개라면 다른 현장이 노출되지 않는지 확인

## 4. Git

빌드와 화면 테스트가 정상인 경우에만 변경 파일 3개를 추가합니다.

```powershell
git add src/Dashboard.jsx
git add src/components/Sidebar.jsx
git add src/page/UserManagement.jsx
git status
```

`git add .`은 사용하지 않습니다.
