# v52.26 적용방법

## 목적
작업자 출·퇴근 앱을 재설치하거나 카메라 권한이 초기화/차단된 경우
QR 촬영 화면이 검게 멈추는 UX를 방지합니다.

## 변경 동작

### 권한이 아직 정해지지 않은 경우
`출·퇴근 QR 촬영`
→ `카메라 권한 필요`
→ `카메라 사용 허용`
→ Chrome/Safari 카메라 시스템 권한창
→ `허용`
→ QR 촬영

### 권한이 이미 허용된 경우
`출·퇴근 QR 촬영`
→ 바로 카메라 실행

### 권한이 차단된 경우
검은 카메라 화면을 열지 않고
`카메라 권한이 현재 차단되어 있습니다` 안내를 표시합니다.

Android:
- Chrome 설정 → 사이트 설정 → 카메라 → 해당 사이트 → 허용
- 필요 시 휴대폰 설정 → 앱 → Chrome → 권한 → 카메라 → 허용

## SQL
SQL 변경 없음.

## 적용

```powershell
node .\release_v52.26\apply-v52.26-worker-camera-permission.cjs
```

`[v52.26 적용 완료]` 확인 후:

```powershell
npm run build
```

## Git

실제 변경 파일은 1개입니다.

```powershell
git add src/page/AttendanceWorkerPortal.jsx
git status
git commit -m "v52.26 improve worker camera permission flow"
git push origin main
```

`git add .`은 사용하지 않습니다.

## 배포 후 테스트

### 테스트 A — 정상 권한
1. 기존 카메라 허용 상태
2. QR 촬영 클릭
3. 바로 후면 카메라가 열리는지 확인

### 테스트 B — 권한 초기화
1. Chrome 사이트 카메라 권한 초기화
2. QR 촬영 클릭
3. `카메라 권한 필요` 안내창 확인
4. `카메라 사용 허용` 클릭
5. Chrome 시스템 권한창에서 허용
6. QR 촬영 정상 확인

### 테스트 C — 권한 차단
1. 해당 사이트 카메라 권한을 차단
2. QR 촬영 클릭
3. 검은 카메라 화면이 열리지 않아야 함
4. 권한 복구 안내가 표시되어야 함
