# v52.16 적용방법

기준 운영본: v52.14.9 Production

> v52.15 메신저 전체메시지 기능은 `AttendanceManagement.jsx`를 수정하지 않으므로 v52.15를 먼저 적용한 상태에서도 v52.16을 그대로 적용할 수 있습니다.

## 1. Supabase SQL
SQL Editor에서 다음 파일을 전체 실행합니다.

`release_v52.16/Supabase에서_실행/00_v52.16_근태_근로자관리_가입삭제.sql`

성공 시 마지막 조회 결과에 다음 두 함수가 표시됩니다.
- `attendance_manager_delete_worker_v52_16`
- `attendance_manager_list_workers_v52_16`

## 2. 프로그램 적용
프로젝트 최상위 PowerShell:

`node .\\release_v52.16\\apply-v52.16-attendance-worker-management.cjs`

적용 스크립트는 현재 `src/page/AttendanceManagement.jsx`가 v52.14.9 Production 기준 파일인지 Git blob SHA로 확인한 후 자동 백업하고 교체합니다.

## 3. 빌드
`npm run build`

## 4. 확인
- 근태관리 탭 순서: `... 기기 변경 / 변경 이력 / 근로자 관리 / 출·퇴근 QR`
- 근로자 관리에서 가입일시가 표시되는지
- 테스트계정 삭제가 가능한지
- 삭제 직후 기존 근로자 세션이 끊기는지
- 삭제한 휴대폰번호로 다시 가입 가능한지
- 같은 휴대폰 기기에서도 다시 가입 가능한지
- 변경 이력에 `근로자 가입내역 삭제`가 남는지

## 5. Git
이번 v52.16 프로그램 변경 파일은 1개입니다.

`git add src/page/AttendanceManagement.jsx`

`git add .`은 사용하지 않습니다.
