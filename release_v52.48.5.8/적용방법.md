# v52.48.5.8 적용 방법

이 패키지는 `v52.48.5.7`이 적용된 프로젝트를 기준으로 합니다.

ZIP 안의 `release_v52.48.5.8` 폴더를 프로젝트 최상위 폴더에 복사합니다. 프로젝트 최상위는 `package.json`과 `src` 폴더가 보이는 위치입니다.

PowerShell에서 다음 명령을 순서대로 실행합니다.

```powershell
node .\release_v52.48.5.8\apply-v52.48.5.8-worker-language.cjs
npm run build
git add src/page/AttendanceWorkerPortal.jsx
git status
git commit -m "v52.48.5.8 add language selector to worker header"
git push origin main
```

이번 버전은 추가 Supabase SQL이 없습니다.

## 배포 후 확인

- Vercel Production이 `Ready`인지 확인합니다.
- 근태 앱을 완전히 종료한 뒤 다시 실행합니다.
- 작업자 로그인 후 우측 상단에서 `Language`가 나가기 버튼 왼쪽에 표시되는지 확인합니다.
- 6개 언어를 각각 선택할 수 있는지 확인합니다.
- 선택 즉시 작업자 화면의 고정 문구가 변경되는지 확인합니다.
- 앱을 종료했다가 다시 열어도 선택 언어가 유지되는지 확인합니다.
- 언어 선택과 나가기 버튼이 겹치지 않는지 확인합니다.

앱 재설치는 필요하지 않습니다.
