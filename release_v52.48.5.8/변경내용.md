# v52.48.5.8 변경 내용

## 로그인 후 Language 선택 추가

- 로그인된 작업자 화면 우측 상단에 `Language` 선택 메뉴를 추가했습니다.
- 요청한 대로 나가기 버튼 바로 왼쪽에 배치했습니다.
- 한국어, English, 中文, Tiếng Việt, Русский, Монгол을 선택할 수 있습니다.
- 언어를 선택하면 작업자 화면의 제목, 상태, 달력, 출퇴근 문구, QR 버튼과 기존 고정 번역 문구가 즉시 변경됩니다.
- 선택한 언어는 기존 방식대로 저장되어 앱을 다시 열어도 유지됩니다.
- 좁은 휴대폰에서도 언어 선택과 나가기 버튼이 겹치지 않도록 상단 제목 영역의 축소·말줄임 처리를 보완했습니다.

관리자가 직접 작성한 중점위험요인과 공지사항 본문은 작성된 원문 그대로 표시됩니다.

이번 버전은 UI 변경만 포함하므로 추가 Supabase SQL은 없습니다.
