v52.48.5.42.1 - 출력일보 Excel 보완

[변경사항]
1. 출력일보 금월 다운로드의 날짜별 Excel 시트 탭 중 일요일을 빨간색으로 표시합니다.
2. 전일누계는 해당 월 안에서만 계산하지 않고, 선택 일자 이전에 저장된 전체 출력일보 데이터를 분석하여 공종별 누계를 계산합니다.
   - 월이 바뀌어도 누계가 0으로 초기화되지 않습니다.
   - 예: 9월 1일의 전일누계는 8월까지 저장된 출력일보 누계를 이어받습니다.
3. 기존 출력일보 양식, 근로자 목록, 오늘/누계 수식, 미래월 빈양식 다운로드 기능은 유지합니다.
4. SQL 변경은 없습니다.

node release_v52.48.5.42.1/apply-v52.48.5.42.1-daily-report-excel.cjs
