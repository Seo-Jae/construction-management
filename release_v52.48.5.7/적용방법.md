# v52.48.5.7 적용 방법

이 패키지는 `v52.48.5.6`이 적용된 프로젝트를 기준으로 합니다.

ZIP 안의 `release_v52.48.5.7` 폴더를 프로젝트 최상위 폴더에 복사합니다. 프로젝트 최상위는 `package.json`과 `src` 폴더가 보이는 위치입니다.

PowerShell에서 다음 명령을 순서대로 실행합니다.

```powershell
node .\release_v52.48.5.7\apply-v52.48.5.7-work-assignment-scale.cjs
npm run build
git add src/components/AttendanceWorkAssignmentDialog.jsx
git status
git commit -m "v52.48.5.7 enlarge attendance work assignment screen"
git push origin main
```

이번 버전은 추가 Supabase SQL이 없습니다.

- Vercel Production이 `Ready`인지 확인합니다.

- 출근 QR을 촬영해 `오늘 작업정보 입력` 화면을 확인합니다.
