# v52.48.5.7 변경 내용

## 출근 작업정보 화면 비율 재조정

화면 폭만 넓고 내부 요소가 작아 보이던 부분을 다시 수정했습니다.

- 제목을 로그인 화면에 가까운 크기로 확대하고 시작 위치를 아래로 조정
- 부제목과 출근 처리 안내문 글자 확대
- `기타 작업위치` 체크박스와 문구 확대
- 작업 동·작업 층·작업 공정 선택값 글자 확대
- 선택 항목 사이의 세로 간격 확대
- 드롭다운을 펼쳤을 때 표시되는 선택 목록도 확대
- 취소·출근 완료 버튼을 로그인 버튼에 가까운 높이와 글자 크기로 확대

선택 박스의 폭만 키우는 방식이 아니라 화면 전체의 글자와 세로 비율을 조정했습니다.

이번 버전은 UI 조정만 포함하므로 추가 Supabase SQL은 없습니다.
