# v51.87 변경내용

- 지출결의서 작성 화면 상단에 `엑셀 다운로드` 버튼을 추가했습니다.
- 저장 전 현재 작성 중인 내용도 엑셀로 만들 수 있습니다.
- 사용자가 제공한 2개 시트 원본 양식을 템플릿으로 포함했습니다.
- 1번 시트 갑지에 날짜, 항목별 내용, 금액, 합계, 청구일, 영수자를 자동 반영합니다.
- 유류대는 갑지에 `출발지→도착지 도착시간` 형식으로 출력합니다.
- 같은 날짜의 서로 다른 지출항목은 가능한 한 같은 갑지 행에 배치합니다.
- 2번 시트 상세내역의 달력 날짜를 작성월 기준으로 자동 생성합니다.
- 유류대는 상세내역에 `출발지→도착지(유류비)`만 표시합니다.
- 상세내역 유류대에는 이동거리, 금액, 도착시간을 표시하지 않습니다.
- 6주가 필요한 달도 마지막 날짜까지 출력하도록 6주차 영역을 자동 구성합니다.
- 엑셀 기능은 버튼을 누를 때만 로드하여 지출결의서 화면의 최초 로딩 부담을 줄였습니다.
- DB 및 Supabase 함수 변경은 없습니다.
