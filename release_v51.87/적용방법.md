# 지출결의서 작성 v51.87 적용방법

## 적용 대상

지출결의서 작성 v51.86이 적용된 프로젝트를 기준으로 합니다.
이번 버전은 현재 작성 내용을 원본 2시트 엑셀 양식으로 생성하는 기능을 추가합니다.
DB 변경은 없습니다.

## 1. 압축 해제

ZIP 파일을 프로젝트 최상위 폴더에 압축 해제합니다.
프로젝트 최상위 폴더는 `package.json`, `src`, `public` 폴더가 있는 위치입니다.

## 2. 소스 적용

프로젝트 최상위 폴더의 터미널에서 실행합니다.

```bash
node .\release_v51.87\apply-v51.87-expense-resolution.cjs
```

아래 파일은 수정 전에 자동 백업됩니다.

- `src/page/ExpenseResolution.jsx`
- `src/utils/expenseResolutionExcel.js` — 기존 파일이 있을 때
- `public/templates/expense-resolution-template.xlsx` — 기존 파일이 있을 때

> 이번 버전은 Supabase SQL을 실행하지 않습니다.

## 3. 빌드 확인

```bash
npm run build
```

## 화면 사용방법

1. `업무보고관리 > 지출결의서 작성`에서 신규 또는 기존 문서를 엽니다.
2. 좌측에 작성월, 청구일, 영수자와 사용내역을 입력합니다.
3. 상단의 `엑셀 다운로드` 버튼을 누릅니다.
4. 저장 전 작성 중인 내용도 바로 엑셀로 만들 수 있습니다.

## 엑셀 반영 규칙

### 1번 시트 — 갑지

- 시트명: `(MM월)갑지`
- 날짜는 `MM-DD`로 표시
- 유류대: `출발지→도착지 도착시간`
- 유류대와 통행료는 내용과 금액을 함께 반영
- 접대비, 숙박비, 잡자재, 우편·택배비, 기타는 해당 금액 칸에 반영
- 항목별 합계와 총합계 자동 계산
- 청구일과 영수자 자동 반영

같은 날짜의 서로 다른 항목은 가능한 한 같은 행에 배치합니다.
갑지의 출력 행이 40행을 초과하면 다운로드를 중단하고 안내문을 표시합니다.

### 2번 시트 — 상세내역

- 시트명: `(MM월)상세내역`
- 작성월에 맞춰 달력 날짜 자동 배치
- 6주가 필요한 월도 자동 지원
- 유류대는 `출발지→도착지(유류비)`만 표시
- 유류대의 이동거리, 금액, 도착시간은 상세내역에 표시하지 않음
- 그 외 지출은 `사용내용(지출항목)` 형식으로 표시

## 확인 항목

1. 상단에 `엑셀 다운로드` 버튼이 표시되는지
2. 버튼을 누르면 `.xlsx` 파일이 다운로드되는지
3. 파일명이 `YYYY년_MM월_지출결의서_현장명_영수자.xlsx`인지
4. 두 시트명이 선택한 작성월로 변경되는지
5. 갑지 유류대에 출발지, 도착지, 도착시간이 표시되는지
6. 상세내역 유류대에는 출발지, 도착지, 항목만 표시되는지
7. 항목별 합계와 전체 합계가 화면 금액과 일치하는지
8. 6주 달력 월의 마지막 날짜가 누락되지 않는지
