# v52.15 변경내용

기준 운영버전: **v52.14.9 Production 배포 완료 상태**

## 메신저 전체 메시지 전송

- 메신저 별도창 좌측 상단의 `새 대화(+)` 버튼 옆에 **전파 아이콘**을 추가한다.
- 전파 아이콘은 모든 활성 사용자에게 표시되며 역할 제한이 없다.
- 클릭하면 `전체 메시지 전송` 창이 열린다.
- 수신자 목록은 기존 메신저 사용자 목록 RPC를 사용한다.
- 본인을 제외한 활성 가입 사용자가 기본적으로 **전원 선택**된다.
- 사용자는 개별 체크박스를 눌러 수신자를 제외/재선택할 수 있다.
- 표 상단은 `No. / 이름` 두 구분으로 구성한다.
- `No.` 헤더의 체크박스로 전체 선택/전체 해제가 가능하다.
- 행의 좌측에는 체크박스와 순번, 우측에는 이름이 표시된다.
- 선택 인원 수를 상단에 표시한다.
- 메시지는 최대 4,000자까지 작성할 수 있다.
- 전송 전 `선택한 N명에게 동일한 메시지를 전송할까요?` 확인창을 표시한다.

## 전송 방식

전체 메시지는 별도의 공개 그룹방을 만들지 않는다.
선택한 각 사용자와의 **기존 1:1 대화방을 재사용**하고, 방이 없으면 자동으로 생성한 뒤 동일한 메시지를 각각 전송한다.

따라서:

- 수신자끼리 서로의 명단을 볼 수 없다.
- 수신자가 답장하면 발신자와의 1:1 대화로 답장이 온다.
- 기존 읽음/안읽음 처리와 새 메시지 알림 구조를 그대로 사용한다.
- 기존 1:1/그룹/공지/파일/이미지/방장 기능은 변경하지 않는다.

## 권한

`messenger_broadcast_text_message(uuid[], text)` RPC는 **활성 로그인 사용자라면 역할과 무관하게 실행 가능**하다.
최고관리자/관리자/담당자/안전관리자 등 역할에 따른 추가 제한은 없다.
