# v52.14.1 근태관리 긴급보완

## 근로자 가입

- 한글 IME 조합 중 자음·모음이 삭제되던 문제 수정
- 이름은 입력 중 강제변환하지 않고 가입 신청 시 한글 2~10자 검증
- 소속업체 입력과 화면 표시 제거
- `외국인 근로자입니다` 아래에 임시 `테스트계정입니다` 선택 추가
- 테스트계정 선택 시 비밀번호와 비밀번호 확인을 자동으로 `1`로 설정
- 테스트계정 비밀번호 안내 알림 표시
- 담당자 가입 승인 목록에 테스트계정 표시

## 출·퇴근 QR 보안

- 근태관리 탭 순서를 `가입 승인 → 근태 기록 → 기기 변경 → 변경 이력 → 출·퇴근 QR`로 변경
- 출·퇴근 QR 탭 선택 시 확인 후 QR 전용 새 창 실행
- QR 창 생성 성공 후 원래 담당자 화면 자동 로그아웃
- QR 전용 창에서는 회원정보·근태기록·승인·수정 메뉴 미노출
- 관리자 로그인 대신 서버가 발급한 현장 전용 표시 토큰 사용
- QR 표시 세션 유효시간 18시간
- 같은 현장에서 새 표시 세션을 열면 이전 표시 세션 자동 종료
- 기존 5초 QR 갱신·7초 서버 유효시간·30초 일회용 처리토큰 방식 유지

## 호환성

- v52.14가 먼저 적용된 프로젝트용 증분 보완판
- 기존 근로자와 근태 기록 유지
- DB의 기존 `company_name` 칸은 호환을 위해 빈값으로 유지하지만 사용자 화면에서는 사용하지 않음
- 신규 npm 패키지 없음
