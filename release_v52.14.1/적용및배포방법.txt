[사내시스템 v52.14.1 근태관리 긴급보완]

전제조건
- v52.14 근태관리 v1이 먼저 적용되어 있어야 합니다.
- ZIP을 프로젝트 최상위 폴더에 풀어 release_v52.14.1 폴더가 보이게 합니다.

1. Supabase SQL 먼저 실행

Supabase Dashboard > SQL Editor에서 아래 파일 전체를 실행합니다.

release_v52.14.1\Supabase에서_실행\00_v52.14.1_근태관리_긴급보완.sql

2. 프로젝트 코드 적용 및 빌드

프로젝트 최상위 폴더 PowerShell에서 실행합니다.

node .\release_v52.14.1\apply-v52.14.1-attendance-hotfix.cjs
npm run build

3. GitHub 반영 및 Vercel 운영 배포

git add src/App.jsx src/Dashboard.jsx src/page/AttendanceManagement.jsx src/page/AttendanceWorkerPortal.jsx src/page/AttendanceQrDisplay.jsx src/utils/attendance.js
git commit -m "v52.14.1 attendance signup and secure qr display"
git push origin main

git push가 완료되면 Vercel 자동 배포가 시작됩니다.
Vercel > Deployments에서 해당 커밋이 Ready가 되면 운영 주소에서 확인합니다.

4. 운영 확인 순서

1) 정적 QR로 근로자 가입 화면 접속
2) 이름(한글)에 실제 한글 이름 입력 확인
3) 테스트계정입니다 선택 후 비밀번호 1 안내 확인
4) 현장담당자가 가입 승인
5) 근태관리의 마지막 출·퇴근 QR 탭 클릭
6) 자동 로그아웃 확인창에서 확인 선택
7) 새 QR 전용 창 실행 및 원래 담당자 화면 로그아웃 확인
8) 테스트계정 휴대폰에서 휴대폰번호와 비밀번호 1로 로그인
9) QR 촬영 후 출근 처리, 다시 촬영해 퇴근 처리 확인

주의
- 출·퇴근 QR 탭을 누르면 보안을 위해 담당자 화면이 자동 로그아웃됩니다.
- 같은 현장에서 QR 창을 새로 열면 기존 QR 창의 표시 세션은 종료됩니다.
- QR 표시 세션은 시작 후 18시간이 지나면 만료됩니다.
- SQL 실행 전 코드를 먼저 배포하면 신규 가입과 QR 전용 창이 작동하지 않습니다.
