# v52.48.5.18 변경내용

## 1㎡당 구성 항목

- 표 전체 글자 크기와 행 높이, 입력 박스 높이 및 내부 여백을 축소했습니다.
- 기존 `순서` 열의 행별 위·아래 버튼을 선택 체크박스로 변경했습니다.
- 표 상단에 `+ / − / ↑ / ↓` 아이콘을 배치했습니다.
  - `+`: 빈 항목 추가
  - `−`: 체크한 항목 삭제
  - `↑ / ↓`: 체크한 항목을 한 칸씩 이동
- 여러 항목을 함께 체크하면 선택된 항목을 동시에 삭제하거나 순서를 이동할 수 있습니다.
- 비고 우측의 행별 삭제 버튼과 불필요한 열을 제거했습니다.

## 상단 실행 영역

- 제목 아래 도움말 문구를 완전히 제거했습니다.
- `새 작성`, `저장`, `출력/PDF`, `Excel`, `새로고침`을 글자 없는 아이콘 버튼으로 변경했습니다.
- 위 기능을 제목 영역 우측에 모으고 새로고침을 가장 우측에 배치했습니다.
- 금액 요약 하단의 중복 실행 버튼을 제거했습니다.

## 데이터 영향

- 데이터베이스, 저장 형식, 계산식은 변경하지 않았습니다.
- SQL 실행이 필요하지 않습니다.
