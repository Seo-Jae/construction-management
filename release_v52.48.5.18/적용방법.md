# v52.48.5.18 적용방법

적용 기준은 `v52.48.5.17`입니다. 이번 버전은 `일위대가작성`의 화면 구성만 변경하며 SQL 실행은 필요하지 않습니다.

## 1. 코드 적용

프로젝트 최상위 폴더에서 압축을 해제한 뒤 PowerShell에서 실행합니다.

```powershell
node .\release_v52.48.5.18\apply-v52.48.5.18-unit-price-ui.cjs
npm run build
```

적용 스크립트는 기존 `src/page/UnitPriceAnalysis.jsx`를 자동 백업한 후 전체 교체합니다. 같은 버전을 다시 실행하면 이미 적용된 상태를 확인하고 종료합니다.

## 2. Git 반영

```powershell
git add src/page/UnitPriceAnalysis.jsx
git status
git commit -m "v52.48.5.18 refine unit price analysis UI"
git push origin main
```

배포 후 `자재관리 > 일위대가작성`에서 구성표의 체크박스와 상단 아이콘을 확인합니다.
