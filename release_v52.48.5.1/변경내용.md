# v52.48.5.1 변경내용

v52.48.5의 레이아웃 변경 내용은 그대로 유지합니다.

추가 수정은 적용스크립트 안정성입니다.

## v52.48.5 오류

휴대폰 입력칸과 비밀번호 입력칸의 일부 sx가 동일하여
`replaceUnique`가 2개를 발견하고 중단했습니다.

## v52.48.5.1

`replaceAfterAnchor`를 사용합니다.

- 휴대폰: placeholder 휴대폰번호 이후만 탐색
- 비밀번호: placeholder 비밀번호 이후만 탐색

따라서 동일 sx 코드가 여러 곳에 있어도 서로 잘못 수정하지 않습니다.

## 포함되는 UI 변경

- MobileShell 부모 강제 입력/버튼 크기 cleanLogin 제외
- 흰색 상태바
- 기존 scale 제거
- 좌측 뒤로가기
- W 로그인 세로 위치 재배치
- 서비스명 보조문구 제거
- 입력칸 위치 재조정
- 로그인/가입신청/관리자모드 위치 재배치
