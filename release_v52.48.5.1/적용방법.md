# v52.48.5.1 적용방법

v52.48.5에서 다음 오류가 난 경우 사용하는 수정본입니다.

```text
[v52.48.5 적용 중단]
휴대폰 실제 크기: 기준 코드가 2개 이상 발견되었습니다.
```

v52.48.5는 파일 저장 전에 중단되었으므로 복구 작업은 필요 없습니다.

## 수정점

기존에는 휴대폰 입력 스타일 조각 자체가 파일에 2개 존재해서 중단되었습니다.

이번에는:

- `placeholder="휴대폰번호"` 뒤의 스타일만 수정
- `placeholder="비밀번호"` 뒤의 스타일만 수정

하도록 각각 범위를 제한했습니다.

## 적용

```powershell
node .\release_v52.48.5.1\apply-v52.48.5.1-attendance-login-reference-hotfix.cjs
npm run build
```

## Git

```powershell
git add src/page/AttendanceWorkerPortal.jsx
git status
git commit -m "v52.48.5.1 rebuild attendance login layout"
git push origin main
```

`git add .`은 사용하지 않습니다.
