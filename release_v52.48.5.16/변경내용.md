# v52.48.5.16 변경내용

## 금월 투입현황 날짜 영역 고정

- 모든 달의 날짜 영역을 31칸으로 고정해 월 이동 시 표 너비가 변하지 않습니다.
- 28일로 끝나는 달은 다음 달 `1일·2일·3일`을 이어서 표시합니다.
- 윤년 2월은 다음 달 `1일·2일`, 30일로 끝나는 달은 다음 달 `1일`을 표시합니다.
- 다음 달 날짜는 `3/1` 형식으로 표시해 현재 달 날짜와 구분합니다.
- 다음 달 날짜에 해당하는 명단 셀은 회색으로 표시하고 근태 숫자를 출력하지 않습니다.
- 다음 달 날짜에 해당하는 소계 셀도 회색 빈칸으로 표시합니다.
- 해당 월로 이동하면 1일부터 정상 근태자료와 소계가 표시됩니다.
- 기존 명단 최하단 소계와 검색 결과 기준 계산은 그대로 유지합니다.

이번 버전은 프론트엔드 UI와 화면 계산만 변경하며 Supabase SQL 실행은 필요하지 않습니다.
