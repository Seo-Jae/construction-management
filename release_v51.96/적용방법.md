# v51.96 적용방법

프로젝트 최상위 폴더에서 PowerShell을 열고 아래 명령을 실행합니다.

```powershell
node .\release_v51.96\apply-v51.96-management-header.cjs
npm run build
```

빌드 완료 후 아래 항목을 확인합니다.

1. 좌측 상단 욱림 로고의 흰 배경이 없어지고 빨간 마크만 보이는지 확인
2. `공사 관리 ∨`를 누르면 `공사 관리`, `안전 관리` 선택 목록이 열리는지 확인
3. 관리영역을 선택하면 사이드 메뉴와 본문이 해당 영역으로 전환되는지 확인
4. 메뉴 접기·펼치기 버튼이 브랜드 영역 맨 오른쪽에 표시되는지 확인
5. 메뉴를 접으면 `〈`가 `〉`로 바뀌고 다시 펼칠 수 있는지 확인
6. 공사 관리로 복귀했을 때 직전에 보던 메뉴와 현장이 유지되는지 확인

이번 버전은 Supabase SQL 실행이 필요하지 않습니다.
