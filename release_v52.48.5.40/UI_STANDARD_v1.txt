욱림건설 통합관리시스템 공통 UI v1 / v52.48.5.40

[적용 범위]
- 내부 업무화면 전체(.wooklim-admin-ui)
- 로그인 화면과 근로자 전용 근태 포털은 제외

[공통 규격]
- 페이지 제목: 18px / 700
- 섹션 제목: 13px / 700 기준
- 본문: 12px 기준
- 보조 설명: 11px 기준
- 기본 버튼/입력/토글 높이: 30px
- 탭 높이: 32px
- 카드/박스 모서리: 4px
- 카드 테두리: #d8e0ea
- 강한 테두리: #cbd5e1
- 카드 그림자: 기본 제거
- 상태 Chip: 22px 높이 / 4px 모서리
- 표 헤더: #f8fafc 배경 + 700 굵기

[도움말 규칙]
- 상시 노출되는 메뉴 설명문은 페이지 제목 옆 원형 느낌표 아이콘으로 이동
- 마우스 hover: Tooltip
- 클릭: 상세 Popover
- 동적 상태/건수/최종수정시각 등은 짧은 meta로 제목 아래 유지 가능

[1차 대표 적용]
- 회원관리
- 결재함
- 욱림건설 조직도
- 조직도 좌측 '조직' 장식 배지 제거

[안전 규칙]
- 기존 기능/DB/권한/계산 로직 변경 없음
- 기존 파일은 적용 직전 자동 백업
- 예상 코드가 다르면 적용 중단
