v52.48.5.33 기술자료 편집기 v1.1

기준:
- v52.48.5.32 배포본 이후에 적용합니다.
- 기존 일위대가 계산/버전관리/기술자료 이미지/권한은 변경하지 않습니다.
- SQL 변경 없음.

추가:
1) 신규 지시선 기본 각도 = 90° 직교
2) 지시선 각도 선택 = 30° / 60° / 90°
3) 지시선 시작 위치 = 자동 / 왼쪽 / 오른쪽 / 위 / 아래
4) 명칭 방향 = → 오른쪽 / ← 왼쪽
5) 명칭의 좌표는 '전체 라벨 중앙'이 아니라 '번호 원 중심'을 기준으로 저장/표시
6) 새 항목은 화면 왼쪽에 놓으면 명칭이 오른쪽으로, 화면 오른쪽에 놓으면 왼쪽으로 자동 전개
   - 예: 7. AL MOULDING을 좌측 끝에 두더라도 명칭이 이미지 안쪽으로 들어오도록 동작
7) 일반 기술자료 상세보기에도 동일한 30/60/90도 및 시작/명칭 방향이 반영

적용:
node release_v52.48.5.33/apply-v52.48.5.33-annotation-angle-and-anchor.cjs

확인:
npm.cmd run build

배포:
git add src/utils/technicalImageAnnotations.js
git commit -m "v52.48.5.33 기술자료 지시선 각도 및 시작방향 개선"
git push origin main
