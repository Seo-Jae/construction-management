# v52.29 변경내용

## 1. 전일누계 규칙 수정
기존:
- 선택일 이전 전체 공사기간을 누적

변경:
- 선택일과 같은 연·월의 1일부터 전일까지 누적

예:
- 출력일 26.08.12
- 전일누계 대상 26.08.01 ~ 26.08.11

## 2. 직종명 최소 정규화

- 경량 → 경량벽체
- 경량골조 → 경량벽체
- 경량석고 → 경량벽체
- 천정 → 세대천정

## 3. process 보존
과거일보 업로드 시 구분(job)만 통합합니다.
원본 process가 있다면 그대로 저장합니다.

예:
- 원본 job: 경량석고
- 원본 process: 경량석고
- 저장 job: 경량벽체
- 저장 process: 경량석고
