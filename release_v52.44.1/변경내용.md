# v52.44.1 변경내용

## 1. 근로자 저장 오류 원인

현재 오류:

`function jsonb_object_length(jsonb) does not exist`

은 `근로자 조회 v52.44` 기능 자체에서 난 오류가 아닙니다.

근로자 정보 수정 시 호출되는
`labor_worker_master_secure_upsert_v52_41`
내부에서 `jsonb_object_length(v_payload)`를 호출하면서 발생했습니다.

즉, v52.44 적용 시점에 발견됐지만 실제 오류 위치는 v52.41 저장 RPC입니다.

## 2. 저장 오류 수정

기존 함수 전체를 다시 작성하지 않고
DB에 설치된 함수 정의를 `pg_get_functiondef()`로 가져옵니다.

그 중:

`jsonb_object_length(v_payload)`

만 다음 방식으로 교체합니다.

`case when v_payload = '{}'::jsonb then 0 else 1 end`

따라서 기존:
- 보호정보 AES256 암호화
- 기존 암호문 유지
- 필수정보 검증
- 국적 표준화
- 권한검사
- 감사로그

구조는 그대로 유지합니다.

## 3. 국적 Tab

기존 국적 Autocomplete는
`한국`을 입력하면 필터 결과로 `대한민국`을 보여주지만
첫 결과를 자동 선택 후보로 만들지 않았습니다.

추가:
- `autoHighlight`
- `autoSelect`

결과:

`한국 입력 → 대한민국 표시 → Tab → 대한민국 확정`

이 됩니다.

자유입력(`freeSolo`)은 사용하지 않습니다.

따라서 `한국`이라는 비표준 문자열이 DB에 그대로 저장되는 일은 없고
항상 `대한민국` 표준값으로 확정됩니다.

## 4. v52.44 복구

기존 v52.44 적용스크립트도 패키지에 포함했습니다.

v52.44가 이미 적용되어 있으면 건너뛰고,
적용 전이면 근로자 조회 전체목록/성명·공종 필터를 적용합니다.
