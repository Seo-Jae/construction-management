# v52.44.1 복구/핫픽스 적용방법

이번 버전은 v52.44 적용 중 확인된 두 문제를 함께 해결합니다.

1. 근로자 정보 수정 저장 오류
   - `function jsonb_object_length(jsonb) does not exist`
2. 국적 입력 후 Tab 미확정
   - `한국` 검색 시 `대한민국`은 나오지만 Tab을 누르면 선택되지 않음

또한 v52.44 프론트가 실제로 적용되지 않은 경우를 대비해
v52.44 근로자 조회 기능도 다시 적용/확인합니다.

## 1. Supabase SQL

반드시 아래 순서대로 실행합니다.

### 1-1. v52.44 조회 RPC

`release_v52.44.1/Supabase에서_실행/00_v52.44_근로자조회_전체목록_성명공종필터.sql`

이미 실행했다면 다시 실행해도 `create or replace` 방식이라 괜찮습니다.

### 1-2. 저장 오류 HOTFIX

`release_v52.44.1/Supabase에서_실행/01_v52.44.1_근로자저장_jsonb오류_핫픽스.sql`

이 SQL은 기존 v52.41 저장함수 전체를 새로 덮어쓰지 않습니다.

DB에 실제 설치된
`labor_worker_master_secure_upsert_v52_41`
정의를 읽어 `jsonb_object_length(v_payload)` 부분만 교체합니다.

기존 암호화, 권한, 필수정보, 국적 표준화 로직은 유지합니다.

## 2. VS Code 적용

프로젝트 최상위에서:

```powershell
node .\release_v52.44.1\apply-v52.44.1-recovery-hotfix.cjs
npm run build
```

## 3. 확인

### 근로자 정보관리 저장

근로자 정보 수정에서 값을 입력 후 저장합니다.

더 이상:

`function jsonb_object_length(jsonb) does not exist`

오류가 나오지 않아야 합니다.

### 국적 Tab

1. 국적 칸 클릭
2. `한국` 입력
3. 목록에 `대한민국` 표시
4. `Tab`
5. 국적값이 `대한민국`으로 확정
6. 포커스가 다음 `은행` 칸으로 이동

같은 방식으로:

- `China` → `중국`
- `Vietnam` → `베트남`

도 Tab으로 확정됩니다.

### v52.44 근로자 조회

`월별 노임작성 > 근로자 조회`

- 검색 없이 전체 목록 표시
- 성명 / 공종 버튼
- 검색
- 행 클릭 추가
- 이미 추가된 근로자 `추가됨`

확인합니다.
