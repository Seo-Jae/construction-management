# v52.48.5.28 변경 내용

## 가이드 문서명 저장

- 문서명이 비어 있는 상태에서 저장하면 가이드된 문서명을 표시합니다.
- `가이드된 명칭으로 저장할까요?` 안내창에서 `예 / 아니오`를 선택할 수 있습니다.
- `예`를 선택하면 화면의 가이드명이 실제 문서명으로 입력되고 저장됩니다.
- `아니오`를 선택하면 저장하지 않고 작성자가 직접 문서명을 입력할 수 있습니다.

## 버전 누적 관리

- `저장·공유` 목록의 작업 영역에 `버전 이력` 버튼을 추가했습니다.
- v1, v2, v3 등 저장 당시 스냅샷을 각각 확인하고 불러올 수 있습니다.
- 과거 버전을 불러와 수정한 뒤 저장해도 기존 버전은 변경되지 않습니다.
- 저장 시 현재 최신 버전 다음 번호로 새로운 버전이 추가됩니다.
- 편집 화면에 현재 불러온 버전과 저장될 다음 버전을 표시합니다.

기존 `unit_price_document_revisions` 스냅샷을 사용하므로 새 SQL은 없습니다.
