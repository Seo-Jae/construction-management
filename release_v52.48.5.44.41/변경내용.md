# v52.48.5.44.41 변경내용

- 합지도 단열과 동일하게 각 세대의 `타입 + 단열옵션` 조합을 기본 기준으로 사용합니다.
- 단열과 합지는 자동 기준을 유지하면서 `공정별옵션연결`에서 유상 선택옵션을 추가로 연결할 수 있습니다.
- 선택옵션 증감물량은 해당 옵션을 실제 선택한 세대에만 적용됩니다.
- 같은 타입 안에 단열옵션이 여러 종류여도 증감물량이 각 기본행에 중복 집계되지 않습니다.
- 기존 v40의 타입별 합지 기본물량은 새 단열옵션별 행의 초기값으로 승계됩니다.
- Excel 갑지에서도 단열·합지의 단열옵션별 기본행과 선택옵션 증감행을 함께 작성할 수 있습니다.
- `골구도보기`에서 빈 화면 또는 세대 영역을 마우스로 끌어 이동할 수 있습니다.
- 마우스 위치 기준 휠 확대·축소, 상단 `− / +`, 화면맞춤 기능을 추가했습니다.
- PDF와 인쇄 아이콘을 추가했습니다.
- 출력물은 A4 가로 방향이며 전체 동의 좌우 폭과 높이를 자동 축소해 한 장에 맞춥니다.

PDF 아이콘은 브라우저 출력창을 열며 `PDF로 저장`을 선택하면 됩니다.

Supabase SQL 변경은 없습니다.
