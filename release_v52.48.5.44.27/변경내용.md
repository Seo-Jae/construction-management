# v52.48.5.44.27 변경내용

## 옵션현황(선택) 표시 옵션 목록

- 화면 최상위 좌표를 사용하던 기본 팝업 목록을 선택박스 내부 기준의 로컬 목록으로 교체했습니다.
- 목록은 화면 크기나 시스템 배율과 관계없이 표시 옵션 선택박스 바로 아래에서 열립니다.
- `전체 옵션`을 포함해 최대 10행까지만 한 번에 표시합니다.
- 10행을 초과하는 옵션은 목록 내부 세로 스크롤로 확인합니다.
- 목록이 골구도 위에서 왼쪽으로 어긋나 표시되던 문제를 제거했습니다.
- 목록 바깥을 클릭하면 자동으로 닫힙니다.

## 골구도 셀 테두리

- 90% 화면에서 CSS 1px이 실제 0.9px로 환산되며 특정 누적 위치의 상단선이 진하게 보이던 문제를 보정했습니다.
- 시스템 배율에 맞춰 셀 테두리 두께를 역보정하여 최종 화면에서 항상 물리 1px로 표시합니다.
- 층 사이 행 간격도 동일하게 물리 1px로 맞췄습니다.
- 100% 화면과 인쇄에서는 기존 1px 기준을 유지합니다.
- 일반 세대 셀과 필로티 셀에 같은 테두리 기준을 적용했습니다.

데이터베이스 구조 변경은 없습니다.
