# v52.48.5.22 변경내용

## 팝업 높이 고정

- 자재 마스터 팝업의 목록 영역을 460px 고정 높이로 변경했습니다.
- 검색 전, 검색 결과가 많은 경우, 검색 결과가 없는 경우 모두 동일한 팝업 높이를 유지합니다.
- 검색 결과가 없으면 고정된 목록 영역 안에 안내 문구가 표시됩니다.

## 자재 포함 검색

- 대소문자를 구분하지 않습니다.
- 공백, 하이픈, 괄호, 기호를 제거한 뒤 포함 여부를 비교합니다.
- 품명·규격·자재코드를 하나의 검색 문자열로 연결합니다.
- 품명이 `C-STUD`이고 규격이 `50형`으로 나뉘어 있어도 `stud50`으로 검색됩니다.
- 영문 `stud`와 한글 `스터드`를 동일한 단어로 변환합니다.

검색 예시:

- `stud` → `C-STUD(30형)`, `C-STUD(50형)` 등
- `스터드` → `C-STUD` 계열
- `stud50` → `C-STUD(50형)`
- `스터드50형` → `C-STUD(50형)`

## 데이터 영향

- 데이터베이스와 저장 형식은 변경하지 않았습니다.
- SQL 실행이 필요하지 않습니다.
