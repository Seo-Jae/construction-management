# v52.44.2 적용방법

## 이번 오류의 원인

v52.44 기능 자체를 적용한 뒤 마지막 검증에서 아래 문자열을 찾도록 되어 있었습니다.

- `>성명<`
- `>공종<`

하지만 실제 생성된 JSX는 버튼 글자가 줄바꿈/들여쓰기된 형태라
`>성명<`이라는 연속 문자열이 존재하지 않습니다.

즉 실제 기능 패치는 메모리상 정상 생성됐는데,
마지막 검증조건이 잘못되어 파일을 쓰기 전에 중단된 것입니다.

그래서 Git에는 변경사항이 생기지 않았고
`no changes added to commit / Everything up-to-date`가 나온 것입니다.

## v52.44.2 수정

잘못된 표시문자 검사를 제거하고 실제 기능 구조를 검사합니다.

검사:
- `labor_worker_master_browse_v52_44`
- `lookupFilter`
- `등록 근로자 목록`
- `changeLookupFilter`
- `filter === 'trade'`

## 적용

이전에 아래 두 SQL을 둘 다 성공 실행했다면 다시 실행하지 않아도 됩니다.

아직 실행하지 않았거나 실패했다면 순서대로 실행:

1. `release_v52.44.2/Supabase에서_실행/00_v52.44_근로자조회_전체목록_성명공종필터.sql`
2. `release_v52.44.2/Supabase에서_실행/01_v52.44.1_근로자저장_jsonb오류_핫픽스.sql`

### VS Code

```powershell
node .\release_v52.44.2\apply-v52.44.2-recovery-hotfix.cjs
npm run build
```

정상 적용 시 최소한 다음 문구가 나와야 합니다.

- `v52.44.2-v52.44 적용 완료`
- `근로자 정보관리 국적 Tab 확정 적용` 또는 `이미 적용됨`
- `v52.44.2 적용 완료`

## 확인

1. 월별 노임작성 > 근로자 조회
   - 검색 없이 전체 목록
   - 성명 / 공종 버튼
   - 행 클릭 추가
2. 근로자 정보관리 > 수정
   - 저장 가능
   - `jsonb_object_length` 오류 없음
3. 국적
   - `한국` 입력
   - `대한민국` 표시
   - Tab
   - `대한민국` 확정 후 다음 칸 이동

## Git

git add src/page/WorkerMasterManagement.jsx
git status
