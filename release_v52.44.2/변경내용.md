# v52.44.2 변경내용

## 핵심 수정

v52.44 적용 실패 원인은 기능 코드가 아니라 적용스크립트의 마지막 검증문입니다.

잘못된 검증:
- `>성명<`
- `>공종<`

MUI JSX는 실제로 다음처럼 줄바꿈되어 생성됩니다.

```jsx
>
  성명
</Button>
```

따라서 `>성명<` 문자열은 존재할 수 없습니다.

## 수정된 검증

화면 글자의 줄바꿈에 영향을 받지 않는 실제 코드 구조를 검사합니다.

- browse RPC 연결
- lookupFilter state
- 목록 제목
- 필터 변경 함수
- trade 필터 분기

## 함께 유지되는 v52.44.1 수정

v52.44.2 wrapper는 다음도 계속 처리합니다.

- 근로자 저장 `jsonb_object_length` DB 핫픽스
- 국적 `한국 → 대한민국` 검색
- Tab 시 대한민국 자동선택
- 기존 암호화/보안 구조 유지
