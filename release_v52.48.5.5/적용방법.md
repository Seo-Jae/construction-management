# v52.48.5.5 적용 방법

이 패키지는 `v52.48.5.4`가 적용된 프로젝트를 기준으로 합니다.

## 1. Supabase SQL 먼저 실행

Supabase Dashboard → SQL Editor → New query에서 다음 파일의 전체 내용을 실행합니다.

```text
release_v52.48.5.5\Supabase에서_실행\00_v52.48.5.5_근태출근_작업정보.sql
```

실행 후 아래 두 결과표가 표시됩니다.

- `attendance_events` 신규 컬럼 5개
- 신규 RPC 3개

오류가 발생하면 코드 배포를 진행하지 말고 오류 화면을 그대로 전달해주세요.

## 2. 코드 적용

ZIP 안의 `release_v52.48.5.5` 폴더를 프로젝트 최상위 폴더에 복사합니다. 프로젝트 최상위는 `package.json`과 `src` 폴더가 보이는 위치입니다.

PowerShell에서 다음 명령을 순서대로 실행합니다.

```powershell
node .\release_v52.48.5.5\apply-v52.48.5.5-attendance-work-assignment.cjs
npm run build
git add src/page/AttendanceWorkerPortal.jsx src/components/AttendanceWorkAssignmentDialog.jsx src/utils/attendance.js src/utils/attendanceI18n.js
git status
git commit -m "v52.48.5.5 require work details before attendance check in"
git push origin main
```

## 3. 배포 후 확인

- Vercel Production이 `Ready`인지 확인합니다.
- 근태 앱을 완전히 종료한 뒤 다시 실행합니다.
- 회원가입 화면의 공정이 드롭다운인지 확인합니다.
- 승인된 작업자로 출근 QR을 촬영합니다.
- 가입 현장의 동과 선택 동의 층이 표시되는지 확인합니다.
- 공정 기본값이 가입 당시 공정인지 확인합니다.
- `기타 작업위치`를 선택하면 동·층이 사라지고 한 줄 입력란이 나타나는지 확인합니다.
- 작업정보 완료 후에만 출근시간이 생성되는지 확인합니다.
- 언어를 변경해 추가 화면과 공정 목록도 번역되는지 확인합니다.

앱 재설치는 필요하지 않습니다.
