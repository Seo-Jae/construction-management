# v52.48.5.5 변경 내용

## 이번 버전에서 적용한 범위

요청한 1~11번을 적용했습니다. 퇴근 시 골구도 작업완료를 제출하고 담당자 승인 후 진척도에 반영하는 12번은 이번 버전에 포함하지 않았습니다.

## 회원가입 공정 선택형

- 기존 자유입력 공정란을 선택형으로 변경했습니다.
- 기존 출력일보와 근태에서 사용하던 표준 목록을 사용합니다.
- 목록: 소장, 관리자, 직영, 먹매김, 단열, 합지, 경량벽체, 세대천정, 공용홀천정, 몰딩, 걸레받이, 수장, 외주, 기타, 용역
- 화면에는 선택한 언어로 번역해 표시하고, DB에는 기존 시스템 연결을 위한 한글 표준값으로 저장합니다.

## 출근 QR 이후 작업정보 입력

1. 근로자가 출근 QR을 촬영합니다.
2. 기존 방식대로 QR을 즉시 일회용 처리토큰으로 교환합니다.
3. 출근인 경우 작업정보 입력 화면을 표시합니다.
4. 근로자의 가입 현장에 등록된 `building_settings`에서 동과 지상층 수를 불러옵니다.
5. 동을 선택하면 해당 동의 1층부터 최고층까지만 선택할 수 있습니다.
6. 가입 시 선택한 공정이 기본값으로 들어가며 당일 공정으로 변경할 수 있습니다.
7. 작업정보를 완료한 시각에 출근이 확정됩니다.

작업정보 화면에서 취소하거나 서버 검증에 실패하면 출근기록은 생성되지 않습니다.

## 기타 작업위치

- `기타 작업위치`를 선택하면 동·층 선택란이 사라집니다.
- `예: 101동 지하 1층`과 같은 작업위치를 한 줄로 입력합니다.
- 기타 위치를 사용해도 공정 선택은 필수입니다.

## 서버 검증

- 가입한 현장의 골구만 반환합니다.
- 다른 현장의 동을 임의로 전송할 수 없습니다.
- 골구에 없는 동이나 최고층을 초과한 층은 저장할 수 없습니다.
- 표준 목록에 없는 공정은 가입 또는 출근정보로 저장할 수 없습니다.
- QR 교환 후 작업정보 입력 유효시간은 10분입니다.

## 고정 번역

추가된 제목, 안내, 동·층, 기타 위치, 공정 목록, 검증 메시지를 다음 언어로 제공합니다.

- 한국어
- English
- 中文
- Tiếng Việt
- Русский
- Монгол
