# 다음 단계: 퇴근 작업완료 제출과 진척도 승인

이번 v52.48.5.5에는 적용하지 않았습니다.

다음 단계에서는 다음 흐름으로 분리해 구현할 수 있습니다.

1. 퇴근 QR 촬영
2. 당일 출근 시 선택한 동·층·공정 표시
3. 해당 동·층의 골구도 표시
4. 작업자가 완료 세대를 선택해 제출
5. 제출자료를 `승인 대기` 상태로 저장
6. 현장담당자가 골구도에서 확인 후 승인 또는 반려
7. 승인한 세대만 `unit_progress`에 반영
8. 반려자료는 사유와 함께 작업자 제출함으로 반환

작업자 선택이 곧바로 진척도에 반영되지 않도록 승인 대기 테이블과 담당자 확인 화면을 별도로 두는 것이 핵심입니다.
