# v52.44 적용방법

## 변경 내용

`노임관리 > 월별 노임작성 > 근로자 조회`

기존:
- 성명 2자 이상 검색해야 결과 표시
- 검색하지 않으면 빈 화면
- 성명으로만 검색

변경:
- 조회창을 열면 등록 근로자 목록 즉시 표시
- `성명 / 공종` 버튼으로 조회 기준 선택
- 검색어 없이 전체 목록 조회
- 성명 검색 가능
- 공종 검색 가능
- 행 클릭으로 바로 추가
- 기존 `추가` 버튼도 유지
- 이미 이번 달 명단에 들어간 근로자는 `추가됨`

## 4. 확인방법

### 기본목록
1. 월별 노임작성 진입
2. `근로자 조회`
3. 아무것도 입력하지 않음
4. 기존 등록 근로자 목록이 바로 표시되어야 함

### 성명
1. `성명` 버튼 선택
2. `서재형` 또는 이름 일부 입력
3. 검색
4. 이름 기준 결과 표시

### 공종
1. `공종` 버튼 선택
2. 검색어가 자동으로 비워지고 전체 목록 표시
3. 목록은 공종 → 성명 순
4. `관리자`, `몰딩`, `세대천정` 등 입력 후 검색 가능

### 추가
- 근로자 행 자체 클릭 → 명단 추가
- `추가` 버튼 클릭 → 명단 추가
- 추가 후 팝업 유지
- 같은 근로자는 `추가됨`으로 표시되어 재추가 불가
