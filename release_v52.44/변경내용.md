# v52.44 변경내용

## 근로자 조회를 목록형으로 변경

조회 팝업을 열자마자 등록된 근로자를 보여줍니다.

기존처럼 검색을 반드시 먼저 해야 하는 구조를 제거했습니다.

## 조회 기준

상단 버튼:
- 성명
- 공종

`성명`:
- 전체 목록은 성명순
- 입력 시 성명 부분검색

`공종`:
- 전체 목록은 공종 → 성명순
- 입력 시 최근 공종 부분검색

조회 기준을 바꾸면 검색어를 비우고 전체목록을 새 기준으로 다시 표시합니다.

## 추가 방식

두 가지 모두 지원:
1. 목록 행 클릭
2. 우측 `추가` 버튼

추가 후 팝업은 닫히지 않습니다.

이미 현재 작성월 명단에 들어간 근로자는:
- `추가됨`
- 버튼 비활성
- 행 재클릭 추가 방지

## 신규 근로자

기존 `신규 근로자 등록` 기능을 유지합니다.

성명 검색 중 신규 등록을 누르면 검색어를 성명 초기값으로 전달합니다.

공종 검색 중에는 공종명을 성명으로 잘못 넘기지 않도록 성명 초기값을 비워서 신규등록 창을 엽니다.
