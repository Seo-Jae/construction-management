# v52.48.5.44.59 변경내용

## 편집 화면 ↔ 미리보기 ↔ 실제 가이드 비율 완전 통일
- 기존에는 표시 편집기가 `예상 팝업 폭`을 계산해 번호 원/설명박스 크기를 보정했습니다.
- 실제 가이드 창의 현재 폭, 브라우저 크기, 팝업 리사이즈 상태에 따라 실제 이미지 폭이 달라질 수 있어 미세한 크기 차이가 남았습니다.
- 이번 버전부터 **상세 가이드 이미지 1000px을 공통 기준 폭**으로 사용합니다.
- 표시 편집기, 가이드 설정 미리보기, 실제 공개 가이드가 모두 동일한 계산식을 사용합니다.
- 이미지가 커지거나 작아져도 번호 원/설명박스가 이미지와 같은 비율로 확대·축소됩니다.

## 실제 가이드 기준 유지
- 실제 공개 가이드에서 보이던 번호 원/설명박스의 가독성을 기준으로 잡았습니다.
- 약 1000px 폭의 상세 이미지에서는 기존 크기와 사실상 동일합니다.
- .57처럼 실제 가이드 표시를 편집기 크기에 맞춰 작게 만드는 방식은 사용하지 않습니다.

## 설명박스 렌더링 통일
- 가이드 설정 미리보기의 설명박스 글꼴/줄높이/여백을 편집기 및 공개 가이드와 동일하게 맞췄습니다.
- MUI Typography 기본 글꼴 차이로 발생하던 설명박스 폭 차이를 제거했습니다.

## DB
