# v52.48.5.4 적용 방법

이 패키지는 `v52.48.5.3`이 적용된 프로젝트를 기준으로 합니다.

## 1. 압축 해제

ZIP 안의 `release_v52.48.5.4` 폴더를 프로젝트 최상위 폴더에 복사합니다.

프로젝트 최상위 폴더는 `package.json`, `src` 폴더가 보이는 위치입니다.

## 2. PowerShell에서 적용

프로젝트 최상위 폴더에서 다음 명령을 순서대로 실행합니다.

```powershell
node .\release_v52.48.5.4\apply-v52.48.5.4-admin-ratio-language.cjs
npm run build
git add src/page/AttendanceWorkerPortal.jsx src/components/AttendanceMobileAdminQr.jsx src/utils/attendance.js src/utils/attendanceI18n.js
git status
git commit -m "v52.48.5.4 add attendance languages and expand admin ui"
git push origin main
```

적용 스크립트가 원본 파일을 자동 백업합니다. 파일 내용이 예상 버전과 다르면 기존 작업을 보호하기 위해 적용을 중단합니다.

## 3. 배포 확인

- Vercel 배포 상태가 `Ready`가 될 때까지 기다립니다.
- 설치형 앱을 완전히 종료한 뒤 다시 실행합니다.
- 앱 재설치는 필요하지 않습니다.
- SQL 실행도 필요하지 않습니다.

## 4. 확인 항목

- 로그인 화면 우측 상단에 `Language`가 표시되는지 확인합니다.
- 언어를 바꾸면 로그인 화면과 로그인 후 근태 화면 전체 문구가 바뀌는지 확인합니다.
- 관리자 모드 진입 시 입력창과 버튼이 로그인 화면과 비슷한 큰 비율로 표시되는지 확인합니다.
- 앱을 완전히 종료 후 다시 실행해도 선택한 언어가 유지되는지 확인합니다.
