# v52.48.5.4 변경 내용

## 1. 관리자 모드 화면 비율 확대

- 설치형 앱의 관리자 인증 화면과 QR 화면을 로그인 화면과 동일한 `90%` 폭으로 조정했습니다.
- 이전의 작은 카드 형태와 최대 폭 제한을 제거했습니다.
- 관리자 비밀번호 입력창, 시작 버튼, 제목과 안내 문구도 같은 비율에 맞게 확대했습니다.

## 2. 로그인 화면 언어 선택

- 로그인 화면 우측 상단에 영문 표기 `Language` 선택 메뉴를 추가했습니다.
- 선택 목록은 각 언어의 모국어 이름으로 표시됩니다.
  - 한국어
  - English
  - 中文
  - Tiếng Việt
  - Русский
  - Монгол
- 선택한 언어는 브라우저에 저장되어 앱을 다시 실행해도 유지됩니다.

## 3. 근태 앱 전체 화면 다국어화

- 로그인, 가입 신청, 관리자 모드, 출근·퇴근, 월간 근태, 공지, 위험 알림, 카메라 안내, 설치 안내와 오류 메시지를 선택 언어로 표시합니다.
- 현장명, 직원명, 공지 본문처럼 관리자가 직접 작성한 데이터는 입력한 원문 그대로 표시됩니다.
- 날짜와 시간 표기 방식도 선택 언어의 로케일을 따릅니다.
