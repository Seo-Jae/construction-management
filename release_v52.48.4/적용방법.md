# v52.48.4 적용방법

## 목표

근태앱 로그인 화면을
네이버 로그인 화면과 비슷한 비율로 다시 정렬합니다.

이번 버전은 기능을 바꾸는 것이 아니라:

- 좌우 여백
- 제목 위치
- 입력영역 폭
- 버튼 폭
- 전체 균형

을 네이버 화면에 더 가깝게 맞춥니다.

## 핵심 변경

- 기존 v52.48.3의 전체 확대 감은 유지
- 대신 로그인 블록의 layout width를 더 줄여
  좌우 여백을 네이버 화면처럼 확보
- 상단 시작점과 제목/입력 간격 재조정
- 서비스명 작은 문구 비중 축소

## 대상

설치형 근태앱의 `로그인 화면`만 적용됩니다.

- 근로자 로그인
- 가입신청
- 관리자모드 이동 버튼

기능은 유지하고, 화면 비율만 보정합니다.
