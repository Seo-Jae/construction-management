[일위대가작성 - 잡자재 재료비(단수정리) 기본 가산액 수정]

1. 모든 일위대가의 기본 재료비(단수정리) 행은 유지합니다.
2. 품명: 잡자재
3. 규격: 피스 외
4. 단위: 식
5. 기본 가산액: 500원
6. 42.3 미적용 상태에서도 이 패키지 하나만 실행하면 42.3 규칙을 먼저 적용한 뒤 500원으로 보정합니다.
7. 이미 42.3이 적용된 상태에서도 안전하게 500원 규칙만 추가합니다.
8. 기존 저장문서에서 사용자가 직접 지정한 단수정리 가산액은 강제로 500원으로 덮어쓰지 않습니다.
9. SQL 변경 없음.
