# v52.48.5.44.65 변경내용

- 동그라미/점선박스/설명 화살표에서 숨긴 번호가 실제 공개 가이드에서 다시 나타나는 문제를 보강했습니다.
- 번호 숨김 상태를 하나의 boolean 값에만 의존하지 않고 `showNumber=false`, `hideNumber=true`, `number=0` 세 값으로 명확하게 저장합니다.
- `guideCatalog`, 표시 편집기, 가이드 설정 미리보기, 실제 공개 팝업이 모두 동일한 번호 표시 판정 함수를 사용합니다.
- 기존 `.64`에서 이미 번호를 숨긴 도형도 다시 저장/공개하면 숨김 상태가 `number=0`까지 포함해 보강됩니다.
- 순수 `① 번호` 도구는 계속 번호가 항상 표시됩니다.
- 추가 Supabase SQL은 없습니다.
