# 적용 방법

프로젝트 최상위 폴더에 `release_v52.48.5.44.65` 폴더를 넣고 실행합니다.

```powershell
node .\release_v52.48.5.44.65\apply-v52.48.5.44.65-guide-number-publish-sync.cjs
npm run build
git add .
git commit -m "v52.48.5.44.65 가이드 번호 숨김 공개본 동기화 보강"
git push origin main
```

`main` Push 후 Vercel 자동배포를 확인하세요. 자동배포가 시작되지 않을 때만 `npx vercel --prod`를 실행합니다.

## 중요
배포 후 이미 공개 중인 가이드는 `가이드 설정`에서 **공개 버튼을 한 번 다시 눌러** 기존 공개 JSON을 새 숨김 형식으로 갱신해주세요. 이후부터는 숨긴 번호가 실제 공개 가이드에도 그대로 반영됩니다.

추가 Supabase SQL은 없습니다.
