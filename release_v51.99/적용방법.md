# 사내시스템 v51.99 적용방법

이번 버전은 **Supabase SQL을 먼저 실행한 뒤 코드 파일을 적용**해야 합니다.

## 1. Supabase SQL 실행

Supabase 프로젝트의 `SQL Editor`에서 아래 파일 전체를 붙여넣고 실행합니다.

```text
Supabase에서_실행_회원권한_2단계_v51.99.sql
```

SQL은 여러 번 실행해도 기존 회원 설정을 덮어쓰지 않도록 구성되어 있습니다. 기존 회원의 역할과 현장정보를 새 권한 테이블로 자동 이전하며, 현재 메뉴 접근 방식은 변경하지 않습니다.

## 2. 코드 적용

프로젝트 최상위 폴더에서 PowerShell을 열고 아래 명령을 실행합니다.

```powershell
node .\release_v51.99\apply-v51.99-permission-phase2.cjs
npm run build
```

적용 스크립트는 교체 대상 파일을 `backup_v51.99_날짜시간` 폴더에 자동 백업합니다.

## 3. 확인 항목

1. 최고관리자 계정으로 `회원관리`를 엽니다.
2. 기존 회원목록과 승인·거절·사용중지 기능이 정상인지 확인합니다.
3. 회원 한 명을 선택하고 부서와 권한 템플릿이 표시되는지 확인합니다.
4. `소속현장 / 선택현장 / 전체현장`을 바꾸고 저장합니다.
5. 선택현장별 접근 시작일·종료일을 저장한 뒤 다시 열어 값이 유지되는지 확인합니다.
6. `공정별 노임작성 > 월별 노임 예상현황`의 시작월·종료월이 `2026년 8월` 형식인지 확인합니다.
7. `자재관리 > 자재투입현황`의 시작월·종료월도 같은 한국어 형식인지 확인합니다.

## 현재 단계 안내

- 부서·권한 템플릿·현장범위 DB 및 저장 기능: 적용 완료
- 권한 변경 전후 감사이력: DB 기록 완료
- 기존 역할 기반 메뉴 접근: 그대로 유지
- 개인별 세부권한·특수권한 화면과 실제 메뉴/RLS 차단: 다음 단계에서 연결
