# 사내시스템 v51.99 변경내용

## 회원권한 2단계

- 부서 기준정보 추가: 공사·안전·관리·자재·외주·외부업체
- 기본 권한 템플릿 11종 추가
- 메뉴별 권한 정의 및 템플릿 기본 권한 테이블 구성
- 사용자별 부서·권한 템플릿·현장범위 저장 구조 추가
- 접근현장 범위: 소속현장·선택현장·전체현장
- 현장별 접근 시작일·종료일 저장
- 기존 회원의 역할·소속현장을 새 구조로 자동 이전
- 권한 변경 전후 값과 변경자를 감사이력에 기록
- 테이블 직접 접근 차단, 최고관리자 전용 RPC로 조회·저장
- 기존 `admin_update_user_account_projects`를 내부 호출해 기존 승인·사용중지·복수현장 저장 동작 유지
- 이번 단계에서는 기존 역할 기반 메뉴 접근을 유지해 기존 사용자의 메뉴가 사라지지 않음

## 월 표기 수정

- `공정별 노임작성 > 월별 노임 예상현황` 시작월·종료월을 한국어 형식으로 변경
- `자재관리 > 자재투입현황` 시작월·종료월을 한국어 형식으로 변경
- 내부 저장값 `YYYY-MM`은 그대로 유지해 조회·집계 로직에는 영향 없음
