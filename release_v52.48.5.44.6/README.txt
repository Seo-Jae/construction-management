v52.48.5.44.6 - 공정진척 하단 층별 예외타입 다단 표시

변경 파일
- src/BuildingGrid.jsx

기존 문제
- 신규 현장관리의 floorUnitTypes(층별 타입 예외)는 타입별 세대현황 집계에는 반영되지만,
  각 동 하단에는 대표/기본 타입 한 줄만 표시되어 예외 타입이 보이지 않았음.

수정 표시방식
예)
기본 타입
1호=84A / 2호=68A / 3호=68B / 4호=84B

최상층 예외
2호=120T / 3호=120T

하단 표시
[1호] [2호] [3호] [4호]
      [   120T   ]
[84A] [68A] [68B] [84B]

규칙
- 호 라인행(1호,2호...) 표시
- 층별 예외타입은 기본 타입행 위에 표시
- 같은 층에서 인접한 호가 같은 예외타입이면 하나의 넓은 셀로 병합
- 같은 예외 패턴이 여러 층에서 반복될 경우 중복 행 생성을 방지
- 기본 타입은 항상 최하단 유지
- 예외타입 때문에 기본 타입이 대체되지 않음
- aliasUnits가 있는 경우 canonical unit 기준으로 타입 판정
- 색상은 추가하지 않음
  (타입별 색상은 이전 요청대로 우측 타입현황 팝업의 작은 사각형에서만 사용)

SQL 변경 없음

적용:
node release_v52.48.5.44.6/apply-v52.48.5.44.6-building-grid-exception-types.cjs
