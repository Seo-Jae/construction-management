# 지출결의서 작성 v51.85 적용방법

## 적용 대상

지출결의서 작성 v51.84가 적용된 프로젝트를 기준으로 합니다.
이번 수정은 기존 메뉴와 Dashboard를 건드리지 않고 `ExpenseResolution.jsx`만 교체합니다.

## 1. 압축 해제

ZIP 파일을 현재 프로젝트 최상위 폴더에 압축 해제합니다.
프로젝트 최상위 폴더는 `package.json`, `src` 폴더가 있는 위치입니다.

## 2. Supabase SQL 실행

Supabase → SQL Editor에서 아래 파일 전체를 실행합니다.

```text
release_v51.85/Supabase에서_실행_지출결의서_v51.85.sql
```

이 SQL은 v51.84가 이미 적용된 DB에서도 다시 실행할 수 있습니다.
`destination_time` 칼럼을 추가하고 저장 함수를 최신 상태로 교체합니다.

## 3. 소스 적용

프로젝트 최상위 폴더의 터미널에서 실행합니다.

```bash
node .\release_v51.85\apply-v51.85-expense-resolution.cjs
```

수정 전 `src/page/ExpenseResolution.jsx`는 자동 백업됩니다.

## 4. 빌드 확인

```bash
npm run build
```

## 확인 항목

1. 작성월 입력칸에 `August`가 아닌 `2026-08`처럼 숫자로 표시되는지
2. 작성월 선택창의 월이 `01~12` 숫자로 표시되는지
3. 청구일 달력 상단이 `2026-08`처럼 숫자로 표시되는지
4. 사용일 입력칸이 `08-03`처럼 연도 없이 표시되는지
5. 사용일 달력에서 이전·다음 연도로 이동할 수 있는지
6. 유류대 입력 시 출발지, 도착지, 도착시간을 각각 입력할 수 있는지
7. 갑지 미리보기에 `서울 → 용인 07:33`처럼 표시되는지
8. 저장 후 다시 열었을 때 도착시간이 유지되는지
9. 상세내역 캘린더에는 시간과 금액이 표시되지 않는지
