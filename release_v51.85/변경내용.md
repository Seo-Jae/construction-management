# v51.85 변경내용

- 작성월의 브라우저 기본 영문 월 표시를 제거했습니다.
- 작성월은 `YYYY-MM` 숫자 형식으로 표시됩니다.
- 작성월 선택창은 `01~12` 숫자 버튼으로 구성했습니다.
- 청구일과 사용일의 브라우저 기본 달력을 제거했습니다.
- 날짜 달력 상단은 `YYYY-MM` 숫자 형식으로 표시됩니다.
- 달력 요일은 한글로 표시됩니다.
- 사용일 입력칸은 `MM-DD`만 표시합니다.
- 사용일의 실제 저장값에는 연도가 포함되며 기본값은 현재 작성월의 연도입니다.
- 날짜 달력에서 이전·다음 연도로 이동할 수 있습니다.
- 갑지 미리보기의 사용일도 `MM-DD` 형식으로 표시합니다.
- 유류대에 `도착시간` 입력칸을 추가했습니다.
- 도착시간은 `HH:mm` 형식으로 저장됩니다.
- 갑지 미리보기에는 `출발지 → 도착지 HH:mm` 형태로 표시합니다.
- 상세내역 캘린더에는 기존 규칙대로 출발지, 도착지, 항목만 표시합니다.
