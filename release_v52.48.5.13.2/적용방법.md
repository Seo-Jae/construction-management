# v52.48.5.13.2 적용방법

프론트엔드 코드 변경과 재배포는 필요하지 않습니다.

Supabase SQL Editor에서 아래 파일의 전체 내용을 한 번 실행합니다.

`Supabase에서_실행/00_v52.48.5.13.2_테스트근태초기화_작업전허용.sql`

실행 결과 마지막 조회에서 아래 함수명이 한 줄 나오면 적용 완료입니다.

`attendance_manager_reset_test_attendance_v52_48_5_13`

적용 후 기존 화면을 새로고침하고 동일한 테스트계정의 `근태 초기화`를 다시 누르면 됩니다.

## 이후 테스트 방법

1. 테스트계정으로 출근·퇴근 및 진척 제출
2. 담당자가 진척 최종승인
3. 공정진척 화면에서 별도로 작업전 처리하지 않음
4. 근태기록에서 테스트계정의 `근태 초기화` 실행
5. 출근·퇴근 기록과 테스트 승인 진척이 함께 초기화되는지 확인
