# v52.48.5.44.67 적용방법

프로젝트 최상위 폴더에 `release_v52.48.5.44.67` 폴더를 넣은 뒤 아래 순서대로 실행합니다.

```powershell
node .\release_v52.48.5.44.67\apply-v52.48.5.44.67-weekly-report-layout.cjs
npm run build
git add .
git commit -m "v52.48.5.44.67 주간업무보고 화면 비율 조정"
git push origin main
```

`main` Push 후 Vercel 자동배포가 시작되는지 확인합니다. 자동배포가 연결돼 있지 않은 경우에만 별도로 `npx vercel --prod`를 실행합니다.
