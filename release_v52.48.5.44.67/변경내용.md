# v52.48.5.44.67 변경내용

## 주간 업무 보고 > 주간 업무 보고 작성

현재 화면에서 좌측 작성 영역보다 우측 미리보기 영역이 넓어, 주간업무보고 문서 좌우에 불필요한 여백이 남는 부분을 조정했습니다.

- 좌측 작성 영역 비율: **38% → 42%**
- 우측 미리보기 영역 비율: **62% → 58%**
- 좌측 작성 패널 최소 폭: **360px → 400px**
- 우측 미리보기 패널 최소 폭: **620px → 600px**
- 실제 주간업무보고 미리보기 문서의 폭(820px)과 문서 비율은 변경하지 않습니다.

따라서 입력 영역은 조금 더 여유롭게 사용할 수 있고, 우측은 문서 주변의 빈 공간이 줄어드는 방향입니다.

추가 Supabase SQL은 없습니다.
