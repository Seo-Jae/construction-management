# v52.48.5.11 적용 방법

이 패키지는 `v52.48.5.10`이 적용된 프로젝트를 기준으로 합니다.

## 1. Supabase SQL 먼저 실행

Supabase 대시보드의 **SQL Editor**에서 아래 파일 전체를 실행합니다.

```text
release_v52.48.5.11/Supabase에서_실행/00_v52.48.5.11_테스트계정_근태초기화.sql
```

실행 결과 맨 아래에 테이블 1개와 RPC 3개가 모두 표시되면 정상입니다.

## 2. 코드 적용

ZIP 안의 `release_v52.48.5.11` 폴더를 프로젝트 최상위 폴더에 복사합니다. 프로젝트 최상위는 `package.json`과 `src` 폴더가 보이는 위치입니다.

PowerShell에서 아래 명령을 순서대로 실행합니다.

```powershell
node .\release_v52.48.5.11\apply-v52.48.5.11-test-attendance-reset.cjs
npm run build
git add src/page/AttendanceManagement.jsx
git status
git commit -m "v52.48.5.11 add test attendance reset"
git push origin main
```

## 3. 사용 방법

1. 통합관리시스템에서 `근태관리 → 근태 기록`으로 들어갑니다.
2. 초기화할 근태 날짜를 선택합니다.
3. `테스트` 표시가 있는 계정의 `근태 초기화` 버튼을 누릅니다.
4. 확인 후 초기화 사유를 입력합니다.
5. 작업자 출퇴근앱을 다시 열거나 다른 화면으로 전환했다 돌아오면 출근 전 상태로 갱신됩니다.
6. 같은 테스트계정으로 출근 QR부터 다시 시험합니다.

앱 재설치는 필요하지 않습니다.
