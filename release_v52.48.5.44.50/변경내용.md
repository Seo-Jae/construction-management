# v52.48.5.44.50 변경내용

가이드 이미지 표시 편집기의 정밀 편집 사용성을 개선했습니다.

1. 우측 숫자 입력칸의 높이와 스피너(↑↓) 클릭 영역을 확대했습니다.
2. 화면 내 설명박스는 고정 폭 대신 입력 글자 길이에 맞춰 자동으로 생성됩니다. 긴 문구만 최대 폭에서 줄바꿈됩니다.
3. 설명박스 제목 앞에 시스템이 자동으로 붙이던 `1.`, `2.` 등의 번호 접두어를 제거했습니다. 필요한 번호 표기는 사용자가 직접 제목에 입력합니다.
4. 점선박스/동그라미의 번호 원 위치를 `우측상단(기본)`, 상/하/좌/우 중앙, 네 모서리, `자유` 중에서 선택할 수 있습니다.
5. 고정 위치 번호는 도형을 이동하거나 크기를 변경하면 자동으로 따라갑니다. `자유`를 선택하거나 번호 원을 직접 끌면 개별 이동 상태가 됩니다.
6. 점선박스/동그라미 선택 시 8개의 파란 리사이즈 핸들이 표시되어 엑셀 도형처럼 직접 늘리고 줄일 수 있습니다. 도형 자체 드래그 이동도 유지됩니다.
7. 편집 화면을 조직도와 유사하게 개선했습니다. 빈 화면 드래그로 이동, 마우스 위치 기준 휠 확대/축소, +/- 버튼, 현재 배율, `맞춤` 기능을 제공합니다.
8. 번호 연결 화살표는 번호 중심까지 들어가지 않습니다. 시작 번호 외곽에서 출발하고 도착 번호 외곽보다 앞에서 일정 여백을 두고 화살촉이 끝나도록 변경했습니다. 따라서 도착 번호 원에 가려지지 않습니다.

추가 Supabase SQL은 없습니다.
