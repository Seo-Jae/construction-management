# v52.48.5.15 변경내용

## 금월 투입현황 소계

- 근로자 명단 최하단에 파란색 `소계` 행을 추가했습니다.
- 각 날짜 열에는 해당 일자의 투입 인원 합계를 표시합니다.
- 우측 `합계` 열에는 표시된 명단의 월 총 공수를 표시합니다.
- 성명 또는 직종으로 검색하면 검색 결과에 맞춰 날짜별 소계와 월 총 공수가 자동으로 다시 계산됩니다.
- 명단이 없는 경우에는 기존 빈 화면 안내를 유지하며 소계 행을 표시하지 않습니다.

이번 버전은 프론트엔드 UI와 화면 계산만 변경하며 Supabase SQL 실행은 필요하지 않습니다.
