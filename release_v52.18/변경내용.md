# v52.18 변경내용

## 1. 작업 화면 유지
기존 Dashboard는 runtime 권한을
- 창 focus 복귀 시
- 60초 주기

로 다시 읽은 뒤 `currentView` 자동 보정 로직까지 반복 실행했습니다.

v52.18에서는:
- 권한/현장 접근정보 갱신 자체는 그대로 유지
- `currentView` 자동 보정은 로그인 후 권한정보가 준비된 최초 1회만 실행
- 이후 focus/탭복귀/주기 갱신은 사용자가 현재 작업 중인 화면을 변경하지 않음

## 2. Main 미작성 업무 알림
담당자 Main 팝업 하단에:
- `오늘 하루 보지 않기` 체크박스 추가

동작:
- 미체크 후 닫기: 현재 팝업만 닫힘. Main을 다시 방문하면 다시 표시
- 체크 후 닫기: 해당 사용자 기준 한국시간 당일 동안 표시하지 않음
- X / 확인 / 업무 이동 모두 체크 상태를 동일하게 반영
- 다음 날에는 다시 표시
