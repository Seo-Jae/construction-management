# v52.18 적용방법

## 변경 범위
1. 일반 담당자가 다른 프로그램/브라우저 탭을 사용했다가 돌아와도 현재 업무화면 유지
2. Main `미작성 업무 알림`에 `오늘 하루 보지 않기` 체크박스 추가

## SQL
**SQL 변경 없음**

## 적용
프로젝트 최상위에서:

```powershell
node .\release_v52.18\apply-v52.18-screen-preserve-main-alert.cjs
```

정상 메시지를 확인한 뒤:

```powershell
npm run build
```

빌드 마지막에 `✓ built in ...`가 나오면 정상입니다.

## Git
이번 실제 프로그램 변경 파일은 2개입니다.

```powershell
git add src/Dashboard.jsx
git add src/page/MainWorkAlertDialog.jsx
git status
git commit -m "v52.18 preserve work view and daily main alert"
git push origin main
```

`git add .`은 사용하지 않습니다.

## 배포 후 테스트
### 화면 유지
일반 `담당자` 계정으로 다음을 각각 확인합니다.
- 출력일보작성에서 입력 중 → 다른 Chrome 탭 → 복귀
- 공종별 현황 입력 → 다른 프로그램(Excel 등) → 복귀
- 근로계약서작성 → 창 최소화 → 복귀
- 1~2분 다른 프로그램 사용 후 복귀

모두 기존 업무화면이 그대로 유지되어야 합니다.

### Main 업무알림
- 담당자 계정으로 Main 진입 → 미작성 업무 알림 표시
- 체크하지 않고 `확인` → 다른 메뉴로 이동 후 Main 재진입 → 다시 표시
- `오늘 하루 보지 않기` 체크 후 `확인` → Main 재진입 → 표시되지 않음
- X 또는 `이동` 버튼으로 닫아도 체크된 경우 동일하게 당일 숨김
- 다음 한국 날짜가 되면 다시 표시
