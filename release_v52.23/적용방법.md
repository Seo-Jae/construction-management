# v52.23 적용방법

## 변경
작업자 출·퇴근 앱 상단 공지 티커의 흐르는 속도를 현재 대비 약 **1.4배** 빠르게 합니다.

기존:
- 최소 20초
- 최대 70초
- 길이계수 0.42

변경:
- 최소 14.3초
- 최대 50초
- 길이계수 0.30

공지 글씨크기, 박스 높이, 노란색, 공지 사이 간격, 순번표시, 오른쪽→왼쪽 방향은 변경하지 않습니다.

## SQL
SQL 변경 없음.

## 적용

프로젝트 최상위에서:

```powershell
node .\release_v52.23\apply-v52.23-attendance-ticker-speed.cjs
```

`[v52.23 적용 완료]` 확인 후:

```powershell
npm run build
```

## Git

실제 변경 파일은 1개입니다.

```powershell
git add src/page/AttendanceWorkerPortal.jsx
git status
git commit -m "v52.23 increase attendance ticker speed"
git push origin main
```

`git add .`은 사용하지 않습니다.
