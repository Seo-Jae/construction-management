v52.14.8 적용 및 배포 방법

1. ZIP을 프로젝트 최상위 폴더에 압축 해제합니다.

2. 프로젝트 최상위 PowerShell에서 실행합니다.

node .\release_v52.14.8\apply-v52.14.8-attendance-toast-time-editor.cjs
npm run build

3. 변경 파일만 Git에 추가합니다.

git add src/page/AttendanceManagement.jsx src/page/AttendanceWorkerPortal.jsx
git commit -m "v52.14.8 improve attendance toasts and time editing"
git push origin main

4. Vercel 배포가 Ready가 되면 확인합니다.

- 근태관리 > 근태 기록에서 출근 또는 퇴근 수정 아이콘을 누릅니다.
- 수정창에는 날짜 입력 없이 변경 시간과 수정 사유만 표시되는지 확인합니다.
- 변경 시간을 눌러 시·분을 바꾼 뒤, 바깥을 눌러도 설정창이 닫히지 않는지 확인합니다.
- 적용을 누르면 시간 설정창만 닫히고 수정사유 입력창이 유지되는지 확인합니다.
- 저장 후 성공 알림이 화면 상단 중앙 토스트로 표시되는지 확인합니다.
- 가입 승인, 기기 변경, 근로자용 앱의 동적 알림도 토스트로 표시되는지 확인합니다.

Supabase SQL 실행, 앱 삭제·재설치, 추가 npm 패키지 설치는 필요 없습니다.
