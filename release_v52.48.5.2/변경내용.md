# v52.48.5.2 변경내용

v52.48.5.1의 UI 변경 내용은 그대로입니다.

이번 버전의 핵심 수정은 적용스크립트의 마지막 검증입니다.

수정 전:
`mt: appMode ? 7.2 : 4.2`

수정 후:
`mb: appMode ? 7.2 : 4.2`

실제 생성되는 로그인 헤더는 `mb`가 맞습니다.

추가로 이번 패키지는 단순 Node 문법검사만 한 것이 아니라,
v52.48.4 형태의 테스트 소스에 적용스크립트를 실제 실행해:

- 부모 강제크기 해제
- 상태바 흰색 처리
- scale 제거
- 뒤로가기 추가
- 헤더 재배치
- 휴대폰/비밀번호 각각 수정
- 로그인/가입/관리자 버튼 재배치
- 최종 검증 통과
- 파일 저장 완료

까지 확인했습니다.
