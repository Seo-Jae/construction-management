# v52.48.5.2 적용방법

v52.48.5.1에서 아래 오류가 난 경우 사용하는 최종 수정본입니다.

```text
[v52.48.5.1 적용 중단]
적용 후 필수 마커 누락: mt: appMode ? 7.2 : 4.2
```

## 원인

실제 새 로그인 헤더 코드에는:

```text
mb: appMode ? 7.2 : 4.2
```

가 생성되는데, 검증코드가 실수로:

```text
mt: appMode ? 7.2 : 4.2
```

를 찾고 있었습니다.

즉 레이아웃 변경 실패가 아니라 **최종 검증문구 오타**였습니다.

## 적용

```powershell
node .\release_v52.48.5.2\apply-v52.48.5.2-attendance-login-reference-final.cjs
npm run build
```
