# v52.48.5.44.64 변경내용

가이드 표시 편집의 자동 번호를 표시별로 숨길 수 있도록 수정했습니다.

- `동그라미`, `점선박스`, `설명 화살표` 선택 시 우측 설정에 **번호 원 표시** 체크 옵션 추가
- 체크 해제 시 도형/화살표 자체는 그대로 유지하고 번호 원만 숨김
- 번호 없는 동그라미 강조만 단독으로 사용하는 구성 지원
- 번호를 숨긴 표시는 `번호 재정렬` 대상에서 제외
- 번호를 숨긴 표시는 `번호 연결 화살표`의 시작/도착 대상에서 제외
- 이미 번호 연결 화살표가 연결된 표시의 번호를 끄면 해당 번호 연결 화살표도 함께 제거하여 잘못된 연결이 남지 않도록 처리
- 번호 표시를 다시 켤 경우 현재 표시 중인 번호 다음 값을 자동 부여
- 가이드 설정 미리보기와 실제 공개 가이드에서도 동일하게 번호 숨김 반영
- 기존 데이터는 `showNumber` 값이 없으면 기존과 동일하게 번호 표시 상태로 유지
- 별도 `① 번호` 도구는 번호 자체가 목적이므로 번호 숨김 대상에서 제외

추가 Supabase SQL은 없습니다.
