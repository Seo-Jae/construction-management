# v52.48.5.44.64 적용방법

프로젝트 최상위 폴더에서 실행합니다.

```powershell
node .\release_v52.48.5.44.64\apply-v52.48.5.44.64-guide-number-visibility.cjs
npm run build
git add .
git commit -m "v52.48.5.44.64 가이드 표시 번호 숨김 기능"
git push origin main
```

`main` Push 후 Vercel 자동 운영 배포를 확인합니다. 자동배포가 시작되지 않을 때만 아래 명령을 실행합니다.

```powershell
npx vercel --prod
```
