# v52.48.5.44.83 변경내용

대상: `src/page/AttendanceManagement.jsx`

근태관리 상단 탭에서 현재 선택된 탭의 파란 밑줄이
실제 탭 위치보다 왼쪽으로 밀려 보이는 문제를 수정합니다.

현재 근태관리 상단은 MUI `Tabs` 기본 indicator를 사용하고 있으며,
시스템 화면이 CSS 90% 배율일 때 indicator의 좌표 계산이 실제 탭 위치와 어긋나는 현상이 발생합니다.

## 수정

- 근태관리 상단 Tabs의 MUI 기본 indicator 숨김
- 선택된 `Tab` 자체에 `::after` 방식 밑줄 생성
- 밑줄은 해당 Tab의 실제 폭과 위치를 그대로 사용
- 가입 승인 / 근태 기록 / 진척 승인 / 기기 변경 / 변경 이력 /
  근로자 관리 / 중점위험요인 관리 / 공지사항 관리 / 출·퇴근 QR 전체에 적용
- 각 탭의 기존 아이콘, 텍스트, 클릭 동작은 유지

추가 Supabase SQL은 없습니다.
