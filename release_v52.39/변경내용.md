# v52.39 변경내용

## 다운로드 인증 준비 UI

월별 노임작성 상단에:
`다운로드 인증 준비`

버튼을 추가합니다.

통합 점검:
- Excel 사전검증
- verified 보안 휴대폰
- SMS provider
- 저장 명단 snapshot

## OTP Challenge

신규 테이블:
- labor_download_otp_challenges

저장:
- 사용자
- 현장
- 작성월
- roster ID
- snapshot SHA-256
- 보안휴대폰 keyed fingerprint
- 휴대폰 뒤4자리
- 보안휴대폰 verified_at
- OTP HMAC digest
- 시도횟수
- 만료/인증/소모 상태

OTP 원문은 저장하지 않습니다.

## OTP 생성

서버 내부에서 암호학적 난수 6자리 생성.

24-bit 난수 중 16,000,000 미만만 사용 후 modulo 1,000,000 처리하여 modulo bias를 제거합니다.

## HMAC

Vault의 별도 secret:
`labor_download_otp_hmac_key_v52_39`

HMAC 입력:
- challenge ID
- 6자리 OTP
- 현재 명단 snapshot hash
- 보안 휴대폰 fingerprint

따라서 다른 명단/전화번호에 OTP를 재사용할 수 없습니다.

## Snapshot

포함:
- 현장/작성월
- roster id/update
- 근로자 순서
- 공종/비고
- 출역
- 일급/추가지급/공제
- 노임 메모
- worker master updated_at
- worker private updated_at

민감 원문 자체는 hash material에 넣지 않고 private updated_at을 포함합니다.

개인정보가 수정되면 기존 challenge가 무효화됩니다.
