# v52.48.5.44.45 변경내용

## 1. PDF/프린트 좌우 여백 개선
v52.48.5.44.44에서는 출력 배율 계산에 `1`을 상한으로 두어 원본 골구도가 A4 출력영역보다 작을 경우 확대하지 않았습니다.
이번 버전에서는 해당 상한을 제거하여 가로/세로 출력영역 중 먼저 닿는 크기까지 자동 확대합니다. 또한 `@page margin: 0`과 A4 가로 전체폭 297mm를 사용하고 출력 복제본의 바깥 패딩을 제거해 페이지를 최대한 채웁니다.

## 2. 화면 줌 글자 선명도 개선
기존 `transform: scale()` 방식은 171%처럼 비정수 배율에서 텍스트와 선이 흐릿하게 보일 수 있었습니다.
이번 버전에서는 확대에 CSS `zoom`을 사용하고 이동은 `left/top` 좌표로 처리합니다.
또한 이동 좌표를 정수 픽셀로 맞춰 추가적인 서브픽셀 흐림을 줄였습니다.

## 3. 출력과 화면 줌 분리
출력용 복제 DOM에는 `zoom: 1`을 강제로 지정하여 사용자가 화면에서 171% 등으로 확대해둔 상태와 관계없이 항상 원본 기준으로 출력 배율을 계산합니다.
