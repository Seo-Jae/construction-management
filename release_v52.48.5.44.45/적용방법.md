# 적용 및 운영 배포

프로젝트 최상위 폴더에서 PowerShell로 아래 명령을 순서대로 실행합니다.

```powershell
node .\release_v52.48.5.44.45\apply-v52.48.5.44.45-grid-print-zoom-fix.cjs
npm run build
git add .
git commit -m "v52.48.5.44.45 골구도 출력 여백 및 줌 선명도 개선"
git push origin main
```

`main` 브랜치가 Vercel Production에 연결되어 있으면 마지막 push 후 운영 배포가 자동 진행됩니다.
