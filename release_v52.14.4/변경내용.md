# v52.14.4 근태 앱 이름·아이콘·설치형 UI 개선

## 앱 이름과 아이콘

- 앱 이름을 `욱림건설 근태시스템`으로 통일했습니다.
- 아이콘을 초록색 배경과 중앙의 흰색 `W`로 변경했습니다.
- Android용 192px·512px·maskable 아이콘을 추가했습니다.
- iPhone 홈 화면용 180px 아이콘을 추가했습니다.
- 브라우저 제목과 앱 테마 색상도 새 이름·초록색에 맞췄습니다.

## 설치형 앱 전용 화면

- 홈 화면에서 실행한 설치형 앱을 자동 감지합니다.
- 앱에서는 헤더, 작업자 정보, 현장명, 상태 안내, 출·퇴근 시간, 입력칸, 버튼을 스마트폰에 맞게 크게 표시합니다.
- iPhone 안전영역과 하단 여백을 반영했습니다.
- 앱에서는 `앱으로 설치`와 `휴대폰 홈 화면에 앱 추가` 버튼 및 설치 안내창을 숨깁니다.
- Safari·Chrome 등 브라우저로 접속했을 때는 기존 설치 기능을 유지합니다.

## 기존 기능 유지

- v52.14.3의 QR 카메라 무한대기 수정 코드를 그대로 유지합니다.
- 회원가입, 테스트계정, 로그인, 승인상태, 출·퇴근 QR 처리에는 DB 변경이 없습니다.
- Supabase SQL 실행과 npm 패키지 추가 설치는 필요 없습니다.
