# 사내시스템 v52.00 변경내용

## v51.99 SQL 오류 수정

- `unnest(up.project_names)` 결과 별칭과 대상 컬럼의 이름이 모두 `project_name`이어서 발생한 PostgreSQL `42702 ambiguous column` 오류 수정
- 배열과 JSONB의 현장명 변환 구문을 `project_item.project_value`로 명확하게 구분
- v51.99가 롤백된 상태에서도 2~5단계를 통합 SQL 한 번으로 구성

## 회원권한 3단계

- 세부권한을 `상속 / 추가 / 차단` 3상태로 설정
- 모든 접근현장 공통권한과 현장별 예외권한 분리
- 템플릿 기본값과 개인별 예외를 합산한 최종 허용·차단 상태 표시
- 준비중 메뉴를 포함한 실제 사이드바 메뉴 권한표 확장
- 템플릿 변경 시 `개인별 설정 유지 / 새 템플릿으로 초기화 / 변경 취소` 선택

## 회원권한 4단계

- 기존 역할·소속·복수현장을 신규 권한 구조로 자동 변환
- 최고관리자, 본사, 현장 관리자·담당자의 기본 템플릿 자동 지정
- 기존 회원 변환 사실을 최초 변경이력으로 기록

## 회원권한 5단계

- 개인정보, 회원승인, 마감·마감취소, 강제삭제, 원장·DXF 교체 등 특수권한을 일반권한과 분리
- 기본정보·접근현장·세부권한·특수권한을 하나의 RPC 트랜잭션으로 저장
- 저장 전후 스냅샷, 변경자, 변경일시, 변경영역 기록
- 회원관리 화면에서 최근 변경이력 50건 조회

## 기존 기능 보존

- 기존 회원 승인·거절·사용중지·다시 사용 유지
- 기존 복수현장 저장 RPC 연동 유지
- 기존 역할 기반 메뉴 노출은 유지
- 노임·자재 시작월·종료월 한국어 표기 수정 포함
