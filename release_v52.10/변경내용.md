# v52.10 변경내용

기준: 운영 v52.08.4 이상. v52.09를 이미 로컬에 적용한 상태에서도 적용 가능하도록 구성했다.

## 1. 설치 없는 메신저 별도창
- ERP 상단 메신저 버튼을 누르면 현재 업무화면은 이동하지 않는다.
- 별도의 브라우저 팝업창으로 `욱림건설 메신저`가 열린다.
- 같은 메신저 창이 이미 열려 있으면 URL을 다시 로드하지 않고 기존 창만 앞으로 가져온다.
- Dashboard가 재렌더링되어 popup ref가 초기화되어도 같은 이름의 기존 메신저 창을 재사용한다.

## 2. 사이트 밖 시스템 알림
- 새 메시지 알림용 사이트 내부 우측하단 Snackbar를 제거했다.
- 브라우저 알림 권한이 허용된 경우 운영체제/브라우저 시스템 알림으로 표시한다.
- ERP 사이트가 앞에 있든 뒤에 있든, 다른 프로그램을 사용 중이든 시스템 알림을 사용한다.
- 알림을 클릭하면 메신저 창을 열거나 앞으로 가져오고 해당 대화방을 선택한다.
- 브라우저 자체가 완전히 종료된 상태의 Push 알림은 이번 1차 범위에 포함하지 않는다.

## 3. 작성 중 내용과 대화방 유지
- 사용자별 마지막 선택 대화방을 localStorage에 저장한다.
- 각 대화방별 작성 중 텍스트를 사용자별 초안으로 저장한다.
- 다른 대화방으로 갔다 돌아와도 각 대화방의 미전송 텍스트가 복원된다.
- 메신저 창을 닫았다가 다시 열어도 마지막 대화방과 작성 중 텍스트가 복원된다.
- 메시지 전송이 완료되면 해당 대화방 초안은 제거한다.
- 대화방에서 나가면 해당 방의 저장 초안도 제거한다.
- 붙여넣은 이미지 미리보기는 열린 메신저 창을 재사용하는 동안 그대로 유지된다. 브라우저 창을 완전히 닫은 뒤의 이미지 Blob 영구보관은 이번 범위에 포함하지 않는다.

## 4. 대화창 배경
- 기존 `#f1f5f9`보다 한 단계 짙은 `#e2e8f0`으로 변경했다.

## 5. v52.09 기능 누적 유지
- 개인별 글자크기
- 연속 메시지 입력 포커스 유지
- 방장 직접 위임
- 방장 나가기 시 위임 대상 선택
- 메신저 활동을 30분 자동로그아웃의 활동으로 인정
- 한글 이미지 파일명 Storage Invalid key 수정
- Ctrl+V 캡처 이미지 미리보기 후 전송
- 기존 읽음/안읽음, 안 읽은 참여자, 실시간, 첨부, 삭제, 그룹관리, 방 나가기, 깜빡임 안정화 유지
