핵심 흐름
1. 현장 / 회차 / 기준월 / 계약버전 확인
2. [기성 양식 다운로드]
3. Excel에서 노란색 '금회수량' 셀만 입력
4. [기성 양식 업로드]
5. 시스템 미리보기 및 공정 연결 확인
6. 회차 저장 / 작성완료

다운로드 양식
- 시트명: 기성입력양식
- 품목정보 / 계약내역 / 전회누계 / 금회기성 / 누계기성
- 금회수량만 노란색 입력셀
- 금회 재료/노무/경비/합계는 Excel 수식
- 누계 수량/금액/누계율은 Excel 수식
- 이전 회차가 있으면 이전 회차 누계를 전회누계에 자동 반영
- 1회차이면 전회누계 0

안전장치
- _SYSTEM veryHidden 시트
- 현장 / 회차 / 기준월 / 계약버전 불일치 업로드 차단
- AE 숨김열 SYSTEM_ITEM_KEY로 중복 품목 정확히 식별

업로드
- 표준양식 자동 판별
- 기존 외부 기성내역서는 기존 parser로 계속 지원
- 계약품목 공정연결 / 이전회차 공정연결 자동승계 유지

현재 v1 입력규칙
- 사용자는 금회수량만 입력
- 금회 금액 = 금회수량 x 계약 단가
- 누계 = 전회누계 + 금회
- 계약수량 초과 / 음수 입력은 검산오류

SQL 변경 없음
