# v52.17 적용방법

## 0. 기준
- GitHub `main`의 v52.16 기준 파일에서 제작했습니다.
- v52.16 근로자관리 기능은 그대로 보존합니다.
- 변경 파일은 2개입니다.
  - `src/page/AttendanceManagement.jsx`
  - `src/page/AttendanceWorkerPortal.jsx`

## 1. Supabase SQL 먼저 실행
Supabase SQL Editor에서 아래 파일을 처음부터 끝까지 실행합니다.

`release_v52.17/Supabase에서_실행/00_v52.17_근태앱_상단공지티커.sql`

마지막 설치 확인 결과에 다음 함수가 표시되면 정상입니다.
- `attendance_manager_list_notices_v52_17`
- `attendance_manager_save_notice_v52_17`
- `attendance_manager_set_notice_active_v52_17`
- `attendance_worker_me_v52_14`

## 2. 프로그램 적용
프로젝트 최상위 폴더에서 실행합니다.

```powershell
node .\release_v52.17\apply-v52.17-attendance-notice-ticker.cjs
```

적용 스크립트는 현재 파일 SHA256을 검사합니다. 제작 기준과 다른 파일이면 기존 기능 보호를 위해 자동으로 중단합니다.

## 3. 빌드
```powershell
npm run build
```

`✓ built in ...`가 나오면 정상입니다.

## 4. Git
```powershell
git status
git add src/page/AttendanceManagement.jsx
git add src/page/AttendanceWorkerPortal.jsx
git status
git commit -m "v52.17 attendance notice ticker"
git push origin main
```

`git add .`은 사용하지 않습니다.

## 5. Vercel
운영 프로젝트 `wooklim-construction-management`에서 새 Production 배포가 `Ready`인지 확인합니다.

## 6. 운영 확인
1. 근태관리 → `공지사항 관리` 탭 진입
2. 공지 등록
3. 게시 시작일/종료일과 `사용중` 확인
4. 근로자 계정 로그인
5. 앱 상단에서 `공지` 바가 나타나는지 확인
6. 공지문이 오른쪽 → 왼쪽으로 반복 이동하는지 확인
7. 근로자 화면에 닫기(X) 기능이 없는지 확인
8. 관리화면에서 `사용중지` 후 근로자 앱을 다시 열거나 포커스하면 공지가 사라지는지 확인
9. 게시기간이 지난 공지가 자동으로 표시되지 않는지 확인
