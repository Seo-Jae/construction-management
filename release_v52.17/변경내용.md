# v52.17 변경내용

## 근태관리 - 공지사항 관리 탭
기존 `근로자 관리`와 `출·퇴근 QR` 사이에 `공지사항 관리` 탭을 추가했습니다.

관리 항목:
- 공지내용
- 게시 시작일
- 게시 종료일
- 사용여부
- 작성자
- 작성일

기능:
- 공지 등록
- 공지 수정
- 사용중지
- 사용재개
- 현재 선택된 현장별 공지 분리

## 근로자 앱 - 상단 강제 공지 티커
- 로그인한 근로자 화면에만 노출
- 해당 근로자 소속 현장의 게시중 공지만 표시
- 게시기간에 해당하는 공지만 표시
- 오른쪽에서 왼쪽으로 반복 이동
- 여러 공지는 `◆` 구분자로 이어서 표시
- 근로자가 끌 수 있는 닫기 버튼 없음
- 앱 포커스 시 즉시 갱신
- 로그인 상태에서는 60초마다 공지 자동 갱신
