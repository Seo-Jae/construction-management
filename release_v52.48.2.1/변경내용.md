# v52.48.2.1 변경내용

## 오류원인

v52.48.2 적용스크립트가 휴대폰번호 입력칸의 style 일부만 기준문자열로 사용했습니다.

동일한 style이 비밀번호 입력칸에도 존재하여
안전검사가 2개를 발견하고 적용을 중단했습니다.

## 수정

이번 버전은:

- `placeholder="휴대폰번호"`를 먼저 찾은 뒤 그 뒤의 style만 수정
- `placeholder="비밀번호"`를 먼저 찾은 뒤 그 뒤의 style만 수정

하도록 변경했습니다.

따라서 같은 style 문자열이 두 곳 이상 존재해도
정확한 입력칸만 수정합니다.

UI 변경값 자체는 원래 v52.48.2에서 의도했던 값과 동일합니다.
