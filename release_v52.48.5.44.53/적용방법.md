# v52.48.5.44.53 적용방법

프로젝트 최상위 폴더에 `release_v52.48.5.44.53` 폴더를 둔 뒤 실행합니다.

```powershell
node .\release_v52.48.5.44.53\apply-v52.48.5.44.53-guide-toc-panel.cjs
npm run build
git add .
git commit -m "v52.48.5.44.53 가이드 좌측 목차 패널 추가"
git push origin main
```

`main` 브랜치가 Vercel Production에 자동 연결되어 있으면 Push 후 운영 배포가 자동 진행됩니다. 자동 배포가 시작되지 않을 때만 `npx vercel --prod`를 실행합니다.

추가 Supabase SQL은 없습니다.
