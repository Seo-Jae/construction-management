# v52.48.5.44.53 변경내용

- 시스템 가이드 팝업 좌측에 `목차` 패널을 추가했습니다.
- 목차는 상하 스크롤 시 상단 툴바 아래에 고정되어 계속 보입니다.
- `사용 순서 한눈에 보기`와 각 `상세 이용가이드` 항목을 목차에 자동 생성합니다.
- 목차 항목을 클릭하면 해당 가이드 위치로 부드럽게 이동합니다.
- 스크롤 위치에 따라 현재 보고 있는 목차 항목을 강조 표시합니다.
- 기존 중앙 정렬 여백을 줄이고, 가이드 본문은 목차 우측의 남은 영역을 사용하도록 배치했습니다.
- 기존 가이드 이미지, 번호/박스/화살표/설명박스 및 Supabase 데이터 구조는 변경하지 않습니다.
- 추가 SQL은 없습니다.
