# v52.29.1 적용방법

## v52.29 적용 중단 원인

v52.29은 실제 코드 변경을 메모리에서 모두 완료한 뒤 사후검증 중 아래 한 줄 문자열을 찾도록 되어 있었습니다.

```text
sourceProcess ? normalizeText(sourceProcess) : job
```

하지만 실제 생성되는 JSX 코드는 다음처럼 여러 줄입니다.

```js
const process = sourceProcess
  ? normalizeText(sourceProcess)
  : job;
```

그래서 정상 변환 결과를 실패로 오판했습니다.

**v52.29은 파일 저장/백업 단계 전에 중단되므로, 위 오류를 봤다면 기존 프로그램 파일은 수정되지 않은 상태가 정상입니다.**

## SQL

### v52.29 SQL을 이미 성공적으로 실행한 경우
다시 실행하지 않아도 됩니다. DB 정규화는 이미 완료되어 있습니다.

### 아직 SQL을 실행하지 않은 경우
Supabase SQL Editor에서 아래 파일 전체를 실행합니다.

```text
release_v52.29.1\Supabase에서_실행\00_v52.29_용인금어지구_과거일보_job정규화.sql
```

SQL은 재실행해도 안전하게 구성되어 있습니다.
최초 실행 전에 저장한 원본 workers 백업은 그대로 유지됩니다.

## 프로그램 적용

프로젝트 최상위:

```powershell
node .\release_v52.29.1\apply-v52.29.1-daily-report-cumulative-normalization.cjs
```

정상:

```text

```

그 다음:

```powershell
npm run build
```

## Git

변경 파일은 2개입니다.

```powershell
git add src/Dashboard.jsx
git add src/page/HistoricalDailyReportUpload.jsx
git status
git commit -m "v52.29 fix daily report cumulative and legacy jobs"
git push origin main
```

`git add .`은 사용하지 않습니다.
