# v52.29.1 변경내용

기능 내용은 v52.29와 동일합니다.

## 프로그램 기능
- 출력일보 전일누계: 전체 공사기간 → 같은 연월 1일~전일
- 먹메김 → 먹매김
- 경량 / 경량골조 / 경량석고 → 경량벽체
- 천정 → 세대천정
- 과거 Excel의 process는 원본 세부공정 보존
- 기존 DB 구형 job도 runtime에서 호환

## v52.29.1 보완
- v52.29의 잘못된 한 줄 사후검증 문자열 수정
- 실제 다중라인 `const process = sourceProcess ...` 코드로 검증
- 기존 `mapLegacyJob(sourceProcess...)`가 제거되었는지 역검증 추가
- DB backup table의 anon/authenticated 접근 차단 추가

DB 정규화 규칙 자체는 v52.29와 동일합니다.
