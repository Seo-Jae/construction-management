# v52.44.3 적용방법

## 이번 중단 원인

실제 출력:

`[v52.44.2-v52.44 적용 중단]`
`기존 성명 2자 이상 제한 문구가 남아있습니다.`

이 검증은 잘못된 검증이었습니다.

`성명을 2자 이상 입력해주세요.` 문구는 두 군데 용도가 있습니다.

1. 기존 근로자 조회 검색 제한 → 제거되어야 함
2. 신규 근로자 등록 시 성명 최소 2자 검증 → 정상적으로 유지되어야 함

v52.44.2는 파일 전체에서 이 문구가 하나라도 있으면 실패하도록 되어 있어
정상적인 신규등록 검증까지 오류로 오인했습니다.

## v52.44.3 수정

파일 전체 문구 검사를 제거했습니다.

대신 실제 구형 조회 구조만 검사합니다.

- `labor_worker_master_search_v52_33`가 남아있는지
- `query.length < 2` 조회 제한이 남아있는지

이 두 가지가 제거되어 있으면 정상으로 판단합니다.

## SQL

v52.44.2에서 아래 두 SQL을 이미 성공 실행했다면 다시 실행할 필요 없습니다.

아직 실행하지 않았다면 순서대로:

1. `00_v52.44_근로자조회_전체목록_성명공종필터.sql`
2. `01_v52.44.1_근로자저장_jsonb오류_핫픽스.sql`
