# v52.38 적용방법

## 중요
현재 GitHub main은 v52.36 상태이므로 v52.38은
**v52.37 Excel 생성 사전검증 + v52.38 보안 휴대폰 기반을 누적 포함**합니다.

따라서 v52.37 패키지를 따로 적용할 필요 없습니다.

## 1. Supabase SQL

Supabase SQL Editor에서 아래 파일 전체를 실행:

`release_v52.38/Supabase에서_실행/00_v52.38_누적_Excel사전검증_보안휴대폰.sql`

필수 선행:
- v52.34 근로자 보호정보
- v52.35 월별 명단
- v52.36 출역/노임값

## 2. 프로그램 적용

```powershell
node .\release_v52.38\apply-v52.38-security-phone-foundation.cjs
npm run build
```

## 3. Git

빌드 성공 후:

```powershell
git add src/page/MonthlyLaborManagement.jsx
git add src/components/LaborSecurityPhoneDialog.jsx
git status
git commit -m "v52.38 add labor security phone foundation"
git push origin main
```

`git add .` 금지.

## 4. 화면 확인

`노임관리 > 월별 노임작성`

상단:
- Excel 생성 준비
- 보안 휴대폰

`보안 휴대폰` 클릭 후:
1. 현재 인증 상태 확인
2. 본인 휴대폰 번호 입력
3. `인증 대기 번호 등록`
4. 화면에는 `010-****-1234` 형식으로만 표시

## 현재 단계의 의미

번호를 등록해도 `인증 완료`가 아닙니다.

현재 SENS 사업자 연동이 아직 준비되지 않았기 때문에:
- SMS 발송 없음
- OTP 입력 없음
- verified 상태 전환 없음

DB에는 pending 상태로만 저장합니다.

## 보안

전체 휴대폰번호:
- 평문 컬럼 없음
- Supabase Vault 키 사용
- pgcrypto AES256 암호문 저장
- React에는 등록 직후 원문을 다시 반환하지 않음
- 화면에는 뒤 4자리만 표시

## 다음 단계

SENS 사용 가능 시:
1. pending 번호로 6자리 OTP 발송
2. OTP 서버 검증
3. verified 번호로 승격
4. 노임 Excel 다운로드 때 verified 번호로만 재인증
5. 다운로드 감사로그 기록
