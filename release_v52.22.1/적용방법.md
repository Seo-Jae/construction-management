# v52.22.1 적용방법

v52.22의 `공지 순서관리 툴바 추가: 기준 문자열이 2개` 오류를 수정한 보완본입니다.

## 오류 원인
`AttendanceManagement.jsx` 안에서 다음 구조가 `근로자 관리`와 `공지사항 관리`에 각각 존재했습니다.

```text
<Divider />
{!canManage && (
```

v52.22는 이 짧은 구조만 기준으로 잡아 2개가 발견되어 안전장치가 적용을 중단했습니다.

v52.22.1은 `공지사항 새로고침` 버튼까지 포함한 공지사항 전용 영역을 기준으로 사용합니다.

## 현재 파일 상태
v52.22 실행은 실제 파일 저장 전에 중단되므로 `AttendanceManagement.jsx`는 v52.21 상태인 것이 정상입니다.

## SQL
- v52.22 SQL을 이미 Supabase에서 성공 실행했다면 **다시 실행할 필요 없습니다.**
- 아직 실행하지 않았다면 ZIP 안의 기존 v52.22 SQL을 실행합니다.

```text
release_v52.22.1\Supabase에서_실행\00_v52.22_공지_체크순서변경_선택삭제.sql
```

## 프로그램 적용

```powershell
node .\release_v52.22.1\apply-v52.22.1-attendance-notice-toolbar-fix.cjs
```

정상 메시지:

```text
[v52.22.1 적용 완료]
```

그 다음:

```powershell
npm run build
```

## Git

실제 프론트 변경 파일은 1개입니다.

```powershell
git add src/page/AttendanceManagement.jsx
git status
git commit -m "v52.22 attendance notice toolbar ordering"
git push origin main
```

`git add .`은 사용하지 않습니다.
