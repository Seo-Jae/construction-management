# v52.48.5.44.76 변경내용

화면 90% 배율에서 버튼 위에 마우스를 올렸을 때 MUI Tooltip 설명이
버튼/커서보다 왼쪽·위쪽으로 크게 밀리는 문제를 전역 수정합니다.

원인:
- Dashboard가 `html.style.zoom = 0.9`를 사용함
- MUI Tooltip은 Portal로 `body` 쪽에 렌더링됨
- 기존 `src/index.css`의 Portal 좌표 보정에서 Tooltip만 의도적으로 제외되어 있었음
- 화면 우측으로 갈수록 약 10%의 좌표 오차가 누적되어, 저장 버튼처럼 우측 버튼은 설명이 매우 멀리 표시됨

수정:
- `.MuiTooltip-popper` 좌표계에 `--wooklim-dashboard-overlay-inverse-scale` 적용
- Tooltip 본체에는 `--wooklim-dashboard-scale`을 다시 적용해 실제 표시 크기는 기존 90%와 동일하게 유지
- 특정 페이지가 아니라 시스템 전체 MUI Tooltip에 적용

추가 Supabase SQL 없음.
