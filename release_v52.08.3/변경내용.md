# v52.08.3 메신저 읽음·나가기 UI 개선

기준 버전: **v52.08.2**

## 변경사항

1. 내가 보낸 메시지 하단 정보 순서를 다음과 같이 변경
   - 기존: `시:분  읽음/안읽음  삭제`
   - 변경: `읽음/안읽음  시:분  삭제`
2. 1:1 / 그룹 공통 `대화방 나가기`를 우측 정보패널에서 제거하고 대화 헤더 우측 끝 아이콘 버튼으로 이동
   - 두 대화 유형 모두 같은 위치
   - 텍스트 `대화방 나가기`는 화면에 상시 표시하지 않음
   - 마우스 오버 툴팁으로만 기능 안내
3. 그룹방 읽음 규칙 명확화
   - 해당 메시지를 읽어야 하는 참여자 중 1명이라도 미확인이면 `안읽음`
   - 모두 확인하면 `읽음`
   - 메시지 작성 이후 새로 그룹에 들어온 참여자는 과거 메시지의 미확인 인원으로 계산하지 않음
4. 그룹방에서 내가 보낸 메시지의 `안읽음` 글자를 클릭하면 미확인 참여자 명단 팝업 표시
   - 이름
   - 직급/권한
   - 회사/현장
5. v52.08.1의 Realtime 화면 깜빡임 안정화 구조와 v52.08.2의 나가기 RPC는 그대로 유지

## Supabase

추가 SQL 없음. v52.08.2 SQL까지 실행된 DB를 그대로 사용한다.
