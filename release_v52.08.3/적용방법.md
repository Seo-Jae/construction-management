# v52.08.3 적용방법

## 선행조건

- v52.08.2가 현재 프로젝트에 적용되어 있어야 한다.
- v52.08.2의 Supabase SQL이 이미 실행되어 있어야 한다.
- 이번 버전은 추가 SQL이 없다.

## 1. 압축 해제

ZIP의 `release_v52.08.3` 폴더를 현재 프로젝트 최상위에 둔다.

프로젝트 최상위는 `package.json`, `src` 폴더가 보이는 위치다.

## 2. 자동 적용

PowerShell에서 프로젝트 최상위에서 실행:

```powershell
node .\release_v52.08.3\apply-v52.08.3-messenger-read-ui.cjs
```

스크립트는 현재 `src/page/Messenger.jsx`가 검증된 v52.08.2 파일과 동일한지 SHA256으로 먼저 확인한다.
일치할 때만 자동 백업 후 v52.08.3 파일을 적용한다.

## 3. 빌드

```powershell
npm run build
```

마지막에 `✓ built in ...`이 나오면 빌드 성공이다.

## 4. 우선 테스트

1. 1:1 방에서 내가 보낸 메시지 하단이 `읽음/안읽음 → 시:분 → 삭제` 순서인지 확인
2. 1:1 방의 나가기 아이콘이 대화 헤더 우측 끝에 있는지 확인
3. 그룹방에서도 나가기 아이콘 위치가 동일한지 확인
4. 그룹방에서 한 명이라도 읽지 않은 경우 `안읽음`인지 확인
5. 그룹방의 `안읽음` 클릭 시 미확인 참여자 명단이 나오는지 확인
6. 상대가 읽은 뒤 팝업/표시가 Realtime으로 갱신되는지 확인
7. 화면 깜빡임이 다시 발생하지 않는지 확인

아직 Git push는 하지 말고 위 기능 확인 후 배포한다.
