# v52.48.5.44.34 변경내용

## 세대물량관리

- `양식 다운로드` 왼쪽에 `공정별옵션연결` 버튼을 추가했습니다.
- `공정별옵션연결`에서는 기존 Excel 설정창과 동일한 공정·유상옵션 연결 화면을 사용합니다.
- 새 설정창에서 `연결 저장`을 누르면 체크한 공정별 옵션 연결정보가 즉시 현장 데이터에 저장됩니다.
- `공정별옵션연결`과 `양식 다운로드`는 동일한 연결정보를 공유합니다.
  - 한쪽에서 저장한 체크값은 다른 쪽을 열었을 때 그대로 표시됩니다.
  - 새로고침하거나 다시 접속해도 저장된 체크값이 복원됩니다.
- 양식 다운로드 창에서 연결값을 변경하고 내려받는 경우에도 해당 연결정보를 함께 저장합니다.
- 갑지의 빈 옵션 안내문구를 `공정별옵션연결` 기준으로 수정했습니다.

## 데이터베이스

- 기존 `household_quantity` 저장영역을 사용하므로 새 Supabase SQL은 없습니다.
