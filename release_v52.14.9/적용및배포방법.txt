v52.14.9 적용 및 배포 방법

1. ZIP을 프로젝트 최상위 폴더에 압축 해제합니다.

2. Supabase SQL Editor에서 다음 파일의 전체 내용을 먼저 실행합니다.

release_v52.14.9\Supabase에서_실행\00_v52.14.9_안전관리자_중점위험요인.sql

3. 프로젝트 최상위 PowerShell에서 실행합니다.

node .\release_v52.14.9\apply-v52.14.9-safety-risk-broadcast.cjs
npm run build

4. 변경 파일만 Git에 추가합니다.

git add src/Dashboard.jsx src/page/UserManagement.jsx src/page/AttendanceManagement.jsx src/page/AttendanceWorkerPortal.jsx src/page/RiskBroadcastManagement.jsx
git commit -m "v52.14.9 add safety risk broadcasts"
git push origin main

5. Vercel 배포가 Ready가 되면 다음 순서로 확인합니다.

- 최고관리자 계정으로 회원관리에서 본사 가입자를 안전관리자로 변경하고 저장합니다.
- 안전관리자 계정으로 다시 로그인해 근태관리 > 중점위험요인 관리 탭을 엽니다.
- 전체 공통 전파를 등록한 뒤 근로자 앱에서 초록색 공통 배지를 확인합니다.
- 특정 현장 전파를 등록한 뒤 해당 현장 앱에서 파란색 담당 배지를 확인합니다.
- 다른 현장 근로자 앱에는 특정 현장 전파가 표시되지 않는지 확인합니다.
- 현장담당자 계정에서는 본인 현장만 선택되고 전체 공통 선택지가 없는지 확인합니다.
- 전파 종료 후 근로자 앱을 새로고침했을 때 해당 항목이 사라지는지 확인합니다.
- 등록·종료 성공과 오류가 상단 중앙 토스트로 표시되는지 확인합니다.

기존에 설치한 근태 앱은 삭제하거나 다시 설치할 필요가 없습니다.
추가 npm 패키지 설치도 필요 없습니다.
