# v52.14.9 변경내용

## 회원 및 권한

- 시스템 역할에 `안전관리자`를 추가했습니다.
- 신규 가입자는 기존처럼 `본사`로 가입한 뒤 최고관리자가 회원관리에서 `안전관리자`로 변경합니다.
- 안전관리자를 선택하면 본사·안전부서·본사 안전담당 권한 템플릿으로 연결됩니다.
- 안전관리자의 접근현장은 최고관리자가 선택현장 또는 전체현장으로 설정할 수 있습니다.
- 안전관리자는 관리자 전용 기능 전체를 자동으로 얻지 않고, 기존 담당자 수준의 기본 역할에 중점위험요인 전파 권한을 추가로 갖습니다.

## 중점위험요인 관리

- 근태관리 상단의 `근태 기록` 바로 오른쪽에 `중점위험요인 관리` 탭을 추가했습니다.
- 현장담당자는 배정된 현장에만 중점위험요인을 등록할 수 있습니다.
- 관리자·최고관리자·안전관리자는 전체 공통 또는 접근 가능한 특정 현장을 선택해 등록할 수 있습니다.
- 공통 전파는 초록색 `공통` 원형 배지, 특정 현장 전파는 파란색 `담당` 원형 배지로 구분합니다.
- 전파 내용, 대상, 등록자 직책·이름, 등록일시, 상태를 이력에서 확인할 수 있습니다.
- 잘못 등록하거나 종료된 위험요인은 화면 내부 확인창에서 `전파 종료`할 수 있습니다.
- 등록·종료 결과와 오류는 기존 상단 중앙 토스트로 표시합니다.

## 근로자 앱·웹

- 로그인한 근로자에게 전체 공통 전파와 본인 소속현장 전파만 표시합니다.
- 각 항목의 가장 왼쪽에 `공통` 또는 `담당` 원형 배지를 표시합니다.
- 내용 아래에 등록일시, 등록 당시 직책, 작성자 이름을 표시합니다.
- 전파 종료된 항목은 앱·웹에서 즉시 제외됩니다.
- 기존 출결 캘린더, 작업자 정보, 출퇴근 현황, QR 촬영, 앱 이름과 아이콘은 유지합니다.

## 보안

- 화면 버튼 표시와 별개로 Supabase RPC에서 역할·계정상태·현장 접근범위·세부권한을 다시 검사합니다.
- 담당자가 요청값을 변조해 다른 현장이나 전체 공통으로 등록할 수 없도록 차단했습니다.
- 근로자에게는 다른 현장의 중점위험요인을 반환하지 않습니다.
- 작성자 이름과 직책은 게시 당시 값으로 저장하여 이후 회원정보가 변경되어도 과거 이력 표기가 바뀌지 않습니다.

이번 버전은 Supabase SQL 1개 실행이 필요하며 추가 npm 패키지 설치와 근태 앱 재설치는 필요 없습니다.
