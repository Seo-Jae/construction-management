# v52.41 적용방법

## 1. Supabase SQL 먼저 실행

Supabase SQL Editor에서 아래 파일 전체 실행:

`release_v52.41/Supabase에서_실행/00_v52.41_근로자정보_UI_필수정보_국적표준화.sql`

## 2. 프로그램 적용

```powershell
node .\release_v52.41\apply-v52.41-worker-master-ui.cjs
npm run build
```

## 3. Git

빌드 성공 후:

```powershell
git add src/page/WorkerMasterManagement.jsx
git add src/page/MonthlyLaborManagement.jsx
git status
git commit -m "v52.41 improve worker master input ui"
git push origin main
```

`git add .`은 사용하지 않습니다.

## 4. 화면 확인

`노임관리 > 근로자 정보관리`

목록:
- 관리열에 `수정` 글자 없음
- 연필 아이콘만 표시
- 아이콘 줄바꿈 없음
- 상태/사용중 컬럼 없음

등록/수정:
- 사용중 토글 없음
- 외국인등록번호 없음
- 주민등록번호 *
- 전체 휴대폰번호 *
- 국적 *
- 은행 *
- 계좌번호 *
- 예금주 *
- 주소는 선택정보

## 5. 국적

자유입력하지 않습니다. 검색 가능한 고정 목록에서 선택합니다.

예:
- `한국`, `Korea`, `South Korea` 검색 → `대한민국`
- `중국`, `China` 검색 → `중국`
- `Vietnam` 검색 → `베트남`

실제 저장값도 서버에서 표준 한글명으로 다시 검증합니다.

## 6. 생년월일

기존 브라우저 달력 대신:
- 생년: 검색형 연도 선택
- 월: 선택
- 일: 선택

으로 바뀝니다. 생년 칸에 `1992`를 입력해 바로 찾을 수 있습니다.

## 7. 기존 데이터

- 기존 외국인등록번호 암호문/DB 필드는 즉시 삭제하지 않습니다.
- 기존 `is_active` DB 값도 삭제하지 않습니다.
- 알려진 국적 별칭은 SQL 실행 시 표준값으로 안전하게 정규화합니다.
- 기존 예금주 보유여부는 암호문을 서버 내부에서 확인해 `has_account_holder` 상태값만 backfill합니다.
