# v52.41 변경내용

## 관리열
기존 `연필 아이콘 + 수정` 버튼을 연필 아이콘만 표시하는 IconButton으로 변경했습니다.
Tooltip/aria-label은 유지합니다.

## 사용중
근로자 등록/수정 화면의 `사용중` 토글과 목록의 상태 컬럼을 제거했습니다.
기존 DB `is_active` 값은 호환성을 위해 유지합니다.

## 외국인등록번호
신규 입력 UI에서 제거했습니다.
기존 암호화 데이터는 즉시 파기하지 않고 보존합니다.

## 필수 보호정보
필수:
- 주민등록번호
- 전체 휴대폰번호
- 국적
- 은행
- 계좌번호
- 예금주

UI `required` 표시와 서버 최종 merged payload 검증을 모두 적용했습니다.
기존 암호화 값이 이미 있는 수정 건은 빈칸으로 두면 기존값을 유지합니다.
주소는 선택정보입니다.

## 국적 표준화
Autocomplete 고정 목록을 사용합니다.
검색 별칭을 지원해 `한국/Korea/South Korea → 대한민국`, `China → 중국`, `Vietnam → 베트남`처럼 검색할 수 있지만 저장값은 표준 한글명 하나만 사용합니다.
서버에서도 `labor_normalize_nationality_v52_41`로 재검증합니다.

## 생년월일
브라우저 기본 date picker를 제거했습니다.
- 연도: 검색 가능한 Autocomplete
- 월: Select
- 일: 해당 연/월의 실제 일수에 맞춘 Select
윤년도 자동 반영합니다.

## Excel 준비검사
주소와 외국인등록번호는 준비조건에서 제거했습니다.
새 필수조건은 주민등록번호, 전체 연락처, 국적, 은행, 계좌번호, 예금주, 해당 월 공종입니다.
