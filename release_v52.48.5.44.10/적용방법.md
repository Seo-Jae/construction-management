# v52.48.5.44.10 적용방법

기준은 `v52.48.5.44.9.5` 반영 완료본입니다.

1. ZIP을 프로젝트 루트(`package.json`, `src` 폴더가 있는 위치)에 풉니다.
2. PowerShell에서 아래 명령을 실행합니다.

```powershell
node release_v52.48.5.44.10/apply-v52.48.5.44.10-contract-allocation.cjs
```

3. Supabase SQL Editor에서 아래 파일을 전체 실행합니다.

```text
supabase/v52.48.5.44.10_labor_contract_allocations.sql
```

4. 빌드 후 배포합니다.

```powershell
npm run build
git add .
git commit -m "feat: allocate composite contract labor v52.48.5.44.10"
git push
```

## 사용방법

1. `노임관리 > 공정별 노임작성 > 공정별 노임단가`에서 공정을 엽니다.
2. `최초계약 품목 선택`에서 연결 공정이 2개 이상인 품목을 체크합니다.
3. `복합공정 단가 배분`을 누릅니다.
4. 현재 공정 단가를 입력합니다. 공정이 2개이면 나머지는 자동 계산됩니다. 예: 원 단가 5,800원에서 단열 2,600원 입력 → 합지 3,200원.
5. `차액 0원`을 확인하고 `일괄 저장`을 누릅니다.
6. 품목표에서 현재 공정의 배분 단가와 배분 계약 노무비를 확인합니다.
7. `선택값 불러오기` 후 공정 행을 저장합니다.

한 번 저장한 배분값은 같은 최초계약 품목의 다른 연결 공정에서도 재사용됩니다.

## 안전장치

- 같은 연결 공정 조합과 같은 원 단가의 체크 품목만 한 그룹으로 일괄 적용합니다.
- 연결된 모든 공정의 배분 단가 합계가 원 단가와 다르면 저장하지 않습니다.
- 화면 합계가 아닌 Supabase 원 계약품목과 저장된 배분값을 다시 검증해 공정 노무비를 계산합니다.
- 원 단가 또는 연결 공정 구성이 바뀌면 기존 배분값을 무효로 보고 재배분을 요구합니다.
- 적용 전 화면 파일을 `backup_v52.48.5.44.10_날짜시간` 폴더에 백업합니다.
