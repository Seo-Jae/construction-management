# v52.21 변경내용

## 관리자 공지사항 관리

- 공지 데이터에 `sort_order` 추가
- 공지 관리 표 맨 앞에 `순번` 추가
- 등록/수정 팝업에 `표시 순번` 숫자 입력 추가
- 표시 순번은 1 이상만 허용
- 신규 공지는 기본적으로 마지막 번호 제안
- 저장하면 같은 현장의 모든 공지를 1,2,3... 연속 순번으로 자동 정리
- 사용중지된 공지도 관리 순서는 유지

## 작업자 앱 상단 티커

기존:
`A공지　◆　B공지`

변경:
`1. A공지        2. B공지`

- `◆` 완전 제거
- DB `sort_order` 기준 정렬
- 작업자에게 실제 표시되는 공지만 화면상 1,2,3... 번호 부여
- 공지 사이 간격: 설치형 앱 약 64px, 일반 브라우저 약 48px 수준
- 기존 진한 노란색, 글씨 크기, 티커 방향은 유지
