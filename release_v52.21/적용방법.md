# v52.21 적용방법

## 변경 목표

1. `공지사항 관리`에서 공지 표시 순번 지정
2. 관리자 목록에 순번 표시
3. 작업자 앱 공지를 지정 순번대로 출력
4. 기존 `◆` 구분자 제거
5. 작업자 앱의 각 공지 앞에 `1.`, `2.`, `3.` 번호 표시
6. 공지 사이 간격 확대

## 1. Supabase SQL

먼저 Supabase SQL Editor에서 아래 파일 전체를 실행합니다.

```text
release_v52.21\Supabase에서_실행\00_v52.21_근태앱_공지순번_간격개선.sql
```

SQL 적용 후 기존 공지에도 현장별 순번이 자동으로 부여됩니다.

## 2. 프로그램 적용

프로젝트 최상위에서:

```powershell
node .\release_v52.21\apply-v52.21-attendance-notice-order.cjs
```

정상적으로:

```text
[v52.21 적용 완료]
```

가 나오면:

```powershell
npm run build
```

빌드 마지막의 `✓ built in ...`를 확인합니다.

## 3. Git

이번 실제 프론트 변경 파일은 2개입니다.

```powershell
git add src/page/AttendanceManagement.jsx
git add src/page/AttendanceWorkerPortal.jsx
git status
git commit -m "v52.21 attendance notice ordering"
git push origin main
```

`git add .`은 사용하지 않습니다.

## 4. 확인

관리자:
- 공지사항 관리 목록 맨 앞에 `순번` 열 표시
- 신규 등록 시 기본값은 현재 공지 개수 + 1
- 수정 시 기존 순번 표시
- 1번 공지를 3번으로 변경하면 전체가 다시 1,2,3...으로 정리
- 사용중지/사용재개를 해도 저장된 순번 유지

작업자 앱:
- `◆`가 더 이상 표시되지 않음
- 현재 표시되는 공지가 `1. 내용`, `2. 내용`, `3. 내용` 형태
- 관리자에서 지정한 순서대로 흐름
- 공지 사이가 기존보다 확실하게 넓음
