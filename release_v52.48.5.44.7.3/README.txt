[등록 회차 삭제]
- 등록된 기성 회차 목록 우측에 '관리 > 삭제' 추가
- 최고관리자만 서버에서 삭제 허용
- 누계 연결 보호를 위해 가장 최근 회차부터만 삭제 가능
  예: 1,2,3회차가 있으면 3 -> 2 -> 1 순서
- 작성중/작성완료 모두 최근 회차라면 삭제 가능
- 기성 회차/그 회차에 종속된 FK 데이터 삭제
- 계약버전/계약품목 원본은 보존
- 같은 회차의 임시저장도 정리

[미분류 원인]
현재 표준양식 parser에는 B열(구분)이 비어 있으면 자동으로 '미분류' 처리하는 코드가 있었습니다.
따라서 값이 안 넘어간 게 아니라, B열을 비운 행이 조용히 미분류로 바뀔 수 있었습니다.

변경 후:
- 품명이 있는데 B열 구분이 비어 있으면 '구분 미입력' 검산 오류
- 화면에서 미분류로 보이지만 저장에서는 제외
- 실제로 미분류가 맞는 품목은 B열에 '미분류'라고 직접 입력하면 정상 저장
- 업로드 토스트에 구분 미입력 건수 표시

[명칭 통일]
- 기성 작성 메인표: 타입·공구 -> 구분
- 공정 미연결 팝업: 타입·공구 -> 구분
- 필터 제목: 타입 구분 -> 구분
