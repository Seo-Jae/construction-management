# v52.46 변경내용

## 근로자 삭제

관리열을 다음처럼 변경합니다.

`[연필] [쓰레기통]`

삭제는 즉시 실행하지 않습니다.

확인 Dialog:
- 제목: 근로자 삭제
- 문구: `OOO를 정말로 삭제하시겠습니까?`
- 경고: 삭제 정보 복구 불가
- 버튼: `아니오 / 예, 삭제`

## 서버 안전장치

신규 RPC:
`labor_worker_master_delete_v52_46`

검사:
- 로그인 여부
- `labor.worker_master.manage` 권한
- 대상 근로자 존재 여부
- 월별 노임 저장 명단 사용이력

사용이력이 있으면 삭제하지 않습니다.

미사용 근로자만:
- 보호정보 감사기록 정리
- 암호화 보호정보 정리
- 근로자 마스터 삭제

삭제 성공 자체는 별도 `labor_worker_delete_audit_v52_46`에 최소 감사기록으로 남깁니다.
