# v52.46 적용방법

## 변경 1. 근로자 실제 삭제

`노임관리 > 근로자 정보관리 > 관리`

기존 연필 아이콘 오른쪽에 빨간 쓰레기통 아이콘이 추가됩니다.

삭제 순서:
1. 쓰레기통 클릭
2. `정말로 삭제하시겠습니까?` 확인창
3. `예, 삭제`
4. 서버 권한 재검증
5. 월별 명단 사용이력이 없으면 실제 삭제

월별 저장 명단에 이미 사용된 근로자는 과거 이력 보호를 위해 삭제가 차단됩니다.

## 변경 2. 근로자 조회 목록 높이

`월별 노임작성 > 근로자 조회`

목록 영역은 등록 인원수와 관계없이 항상:
- 헤더 1줄
- 근로자 10명

높이로 고정됩니다.

- 1명이어도 10명 크기 유지
- 7명이어도 10명 크기 유지
- 10명까지 높이 변화 없음
- 11명부터 목록 내부 세로 스크롤

## 3. 확인

### 삭제
- 근로자 정보관리 관리열에 연필 + 쓰레기통
- 쓰레기통 클릭 시 확인창
- `아니오` → 아무 변화 없음
- `예, 삭제` → 미사용 근로자 삭제
- 월별 명단 사용이력 있는 근로자 → 삭제 차단 메시지

### 조회목록
- 근로자 1~10명일 때 조회 박스 높이 동일
- 11명 이상일 때 내부 스크롤 생성
- 팝업 전체 높이가 인원수에 따라 출렁이지 않음
