# v52.48.5.44.15 변경내용

## Excel 골구도

- 실제 세대 셀에 달려 있던 입력 규칙 메모를 전부 제거했습니다.
- 동과 동 사이의 빈 열을 2개에서 1개로 줄였습니다.
- 간격용 빈 열의 너비를 Excel 기준 `5.42`로 설정했습니다.
- 기존 단일 시트와 숨김 세대 매핑 구조는 그대로 유지합니다.

## 상단 컨트롤

- `골구도 기준`, `단열 옵션`을 Chip 내부 높이에 의존하지 않는 고정 높이 박스로 변경했습니다.
- 두 박스와 `골구도 다운로드`, `엑셀 업로드`, `저장` 버튼의 실높이를 모두 30px로 맞췄습니다.

## 타입별 단열 옵션 현황

- 골구도 오른쪽에 타입별 단열 옵션 현황 패널을 추가했습니다.
- 각 타입은 `59A 0/131세대(0%)` 형식으로 입력 세대수, 전체 세대수, 비율을 표시합니다.
- 타입 행을 클릭하면 Excel에서 담당자가 입력한 옵션명별 세대수가 펼쳐집니다.
- 한 타입에 해당 옵션이 없더라도 다른 타입에서 등록된 옵션명은 `0세대`로 함께 표시합니다.
- 옵션명은 하드코딩하지 않고 현재 현장에 업로드·저장된 문자열에서 자동 생성합니다.
- 층별 타입 예외, 합쳐진 세대, 필로티를 포함한 실제 유효 골구도 세대만 집계합니다.

## 데이터베이스

- 기존 `option_status_documents` 데이터를 그대로 사용합니다.
- 이번 버전에서 새로 실행할 Supabase SQL은 없습니다.
