# v52.48.5.20 적용방법

적용 기준은 `v52.48.5.19`입니다. 지급자재 여부를 저장하기 위한 데이터베이스 열이 추가되므로 SQL을 반드시 실행해야 합니다.

## 1. 코드 적용

프로젝트 최상위 폴더에서 압축을 해제한 뒤 PowerShell에서 실행합니다.

```powershell
node .\release_v52.48.5.20\apply-v52.48.5.20-unit-price-owner-supplied.cjs
npm run build
```

## 2. Supabase SQL 실행

Supabase Dashboard의 `SQL Editor`에서 아래 파일을 열어 전체 내용을 한 번 실행합니다.

```text
supabase/v52.48.5.20_unit_price_owner_supplied.sql
```

기존 문서와 기본 구성값은 삭제하지 않습니다. 기존 항목은 지급자재가 아닌 상태로 유지되고, 새로 체크한 항목부터 상태가 저장됩니다. SQL은 다시 실행해도 안전합니다.

## 3. Git 반영

```powershell
git add src/page/UnitPriceAnalysis.jsx supabase/v52.48.5.20_unit_price_owner_supplied.sql
git status
git commit -m "v52.48.5.20 add owner supplied materials"
git push origin main
```

배포 후 재료비 항목의 `지급자재 여부`를 체크하여 정미금액·제출금액과 우측 금액 요약이 0원만큼 제외되는지 확인합니다.
