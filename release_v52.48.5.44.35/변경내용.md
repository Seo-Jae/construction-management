# v52.48.5.44.35 변경내용

## 전역 화면 배율 및 펼침 목록

- 시스템 내부 화면배율 90%에서 펼침 목록이 기준 요소보다 왼쪽 또는 위쪽으로 밀리는 문제를 수정했습니다.
- 원인은 문서 전체의 CSS `zoom`과 MUI Portal 좌표가 동시에 축소되던 현상이었습니다.
- 화면 본문의 90%·100% 크기 설정은 유지하면서 Portal 좌표계만 역보정했습니다.
- 펼침 목록 자체 크기는 다시 선택한 시스템 화면배율에 맞춰 표시됩니다.
- 특정 화면별 좌표 보정값을 사용하지 않고 다음 전역 구성요소에 공통 적용했습니다.
  - Menu
  - Select 펼침 목록
  - Popover
  - Autocomplete
  - Tooltip을 제외한 Paper형 Popper
- 시스템 내부 화면배율 90%·100% 전환과 브라우저 확대·축소가 서로 독립적으로 동작합니다.
- 인쇄 시에는 기존처럼 화면배율과 관계없이 100%를 유지합니다.

## 데이터베이스
