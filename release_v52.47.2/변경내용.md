# v52.47.2 변경내용

## 원인

현재 프로젝트는 통합관리시스템과 근태시스템이 같은 `index.html`을 사용합니다.

`index.html`에는 기본값으로:
- title = 욱림건설 통합관리시스템
- favicon = /wooklim-favicon.png

가 지정되어 있습니다.

반면 근태 PWA manifest는 이미:
- 욱림건설 근태시스템
- attendance-icon-192.png
- attendance-icon-512.png

으로 정상 설정되어 있었습니다.

따라서 설치 앱과 브라우저 탭의 이름/아이콘이 서로 달랐습니다.

## 수정

앱 시작 시 URL의 `view` 값을 확인합니다.

`view=attendance-worker`이면:
- document.title → 욱림건설 근태시스템
- rel=icon → /attendance-icon-192.png
- apple-mobile-web-app-title → 욱림건설 근태시스템

그 외에는:
- document.title → 욱림건설 통합관리시스템
- rel=icon → /wooklim-favicon.png

으로 유지합니다.

서비스워커 등록 조건도 같은 `isAttendanceWorkerView` 값을 재사용합니다.
