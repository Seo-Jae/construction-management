# v52.47.2 적용방법

## 변경 내용

근태앱 주소:

`?view=attendance-worker`

로 접속했을 때 브라우저 탭을 다음처럼 표시합니다.

- 사이트명: **욱림건설 근태시스템**
- 브라우저 탭 아이콘: **근태앱과 동일한 attendance-icon-192.png**

일반 통합관리시스템은 그대로 유지합니다.

- 사이트명: 욱림건설 통합관리시스템
- 아이콘: 기존 빨간 욱림 로고 `wooklim-favicon.png`

## 기존 PWA 설정

`public/attendance.webmanifest`는 이미:

- name: 욱림건설 근태시스템
- short_name: 욱림건설 근태시스템
- icon: attendance-icon-192/512

으로 정상 설정되어 있으므로 manifest 자체는 수정하지 않습니다.

## 적용

SQL 변경 없습니다.

프로젝트 최상위에서:

```powershell
node .\release_v52.47.2\apply-v52.47.2-attendance-browser-identity.cjs
npm run build
```

빌드 성공 후:

```powershell
git add src/main.jsx
git status
git commit -m "v52.47.2 separate attendance browser identity"
git push origin main
```

`git add .`은 사용하지 않습니다.

## 확인

### 근태시스템

근태 웹주소를 새로 열면:

- 탭 제목 `욱림건설 근태시스템`
- 탭 아이콘이 앱과 동일한 근태 아이콘

이어야 합니다.

### 통합관리시스템

일반 관리자 주소에서는:

- `욱림건설 통합관리시스템`
- 기존 빨간 욱림 로고

가 그대로 유지되어야 합니다.

## 캐시 주의

파비콘은 Chrome이 강하게 캐시할 수 있습니다.
배포 직후 기존 탭에서 아이콘이 바로 안 바뀌면:

1. 해당 근태 탭을 완전히 닫기
2. 새 탭에서 근태 주소 다시 열기
3. 그래도 이전 아이콘이면 Ctrl+Shift+R 한 번 실행

하면 확인할 수 있습니다.
