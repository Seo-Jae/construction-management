# 적용방법

프로젝트 최상위에서:

```powershell
node .\release_v52.48.5.44.70\apply-v52.48.5.44.70-expense-runtime-access.cjs
npm run build
```

그 다음 Supabase > SQL Editor에서 아래 파일 전체를 1회 실행합니다.

`supabase/v52.48.5.44.70_expense_runtime_access.sql`

SQL 성공 후 Test 담당자 계정에서 `Test현장 > 지출결의서 작성`으로 들어가 신규 작성 → 저장 → 목록 재조회 → 수정 → 삭제 순서로 확인합니다.

Git 반영:

```powershell
git add .
git commit -m "v52.48.5.44.70 expense runtime access"
git push origin main
```

GitHub main push로 운영 Vercel 배포가 자동 진행되는 기존 방식은 그대로 사용합니다. 이 버전의 실제 권한 수정은 Supabase SQL 실행 즉시 적용됩니다.
