# v51.88.1 패키지 설치 오류 수정본

이 수정본은 `pdfjs-dist` 설치 시 기존 프로젝트의 peer dependency 충돌을 피하도록 `--legacy-peer-deps` 옵션을 자동 사용합니다. 이전 v51.88 적용 스크립트가 중단되었다면 이 스크립트를 다시 실행하면 됩니다.

# 지출결의서 작성 v51.88.1 적용방법

## 적용 기준

지출결의서 작성 v51.87이 적용된 프로젝트를 기준으로 합니다.
이번 버전은 사용내역 목록형 전환과 SM하이플러스 통행료 PDF 자동 입력 기능을 추가합니다.
DB 변경은 없습니다.

## 1. 압축 해제

ZIP 파일을 프로젝트 최상위 폴더에 압축 해제합니다.
프로젝트 최상위 폴더는 `package.json`, `src`, `public` 폴더가 있는 위치입니다.

## 2. 소스 적용

프로젝트 최상위 폴더의 터미널에서 실행합니다.

```bash
node .\release_v51.88.1\apply-v51.88.1.1-expense-resolution.cjs
```

적용 스크립트는 다음 작업을 처리합니다.

- 기존 파일 자동 백업
- v51.88.1 파일 복사
- `pdfjs-dist`가 없을 경우 `pdfjs-dist@5.7.284` 자동 설치

적용 파일:

- `src/page/ExpenseResolution.jsx`
- `src/utils/expenseResolutionExcel.js`
- `src/utils/highpassReceiptPdf.js`

> 이번 버전은 Supabase SQL을 실행하지 않습니다.

## 3. 빌드 확인

```bash
npm run build
```

## 화면 사용방법

1. `업무보고관리 > 지출결의서 작성`에서 신규 문서를 엽니다.
2. `통행료 PDF 업로드`를 누릅니다.
3. SM하이플러스 확인증 PDF를 선택합니다.
4. 자동 추출된 사용일, 도착영업소, 도착시간, 금액을 확인합니다.
5. 각 행의 출발지를 입력하거나 상단 일괄 입력을 사용합니다.
6. `선택 내역 추가`를 누릅니다.
7. 사용내역 목록에서 반영 결과를 확인합니다.
8. 필요한 일반 내역은 `내역 추가`로 작성합니다.
9. 저장 또는 엑셀 다운로드를 진행합니다.

## PDF 자동 추출 기준

현재 자동 추출은 사용자가 제공한 SM하이플러스 확인증처럼 문자가 포함된 PDF 형식을 기준으로 합니다.
스캔 이미지 PDF, 다른 카드사 양식, 화면을 사진으로 촬영한 PDF는 자동 추출되지 않을 수 있습니다.
자동 추출 후 도착영업소, 시간, 금액은 수정할 수 있습니다.

## 확인 항목

1. 사용내역이 카드가 아닌 표 목록으로 표시되는지
2. `내역 추가`를 눌러야 입력 팝업이 열리는지
3. 통행료 PDF에서 전체 영수증 건수가 읽히는지
4. 출발지 일괄 입력이 선택 내역에 적용되는지
5. 중복 내역이 자동 선택 해제되는지
6. 목록에 사용일, 통행료, 경로, 시간, 금액이 표시되는지
7. 갑지에 도착영업소와 시간이 들어가는지
8. 상세내역에 출발지→도착영업소가 표시되는지
9. 저장 후 다시 열었을 때 통행료 내역이 유지되는지
10. 엑셀 다운로드 결과의 통행료 금액과 합계가 일치하는지
