# 지출결의서 작성 v51.88.1 변경내용

## 1. 사용내역 입력 방식 변경

- 기존처럼 모든 입력 박스가 계속 펼쳐져 있는 구조를 제거했습니다.
- 등록된 내역은 표 형태로 한 줄씩 나열됩니다.
- `내역 추가`를 눌렀을 때만 입력창이 팝업으로 열립니다.
- 목록 행 또는 수정 아이콘을 누르면 기존 내역을 수정할 수 있습니다.
- 목록에서 사용일, 항목, 사용내용, 금액을 한 번에 확인할 수 있습니다.

## 2. 통행료 PDF 업로드

- `통행료 PDF 업로드` 버튼을 추가했습니다.
- SM하이플러스 문자형 PDF의 각 영수증에서 다음 정보를 자동 추출합니다.
  - 영수일시의 날짜
  - 한국도로공사 옆 도착영업소
  - 영수일시의 시·분
  - 영수금액
- 업로드 확인창에서 사용자는 출발지만 입력합니다.
- 여러 내역에 같은 출발지를 한 번에 넣는 일괄 적용 기능을 제공합니다.
- 선택한 내역만 사용내역 목록에 추가됩니다.

## 3. 중복 방지

현재 목록에 같은 `사용일 + 도착시간 + 도착영업소 + 금액` 조합이 있으면 중복 내역으로 판단합니다.
중복 내역은 업로드 확인창에서 자동 선택 해제되고 다시 선택할 수 없습니다.

## 4. 작성월 처리

PDF의 영수월과 현재 작성월이 다르고 기존 사용내역이 없다면,
`작성월을 PDF 영수월로 변경`을 선택할 수 있습니다.

## 5. 갑지 및 상세내역 반영

- 갑지 통행료 내용: `도착영업소 도착시간`
- 상세내역 통행료 내용: `출발지→도착영업소(통행료)`
- 통행료 금액은 기존 통행료 금액 칸과 합계에 반영됩니다.

## 6. 적용 범위

- DB 변경 없음
- Supabase SQL 실행 없음
- PDF 분석을 위해 `pdfjs-dist` 패키지를 사용하며 적용 스크립트가 없을 경우 자동 설치합니다.
