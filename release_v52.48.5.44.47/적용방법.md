# 적용 및 운영 배포

## 1. Supabase SQL 먼저 실행
Supabase Dashboard → SQL Editor에서 아래 파일 내용을 전체 실행합니다.

`release_v52.48.5.44.47/supabase_v52.48.5.44.47_system_guides.sql`

정상 실행되면 다음이 생성됩니다.
- `public.system_guides`
- `public.get_system_guide(text)`
- Storage bucket `system-guide-images`
- 관련 RLS 정책

## 2. 프로젝트 적용
프로젝트 최상위 폴더에 `release_v52.48.5.44.47` 폴더를 넣은 뒤 PowerShell에서 실행합니다.

```powershell
node .\release_v52.48.5.44.47\apply-v52.48.5.44.47-guide-popup-foundation.cjs
npm run build
git add .
git commit -m "v52.48.5.44.47 가이드 설정 및 팝업 가이드 기반 구조"
git push origin main
```

`main` 브랜치가 Vercel Production과 연결되어 있으면 push 후 운영 배포가 자동 진행됩니다.

## 3. 적용 후 확인
1. 최고관리자 계정: 좌측 하단에 `가이드 설정`이 표시되는지 확인
2. 일반 사용자 계정: 좌측에 `가이드 설정` 메뉴가 표시되지 않는지 확인
3. 실제 메뉴(예: 일위대가작성) 진입 후 상단 `가이드` 버튼이 표시되는지 확인
4. 미작성 메뉴에서 가이드 클릭 시 별도 창에 `가이드 준비중`이 표시되는지 확인
5. 최고관리자 → 가이드 설정에서 테스트 가이드를 작성하고 `저장` 후 `작성 미리보기` 확인
6. `공개` 후 해당 실제 메뉴의 가이드 버튼에서 공개 내용이 표시되는지 확인
7. 공개 가이드 수정 후 `저장`만 했을 때 일반 사용자는 기존 공개본을 계속 보는지 확인
8. 다시 `공개`를 눌렀을 때 수정본으로 변경되는지 확인
