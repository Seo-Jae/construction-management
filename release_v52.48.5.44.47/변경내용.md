# v52.48.5.44.47 변경내용

## 가이드 접근 구조 변경
- 기존의 전체 사용자용 `가이드` 좌측 메뉴 방식을 폐기했습니다.
- 좌측 메뉴는 `가이드 설정`으로 변경하고 `최고관리자`에게만 표시합니다.
- `guide` 화면에 URL/세션 값으로 직접 접근하더라도 최고관리자가 아니면 권한 판정에서 제외됩니다.

## 실제 메뉴의 가이드 버튼
- 현재 사용 중인 메뉴에 대응하는 `가이드` 버튼을 상단 공통 영역에 추가했습니다.
- 메뉴별로 버튼 위치가 달라지지 않도록 Dashboard 공통 AppBar에서 현재 `currentView`를 기준으로 표시합니다.
- 가이드가 아직 공개되지 않은 메뉴는 팝업 창에서 `가이드 준비중`으로 표시됩니다.

## 별도 팝업 가이드 창
- 우측 패널 방식 대신 별도 브라우저 팝업 창을 사용합니다.
- 일위대가 기술자료 이미지 조회창과 같은 방향으로, 큰 독립 창에서 많은 설명과 이미지를 볼 수 있도록 했습니다.
- 창 크기는 현재 모니터 가용영역에 맞춰 자동 계산되며 크기조절/스크롤/인쇄/닫기를 지원합니다.

## 최고관리자 가이드 설정
- 전체 메뉴 구조를 동일하게 표시합니다.
- 상태: `준비중` / `작성중` / `공개`
- 메뉴별 제목, 요약, 단계별 제목/설명, 이미지, 이미지 설명, 주의·참고사항 작성
- 단계 추가/삭제/순서 이동
- `저장`: 초안 저장
- `작성 미리보기`: 공개 전 별도 팝업 형태로 확인
- `공개`: 현재 초안을 공개본으로 복사하여 일반 사용자에게 즉시 반영
- 공개된 가이드를 수정하여 저장해도 기존 공개본은 유지되며, 다시 `공개`를 눌렀을 때만 새 내용이 노출됩니다.
- `공개 중지`: 일반 사용자에게 다시 준비중 상태로 전환

## Supabase
- `public.system_guides` 테이블 추가
- 초안과 공개본을 별도 컬럼으로 저장
- 일반 사용자는 테이블 직접 조회 불가
- `public.get_system_guide(text)` RPC로 공개본만 조회
- `system-guide-images` 비공개 Storage 버킷 추가
- 인증 사용자는 이미지 조회 가능, 등록/수정/삭제는 최고관리자만 가능
