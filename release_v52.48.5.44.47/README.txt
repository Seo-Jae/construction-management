v52.48.5.44.47
가이드 설정 + 현재 메뉴 별도 팝업 가이드 기반 구조

주요 변경
1. 좌측 `가이드` 메뉴를 `가이드 설정`으로 변경하고 최고관리자에게만 표시
2. 일반 사용자는 별도 가이드 메뉴가 보이지 않음
3. 실제 메뉴 화면 상단 공통 영역에 `가이드` 버튼 표시
4. 가이드 클릭 시 일위대가 기술자료 이미지 조회창과 유사한 별도 브라우저 팝업 창으로 가이드 표시
5. 최고관리자 `가이드 설정`에서 제목/요약/단계별 설명/이미지/주의사항 작성 가능
6. 초안 저장과 공개 분리
7. 공개된 가이드만 일반 사용자에게 노출
8. 가이드 이미지는 비공개 Supabase Storage 버킷에 저장

필수
- Supabase SQL Editor에서 `supabase_v52.48.5.44.47_system_guides.sql` 1회 실행
