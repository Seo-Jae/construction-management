v52.48.5.44.7.1 - 최초계약 빈양식 다운로드

원인
- v52.48.5.44.7은 progress_contract_items에 이미 계약품목이 있어야
  기성 양식을 생성하도록 만들었음.
- 하지만 최초계약은 아직 계약품목이 등록되지 않은 상태에서
  바로 Excel 양식을 받아 계약내역을 입력해야 하므로 순서가 뒤집혀 있었음.

수정
1. 최초계약 또는 신규 계약버전에 계약품목이 0건이어도 다운로드 가능
2. 이 경우 500개의 빈 계약입력 행을 가진 '계약등록용 양식' 생성
3. 노란색 입력영역
   - 타입·공구
   - 옵션
   - 품명
   - 규격
   - 단위
   - 계약수량
   - 재료비단가
   - 노무비단가
   - 경비단가
   - 금회수량
4. 사용하지 않는 행은 품명만 비워두면 업로드시 자동 제외
5. 계약 재료비/노무비/경비는 수량×단가로 시스템에서 재계산
6. 기존 계약품목이 이미 있는 계약버전은 기존 v1 규칙 유지
   - 계약내역/전회누계 자동
   - 금회수량만 노란색 입력
7. 기존 외부 기성엑셀 업로드 호환 유지
8. SQL 변경 없음

node release_v52.48.5.44.7.1/apply-v52.48.5.44.7.1-initial-contract-template.cjs
