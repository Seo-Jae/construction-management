# v52.43 적용방법

## 수정 내용

생년 입력칸에서 `1992`를 키보드로 입력한 뒤 `Tab`을 누르면
기존에는 선택값으로 확정되지 않고 다음 칸으로 이동하는 문제가 있었습니다.

v52.43에서는 월별 노임작성과 근로자 정보관리 두 화면 모두:

- 직접 `1992` 입력
- `Tab`
- 자동으로 `1992` 선택값 확정
- 월 칸으로 정상 이동

되도록 수정합니다.

`Enter`로도 동일하게 확정됩니다.

## 1. SQL

SQL 변경 없습니다.

## 2. 적용

프로젝트 최상위에서:

```powershell
node .\release_v52.43\apply-v52.43-birth-year-tab-commit.cjs
npm run build
```

## 3. Git

빌드 성공 후:

```powershell
git add src/page/MonthlyLaborManagement.jsx
git add src/page/WorkerMasterManagement.jsx
git status
git commit -m "v52.43 fix birth year tab commit"
git push origin main
```

`git add .`은 사용하지 않습니다.

## 4. 테스트

### 월별 노임작성
`+ > 신규 근로자 등록`

1. 성명 입력
2. 생년 칸에 `1992` 직접 입력
3. `Tab`
4. 월 칸으로 이동
5. 다시 생년 칸을 확인했을 때 `1992`가 유지되어야 함
6. 월/일 선택 후 등록 정상 동작 확인

### 근로자 정보관리
`근로자 등록` 또는 `수정`

동일하게:
`1992 입력 → Tab → 1992 유지`

를 확인합니다.

## 입력 제한

유효 범위:
- 1920년
- 현재연도

목록에 없는 연도는 Tab/Enter 시 확정하지 않습니다.
