# v52.43 변경내용

## 원인

MUI Autocomplete는 기존 설정에서 목록 항목을 클릭해 선택했을 때만
`value`가 확정되었습니다.

키보드로 `1992`를 직접 입력한 상태는 input text일 뿐
실제 `birthYear` 값이 아니어서 Tab으로 포커스가 이동하면 값이 사라졌습니다.

## 수정

생년 Autocomplete에:
- `freeSolo`
- `autoSelect`

를 적용했습니다.

따라서 사용자가 유효한 4자리 연도를 직접 입력한 뒤
Tab 또는 Enter를 누르면 해당 값이 자동으로 선택값으로 확정됩니다.

## 안전 처리

확정할 때 `BIRTH_YEAR_OPTIONS` 안에 실제 존재하는 연도인지 다시 검사합니다.

따라서:
- 1992 → 정상
- 2026 → 정상
- 1910 → 미확정
- 3000 → 미확정
- abcd → 미확정

입니다.

입력칸도 numeric + 최대 4자리로 설정했습니다.

## 적용 화면

- 월별 노임작성 > 신규 근로자 등록
- 근로자 정보관리 > 근로자 등록/수정

두 화면을 동일하게 수정합니다.
