# 사내시스템 v52.05 변경내용

## Main 캘린더 화면 구성

- 기존 캘린더 박스 내부를 좌우로 분리했습니다.
- 좌측 2/3에는 캘린더를 배치했습니다.
- 우측 1/3에는 해당 월의 주요일정 목록을 배치했습니다.
- 작은 화면에서는 캘린더 아래에 주요일정 목록이 이어집니다.
- 기존 캘린더 하단의 일정 목록은 제거했습니다.

## 명칭 변경

- 화면의 `주요 이슈` 명칭을 `주요일정`으로 변경했습니다.
- 등록·수정·삭제 버튼과 토스트 문구도 주요일정 기준으로 통일했습니다.

## 날짜 상세 팝업

- 빨간 점이 표시된 날짜만 클릭할 수 있습니다.
- 클릭하면 해당 날짜의 주요일정 상세 팝업이 열립니다.
- 같은 날짜에 여러 일정이 있으면 한 팝업에 모두 표시합니다.
- 일정 내용, 작성자, 등록 현장, 공유 범위, 최종 수정일을 표시합니다.
- 일정이 없는 날짜는 클릭 동작이 없습니다.

## 유지 기능

- 출력일보 등록일의 녹색 점을 유지했습니다.
- 일정 등록·수정·삭제 기능을 유지했습니다.
- 현장별 일정과 전체현장 공유 권한 규칙을 유지했습니다.
- 공지사항, 주요공정 및 다른 Main 기능은 변경하지 않았습니다.
- Supabase 테이블과 함수는 변경하지 않았습니다.
