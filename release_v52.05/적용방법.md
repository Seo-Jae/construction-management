# 사내시스템 v52.05 적용방법

현재 v52.04가 적용된 프로젝트를 기준으로 합니다.

## 1. 압축 해제

ZIP을 프로젝트 최상위 폴더에 압축 해제합니다.

## 2. 프런트 파일 적용

프로젝트 최상위 폴더에서 실행합니다.

```powershell
node .\release_v52.05\apply-v52.05-main-calendar-schedule-layout.cjs
npm run build
```

이번 버전은 Supabase SQL 실행이 필요하지 않습니다.

## 3. 개발 화면 확인

```powershell
npm run dev
```

## 4. 확인 항목

- Main의 공지사항 좌측 1/3·캘린더 박스 우측 2/3 유지
- 캘린더 박스 내부의 캘린더 좌측 2/3·주요일정 우측 1/3 배치
- `주요 이슈`가 `주요일정`으로 표시되는지 확인
- 일정이 등록된 날짜에 빨간 점 표시
- 빨간 점이 있는 날짜 클릭 시 상세 팝업 표시
- 팝업에 내용·작성자·현장·공유 범위·수정일 표시
- 일정이 없는 날짜 클릭 시 아무 동작 없음
- 일정 등록·수정·삭제 및 전체현장 공유 유지

## 5. Git 반영

화면 확인 후 프로젝트 최상위 폴더에서 실행합니다.

```powershell
git status
git add src/page/MainDashboard.jsx
git commit -m "feat: improve main calendar schedule layout"
git push
```
