# v51.95 적용방법

프로젝트 최상위 폴더에서 PowerShell을 열고 아래 명령을 실행합니다.

```powershell
node .\release_v51.95\apply-v51.95-management-area.cjs
npm run build
```

빌드가 완료되면 아래 항목을 확인합니다.

1. 상단에 회사 로고가 보이는지 확인
2. 기존 건설 이모지 아이콘이 사라졌는지 확인
3. `공사 관리`, `안전 관리` 탭이 보이는지 확인
4. `결재함` 제목 앞의 `욱림건설 -`이 사라졌는지 확인
5. 안전 관리 선택 시 공사관리 메뉴와 현장 선택창이 숨겨지는지 확인
6. 공사 관리로 돌아왔을 때 직전 메뉴와 현장이 유지되는지 확인

이번 버전은 Supabase SQL 실행이 필요하지 않습니다.
