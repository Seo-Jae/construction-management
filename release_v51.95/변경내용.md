# v51.95 변경내용

- 상단의 건설 이모지 아이콘을 제거했습니다.
- 상단에 욱림건설 회사 로고를 표시했습니다.
- 회사 로고 옆에 `공사 관리`, `안전 관리` 전환 탭을 추가했습니다.
- 현재까지 구현된 모든 메뉴는 `공사 관리` 영역에 그대로 유지했습니다.
- `안전 관리` 선택 시 공사관리 사이드 메뉴와 현장 선택창을 숨기고 안전관리 전용 영역을 표시합니다.
- 다시 `공사 관리`로 돌아오면 직전에 선택했던 공사 메뉴와 현장이 그대로 복원됩니다.
- 새로고침 후에도 마지막으로 선택한 관리영역을 유지합니다.
- `욱림건설 - 결재함`은 `결재함`으로 표시되도록 회사명 접두어를 제거했습니다.
- 전체 현장 화면 제목도 `욱림건설 전체 현장 Dashboard`에서 `전체 현장 Dashboard`로 정리했습니다.
- Supabase SQL 변경은 없습니다.
