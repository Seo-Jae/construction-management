# v52.33 적용방법

## 반드시 먼저
Supabase SQL Editor에서 아래 파일 전체를 실행합니다.

`release_v52.33/Supabase에서_실행/00_v52.33_근로자마스터_기반.sql`

## 그 다음 프로그램 적용

프로젝트 최상위에서:

```powershell
node .\release_v52.33\apply-v52.33-worker-master-foundation.cjs
npm run build
```

## Git
빌드 성공 후 아래 파일만 올립니다.

```powershell
git add src/Dashboard.jsx
git add src/components/Sidebar.jsx
git add src/page/MonthlyLaborManagement.jsx
git add src/page/WorkerMasterManagement.jsx
git status
git commit -m "v52.33 add labor worker master foundation"
git push origin main
```

`git add .`은 사용하지 않습니다.

## 최고관리자 확인
최고관리자는 SQL 적용 후 `노임관리 > 근로자 정보관리` 메뉴가 자동으로 보입니다.

## 일부 관리자에게 권한 부여
최고관리자 계정으로:

`회원관리 > 해당 사용자 > 특수권한`

에서 신규 권한:

`근로자 정보관리`

를 켭니다.

일반 관리자/담당자에게는 자동 부여되지 않습니다.

## 담당자 확인
담당자는 `근로자 정보관리` 메뉴는 보이지 않습니다.

하지만 자기 현장에서 `노임관리 > 월별 노임작성 > 근로자 조회`는 기존 `공정별 노임작성` 조회권한(`labor.cost.view`)이 있으면 사용할 수 있습니다.

검색 결과는:
- 성명
- 생년월일
- 휴대폰 뒤 4자리
- 최근 공종

만 내려옵니다.
