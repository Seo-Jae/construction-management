## 기존 권한 UI 확인
현재 회원관리 특수권한 화면은 `permission_definitions.is_sensitive = true` 권한을 DB 카탈로그에서 자동으로 표시합니다.

따라서 신규 `labor.worker_master.manage` 권한은 SQL 적용 후 회원관리 특수권한에 자동 노출되며 `UserManagement.jsx` 수정은 필요 없습니다.
