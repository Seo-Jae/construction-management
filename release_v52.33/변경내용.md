# v52.33 변경내용

## 2단계 목표
회사 공통 `근로자 마스터` 기반을 만들고 월별 노임작성 검색과 연결합니다.

## 권한
신규 특수권한:
- `labor.worker_master.manage`
- 화면 표시명: `근로자 정보관리`

자동 접근:
- 최고관리자

별도 특수권한 필요:
- 관리자

접근 불가:
- 담당자
- 특수권한이 없는 관리자

담당자는 근로자 마스터 메뉴는 볼 수 없지만 월별 노임작성 안에서는 기존 근로자를 검색할 수 있습니다.

## 근로자 마스터 저장항목
이번 단계:
- 성명
- 생년월일
- 휴대폰 뒤 4자리
- 최근 공종
- 비고
- 사용중/비활성

## 담당자 검색결과
RPC는 아래만 반환:
- 근로자 ID
- 성명
- 생년월일
- 휴대폰 뒤 4자리/마스킹값
- 최근 공종

주소, 주민번호, 계좌정보 등의 원문은 반환하지 않습니다.

## 월별 노임작성
기존 v52.32의 명단 조작은 유지:
- 신규 행 추가
- 선택 삭제
- ↑ / ↓
- 공종 개별입력
- 공종 일괄변경

변경:
- 기존 더미 `workerOptions` 검색 제거
- 실제 Supabase RPC 검색 연결
- 현장 변경 시 기존 임시 명단/검색결과 초기화
- 검색 → 추가 → 다시 검색 → 추가 반복 유지
- 이미 추가한 근로자는 `추가됨`

## DB 보안
- `labor_worker_master` 직접 SELECT/INSERT/UPDATE 차단
- RLS 활성화
- RPC를 통해서만 조회/등록/수정
- 회사 공통 마스터 관리 RPC는 특수권한 검사
- 월별 노임검색 RPC는 `labor.cost.view` + 해당 현장 접근권한 검사
- 근로자 등록/수정 감사로그 저장
