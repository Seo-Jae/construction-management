# v52.48.5.14 변경내용

## 새로고침 버튼 통일

- 가입 승인
- 근태 기록
- 진척 승인
- 기기 변경
- 변경 이력
- 근로자 관리
- 공지사항 관리

위 화면의 새로고침을 모두 동일한 원형 아이콘 버튼으로 통일했습니다. 새로고침 중에는 같은 위치에 작은 진행 표시가 나타납니다.

## 근태 기록 날짜 이동

- 날짜 선택창 왼쪽에 이전 날짜 버튼 추가
- 날짜 선택창 오른쪽에 다음 날짜 버튼 추가
- 버튼을 누를 때 하루 단위로 이동
- 날짜 이동 즉시 선택한 일자의 근태 기록 자동 조회
- 기존 달력형 날짜 직접 선택 기능 유지

이번 버전은 프론트엔드 UI만 변경하며 Supabase SQL 실행은 필요하지 않습니다.
