# v52.48.5.14 적용방법

적용 기준은 `v52.48.5.13.1`이며, `v52.48.5.13.2`는 SQL 전용 수정이므로 실행 여부와 관계없이 적용할 수 있습니다.

프로젝트 최상위 폴더에서 압축을 해제한 뒤 PowerShell에서 실행합니다.

```powershell
node .\release_v52.48.5.14\apply-v52.48.5.14-attendance-refresh.cjs
npm run build
git add src/page/AttendanceManagement.jsx
git status
git commit -m "v52.48.5.14 unify attendance refresh controls"
git push origin main
```

Supabase SQL은 실행하지 않습니다. 앱 재설치도 필요 없으며 배포 후 새로고침하거나 앱을 재실행하면 됩니다.
