# v52.48.5.44.26 변경내용

## 화면 90% 높이 보정

- 기존에는 대시보드 높이 `100vh`까지 화면 배율 90%가 적용되어 실제 작업영역이 화면 높이의 약 90%만 사용됐습니다.
- 90% 선택 시 가용 높이를 약 `111.11vh`로 역보정하여 최종 표시 높이가 다시 화면 100%를 채우도록 변경했습니다.
- 100% 선택 시에는 기존처럼 `100vh`를 사용합니다.
- 대시보드 최상위 영역, 본문, 좌측 메뉴 높이에 동일 기준을 적용했습니다.
- 팝업 배경 높이도 같은 기준으로 보정했습니다.
- 문서 자체의 불필요한 외부 스크롤은 차단하고 각 화면 내부 스크롤만 유지합니다.
- 인쇄 시에는 기존과 같이 배율과 높이를 100% 기준으로 복원합니다.

## 옵션별 비교

- 상단 옵션선택 카드 높이를 72px에서 64px로 줄였습니다.
- 옵션선택 영역은 가로 스크롤만 허용하고 불필요한 상하 스크롤을 제거했습니다.
- 카드 마우스 강조 시 위로 이동하던 효과를 제거해 세로 오버플로가 다시 생기지 않도록 했습니다.

데이터베이스 구조 변경은 없습니다.
