v52.48.5.39 - 일위대가 Excel 사용자 양식 적용

기준
- 사용자 제공 파일: 일위대가양식.xlsx
- 현재 일위대가 작성/저장/버전/기술자료 기능은 수정하지 않음
- Excel 다운로드 함수만 교체
- SQL 변경 없음

양식 분석
- 시트: 일위대가
- 기본 영역: A1:N27
- 인쇄영역: A1:N29
- 상단: NO / 일위대가 / 품명 / 규격 / 단위
- 헤더: 4~5행
- 기본 항목: 6~25행 (20행)
- 합계: 26행
- 특이사항: 27행
- 헤더 배경: 연한 청록색
- 용지 방향: 가로

다운로드 동작
- 정미값 시트 / 제출용 시트 2개 생성
- 두 시트 모두 사용자 제공 양식을 그대로 기준으로 사용
- 항목 20개 이하: 기본 20행 유지
- 항목 20개 초과: 동일 본문행 스타일을 자동 복제하여 확장
- 재료비/노무비/경비 금액 및 합계는 양식 수식 구조 사용
- 지급자재/비고는 N열 반영
- 문서의 중분류/세부규격/단위는 우측 상단 정보란에 반영
