# v52.48.5.44.23 변경내용

- `옵션선택` 박스를 클릭하면 현장에 저장된 옵션 목록이 표시됩니다.
- 옵션은 `단열 옵션`과 `선택 옵션`으로 구분해 나열합니다.
- 각 옵션의 해당 세대 수를 함께 표시합니다.
- 최대 6개 옵션을 선택할 수 있고 동일 옵션 중복선택은 방지합니다.
- 선택된 박스를 다시 클릭해 옵션을 변경하거나 선택 해제할 수 있습니다.
- 실제 선택된 옵션 수만큼 모든 세대 셀을 동일한 폭으로 분할합니다.
- 각 옵션에 해당하는 세대의 분할칸만 상단 박스와 같은 계열 색상으로 채웁니다.
- 해당하지 않는 옵션 분할칸은 흰색으로 유지합니다.
- 셀 중앙에는 기존 호수를 유지하고 마우스를 올리면 적용 옵션을 확인할 수 있습니다.
- 데이터베이스 구조 변경은 없습니다.
