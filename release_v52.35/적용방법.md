# v52.35 적용방법

## 1. Supabase SQL 먼저 실행

Supabase SQL Editor에서:

`release_v52.35/Supabase에서_실행/00_v52.35_월별노임명단_저장.sql`

전체 실행합니다.

v52.35 SQL은 v52.33 근로자 마스터/권한 구조를 사용합니다.
v52.34 개인정보 암호화 단계와는 독립적으로 동작하므로 v52.34 적용 여부와 관계없이 충돌하지 않게 설계했습니다.

## 2. 프로그램 적용

프로젝트 최상위:

```powershell
node .\release_v52.35\apply-v52.35-monthly-labor-roster.cjs
npm run build
```

## 3. Git

빌드 성공 후:

```powershell
git add src/page/MonthlyLaborManagement.jsx
git status
git commit -m "v52.35 persist monthly labor roster"
git push origin main
```

`git add .` 금지.

## 4. 화면 검증

`노임관리 > 월별 노임작성`

확인:
1. 현장 선택
2. 작성월 선택
3. 근로자 조회 → 여러 명 연속 추가
4. 신규 근로자 등록 → 명단 즉시 추가
5. 공종 변경
6. 비고 입력
7. ↑↓ 순서 변경
8. 저장
9. 다른 화면으로 이동했다가 다시 진입
10. 같은 현장/작성월 선택 시 순서/공종/비고가 그대로 복원
11. 다른 작성월은 별도 명단으로 표시

## 신규 근로자

담당자도 자기 현장 노임작성 권한(`labor.cost.view`) 안에서:
- 성명
- 생년월일
- 휴대폰 뒤 4자리
- 공종

을 입력해 신규 근로자 마스터를 만들 수 있습니다.

이것은 `근로자 정보관리` 메뉴 접근권한과 별개입니다.

## 개인정보

월별 명단 DB에는 주민번호/주소/계좌/전체전화번호를 저장하지 않습니다.

`worker_master_id`만 연결합니다.
