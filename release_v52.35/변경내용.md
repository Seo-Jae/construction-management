# v52.35 변경내용

## 월별 명단 DB 저장

신규 테이블:
- labor_monthly_rosters
- labor_monthly_roster_items
- labor_monthly_roster_audit

키:
- 현장
- 작성월

저장:
- 근로자 master ID
- 표시 순서
- 해당 월 공종
- 비고

개인정보 원문은 중복 저장하지 않습니다.

## 조회
현장/작성월 변경 시 저장된 명단을 RPC로 불러옵니다.

복원:
- 명단 인원
- ↑↓ 순서
- 월별 공종
- 비고
- 마스킹된 식별정보

## 저장
`저장` 버튼 추가.

저장하지 않은 변경이 있으면:
- 상단에 상태 표시
- 브라우저 새로고침/종료 시 경고
- 작성월 변경 시 확인창

## 신규 근로자
기존 빈 행 직접추가를 업무용 신규등록 흐름으로 변경.

필수:
- 성명
- 생년월일
- 휴대폰 뒤4자리
- 공종

서버에서 동일:
`성명 + 생년월일 + 휴대폰 뒤4자리`
가 있으면 중복 마스터를 만들지 않고 기존 근로자를 재사용합니다.

## 권한

- 자기 권한 현장만 월별 명단 조회/저장/신규 최소등록

근로자 정보관리 메뉴 권한은 여전히 별도 `labor.worker_master.manage`.
