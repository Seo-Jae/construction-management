## 1) 코드 적용
프로젝트 최상위 폴더에서:

```powershell
node .\release_v52.48.5.44.68\apply-v52.48.5.44.68-weekly-overview-sites-reapproval.cjs
```

## 2) Supabase SQL 실행 (필수)

`release_v52.48.5.44.68/supabase_v52.48.5.44.68_weekly_report_revision.sql`

## 3) 빌드

```powershell
npm run build
```

## 4) Git 및 운영 배포

```powershell
git add .
git commit -m "v52.48.5.44.68 주간업무 현장설정 및 재결재 수정"
git push origin main
```

`main`이 Vercel Production과 연결되어 있으면 Push 후 자동 운영배포를 확인합니다.
자동배포가 시작되지 않을 때만 `npx vercel --prod`를 실행합니다.
