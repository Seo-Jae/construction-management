# v52.17.3.1 적용방법

v52.17.3 적용 스크립트의 백업 폴더 생성 오류를 수정한 보완본입니다.

프로젝트 최상위에서:

```powershell
node .\release_v52.17.3.1\apply-v52.17.3.1-attendance-ticker-size-fix.cjs
```

적용 완료 후 로컬 의존성을 복구합니다.

```powershell
npm install --legacy-peer-deps
```

그 다음 빌드:

```powershell
npm run build
```

빌드 성공 후:

```powershell
git add src/page/AttendanceWorkerPortal.jsx
git status
git commit -m "v52.17.3 attendance ticker size"
git push origin main
```

`git add .`은 사용하지 않습니다.
