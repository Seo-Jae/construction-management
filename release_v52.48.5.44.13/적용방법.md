# v52.48.5.44.13 적용방법

기준 버전은 `v52.48.5.44.12`입니다.

## 1. 압축 해제

프로젝트 최상위 폴더에 압축을 해제합니다. 압축 해제 후 프로젝트 폴더 안에 `release_v52.48.5.44.13` 폴더가 보여야 합니다.

## 2. 코드 적용

PowerShell에서 프로젝트 최상위 폴더로 이동한 뒤 실행합니다.

```powershell
node release_v52.48.5.44.13/apply-v52.48.5.44.13-insulation-option-excel.cjs
```

적용 스크립트는 v52.48.5.44.12 파일 해시를 먼저 검사하고, 다른 변경이 있으면 덮어쓰지 않고 중단합니다. 기존 파일은 `backup_v52.48.5.44.13_날짜시간` 폴더에 한 번 백업됩니다.

## 3. Supabase SQL 실행

Supabase Dashboard의 SQL Editor에서 아래 파일의 내용을 전체 복사해 1회 실행합니다.

```text
release_v52.48.5.44.13/supabase/v52.48.5.44.13_option_status_documents.sql
```

SQL을 먼저 실행하지 않아도 사이트 전체가 멈추지는 않지만, `옵션현황(단열)`의 저장 버튼은 사용할 수 없습니다.

## 4. 빌드 및 배포

```powershell
npm run build
git add .
git commit -m "feat: add insulation option Excel workflow v52.48.5.44.13"
git push
```

Vercel에서 배포 완료 후 `옵션관리 > 옵션현황(단열)`로 이동해 확인합니다.

## 5. 확인 순서

1. `골구도 다운로드`를 눌러 Excel을 내려받습니다.
2. 동별 시트의 세대 셀에서 호수를 지우고 단열 옵션명을 입력합니다.
3. 필요한 경우 옵션별 셀 채우기 색상을 지정합니다.
4. `엑셀 업로드`로 같은 파일을 불러옵니다.
5. 화면 골구도와 옵션별 범례를 확인합니다.
6. `저장`을 누른 뒤 새로고침해 같은 값이 유지되는지 확인합니다.
