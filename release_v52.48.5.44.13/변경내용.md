# v52.48.5.44.13 변경내용

## 옵션현황(단열)

- 현장관리에서 등록한 실제 골구도를 Excel로 내려받습니다.
- Excel은 `작성안내`와 동별 골구도 시트로 구성됩니다.
- 필로티, 예외층, 합쳐진 세대, 기본 타입을 양식에 반영합니다.
- 각 세대 셀에 표시된 호수를 단열 옵션명으로 덮어써 작성합니다.
- 옵션별 셀 채우기 색상을 지정하면 업로드 시 옵션명과 함께 반영합니다.
- 색상을 넣지 않은 옵션은 옵션명 기준으로 색상을 자동 지정합니다.
- 숨김 세대키를 사용해 `901`과 `0901` 같은 표기 차이로 세대가 잘못 연결되는 문제를 방지합니다.
- 다른 현장의 파일, 다른 양식, 시트·셀 위치가 변경된 파일은 저장 전에 차단합니다.
- 업로드 결과는 먼저 화면 골구도에 미리 표시되고 `저장`을 눌러야 확정됩니다.
- 옵션별 범례, 옵션 종류 수, 적용 세대 수, 원본 파일명과 최근 저장시각을 표시합니다.
- 저장된 옵션은 재접속·새로고침 후 다시 불러옵니다.

## 데이터 저장

- 현장·옵션구분별 세대 옵션을 JSON 문서 한 건으로 저장해 1,000세대가 넘는 현장도 한 번에 불러옵니다.
- `옵션현황(선택)`에서 같은 저장 구조를 재사용할 수 있도록 옵션구분을 분리했습니다.
- 신규 Supabase 테이블 `option_status_documents`가 추가됩니다.

## 영향 범위

- `옵션현황(선택)`과 `옵션별 비교`는 기존 기본 화면 상태를 유지합니다.
- 기존 공정진척 골구도의 클릭·진척 표시 동작은 변경하지 않습니다.
