## Excel 왕복 검증

- 테스트 골구도에서 기존 옵션명·색상 다운로드 후 재업로드 성공
- Excel에서 새 옵션명과 셀 색상을 입력한 뒤 옵션명·색상 동시 인식 성공
- 필로티, 예외층, 합쳐진 세대가 있는 골구도 생성·해석 성공
- 실제 13개 동·1,275세대 설정으로 Excel 생성 및 재업로드 성공
- 실제 설정 기준 시트 15개 생성 확인: 작성안내 1개, 동별 시트 13개, 숨김 시스템정보 1개
- 작성하지 않은 1,275세대가 옵션으로 잘못 인식되지 않는 것 확인

## 안전성

- 현재 현장명과 Excel 현장명이 다르면 업로드 차단
- 골구도 시트명·세대 셀 위치·숨김 세대키가 변경되면 업로드 차단
- 업로드만으로 DB를 변경하지 않고 화면 미리보기 후 저장하는 흐름 확인
- `option_status_documents` 테이블이 없을 때 전체 사이트 오류 대신 SQL 실행 안내 표시
