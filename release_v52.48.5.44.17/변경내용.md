# v52.48.5.44.17 변경내용

- 사용자가 제공한 `선택옵션 양식.xlsx`를 선택옵션 다운로드 양식으로 적용했습니다.
- A6:E6 이하에 현장 골구도의 동, 층, 호, 동호수, 타입이 자동으로 입력됩니다.
- F5:W5에 최대 18개의 유상옵션명을 입력할 수 있습니다.
- F6:W 이하는 해당 옵션을 선택한 경우 `선택`, 미선택은 빈칸으로 작성합니다.
- 업로드 시 현장 불일치, A:E 자동입력값 변경, 중복 옵션명, 잘못된 선택값, 세대행 누락을 차단합니다.
- 업로드한 결과는 골구도에 세대별 `N개 선택`으로 표시되며, 저장 버튼으로 Supabase에 반영됩니다.
- 저장된 옵션명과 선택값은 다음 양식 다운로드 시 다시 채워집니다.
- 신규 Supabase SQL은 없습니다.
