# v52.36 변경내용

- 근로자 순서
- 공종
- 비고

v52.36 추가:

- 일급
- 추가지급
- 수동공제
- 노임 메모

## 일자별 출역

근로자별 `출역·노임 입력` 팝업에서 해당 월의 1일~말일까지 입력합니다.

DB에는 JSONB 원천값으로 저장합니다.

예:
```json
{{"1":1,"2":1,"3":0.5,"5":1}}
```

0인 날짜는 저장하지 않아 데이터 크기를 줄입니다.

## 월별 스냅샷

일급과 노임값은 근로자 마스터가 아닌 `해당 현장/해당 월` 명단에 저장합니다.

따라서 같은 근로자라도:
- 8월 일급 180,000원
- 9월 일급 190,000원

처럼 서로 다르게 저장할 수 있습니다.

## 계산값

DB에는 원천값을 저장하고 화면에서 계산합니다.

- 총출역
- 기본지급
- 총지급
- 실지급 예상

계산 결과 자체를 고정 저장하지 않아 추후 회사 Excel 계산규칙이 바뀌어도 원천값으로 다시 계산할 수 있습니다.

## 법정공제

이번 버전에서는 법정공제 자동계산을 하지 않습니다.

현재 `수동공제`는 실제 Excel 연결 전 테스트/업무 보조용 값입니다.
