# v52.36 적용방법

## 1. Supabase SQL 먼저 실행

Supabase SQL Editor에서 아래 파일 전체를 실행합니다.

`release_v52.36/Supabase에서_실행/00_v52.36_출역_노임값_저장.sql`

v52.35 월별 명단 DB가 먼저 적용돼 있어야 합니다.

## 2. 프로그램 적용

프로젝트 최상위에서:

```powershell
node .\release_v52.36\apply-v52.36-monthly-payroll.cjs
npm run build
```

## 3. Git

빌드 성공 후:

```powershell
git add src/page/MonthlyLaborManagement.jsx
git status
git commit -m "v52.36 add monthly attendance and payroll values"
git push origin main
```

`git add .`은 사용하지 않습니다.

## 4. 화면 확인

`노임관리 > 월별 노임작성`

근로자 행 우측의 `입력` 버튼을 누릅니다.

입력 가능:
- 1일~해당 월 말일까지 출역
- 일급
- 추가지급
- 수동공제
- 노임 메모

출역 예:
- 정상 1일: `1`
- 반일: `0.5`
- 미출역: 빈칸 또는 `0`

현재 허용범위는 일자별 `0~2`입니다.

## 5. 계산

화면 계산:

`기본지급 = 총출역 × 일급`

`총지급 = 기본지급 + 추가지급`

`실지급 예상 = 총지급 - 수동공제`

실지급 예상은 0원 미만으로 표시하지 않습니다.

## 6. 중요한 범위

이번 단계에서는 다음을 자동계산하지 않습니다.

- 소득세
- 지방소득세
- 국민연금
- 건강보험
- 고용보험
- 기타 법정/회사 공제

실제 회사 노임 Excel 양식과 계산기준을 확인한 뒤 연결합니다.

## 7. 개인정보

이번 테이블에는 주민번호, 전체 전화번호, 주소, 계좌번호 등 개인정보 원문을 추가하지 않습니다.
