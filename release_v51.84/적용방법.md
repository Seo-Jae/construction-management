# 지출결의서 작성 v51.84 1차 적용방법

## 1. 이번 버전에 포함된 기능

- `업무보고관리 > 주간 업무 보고` 바로 아래에 `지출결의서 작성` 메뉴 추가
- 현장별 지출결의서 목록 조회
- 새 지출결의서 작성
- 기존 지출결의서 클릭 후 수정
- 지출결의서 삭제
- 좌측 작성 / 우측 미리보기 화면
- 우측 `갑지 미리보기`와 `상세내역 미리보기` 전환
- 유류대 출발지와 도착지 분리 입력
- 캘린더 상세내역에 `출발지→도착지(유류비)` 자동 표시
- 상세내역에는 이동거리와 금액 미표시
- 항목별 금액 및 전체 합계 자동 계산
- Supabase 현장별 저장·조회 권한 적용

이번 1차 버전에는 결재요청, 결재함 연결, 엑셀 다운로드 기능을 넣지 않았습니다.

---

## 2. ZIP 압축 해제 위치

프로젝트 최상위 폴더에 압축을 해제하는 방법이 가장 간단합니다.

현재 프로젝트 경로가 다음과 같다면:

```text
C:\Users\서재형\Desktop\new
```

압축 해제 후 다음 구조가 되도록 합니다.

```text
C:\Users\서재형\Desktop\new
├─ src
├─ package.json
└─ release_v51.84
   ├─ apply-v51.84-expense-resolution.cjs
   ├─ Supabase에서_실행_지출결의서_v51.84.sql
   ├─ 적용방법.md
   └─ src
      └─ page
         └─ ExpenseResolution.jsx
```

---

## 3. Supabase SQL 실행

1. Supabase 프로젝트를 엽니다.
2. 좌측 `SQL Editor`로 들어갑니다.
3. 아래 파일 내용을 전부 복사해서 실행합니다.

```text
release_v51.84\Supabase에서_실행_지출결의서_v51.84.sql
```

정상 실행 시 다음 객체가 생성됩니다.

```text
expense_resolutions
expense_resolution_items
save_expense_resolution(...)
delete_expense_resolution(...)
expense_resolution_can_access_project(...)
```

기존 업무보고 및 품의보고 테이블은 수정하지 않습니다.

---

## 4. 소스 자동 적용

프로젝트 최상위 폴더에서 명령 프롬프트 또는 PowerShell을 열고 실행합니다.

```bash
node .\release_v51.84\apply-v51.84-expense-resolution.cjs
```

스크립트가 다음 파일을 수정하거나 추가합니다.

```text
src\Dashboard.jsx
src\components\Sidebar.jsx
src\page\ExpenseResolution.jsx
```

기존 `Dashboard.jsx`와 `Sidebar.jsx`는 같은 폴더에 아래 형식으로 자동 백업됩니다.

```text
Dashboard.jsx.bak-v51.84-날짜시간
Sidebar.jsx.bak-v51.84-날짜시간
```

스크립트가 `위치를 찾지 못했습니다`라고 중단되면 수동으로 억지 적용하지 말고, 오류 문구와 현재 두 파일을 전달해야 합니다.

## 6. 화면 테스트 순서

1. 로그인합니다.
2. 관리자는 상단에서 테스트할 현장을 선택합니다.
3. `업무보고관리`를 펼칩니다.
4. `주간 업무 보고` 아래의 `지출결의서 작성`을 누릅니다.
5. `새 지출결의서`를 누릅니다.
6. 유류대 항목에서 사용일, 출발지, 도착지, 금액을 입력합니다.
7. 우측 `상세내역 미리보기`를 눌러 해당 날짜에 다음 형태로 표시되는지 봅니다.

```text
출발지→도착지(유류비)
```

8. 상세내역에 이동거리와 금액이 나타나지 않는지 확인합니다.
9. 다른 항목을 추가하고 갑지 합계가 자동 계산되는지 확인합니다.
10. 저장 후 목록으로 돌아오는지 확인합니다.
11. 저장된 행을 한 번 클릭해 수정 화면이 열리는지 확인합니다.
12. 새로고침 후에도 저장자료가 남아 있는지 확인합니다.
