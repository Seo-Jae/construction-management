# v52.48.5.44.55 적용방법

프로젝트 최상위 폴더에 `release_v52.48.5.44.55` 폴더를 넣은 뒤 PowerShell에서 아래 순서대로 실행합니다.

```powershell
node .\release_v52.48.5.44.55\apply-v52.48.5.44.55-guide-point-connector.cjs
npm run build
git add .
git commit -m "v52.48.5.44.55 가이드 지점 연결 화살표 추가"
git push origin main
```

`main` 브랜치 Push로 Vercel 운영 배포가 자동 시작되는 현재 구성에서는 별도로 `npx vercel --prod`를 실행할 필요가 없습니다. 자동 배포가 시작되지 않는 경우에만 수동 운영 배포를 실행합니다.

추가 Supabase SQL은 없습니다.
