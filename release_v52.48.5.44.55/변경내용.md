# v52.48.5.44.55 변경내용

## 가이드 편집 - 지점 연결 화살표 추가

- 기존 `번호 연결 화살표`와 별도로 `지점 연결 화살표` 버튼을 추가했습니다.
- `지점 연결 화살표`는 번호 원을 연결하지 않고, 이미지의 임의 위치 2곳을 직접 지정해 연결합니다.
- 생성 방식은 드래그가 아닙니다.
  1. 시작 지점을 한 번 클릭합니다.
  2. 화살표가 향할 도착 지점을 한 번 클릭합니다.
  3. 두 지점을 연결하는 화살표가 생성됩니다.
- 첫 지점을 클릭하면 임시 시작점이 표시되어 두 번째 클릭 위치를 쉽게 지정할 수 있습니다.
- 생성된 화살표에는 별도 번호 원이나 설명박스가 자동 생성되지 않습니다.
- 기존 `번호 연결 화살표` 기능은 그대로 유지됩니다.
- 생성 후 우측 설정 패널에서 색상, 선 두께, 시작 X/Y, 도착 X/Y를 미세 조정할 수 있습니다.
- 선택/이동 상태에서는 화살표 전체를 끌어서 위치를 이동할 수 있습니다.
- 작성 미리보기, 공개 가이드 팝업, 가이드 설정 화면의 이미지 미리보기에도 동일하게 렌더링됩니다.

## DB

- 추가 Supabase SQL 없음
- 기존 JSONB 가이드 데이터 구조 안에 새 표시 타입을 저장하므로 DB 스키마 변경이 필요하지 않습니다.
