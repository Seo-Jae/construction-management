# 검증결과

- 사용자 제공 운영 DB 함수 원문으로 실제 helper 이름 확인: `expense_resolution_can_access_project(text)`
- `save_expense_resolution` / `delete_expense_resolution` 업무 로직은 수정하지 않음
- SQL 끝부분에 helper 소스 및 실제 RPC 참조 상태 검증 SELECT 포함
- 적용 스크립트 `node --check` 검증
- 적용 스크립트 1회/재적용 동작 검증
- 실제 Supabase 운영 DB 실행은 이 환경에서 수행하지 못함
