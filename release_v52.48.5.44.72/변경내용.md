# 변경내용

실제 운영 `save_expense_resolution`, `delete_expense_resolution` 함수 원문을 기준으로 수정 대상을 바로잡았습니다.

두 함수 모두 `public.expense_resolution_can_access_project(text)`를 호출하고 있으므로, 해당 helper 자체를 교체합니다.

자기 소속현장은 메뉴 ACL과 무관하게 지출결의서 CRUD를 기본 허용합니다. 자기 소속현장이 아닌 추가 접근현장은 기존 런타임 권한 v2의 `report.expense.view` 권한을 그대로 적용합니다.
