# v52.48.5.44.25 변경내용

## 옵션현황(선택)

- `등록 동`, `전체 세대`, `유상옵션`, `선택 세대`, `선택 건수`, 파일명으로 구성된 기존 요약행을 삭제했습니다.
- 화면 중간 상단에는 `세대수 : 00세대`만 표시합니다.
- 특정 표시 옵션을 선택하면 해당 옵션이 적용된 세대수를 표시합니다.
- `전체 옵션` 상태에서는 옵션을 하나 이상 선택한 전체 세대수를 표시합니다.
- 우측의 표시 옵션 선택 기능은 그대로 유지합니다.

## 옵션별 비교

- 선택된 비교 카드에 `옵션비교` 명칭을 표시합니다.
- 카드에 실제 선택한 옵션명과 해당 세대수를 함께 표시합니다.
- 카드 우측 상단에 X 버튼을 추가했습니다.
- X 버튼을 누르면 저장된 옵션 자료는 변경하지 않고 해당 비교 칸에서만 즉시 해제합니다.
- 기존 옵션 선택 팝업과 세대 셀 분할 비교 기능은 유지합니다.

데이터베이스 구조 변경은 없습니다.
