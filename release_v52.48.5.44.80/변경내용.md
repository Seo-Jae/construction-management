# v52.48.5.44.80 변경내용

`세대물량관리 > 공정별 세대물량 골구도` 팝업 상단 공정 탭의
선택 밑줄이 탭명보다 왼쪽으로 밀려 보이는 문제를 수정합니다.

## 원인

현재 팝업은 MUI `Tabs`의 기본 indicator를 사용하고 있습니다.
시스템 화면이 CSS `zoom: 90%`로 표시되는 상태에서는
MUI가 계산하는 indicator의 `left / width` 좌표와 실제 Tab 표시 위치에
오차가 생길 수 있습니다.

## 수정

- 해당 골구도 팝업에 한해서 MUI 기본 `.MuiTabs-indicator` 숨김
- 선택된 `.MuiTab-root.Mui-selected` 자체에 `::after` 밑줄 생성
- 밑줄은 선택된 탭의 `left: 0 / right: 0`을 그대로 사용
- 따라서 단열 / 합지 / 경량벽체 / 세대천정 / 몰딩 / 걸레받이 어느 탭을 눌러도
  밑줄이 선택된 탭 바로 아래에 붙어 이동
- 다른 화면의 Tabs에는 영향 없음

추가 Supabase SQL은 없습니다.
