# 지출결의서 작성 v51.86 적용방법

## 적용 대상

지출결의서 작성 v51.85가 적용된 프로젝트를 기준으로 합니다.
이번 수정은 유류대 입력칸의 순서와 너비만 조정하며 DB 변경은 없습니다.

## 1. 압축 해제

ZIP 파일을 현재 프로젝트 최상위 폴더에 압축 해제합니다.
프로젝트 최상위 폴더는 `package.json`, `src` 폴더가 있는 위치입니다.

## 2. 소스 적용

프로젝트 최상위 폴더의 터미널에서 실행합니다.

```bash
node .\release_v51.86\apply-v51.86-expense-resolution.cjs
```

수정 전 `src/page/ExpenseResolution.jsx`는 자동 백업됩니다.

> 이번 버전은 Supabase SQL을 실행하지 않습니다.

## 3. 빌드 확인

```bash
npm run build
```

## 확인 항목

1. 유류대 선택 시 첫 줄에는 `사용일`, `지출항목`만 표시되는지
2. 다음 줄의 입력 순서가 `출발지 → 도착지 → 금액 → 도착시간`인지
3. 출발지와 도착지 칸이 이전보다 좁아졌는지
4. 금액 칸이 출발지·도착지 다음에 배치되는지
5. 도착시간 칸에서 `02:00 PM` 또는 `02:00 AM`이 잘리지 않는지
6. 유류대 외 항목은 기존처럼 첫 줄에 금액 칸이 표시되는지
