# v52.48.5.9 적용 방법

이 패키지는 `v52.48.5.8`이 적용된 프로젝트를 기준으로 합니다.

## 1. Supabase SQL 먼저 실행

Supabase 대시보드의 **SQL Editor**에서 아래 파일 전체를 실행합니다.

```text
release_v52.48.5.9/Supabase에서_실행/00_v52.48.5.9_퇴근진척제출_담당자승인.sql
```

실행 결과 맨 아래에 테이블 2개와 RPC 6개가 모두 표시되면 정상입니다.

## 2. 코드 적용

ZIP 안의 `release_v52.48.5.9` 폴더를 프로젝트 최상위 폴더에 복사합니다. 프로젝트 최상위는 `package.json`과 `src` 폴더가 보이는 위치입니다.

PowerShell에서 아래 명령을 순서대로 실행합니다.

```powershell
node .\release_v52.48.5.9\apply-v52.48.5.9-checkout-progress.cjs
npm run build
git add src/page/AttendanceWorkerPortal.jsx src/page/AttendanceManagement.jsx src/utils/attendanceI18n.js src/components/AttendanceCheckoutProgressDialog.jsx src/components/AttendanceProgressFloorGrid.jsx
git status
git commit -m "v52.48.5.9 add checkout progress approval workflow"
git push origin main
```

## 3. 배포 후 확인

- 작업자가 출근할 때 표준 작업위치(동·층)와 공정을 선택합니다.
- 퇴근 QR을 촬영하면 오전 작업정보와 완료 여부 화면이 나오는지 확인합니다.
- 완료 세대를 선택해 퇴근한 뒤 근태관리의 `진척 승인` 탭에 승인대기 건이 나오는지 확인합니다.
- 승인 전에 기존 진척관리 색상이 바뀌지 않는지 확인합니다.
- `확인완료 승인` 후에만 해당 세대가 작업완료로 반영되는지 확인합니다.
- 반려했을 때 진척도는 변하지 않고 퇴근 기록은 유지되는지 확인합니다.
- Language를 바꿨을 때 퇴근 진척 화면의 고정 문구가 선택한 언어로 바뀌는지 확인합니다.

앱 재설치는 필요하지 않습니다. 배포 후 앱을 완전히 종료하고 다시 실행해주세요.
