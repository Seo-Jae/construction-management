# v52.48.5.44.42 변경내용

- MUI 9에서 무시되던 `PaperProps`를 `slotProps.paper`로 교체했습니다.
- 골구도 다이얼로그가 제목과 탭 높이만큼만 접히던 현상을 수정했습니다.
- 다이얼로그 본문과 골구도 뷰포트에 남은 화면 높이가 정확히 배정되도록 수정했습니다.
- 뷰포트 크기가 아직 0에 가까울 때 35% 자동맞춤이 먼저 실행되지 않도록 재시도 로직을 추가했습니다.
- 같은 화면의 Excel 설정 다이얼로그도 현재 MUI 방식으로 함께 변경했습니다.
- 계산식과 저장 데이터 구조는 변경하지 않았습니다.
