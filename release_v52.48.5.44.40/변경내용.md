# v52.48.5.44.40 변경내용

- 세대물량관리 상단의 `공정별옵션연결` 왼쪽에 `골구도보기` 버튼을 추가했습니다.
- 골구도 창에서 단열·합지·경량벽체·세대천정·몰딩·걸레받이 및 추가 공정을 전환할 수 있습니다.
- 단열공정은 각 세대의 `타입 + 단열옵션`에 해당하는 기본물량을 표시합니다.
- 그 외 공정은 각 세대의 `타입 기본물량 + 해당 세대가 선택한 연결 옵션의 증감물량 합계`를 표시합니다.
- 옵션을 여러 개 선택한 세대는 해당 공정에 연결된 옵션만 모두 합산합니다.
- 음수 증감은 감소, 양수 증감은 증가로 계산합니다.
- 계산값을 클릭해 저장하는 방식이 아니라 현재 저장 자료에서 즉시 계산하므로, 옵션이나 물량이 바뀌면 골구도 값도 함께 바뀝니다.
- 미입력 기본물량 또는 증감물량이 있는 세대는 `미입력`과 주황색 테두리로 표시합니다.
- 세대 셀에 마우스를 올리면 타입, 기본물량, 적용된 옵션별 증감량, 최종 세대물량을 확인할 수 있습니다.

Supabase SQL 변경은 없습니다.
