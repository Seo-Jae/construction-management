# 사내시스템 v52.09 변경내용

기준 버전: **v52.08.4 메신저 1인 그룹방 나가기 수정까지 배포된 프로젝트**

## 1. 메신저 별도창

- 상단 메신저 아이콘을 눌러도 현재 업무 화면을 메신저 화면으로 전환하지 않습니다.
- 별도 브라우저 팝업 창으로 메신저를 엽니다.
- 현재 업무 화면의 메뉴/작성 위치/React 입력상태를 그대로 유지합니다.
- 이미 메신저 창이 열려 있으면 새 창을 계속 만들지 않고 기존 창을 앞으로 가져옵니다.
- 별도창에서는 공사관리 Sidebar를 표시하지 않고 메신저만 사용합니다.

## 2. 사용자별 글자크기

- 메신저 별도창 상단에 `A- / 현재비율 / A+` 조절 기능을 추가했습니다.
- 85% ~ 130% 범위에서 단계 조절할 수 있습니다.
- 사용자 계정별 설정을 Supabase `messenger_user_preferences`에 저장합니다.
- 가운데 비율 버튼을 누르면 100%로 돌아옵니다.

## 3. 연속 메시지 입력

- 메시지 전송 중 입력칸을 disabled 처리해 포커스를 잃던 구조를 제거했습니다.
- 메시지 전송 후 입력칸으로 자동 포커스가 돌아옵니다.
- 연속해서 메시지를 입력할 수 있습니다.

## 4. 새 메시지 알림

- 사이트를 보고 있는 동안 새 안읽음 메시지가 오면 화면 **우측 하단 Snackbar 알림**을 표시합니다.
- 브라우저가 뒤에 있거나 다른 프로그램을 사용 중이면 브라우저의 **시스템 알림(Notification API)**을 사용합니다.
- 시스템 알림은 브라우저 알림 권한이 `허용`이어야 합니다.
- 메신저 아이콘을 사용자가 클릭할 때 아직 권한을 정하지 않았다면 브라우저 알림 권한을 요청합니다.
- 현재 별도 메신저창에서 실제로 보고 있는 대화방은 중복 알림을 억제합니다.

※ 시스템 알림의 정확한 화면 위치는 Windows/브라우저가 결정합니다. Windows에서는 일반적으로 우측 하단 알림 영역에 표시됩니다.

## 5. 방장 권한 위임

- 그룹 관리 참여자 목록에서 방장이 다른 참여자에게 `방장 위임`할 수 있습니다.
- 권한을 넘긴 기존 방장은 방에서 나가지 않고 일반 참여자로 계속 대화할 수 있습니다.
- 다른 참여자가 방장이 된 사실은 Realtime으로 갱신됩니다.

## 6. 방장이 대화방을 나가는 방법

- 방장 혼자 남은 그룹방: 기존처럼 바로 나갈 수 있습니다.
- 다른 참여자가 있는 그룹방: 자동으로 임의의 사람에게 넘기지 않습니다.
- 나가기 버튼을 누르면 **방장 권한을 넘길 사람 선택창**이 먼저 표시됩니다.
- 사용자가 직접 위임 대상자를 선택하고 확인한 뒤 나갑니다.
- 완료 알림에 누구에게 방장 권한을 넘겼는지 표시합니다.
- 일반 참여자 및 1:1방 나가기는 기존 동작을 유지합니다.

## 7. 메신저도 업무 활동으로 인정

- 기존 30분 자동 로그아웃 활동시간을 `sessionStorage` 단일창 기준에서 같은 도메인의 창들이 공유하는 `localStorage` 기준으로 변경했습니다.
- 메인 업무창과 별도 메신저창 중 어느 한쪽에서 마우스/키보드/스크롤 등 활동이 있으면 양쪽 모두 사용 중으로 판단합니다.
- 메신저로 대화를 계속하고 있는데 메인 업무창이 30분 동안 조작되지 않았다는 이유로 자동 로그아웃되는 문제를 방지합니다.

## 8. 이미지 첨부 Invalid key 수정

기존 Storage 경로는 원본 한글 파일명을 그대로 포함했습니다.

예:

```text
.../대화내용_캡쳐.jpg
```

Supabase Storage가 허용하지 않는 문자가 object key에 포함될 수 있어 `Invalid key`가 발생했습니다.

v52.09에서는 Storage object key를 다음처럼 UUID/숫자/ASCII 확장자로만 생성합니다.

```text
room-uuid/user-uuid/시간-random-uuid.jpg
```

사용자에게 보이는 원본 파일명은 `messenger_attachments.file_name`에 별도 보존합니다.

## 9. 캡처 이미지 Ctrl+V

- 메시지 입력칸에 캡처 이미지를 `Ctrl+V`하면 즉시 업로드하지 않습니다.
- 입력창 위에 이미지 미리보기를 먼저 표시합니다.
- 미리보기 우측 상단 X로 전송 전 제거할 수 있습니다.
- 텍스트와 이미지를 확인한 뒤 전송 버튼을 눌러 전송합니다.
- 한 번에 최대 5개의 붙여넣기 이미지를 준비할 수 있습니다.

## 유지되는 기존 기능

- 1:1 대화
- 그룹 대화
- Realtime 메시지
- 읽음/안읽음
- 그룹 안읽은 참여자 명단
- 사진/일반파일 전송 및 다운로드
- 내 메시지 삭제
- 그룹방 이름 변경
- 참여자 추가/제외
- 1:1/그룹 대화방 나가기
- v52.08.1 깜빡임 방지 구조
