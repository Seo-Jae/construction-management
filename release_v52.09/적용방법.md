# v52.09 적용방법

선행조건: **현재 프로젝트가 v52.08.4까지 적용된 상태**

## 1. Supabase SQL

Supabase SQL Editor에서 아래 파일을 처음부터 끝까지 전체 실행합니다.

```text
release_v52.09/Supabase에서_실행/00_v52.09_메신저_사용성_알림_방장권한.sql
```

이 SQL은:

- 사용자별 메신저 글자크기 설정
- 그룹 방장 직접 위임
- 방장 나가기 시 위임 대상 선택

을 추가합니다.

## 2. 프로그램 파일 적용

ZIP의 `release_v52.09` 폴더를 현재 프로젝트 최상위(`package.json`이 있는 위치)에 둡니다.

PowerShell:

```powershell
node .\release_v52.09\apply-v52.09-messenger-usability.cjs
npm run build
```

적용 스크립트는 현재 v52.08.4 핵심 파일의 SHA256을 먼저 확인합니다.
검증되지 않은 파일이면 기존 기능 보호를 위해 자동 덮어쓰기를 중단합니다.

정상 적용되면 기존 파일은 다음 형태로 자동 백업됩니다.

```text
backup_v52.09_YYYY-MM-DDTHH-MM-SS
```

## 3. 필수 테스트 순서

1. 기존 업무 작성 화면에서 값을 입력한 상태로 상단 메신저 아이콘 클릭
2. 업무 화면이 그대로 남고 별도 메신저창이 열리는지 확인
3. 메신저 아이콘을 다시 눌러 창이 여러 개 생기지 않고 기존 창이 앞으로 오는지 확인
4. A-/A+로 글자크기 변경 → 창 닫기/재실행 후 설정 유지 확인
5. 메시지를 2~3회 연속 Enter 전송 → 다시 클릭하지 않아도 계속 입력되는지 확인
6. 브라우저 알림 권한 `허용`
7. 다른 계정에서 메시지 전송 → 업무화면 우측 하단 알림 확인
8. 브라우저를 뒤로 보내거나 다른 프로그램 사용 중 메시지 전송 → 시스템 알림 확인
9. 그룹방 방장 상태에서 다른 참여자에게 `방장 위임` → 본인은 방에 남고 상대가 방장이 되는지 확인
10. 다시 방장 상태에서 나가기 → 위임 대상 선택창이 뜨는지 확인
11. 혼자 남은 그룹방에서는 선택창 없이 나갈 수 있는지 확인
12. 한글 이름의 JPG/PNG 파일 첨부 → `Invalid key` 없이 전송 확인
13. 캡처 후 메시지 입력칸에서 Ctrl+V → 미리보기 → 전송 확인
14. 메신저만 30분 이상 사용하는 상황에서 자동 로그아웃되지 않는지 확인

## 4. 배포

위 테스트와 `npm run build` 성공을 확인한 후 Git/Vercel 배포합니다.

`git add .`은 사용하지 않습니다. 변경 파일만 정확히 추가합니다.
