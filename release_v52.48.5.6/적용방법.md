# v52.48.5.6 적용 방법

이 패키지는 `v52.48.5.5`가 정상 적용된 프로젝트를 기준으로 합니다.

## 1. Supabase SQL 먼저 실행

Supabase Dashboard → SQL Editor → New query에서 다음 파일의 전체 내용을 실행합니다.

```text
release_v52.48.5.6\Supabase에서_실행\00_v52.48.5.6_근태기록_작업정보표시.sql
```

마지막 결과의 `dashboard_function_ready`가 `true`인지 확인합니다. 오류가 발생하면 코드 배포를 진행하지 말고 오류 화면을 그대로 전달해주세요.

## 2. 코드 적용

ZIP 안의 `release_v52.48.5.6` 폴더를 프로젝트 최상위 폴더에 복사합니다. 프로젝트 최상위는 `package.json`과 `src` 폴더가 보이는 위치입니다.

PowerShell에서 다음 명령을 순서대로 실행합니다.

```powershell
node .\release_v52.48.5.6\apply-v52.48.5.6-attendance-ui-records.cjs
npm run build
git add src/page/AttendanceWorkerPortal.jsx src/components/AttendanceWorkAssignmentDialog.jsx src/page/AttendanceManagement.jsx
git status
git commit -m "v52.48.5.6 enlarge attendance UI and show work details"
git push origin main
```

## 3. 배포 후 확인

- Vercel Production이 `Ready`인지 확인합니다.
- 근태 앱을 완전히 종료한 뒤 다시 실행합니다.
- 회원가입 화면이 로그인처럼 화면 너비의 약 90%를 사용하는지 확인합니다.
- 회원가입 입력칸과 가입 버튼이 크게 표시되는지 확인합니다.
- 로그인 후 작업자 카드, 달력, 출퇴근 버튼이 크게 표시되는지 확인합니다.
- 출근 QR 촬영 후 작업위치·공정 입력 화면이 크게 표시되는지 확인합니다.
- 출근 완료 후 `통합관리시스템 > 근태 기록`에서 작업위치와 당일 공정이 보이는지 확인합니다.
- 기타 위치로 출근한 경우 작업자가 작성한 한 줄 위치가 그대로 보이는지 확인합니다.

앱 재설치는 필요하지 않습니다.
