# v52.48.5.44.43 변경내용

- 기준 버전: v52.48.5.44.42
- 골구도 세대물량 계산 결과에 일부 누락/비정상 필드가 있어도 화면 전체가 중단되지 않도록 방어 로직을 추가했습니다.
- 골구도 계산 함수 자체에서 예외가 발생하면 다이얼로그 안에서 오류 내용을 확인할 수 있도록 했습니다.
- 세대별 골구도 표시 데이터의 `adjustmentRows`, `missingItems`, `cellKey`, 수량값을 안전하게 처리하도록 보강했습니다.
- 기존 `window.open()` 새 창 출력 방식을 제거했습니다.
- PDF/프린트 아이콘은 동일 출력을 팝업에 의존하지 않는 전용 iframe 문서에서 실행하도록 변경했습니다.
- 출력 전 폰트/이미지 로딩을 기다린 뒤 A4 가로 1장 영역에 자동 축소·가운데 정렬하도록 했습니다.
- 출력용 MUI ripple 요소는 제거하고, 인쇄 색상 유지와 가로 1페이지 설정은 그대로 유지합니다.
- 기존 단열·합지 자동기준, 공정별 옵션연결, Excel 업/다운로드, Supabase 저장 구조는 변경하지 않았습니다.
- 새 Supabase SQL은 없습니다.
