# 지출결의서 작성 v51.91 적용방법

## 적용 기준

- 기준 버전: v51.90
- v51.89의 통행료 PDF 경로·km 일괄입력 기능을 유지합니다.
- v51.90의 엑셀 날짜 형식과 상세내역 색상 수정을 유지합니다.
- 화면은 사용내역 좌측, 미리보기 우측으로 변경합니다.
- DB 변경은 없으므로 Supabase SQL을 실행하지 않습니다.

## 1. 압축 해제

ZIP 파일을 프로젝트 최상위 폴더에 압축 해제합니다.

```text
C:\Users\서재형\Desktop\new
├─ package.json
├─ src
├─ public
└─ release_v51.91
```

## 2. 소스 적용

PowerShell에서 프로젝트 최상위 폴더로 이동한 후 실행합니다.

```powershell
node .\release_v51.91\apply-v51.91-expense-resolution.cjs
```

적용 파일:

- `src/page/ExpenseResolution.jsx`
- `src/utils/expenseResolutionExcel.js`
- `src/utils/highpassReceiptPdf.js`

기존 대상 파일은 적용 전에 자동 백업됩니다. `pdfjs-dist`가 없다면 `5.7.284` 버전을 `--legacy-peer-deps` 옵션으로 자동 설치합니다.

## 3. 빌드 확인

```powershell
npm run build
```

`Some chunks are larger than 500 kB`는 용량 경고입니다. 마지막에 `built in`이 표시되면 정상입니다.

`@mui/material`을 찾지 못한다는 오류가 발생하면 아래 명령을 먼저 실행합니다.

```powershell
npm install @mui/material @mui/icons-material @emotion/react @emotion/styled --legacy-peer-deps
npm run build
```

## 4. 화면 확인

1. `업무보고관리 > 지출결의서 작성`에서 신규 문서를 엽니다.
2. 좌측에 기본정보·사용내역, 우측에 미리보기가 표시되는지 확인합니다.
3. 가운데 세로 조절선을 좌우로 드래그해 양쪽 폭이 바뀌는지 확인합니다.
4. 조절선을 더블클릭했을 때 기본 비율로 돌아오는지 확인합니다.
5. 기본 갑지에는 날짜·유류대·금액·통행료·금액·접대비·숙박비만 표시되는지 확인합니다.
6. 잡자재·우편/택배·기타 항목을 추가했을 때 해당 열만 표시되는지 확인합니다.
7. 폭이 부족할 때 사용하지 않은 접대비·숙박비 열이 숨겨지는지 확인합니다.
8. 실제 사용 항목이 많아 모두 표시해야 할 때만 갑지 표 안에 가로 스크롤이 생기는지 확인합니다.
9. 통행료 PDF 업로드와 `서울→용인 35km` 표시가 유지되는지 확인합니다.
10. 엑셀 다운로드 후 날짜 형식 `yyyy-mm-dd aaa`와 상세내역 색상이 유지되는지 확인합니다.

## 저장 및 DB

- 이동거리(km)는 기존 `description` 필드에 저장합니다.
- 새로운 DB 컬럼이나 Supabase SQL은 없습니다.
