# 지출결의서 작성 v51.91 변경내용

## 1. 좌우 배치 복귀

- 좌측: 기본정보 및 사용내역
- 우측: 갑지 및 상세내역 미리보기
- 화면이 좁은 환경에서는 기존처럼 세로로 배치됩니다.

## 2. 사용자 폭 조절

- 가운데 세로 조절선을 드래그해 사용내역과 미리보기 폭을 조절할 수 있습니다.
- 좌우 화살표 키로도 2%씩 조절할 수 있습니다.
- Shift와 좌우 화살표를 함께 누르면 5%씩 조절합니다.
- 조절선을 더블클릭하면 기본 46:54 비율로 돌아갑니다.
- 한쪽 화면이 사라지지 않도록 25%~75% 범위에서 조절됩니다.

## 3. 갑지 미리보기 열 자동 정리

- 기본 표시: 날짜, 유류대, 금액, 통행료, 금액, 접대비, 숙박비
- 잡자재, 우편/택배, 기타는 실제 사용내역에 해당 항목이 있을 때만 표시합니다.
- 추가 항목 때문에 현재 미리보기 폭이 부족하면 사용하지 않은 접대비와 숙박비를 자동으로 숨깁니다.
- 실제 사용 중인 항목은 숨기지 않습니다.
- 필요한 열이 모두 들어가지 않는 경우에만 갑지 표 내부에 가로 스크롤을 허용합니다.

## 4. 기존 기능 유지

- v51.89 통행료 PDF 업로드, 출발지·km 일괄입력, 경로 표시 유지
- v51.90 엑셀 날짜 `yyyy-mm-dd aaa` 및 상세내역 RGB 색상 유지
- Supabase SQL 없음
