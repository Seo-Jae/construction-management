# v52.48.5.44.9 적용방법

기준은 `v52.48.5.44.8.3` 반영 완료본입니다.

1. ZIP을 프로젝트 루트(`package.json`, `src` 폴더가 있는 위치)에 풉니다.
2. PowerShell에서 아래 명령을 실행합니다.

```powershell
node release_v52.48.5.44.9/apply-v52.48.5.44.9-labor-contract-items.cjs
```

3. Supabase SQL Editor에서 아래 파일을 전체 실행합니다.

```text
supabase/v52.48.5.44.9_labor_contract_item_links.sql
```

4. 빌드 후 배포합니다.

```powershell
npm run build
git add .
git commit -m "feat: link labor rates to initial contract items v52.48.5.44.9"
git push
```

## 화면 확인

1. `노임관리 > 공정별 노임작성 > 공정별 노임단가`로 이동합니다.
2. 원하는 공정의 `계약 노무비` 아래 `품목 선택`을 누릅니다.
3. `기성관리 > 계약품목 공정연결`에서 해당 공정으로 분류한 최초계약 품목이 나오는지 확인합니다.
4. 같은 단위의 품목을 선택하고 `선택값 불러오기`를 누릅니다.
5. 계약 노무비와 총 예정물량이 자동 합산되었는지 확인합니다.
6. 실행 노임총액과 변경 사유를 입력한 뒤 행 저장 버튼을 누릅니다.
7. 다시 열었을 때 선택 품목과 합계가 유지되는지 확인합니다.

## 안전장치

- 적용 스크립트는 사용자 제공 최신본의 화면 파일 해시를 확인합니다.
- 다른 파일이면 기존 변경을 보호하기 위해 적용을 중단합니다.
- 교체 전 화면 파일은 `backup_v52.48.5.44.9_날짜시간` 폴더에 백업합니다.
- DB 저장 시 화면 합계값을 신뢰하지 않고 선택된 최초계약 품목을 다시 조회해 합산합니다.
- 계약버전·현장·품목 소속과 단위 일치를 모두 검증한 후 한 트랜잭션으로 저장합니다.
