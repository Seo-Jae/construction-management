# v52.48.5.44.9 변경내용

## 공정별 노임단가

- `계약 노무비` 우측에 최초계약 품목 선택 기능 추가
- 공정 입력 또는 기존 공정 선택 후 해당 공정으로 분류된 계약품목만 조회
- 품목 구분·품명·규격·단위·계약수량·계약 노무비·연결 공정 표시
- 품명·규격·구분 검색 지원
- 선택 건수·계약수량 합계·계약 노무비 합계 표시
- 선택한 품목을 계약 노무비와 총 예정물량에 함께 반영
- 연결된 행은 `N개 품목`으로 표시하고 다시 열어 선택을 수정 가능
- 연결 해제 후에는 기존 숫자를 유지한 채 직접입력으로 전환
- 단위가 서로 다른 품목의 물량 합산 및 저장 차단

## 저장 구조

- `labor_process_contract_item_links` 테이블 추가
- 현장·공정·최초계약 버전·계약품목 ID 저장
- 저장 당시 source key, 품명, 규격, 단위, 계약수량, 계약 노무비 스냅샷 보존
- 기존 노임단가 저장과 계약품목 연결 저장을 한 트랜잭션으로 처리
- DB에서 선택 품목을 재조회해 계약 노무비와 총 예정물량을 다시 계산
