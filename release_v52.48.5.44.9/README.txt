v52.48.5.44.9 공정별 노임단가-최초계약 품목 연결

기준 버전
- v52.48.5.44.8.3 반영 완료본

핵심 변경
- 공정별 노임단가의 계약 노무비 우측에서 최초계약 품목을 선택할 수 있습니다.
- 계약품목 공정연결에서 현재 공정으로 분류된 품명·규격·단위·수량·노무비를 표시합니다.
- 선택 품목의 계약 노무비 합계와 계약수량 합계를 동시에 불러옵니다.
- 서로 다른 단위는 총 예정물량으로 합산할 수 없으므로 저장을 차단합니다.
- 저장 시 품목 ID와 당시 계약값 스냅샷을 보존합니다.
- 실행 노임총액은 실행예산 입력 메뉴를 만드는 다음 단계까지 수동 입력을 유지합니다.

적용 순서
1. 적용 스크립트 실행
2. Supabase SQL 실행
3. npm run build
4. 사이트 기능 확인

자세한 명령은 적용방법.md를 확인해주세요.
