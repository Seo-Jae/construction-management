# 사내시스템 v52.06 적용방법

사용자가 전달한 `new (3).zip` 실제 프로젝트를 기준으로 만든 수정본입니다.
Supabase SQL 변경은 없습니다.

## 1. ZIP 압축 해제

프로젝트 최상위 폴더(`package.json`, `src`가 있는 곳)에 압축을 풉니다.

## 2. 적용

PowerShell에서 프로젝트 최상위 폴더로 이동 후 실행합니다.

```powershell
node .\release_v52.06\apply-v52.06-date-ui-main-schedule-divider.cjs
npm run build
```

적용 스크립트는 교체 전 기존 파일을 `backup_v52.06_...` 폴더에 자동 백업합니다.

## 3. 화면 확인

```powershell
npm run dev
```

확인할 내용:

- 날짜 입력칸이 `26-08-10`처럼 `yy-mm-dd`로 보이는지
- 날짜 입력칸 클릭 시 영문/목록식이 아닌 한글 캘린더가 열리는지
- 월 전용 입력은 `2026년 8월`로 보이고 1월~12월 선택판이 열리는지
- 출력일보 달력 요일이 `일 월 화 수 목 금 토`인지
- Main 캘린더와 주요일정 사이의 연한 세로선이 아래까지 이어지는지
- 주요일정이 없는 달에도 세로선이 동일하게 유지되는지
- 기존 저장·수정·삭제 기능이 정상인지
