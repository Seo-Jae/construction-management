# v52.06 날짜 UI 점검결과

## 점검 기준

- 년/월/일 전체 날짜 입력: 화면 `yy-mm-dd`
- 클릭: 한글 캘린더
- 요일: 한글
- 월 전용 업무: `yyyy년 m월` + 12개월 선택판
- DB 저장 형식은 기존 `yyyy-mm-dd` 또는 `yyyy-mm` 유지

| 화면/파일 | 기존 | 수정 |
|---|---|---|
| Dashboard 근로자 불러오기 | 브라우저 date | 공통 한글 날짜 달력 |

## 코드 점검 결과

- 현재 소스의 `type="date"` 잔존: 0건
- 현재 소스의 `type="month"` 잔존: 0건
- 현재 소스의 영문 요일 `Sun~Sat / Sunday~Saturday` 잔존: 0건
- TypeScript transpile 기반 JSX/JS 문법 진단: 오류 0건

## 의도적으로 유지한 예외

- 지출결의서 `사용일`: 기존 업무 규칙에 따라 `mm-dd` 화면 표시 유지
- 월만 필요한 화면: `yy-mm-dd`로 억지 변환하지 않고 `yyyy년 m월` 월 선택기로 유지
- DB 및 Supabase 저장값: 호환성을 위해 4자리 연도 ISO 값을 유지
- PDF/Excel 등 기존 문서 출력용 날짜 양식은 이번 UI 점검 범위에서 임의 변경하지 않음
