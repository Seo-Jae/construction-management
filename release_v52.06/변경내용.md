# 사내시스템 v52.06 변경내용

기준 파일은 사용자가 전달한 `new (3).zip`의 실제 최신 프로젝트입니다.

## 1. 날짜 선택 UI 기본 규칙 통일

기본 날짜 입력은 다음 규칙으로 통일했습니다.

- 화면 표시: `yy-mm-dd`
- 실제 저장값: 기존 DB 호환을 위해 `yyyy-mm-dd` 유지
- 선택 방식: 브라우저 기본 `type="date"` 대신 시스템 공통 한글 캘린더 사용
- 요일: `일 월 화 수 목 금 토`
- 월·연도 이동: 한글 표기
- 오늘 버튼 제공
- 기존 min/max 날짜 제한 유지

새 공통 컴포넌트:

- `src/components/KoreanDatePicker.jsx`

## 2. 월 전용 선택 기능

월만 선택하는 업무 화면은 날짜로 강제 변경하지 않고 기존 업무 의미를 유지했습니다.
다만 목록식 선택과 브라우저 기본 월 입력을 제거하고 `연도 + 12개월 월 선택판`으로 통일했습니다.

공통 월 컴포넌트:

- `src/components/KoreanMonthSelect.jsx`

적용 화면:

- 노임관리 시작월·종료월
- 자재투입 시작월·종료월
- 근로계약서 계약 대상 월
- 기성관리 기준월
- 주간업무총괄 보관 월
- 출력일보 월 이동

## 3. 날짜 입력 적용 화면

- 출력일보 팝업의 근로자 불러오기 날짜
- Main 주요일정 등록·수정 날짜
- 노임관리 단가 적용일
- 자재투입 확정 입고일 및 개별 입고일
- 공정진척 완료일 및 목표일
- 회원관리 현장 접근 시작일·종료일
- 품의보고 작성일
- 지출결의서 날짜 입력

지출결의서의 `사용일`은 기존 업무 규칙상 `mm-dd` 표시를 유지하되, 클릭 시 한글 캘린더를 사용하도록 통일했습니다.

## 4. 한글 캘린더 표현 정리

- 출력일보 달력의 `Sun~Sat`을 `일~토`로 변경
- 지출결의서 캘린더 미리보기의 영문 요일을 `일~토`로 변경
- 캘린더 월 제목을 `2026.08`보다 `2026년 8월` 형태로 표시

## 5. Main 주요일정 세로 경계선

- 캘린더와 우측 주요일정 사이의 기존 연한 경계선 색상은 유지
- 주요일정이 있든 없든 경계선이 캘린더 박스 아래까지 이어지도록 수정
- 데스크톱 2/3·1/3 비율과 작은 화면 1열 반응형은 유지

## 6. 유지 사항

- Supabase 테이블·RPC 변경 없음
- 날짜 DB 값 형식 변경 없음
- 출력일보·공정진척·지출결의서·회원권한·주요일정 저장 로직 변경 없음
- 기존 Main 공지사항·진척률·근로계약서 현황·주요공정 기능 변경 없음
