# v52.12 변경내용

기준 버전: **v52.11 권한 프로세스 개선본**

## 메신저 입력부

- 메시지 입력칸 왼쪽의 클립 버튼을 기존 높이의 절반 크기로 축소했습니다.
- 클립 버튼 아래에 원형 `+` 공지사항 버튼을 추가했습니다.
- 기존 사진·파일 첨부, 붙여넣기 이미지, 메시지 전송 기능은 유지합니다.

## 채팅방 공지사항

- 대화방 참여자는 역할과 관계없이 누구나 공지사항을 등록할 수 있습니다.
- 공지사항은 제목, 내용, 작성자, 직급, 등록시각을 보관합니다.
- 공지사항 창 왼쪽에는 해당 채팅방의 전체 공지 목록을 최신순으로 표시합니다.
- 왼쪽에서 과거 공지를 누르면 오른쪽에 공지 내용을 미리보기로 표시합니다.
- `새 공지 작성` 상태에서는 오른쪽에 작성 화면만 표시하고 별도 미리보기는 표시하지 않습니다.

## 채팅방 상단 공지

- 새 공지를 등록하면 해당 채팅방 상단에 가장 최근 공지 1건을 표시합니다.
- 공지 제목, 내용 일부, 작성자, 직급, 등록시각을 표시합니다.
- 상단 공지 본문을 누르면 전체 내용을 확인할 수 있습니다.
- `다시 보지 않기`: 해당 사용자에게 해당 공지를 계속 숨기며 DB에 저장합니다.
- `닫기`: 현재 입장 중에만 숨기며, 방을 나갔다 다시 들어오거나 새로 접속하면 다시 표시합니다.
- 이전 공지를 다시 보지 않도록 설정했더라도 이후 등록된 새 공지는 정상 표시합니다.

## DB 및 권한

- `messenger_announcements`: 채팅방별 공지 원본
- `messenger_announcement_dismissals`: 사용자별 다시 보지 않기 기록
- 방 참여 여부를 서버에서 검사한 뒤 공지 등록·조회·숨김을 처리합니다.
- 작성자의 계정이 삭제되어도 공지 제목·내용·작성자명은 보존되도록 구성했습니다.
- 신규 공지는 Supabase Realtime으로 열린 채팅방에 즉시 반영합니다.
