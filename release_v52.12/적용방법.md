# v52.12 적용방법

이 패키지는 **v52.11이 적용된 프로젝트**에 사용하는 증분본입니다.

## 1. Supabase SQL 실행

Supabase Dashboard의 SQL Editor에서 다음 파일 전체를 실행합니다.

```text
release_v52.12\Supabase에서_실행\00_v52.12_메신저_채팅방공지사항.sql
```

마지막 결과에 다음 문구가 나오면 정상입니다.

```text
v52.12 메신저 채팅방 공지사항 SQL 적용 완료
```

## 2. 프런트 파일 적용

압축을 풀어 `release_v52.12` 폴더를 프로젝트 최상위 폴더에 둔 뒤 PowerShell에서 실행합니다.

```powershell
node .\release_v52.12\apply-v52.12-messenger-announcements.cjs
npm run build
npm run dev
```

적용 스크립트는 현재 `src/page/Messenger.jsx`가 검증된 v52.11 기준인지 확인한 뒤 기존 파일을 자동 백업하고 교체합니다.

## 3. 확인 항목

1. 메신저에서 대화방을 선택합니다.
2. 입력칸 왼쪽에 위쪽 클립, 아래쪽 원형 `+`가 표시되는지 확인합니다.
3. `+`를 누르고 새 공지를 등록합니다.
4. 채팅방 상단에 새 공지가 표시되는지 확인합니다.
5. 공지 내용을 눌러 과거 공지 목록과 우측 미리보기가 열리는지 확인합니다.
6. `닫기` 후 다른 방에 갔다 돌아왔을 때 공지가 다시 표시되는지 확인합니다.
7. `다시 보지 않기` 후 다시 접속해도 해당 공지가 표시되지 않는지 확인합니다.

## 주의

- SQL을 실행하지 않고 프런트만 적용하면 공지사항 조회·등록이 동작하지 않습니다.
- 현재 `Messenger.jsx`가 별도로 수정된 상태라면 스크립트가 기존 기능 보호를 위해 적용을 중단합니다. 이 경우 현재 파일을 기준으로 병합해야 합니다.
