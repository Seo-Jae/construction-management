v52.48.5.30 - 일위대가 기술자료 이미지 상세보기

[기준]
- v52.48.5.28 이후 개발 내용을 그대로 유지합니다.
- v52.48.5.29 / v52.48.5.29.1에서 적용한 기술자료 업로드 및 권한 구조를 변경하지 않습니다.
- 이번 버전은 src/page/UnitPriceAnalysis.jsx의 '이미지 조회 방식'만 확장합니다.

[적용 내용]
1. 일위대가작성 우측 기술자료 썸네일을 클릭할 수 있습니다.
2. 클릭하면 화면의 약 96vw × 92vh 크기의 별도 상세보기 창(Dialog)이 열립니다.
3. 상세보기 이미지는 가로/세로 비율을 유지하면서 화면에서 가능한 최대 크기로 표시합니다.
4. 기술자료 조회는 기존 일위대가 열람 사용자 모두 가능합니다.
5. 이미지 업로드/교체/삭제는 기존 규칙 그대로 최고관리자 또는 최고관리자가 별도 권한을 부여한 사용자만 가능합니다.
6. Supabase DB, Storage, 기존 권한, 일위대가 계산/저장/버전 이력은 수정하지 않습니다.

[적용]
new 폴더에서:
node release_v52.48.5.30/apply-v52.48.5.30-technical-image-preview.cjs

그 다음:
npm.cmd run build
npm.cmd run dev

[주의]
- SQL 실행은 필요 없습니다.
- 스크립트는 예상 위치가 다르면 적용을 중단하고 기존 파일을 수정하지 않습니다.
- 실제 수정 전에 UnitPriceAnalysis.jsx를 backup_v52.48.5.30_날짜시간 폴더에 자동 백업합니다.
