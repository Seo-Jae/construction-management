# v52.31 변경내용

## 변경 이력 버튼형 필터

기존:
- 최근 변경 이력 전체를 한 번에 표시
- 처리내용 구분은 표의 `처리내용` 컬럼에서만 확인

변경:
- 설명 문구 바로 아래 버튼형 필터
- `전체` 기본 선택
- 실제 `row.action_label` 값을 기준으로 처리유형 버튼 자동 생성
- 한 번에 하나의 필터만 선택
- 선택된 버튼은 contained 형태로 명확히 표시
- 필터 결과가 없을 경우 별도 안내

## 자동 유형 방식의 이유
처리내용을 코드에 `승인`, `반려`, `기기변경` 등으로 고정하면 향후 새로운 audit 유형이 추가될 때 버튼을 또 수정해야 합니다.

v52.31은 현재 조회된 `recent_audit.action_label`에서 고유값을 추출하므로:
- 현재 존재하는 실제 처리유형을 정확히 표시
- 신규 처리유형 자동 대응
- 기존 DB/RPC 변경 없음
