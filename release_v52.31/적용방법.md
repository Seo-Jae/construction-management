# v52.31 적용방법

## 변경 내용
근태관리 > 변경 이력에서 안내문 아래에 처리내용별 버튼 필터를 추가합니다.

기본:
- 전체

그 뒤 버튼:
- 현재 `dashboard.recent_audit`에 실제 존재하는 `action_label` 값을 자동으로 생성

예:
- 가입신청
- 승인
- 반려
- 기기변경승인
- 가입내역 삭제
- 수동수정

실제 DB에 있는 처리내용 명칭을 그대로 사용하므로 앞으로 새로운 처리유형이 추가되어도 최근 변경 이력에 나타나면 자동으로 버튼이 생깁니다.

## SQL
SQL 변경 없음.

## 적용

프로젝트 최상위에서:

```powershell
node .\release_v52.31\apply-v52.31-attendance-audit-action-filter.cjs
```

정상 메시지:

```text
[v52.31 적용 완료]
```

그 다음:

```powershell
npm run build
```

## Git

변경 파일은 1개입니다.

```powershell
git add src/page/AttendanceManagement.jsx
git status
git commit -m "v52.31 add attendance audit action filters"
git push origin main
```

`git add .`은 사용하지 않습니다.

## 화면 검증

근태관리 > 변경 이력:

1. 안내문 아래에 `전체` + 처리내용별 버튼 표시
2. 기본은 `전체` 선택
3. 버튼 하나 클릭 시 해당 처리내용만 표에 표시
4. 다른 버튼 클릭 시 이전 선택이 풀리고 새 버튼만 선택
5. `전체` 클릭 시 전체 변경 이력 복귀
6. 현장 변경 시 `전체`로 자동 초기화
