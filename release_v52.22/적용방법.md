# v52.22 적용방법

## 변경내용

공지사항 관리의 순서 변경 방식을 `공정별 노임작성`과 동일한 목록 조작 방식으로 변경합니다.

상단 툴바:
- `+` 공지 등록
- `−` 선택 공지 삭제
- `↑` 선택 공지 한 칸 위로
- `↓` 선택 공지 한 칸 아래로
- `선택 N개`

표:
- 헤더 전체선택 체크박스
- 각 행 체크박스
- 기존 순번 표시 유지

등록/수정:
- `표시 순번` 직접 입력란 제거
- 신규 공지는 자동으로 가장 마지막에 추가
- 수정은 내용/게시기간/사용여부만 수정

## 1. SQL

Supabase SQL Editor에서:

```text
release_v52.22\Supabase에서_실행\00_v52.22_공지_체크순서변경_선택삭제.sql
```

전체 실행합니다.

v52.21 SQL이 먼저 적용되어 있어야 합니다.

## 2. 프론트 적용

프로젝트 최상위에서:

```powershell
node .\release_v52.22\apply-v52.22-attendance-notice-toolbar.cjs
```

`[v52.22 적용 완료]` 확인 후:

```powershell
npm run build
```

## 3. Git

이번 실제 프론트 변경 파일은 1개입니다.

```powershell
git add src/page/AttendanceManagement.jsx
git status
git commit -m "v52.22 attendance notice toolbar ordering"
git push origin main
```

`git add .`은 사용하지 않습니다.

## 4. 테스트

### 순서 이동
1. 공지 3개 이상 등록
2. 2번 공지 체크
3. `↑` 클릭 → 1번 위치로 이동 확인
4. `↓` 클릭 → 다시 아래로 이동 확인
5. 2개 연속 공지를 동시에 체크한 후 이동 → 두 공지의 내부 순서가 유지되는지 확인

### 삭제
1. 한 개 또는 여러 공지 체크
2. `−` 클릭
3. 삭제 확인창에서 `선택 삭제`
4. 해당 공지가 사라지는지 확인
5. 남은 순번이 1,2,3...으로 자동 정리되는지 확인

### 작업자 앱
관리자 목록의 최종 순서대로 작업자 상단 티커가 1., 2., 3. 순서로 표시되는지 확인합니다.
