# v52.22 변경내용

## 공지사항 순서조작 UI

기존 v52.21:
- 수정 팝업에서 `표시 순번` 숫자를 직접 입력

v52.22:
- 숫자 직접입력 방식 제거
- `공정별 노임작성`과 같은 체크 선택 + 위/아래 이동 방식
- 여러 행 동시 선택 가능
- 여러 행 이동 시 선택 행끼리 상대 순서 유지
- 헤더 전체 선택/해제 지원
- 현재 선택 개수 표시

## 삭제

- 상단 `−` 버튼으로 선택 공지 삭제
- 한 개/여러 개 동시 삭제
- 삭제 전 확인 Dialog
- 삭제 후 남은 공지 1,2,3... 자동 재정렬

## 신규 공지

- `+` 버튼으로 등록
- 순번 입력 없이 자동으로 가장 마지막에 추가

## 변경 파일

프론트:
- `src/page/AttendanceManagement.jsx`

SQL:
- `attendance_normalize_notice_order_v52_22(text)`
- `attendance_manager_reorder_notices_v52_22(text, uuid[])`
- `attendance_manager_delete_notices_v52_22(text, uuid[])`

작업자 앱 `AttendanceWorkerPortal.jsx`는 변경하지 않습니다.
v52.21에서 이미 DB sort_order 기준으로 공지 표시하도록 구현되어 있으므로,
관리 순서 변경/삭제 결과가 기존 자동갱신 시 그대로 반영됩니다.
