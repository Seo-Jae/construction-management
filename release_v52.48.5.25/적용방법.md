# v52.48.5.25 적용방법

적용 기준은 `v52.48.5.24`입니다. 경비(단수정리) 항목 유형을 저장할 수 있도록 SQL을 반드시 실행해야 합니다.

## 1. 코드 적용

프로젝트 최상위 폴더에서 압축을 해제한 뒤 PowerShell에서 실행합니다.

```powershell
node .\release_v52.48.5.25\apply-v52.48.5.25-labor-rounding.cjs
npm run build
```

## 2. Supabase SQL 실행

Supabase Dashboard의 `SQL Editor`에서 아래 파일을 열어 전체 내용을 한 번 실행합니다.

```text
supabase/v52.48.5.25_unit_price_rounding_expense.sql
```

기존 문서와 기본 구성값은 삭제하지 않습니다. SQL은 다시 실행해도 안전합니다.

## 3. Git 반영

```powershell
git add src/page/UnitPriceAnalysis.jsx supabase/v52.48.5.25_unit_price_rounding_expense.sql
git status
git commit -m "v52.48.5.25 add labor calculator and rounding expense"
git push origin main
```

배포 후 노무비에 `㎡당 금액 9,000원`, 기준단가 `250,000원`을 입력하여 `0.036인`이 표시되는지 확인합니다. 경비(단수정리)의 기본 가산액 100원과 200원 변경도 함께 확인합니다.
