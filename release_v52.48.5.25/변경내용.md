# v52.48.5.25 변경내용

## 노무비 정미수량 자동 계산

- 노무비 행의 `정미수량/㎡금액` 칸에는 1㎡당 지급할 노무비를 원 단위로 입력합니다.
- 정미수량은 `㎡당 노무비 ÷ 노무 기준단가`로 자동 계산합니다.
- 예: 9,000원 ÷ 250,000원 = 0.036인.
- 노무 기준단가를 변경하면 입력한 ㎡당 노무비를 유지하면서 정미수량을 다시 계산합니다.
- 기본정보·단가의 규격별 기본 구성에서도 같은 입력 방식을 사용합니다.
- 저장되는 값은 계산된 정미수량이므로 기존 문서 저장 구조와 호환됩니다.

## 경비(단수정리) 추가

- 구분 선택에 `경비(단수정리)`를 추가했습니다.
- 선택 시 품명 `경비 단수정리`, 단위 `식`, 기본 가산액 100원이 자동 설정됩니다.
- 단수정리 금액은 다른 모든 항목의 제출금액을 합산한 뒤 자동 계산합니다.
- 계산식은 `다음 100원 단위까지의 차액 + 기본 가산액`입니다.
- 예: 14,761원 + 139원 = 14,900원.
- 기본 가산액을 200원으로 바꾸면 14,761원 + 239원 = 15,000원이 됩니다.
- 다른 항목의 할증률·수량·단가가 바뀔 때마다 단수정리 금액도 즉시 다시 계산됩니다.
- 단수정리 행을 표의 중간에 두어도 전체 제출금액을 기준으로 계산합니다.
- 문서 또는 규격별 기본값에는 단수정리 행을 한 개만 넣을 수 있습니다.
- 단수정리 금액은 정미금액에는 포함하지 않고 제출용 경비에만 포함합니다.

## 출력 및 저장

- 우측 금액 요약의 경비·총 제출금액에 단수정리 금액을 포함합니다.
- 저장 문서, 타 현장 공유, Excel, 출력/PDF에 같은 계산 기준을 적용합니다.

## 데이터베이스

- `unit_price_spec_items`와 `unit_price_document_items`의 구분값에 `expense_rounding`을 추가합니다.
- 기존 데이터는 변경하거나 삭제하지 않습니다.
