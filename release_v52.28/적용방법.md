# v52.28 적용방법

## 변경
- 브라우저 탭의 보라색 번개 아이콘 → 욱림 빨간 로고
- 브라우저 탭 제목 → `욱림건설 통합관리시스템`
- URL 공유 제목(Open Graph) → `욱림건설 통합관리시스템`
- 공유 설명 추가
- 공유 대표 이미지 추가
- `package.json`, `package-lock.json` 프로젝트명 `new` 제거
- 작업자 근태앱의 초록색 W PWA 아이콘은 변경하지 않음

## SQL
SQL 변경 없음.

## 적용

```powershell
node .\release_v52.28\apply-v52.28-browser-share-branding.cjs
```

`[v52.28 적용 완료]` 확인 후:

```powershell
npm run build
```

## Git

실제 변경/추가 파일:

```powershell
git add index.html
git add package.json
git add package-lock.json
git add public/wooklim-favicon.png
git add public/wooklim-social-preview.png
git status
git commit -m "v52.28 update browser and share branding"
git push origin main
```

`git add .`은 사용하지 않습니다.

## 배포 후 확인
1. Chrome에서 강력 새로고침(Ctrl+Shift+R)
2. 탭 아이콘이 욱림 빨간 로고인지 확인
3. 탭 제목이 `욱림건설 통합관리시스템`인지 확인
4. URL을 메신저에 새로 전송해 공유 제목 확인

### 공유 제목이 잠시 예전 `new`로 보이는 경우
카카오톡/메신저/브라우저가 이전 링크 미리보기를 캐시하고 있을 수 있습니다.
배포 직후 테스트할 때는 아래처럼 임시 쿼리를 붙이면 새 미리보기를 확인하기 쉽습니다.

```text
https://wooklim-construction-management.vercel.app/?v=52.28
```

실제 페이지 기능에는 영향을 주지 않습니다.
