# v52.48.5.10 변경내용

## 출근 작업범위

- 출근 QR 후 하나의 동을 선택하고 시작층부터 마지막층까지 연속된 여러 층을 등록할 수 있습니다.
- 선택한 층 전체를 작업예정으로 등록하거나, 각 층 골구도에서 작업예정 세대만 선택할 수 있습니다.
- 가입 때 선택한 공정이 기본값으로 표시되며 당일 공정으로 변경할 수 있습니다.
- 기타 작업위치 입력 방식은 기존과 동일하게 유지됩니다.

## 퇴근 완료 제출

- 출근 때 등록한 모든 동·층 골구도가 자동으로 표시됩니다.
- 각 층을 한 번에 전체 완료로 선택하거나 개별 세대를 선택할 수 있습니다.
- 당일 다른 동으로 이동한 경우 퇴근 화면에서 다른 동과 층 범위를 추가할 수 있습니다.
- 출근 때 골구도에서 지정한 작업예정 세대는 주황색으로 표시됩니다.
- 이미 진척관리에 완료된 세대는 파란색으로 구분되고 중복 제출되지 않습니다.

## 담당자 확인

- 통합관리시스템 근태관리에서 출근 등록 위치와 퇴근 시 추가 위치를 구분해 표시합니다.
- 작업자가 제출한 모든 동·층의 완료세대를 골구도로 확인할 수 있습니다.
- 출근 때 선택한 작업예정 세대도 함께 표시해 계획과 실제 제출을 비교할 수 있습니다.
- 확인완료 승인 후에만 기존 진척관리에 작업완료가 반영됩니다.
- 반려해도 출·퇴근 근태기록은 유지됩니다.

## 다국어

- 새 출근 범위, 작업예정 세대, 다른 동 추가, 층 전체 선택 문구를 한국어·영어·중국어·베트남어·러시아어·몽골어 고정 번역으로 추가했습니다.

## 데이터 보호

- 새 다중 범위 데이터는 별도 테이블에 보존합니다.
- 기존 v52.48.5.9 단일 동·층 제출도 담당자 화면에서 계속 조회하고 승인할 수 있습니다.
- 서버가 제출된 동·층·호수를 현장 골구도와 다시 대조합니다.
