# v52.48.5.44.81 변경내용

대상: `src/utils/systemGuidePopup.js`

시스템 가이드의 화면/인쇄 공통 표시에서 불필요한 두 문구를 전부 제거합니다.

- 상단 소개 영역의 초록색 `공개 가이드` 문구 제거
- `사용 순서 한눈에 보기` 제목 아래의
  `각 화면의 대표 흐름만 빠르게 확인하고, 상세한 표시는 아래 이용가이드에서 확인하세요.` 문구 제거
- `사용 순서 한눈에 보기` 제목 자체는 유지
- `가이드 전체 안내(선택)`에 입력한 본문은 유지
- 상세 이용가이드, 이미지, 주석, 목차는 변경하지 않음

공통 `renderSystemGuidePopup`에서 제거하므로 기존에 공개된 가이드를 포함해 모든 시스템 가이드에 동일하게 적용됩니다.
별도 재공개는 필요하지 않습니다.
추가 Supabase SQL도 없습니다.
