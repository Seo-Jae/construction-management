# v52.48.5.44.44 적용부터 운영 배포까지

`v52.48.5.44.43`이 적용된 프로젝트 최상위 폴더에 `release_v52.48.5.44.44` 폴더를 둔 뒤 PowerShell에서 아래를 한 번에 실행합니다.

```powershell
node .\release_v52.48.5.44.44\apply-v52.48.5.44.44-grid-print-layout-fix.cjs
npm run build
git add .
git commit -m "v52.48.5.44.44 골구도 PDF 프린트 출력 크기 수정"
git push origin main
```

GitHub `main` 브랜치가 Vercel Production 자동배포와 연결되어 있으면 `git push origin main` 완료 후 운영 배포가 자동으로 진행됩니다.

직접 Vercel 운영배포를 사용하는 환경에서만 마지막에 아래 명령을 추가합니다.

```powershell
npx vercel --prod
```

자동배포가 연결된 경우 `git push`와 `npx vercel --prod`를 동시에 사용하지 않는 것을 권장합니다.

새 Supabase SQL은 없습니다.
