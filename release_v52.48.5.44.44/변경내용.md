# v52.48.5.44.44 변경내용

## 문제 원인
v52.48.5.44.43의 출력은 별도 iframe에 `gridContentRef.current.innerHTML`과 스타일 태그를 복제하는 방식이었습니다.
MUI/Emotion 런타임 스타일은 iframe으로 완전히 복제되지 않을 수 있어 `BuildingGrid` 내부의 필로티 SVG가 기준 셀을 잃고 출력 영역 전체를 기준으로 확대될 수 있었습니다. 이때 실제 골구도 크기 계산도 왜곡되어 전체 골구도가 좌측 상단에 매우 작게 축소되었습니다.

## 수정
- iframe 출력 제거
- 현재 문서에서 실제 렌더링 중인 골구도 DOM을 `cloneNode(true)`로 복제
- 현재 페이지의 MUI/Emotion 스타일시트를 그대로 사용
- 화면에서 사용한 줌/드래그 transform은 출력에 포함하지 않음
- A4 가로, 5mm 여백, 1페이지 자동 축소 및 중앙 정렬
- 필로티 X선이 페이지 전체로 확대되는 현상 방지
- PDF 저장/인쇄 모두 동일한 안정화된 출력 경로 사용

## 영향 범위
- `src/page/HouseholdQuantityManagement.jsx` 1개 파일만 변경
- Supabase/DB 구조 변경 없음
