# 욱림건설 Windows 프로그램

React 웹을 그대로 사용하는 Electron 전용 프로그램입니다. 운영 주소는 `security.cjs`에 고정되어 있으며, 웹과 같은 Supabase 로그인·권한·현장 자료를 사용합니다. 브라우저 로그인과 프로그램 로그인은 별도이므로 최초 실행 시 로그인합니다. 인터넷 연결이 필요합니다.

## 설치 및 실행

- Windows 10/11, 64비트 PC용입니다.
- 최신 설치 파일은 `desktop/out/Wooklim-Setup-0.1.11-x64.exe`입니다. 0.1.8 이하에는 업데이터가 없어 최초 전환이 한 번 필요합니다. 0.1.9부터는 시작 후와 4시간마다 새 프로그램 버전을 확인해 자동 다운로드합니다. 0.1.11부터 프로그램 자체 업데이트는 **더보기 → 프로그램 업데이트 확인 / 적용**에서 따로 실행하며 이 경우에만 재시작합니다. 기존 프로그램을 삭제할 필요가 없습니다.
- 웹 배포는 30초마다, 그리고 앱으로 돌아왔을 때 확인합니다. 실행 중인 화면의 JS/CSS 파일과 운영 배포 파일을 비교하여 **최신 버전 / 업데이트 필요**를 표시합니다. 상단 버튼은 웹 화면 업데이트만 처리하며 설치 프로그램 업데이트를 실행하지 않습니다. **업데이트 필요**를 누르면 저장 안내와 **확인 / 취소** 버튼이 나옵니다. **확인**은 프로그램 종료 없이 화면만 새로고침하며, **취소**는 현재 작업 화면을 유지합니다. 통신에 실패하면 **최신 버전**으로 오인하지 않도록 **업데이트 확인**을 표시합니다.
- 설치 대상은 항상 **이 컴퓨터의 모든 사용자**입니다. 개인 전용 선택 화면은 표시하지 않으며, 설치 시 Windows 관리자 권한 승인이 필요합니다.
- 바탕화면 또는 시작 메뉴의 **욱림건설 통합관리**를 실행합니다.
- 두 번 실행해도 기존 창을 앞으로 가져옵니다. 닫기(X)는 창만 숨기며 작성 중인 내용과 로그인 상태를 유지합니다.
- 작업표시줄 숨겨진 아이콘의 WL 아이콘을 클릭하면 다시 열립니다. 트레이 우클릭 → **완전히 종료**를 선택해야 프로그램이 종료됩니다.
- 로그인한 상태에서는 숨겨도 기존 메신저 수신 연결이 유지됩니다. 설치형의 업무 사이트 알림 권한은 별도 승인 없이 허용됩니다. 본창과 메신저 별도 창의 알림은 Electron의 Windows 직접 알림으로 전달하며, 클릭하면 원래 창을 복원하고 기존 대화 이동 동작을 실행합니다. 테스트 알림의 전달 실패는 안내창으로 표시합니다. Windows에서 알림을 끄거나 방해 금지를 설정한 경우 그 설정이 우선합니다. 완전히 종료하거나 로그아웃하면 수신하지 않습니다.
- 제거는 Windows 설정 → 앱에서 합니다. 재설치 시 로그인 정보 보존을 위해 사용자 프로필은 자동 삭제하지 않습니다. 공용 PC에서는 종료 전에 로그아웃합니다.

## 프로그램 메뉴

- 남색 앱 바에 WL 엠블럼, 연결 상태, 새로고침·인쇄·PDF 저장·더보기 아이콘을 표시합니다. 오른쪽에는 Windows 기본 최소화·최대화·닫기 버튼이 같은 색상으로 표시됩니다.
- 인쇄(Ctrl+P)와 PDF 저장(Ctrl+Shift+S)은 앱 안의 인쇄 미리보기를 엽니다. 왼쪽에서 프린터·매수·페이지·색상·양면을 선택하고 오른쪽에서 문서를 확인합니다. 인쇄를 누르면 선택한 프린터에 바로 요청하며, 미리보기를 지원하지 않는 Windows 인쇄창을 다시 열지 않습니다. 문서의 가로/세로 방향은 기존 양식을 따릅니다. PDF 저장은 미리보기의 전체 문서를 저장합니다. 새로고침은 F5입니다.
- 더보기: 업데이트 확인 / 적용, 다운로드 폴더, 확대·축소, 전체 화면(F11), 편집, 브라우저로 열기, 프로그램 정보
- 앱 바의 빈 공간을 드래그하면 창을 이동할 수 있으며, 최대화 버튼의 Windows 창 배치 기능도 유지됩니다.
- 본창과 팝업의 작업표시줄 아이콘에도 WL 엠블럼을 지정합니다. 개발·테스트 실행의 Windows 앱 식별자는 설치 프로그램과 분리하여 테스트가 운영 바로가기의 아이콘 연결에 영향을 주지 않도록 합니다.
- 기존 화면의 인쇄 버튼도 같은 미리보기로 연결됩니다. 메뉴별 버튼에는 선택한 자료와 문서 양식을 준비하는 기능이 있으므로 유지합니다. 상단 버튼은 현재 화면의 인쇄 스타일을 사용하며 메뉴별 자료 준비 동작을 대신하지는 않습니다.
- 엑셀 등의 다운로드 시 Windows 저장 위치 선택창을 표시합니다.
- 문서 편집·인쇄·메신저 팝업은 프로그램 안에서 열고, 외부 HTTPS 링크는 확인 후 기본 브라우저로 엽니다.

## 개발 명령 (저장소 루트)

```powershell
npm --prefix desktop ci
npm run desktop:start
npm run desktop:dev
npm run desktop:test
npm run desktop:build
```

`desktop:start`는 운영 웹에 접속합니다. `desktop:dev`는 별도 Vite 서버(127.0.0.1:5174)를 시작한 후 개발 화면을 프로그램에서 엽니다. 기존 `npm run dev` 및 웹 배포 절차는 유지됩니다. 프로그램의 의존성과 lock 파일은 `desktop/`에 별도로 관리합니다.

아이콘은 새로 제공된 시안 블루 3D WL 엠블럼(`desktop/assets/emblem-source.png`)을 그대로 사용합니다. 설치·제거 파일, 설치 화면, 프로그램 창과 바로가기 아이콘에 공통 적용됩니다. 다시 생성하려면 `powershell -ExecutionPolicy Bypass -File desktop/scripts/prepare-icon.ps1`를 실행합니다. 이 스크립트는 16~256px 다중 크기 ICO와 설치 화면용 BMP를 생성합니다.

## 확인 및 배포 범위

```powershell
npm run build
npm run desktop:test
npm --prefix desktop run smoke
```

Smoke 검사는 독립적인 임시 프로필로 로그인 화면, 팝업, 샌드박스, PDF 생성, Blob 다운로드, 트레이 숨김·종료를 확인합니다. 본창과 팝업에서 로컬 테스트 알림을 만들고 Windows 알림의 실제 show 이벤트를 기다립니다. 클릭 경로는 네이티브 이벤트를 모의 발생시켜 검증합니다. 로그인하거나 운영 자료를 수정하지 않습니다. 설치 파일 생성 후 `desktop/out/win-unpacked/WooklimConstruction.exe --desktop-smoke-test`로 패키지 실행도 검증할 수 있습니다.

- 웹 기능: 기존 Vercel 배포 후 프로그램에서 새로고침하면 반영됩니다.
- Electron 프로그램 자체: GitHub Releases의 설치 파일·blockmap·latest.yml을 사용합니다. 사용자 앱에는 배포 인증정보를 포함하지 않습니다. 체크섬 확인 후 다운로드하며, 사용자가 재시작을 선택할 때만 설치합니다. 모든 사용자 설치이므로 Windows 관리자 권한 확인이 나타날 수 있습니다.
- 배포 요청 시 `npm run desktop:build` 후 `node desktop/scripts/publish-release.cjs`를 실행합니다. 스크립트는 기존 Git 인증을 메모리에서만 사용하며, 초안에 파일을 모두 업로드한 뒤 공개합니다. 기존 릴리스는 덮어쓰지 않습니다.
- 첫 시험판은 코드 서명 인증서가 없는 서명되지 않은 설치 파일입니다. Windows에서 게시자를 확인할 수 없다는 안내가 나올 수 있습니다. 직원 대상 배포 전 회사 명의 코드 서명을 구성해야 합니다.
- 빌드에는 프론트의 `.env`, DB 키, 로컬 백업, 작업 자료가 포함되지 않습니다.
- 원격 화면에는 Node.js나 파일 시스템 API를 노출하지 않습니다. 로컬 앱 바와 업무 화면은 별도 WebContents로 분리하며, 앱 바의 상위 프레임에서 허용된 명령만 요청할 수 있습니다. 업데이트 주소와 설치 명령은 원격 화면에서 변경할 수 없습니다. 알림 브리지는 등록된 업무 창의 상위 프레임과 사이트 출처를 검사하고 제목·본문 길이와 보관 개수를 제한합니다. 외부 아이콘 경로, 파일 경로 또는 임의 명령을 받지 않습니다.

참고: [Electron 보안 지침](https://www.electronjs.org/docs/latest/tutorial/security), [NSIS 설치 프로그램 설정](https://www.electron.build/nsis/).
