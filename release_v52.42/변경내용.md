# v52.42 변경내용

## 문제 1: 생년월일 글자 겹침

기존 `TextField type="date"`에서
브라우저 날짜 placeholder와 MUI label이 겹쳐 보이던 구조를 제거했습니다.

## 문제 2: 과거 연도 선택 불편

브라우저 기본 달력을 완전히 제거하고
근로자 정보관리 v52.41과 같은 방식으로 바꿨습니다.

구성:
- 생년: 검색 가능한 Autocomplete
- 월: Select
- 일: Select

예:
`1992`를 생년 검색창에 입력해 바로 선택할 수 있습니다.

## 날짜 유효성

연/월 기준 실제 말일을 계산합니다.

따라서:
- 2024-02 → 29일까지
- 2025-02 → 28일까지
- 4/6/9/11월 → 30일까지
- 나머지 → 31일까지

자동 반영됩니다.

## 기존 기능 보존

그대로 유지:
- 성명
- 휴대폰 뒤4자리
- 공종
- 안내문
- 등록 후 명단 추가
- 중복 근로자 처리
- 신규 근로자 등록 RPC

날짜 전달형식도 기존 `YYYY-MM-DD`를 유지합니다.
