# v52.42 적용방법

## 변경 대상

`노임관리 > 월별 노임작성 > + > 신규 근로자 등록`

생년월일 입력방식을 근로자 정보관리와 동일하게 통일합니다.

## SQL

이번 버전은 SQL 변경이 없습니다.

기존 신규 근로자 등록 RPC에는 최종 날짜를
`YYYY-MM-DD` 형식으로 그대로 전달합니다.

## 프로그램 적용

프로젝트 최상위에서:

```powershell
node .\release_v52.42\apply-v52.42-monthly-worker-birthdate-ui.cjs
npm run build
```

## Git

빌드 성공 후:

```powershell
git add src/page/MonthlyLaborManagement.jsx
git status
git commit -m "v52.42 unify monthly worker birth date input"
git push origin main
```

`git add .`은 사용하지 않습니다.

## 화면 확인

신규 근로자 등록 팝업에서:

- `생년월일` 글자가 겹치지 않아야 함
- 브라우저 달력 아이콘/기본 date picker가 없어야 함
- 생년 / 월 / 일 3칸으로 표시
- 생년에서 `1992` 등을 검색해 바로 선택 가능
- 월 선택 후 일 선택 가능
- 2월/윤년, 30일/31일이 자동 반영
- 등록 시 기존과 동일하게 YYYY-MM-DD로 DB에 전달
