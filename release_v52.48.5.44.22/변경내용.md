# v52.48.5.44.22 변경내용

- `옵션별 비교` 상단에 `옵션선택` 박스 6개를 한 줄로 배치했습니다.
- 참고 이미지처럼 각 박스에 서로 다른 파스텔 배경색과 테두리색을 적용했습니다.
- 박스 높이, 간격, 둥근 모서리와 중앙 정렬을 참고 이미지에 가깝게 구성했습니다.
- 화면 폭이 좁으면 선택 박스 영역만 가로 스크롤됩니다.
- 기존 `기준 옵션`, `비교 옵션` 비활성 입력칸을 제거했습니다.
- 파란색 임시 안내문을 제거했습니다.
- 비교 화면의 `등록 동`, `전체 세대`, `비교 옵션 미선택` 현황칩을 제거했습니다.
- 골구도 배경을 흰색으로 정리했습니다.
- 데이터베이스 구조 변경은 없습니다.
