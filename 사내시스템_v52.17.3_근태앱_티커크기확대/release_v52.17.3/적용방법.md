# v52.17.3 적용방법

이번 버전은 **근태앱 상단 공지 티커 크기만 확대**합니다.

## 1. SQL
SQL 변경 없음. Supabase에서 실행할 내용이 없습니다.

## 2. 적용
프로젝트 최상위 폴더에서:

```powershell
node .\release_v52.17.3\apply-v52.17.3-attendance-ticker-size.cjs
```

## 3. 빌드

```powershell
npm run build
```

마지막에 `✓ built in ...`가 나오면 정상입니다.

## 4. Git

이번 실제 프로그램 변경 파일은 1개입니다.

```powershell
git add src/page/AttendanceWorkerPortal.jsx
git status
git commit -m "v52.17.3 attendance ticker size"
git push origin main
```

`git add .`은 사용하지 않습니다.

## 5. 배포 후 확인
- 갤럭시 설치형 근태앱 로그인
- 상단 노란색 공지 티커 높이가 기존보다 커졌는지 확인
- `공지` 글씨가 더 커졌는지 확인
- 오른쪽에서 왼쪽으로 흐르는 공지 본문 글씨가 더 커졌는지 확인
- 기존 진한 노란색 배경, 강제 노출, 자동 흐름이 유지되는지 확인
