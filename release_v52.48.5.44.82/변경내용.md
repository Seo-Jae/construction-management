# v52.48.5.44.82 변경내용

대상: `src/utils/systemGuidePopup.js`

시스템 가이드 인쇄 시 `상세 이용가이드` 제목만 1페이지 하단에 남고,
첫 상세 항목이 2페이지로 밀리는 문제를 모든 가이드에서 공통 수정합니다.

## 변경

- 인쇄 전용 CSS에서 `.details` 영역에 강제 페이지 나눔 적용
- `상세 이용가이드` 전체 영역은 항상 새 페이지에서 시작
- `.details`를 인쇄 시 block으로 변경해 브라우저의 flex fragmentation 오차 방지
- `상세 이용가이드` 제목 뒤에는 페이지 나눔 방지
- 상세 카드 사이 간격은 기존과 유사하게 유지

결과:
- 1페이지: 상단 안내 + `사용 순서 한눈에 보기`
- 2페이지 상단: `상세 이용가이드`
- 그 아래부터 1번 상세 가이드 시작
