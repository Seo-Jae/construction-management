v52.48.5.44.5 - 공정별 현황 입력 타입별 세대 현황 플로팅 패널

변경 파일
- src/page/ProgressInput.jsx

기능
- 공정별 현황 입력 화면 상단 우측에 작은 독립 패널로 표시
- 현재 선택 공정 기준 타입별:
  □ 59A  0/131세대 (0%)
  □ 84C  0/68세대  (0%)
- 하단 합계:
  합계 0/640세대 (0%)

색상
- 각 타입은 패널의 작은 사각형에서만 서로 다른 색상 사용
- 기존 세대 그리드나 다른 UI에는 타입 색상을 적용하지 않음

타입 판정
1. 신규 현장관리의 building_settings.config_json.unitTypes
2. 층별 타입 예외 floorUnitTypes
3. 기존 현장의 project_unit_types
모두 지원

층별 타입 예외
- 예: 기본 2호=68A, 29층 2호=120T
- 타입 전체 세대수 집계에서 29층 2호는 120T로 계산

플로팅 패널
- 최초 위치: 화면 상단 우측
- 제목줄 드래그로 이동
- 최소화 아이콘
- 닫기 아이콘
- 닫으면 우측 상단에 작은 '타입 현황' 다시열기 버튼 표시
- 위치/최소화/닫기 상태는 현장별 브라우저 localStorage에 저장

완료수량
- 현재 선택 공정의 unit_progress 상태가 '작업완료'인 실제 세대만 완료로 계산
- 합계는 전체 실제 세대 기준

SQL 변경 없음

적용
node release_v52.48.5.44.5/apply-v52.48.5.44.5-progress-type-summary-panel.cjs
