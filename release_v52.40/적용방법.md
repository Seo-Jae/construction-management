# v52.40 적용방법

## 확정 업무방향

월별 노임작성에서는 노임을 작성하지 않습니다.

웹 시스템 역할:
- 월별 필요한 근로자 조회
- 명단 선별/저장
- 순서 변경
- 공종/비고 정리
- 개인정보 누락 확인
- 보안 인증
- 회사 Excel 다운로드 준비

Excel 역할:
- 출역 일자
- 일급/단가
- 노임금액
- 지급/공제 계산

## 1. Supabase SQL

SQL Editor에서:

`release_v52.40/Supabase에서_실행/00_v52.40_월별노임작성_조회다운로드형_전환.sql`

실행합니다.

기존 v52.36의 출역/일급/금액 컬럼은 삭제하지 않습니다.
현재 기능에서만 사용하지 않도록 바꿉니다.

## 2. 프로그램 적용

```powershell
node .\release_v52.40\apply-v52.40-monthly-labor-lookup-ui.cjs
npm run build
```

## 3. Git

```powershell
git add src/page/MonthlyLaborManagement.jsx
git status
git commit -m "v52.40 simplify monthly labor to worker lookup"
git push origin main
```

`git add .`은 사용하지 않습니다.

## 4. 화면 확인

표 컬럼:
- 체크박스
- 순번
- 성명
- 공종
- 생년월일
- 휴대폰
- 비고

없어야 하는 UI:
- 출역
- 일급
- 총지급
- 수동공제
- 실지급
- 노임입력
- 출역·노임 입력 팝업

상단 +/삭제/↑/↓는 공정별 노임작성과 같은 아이콘/박스 스타일로 표시됩니다.
