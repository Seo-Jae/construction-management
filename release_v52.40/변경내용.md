# v52.40 변경내용

## 월별 노임작성 역할

노임계산 화면이 아니라
`월별 근로자 자료 선별 + 개인정보 Excel 다운로드 준비 화면`
으로 정리합니다.

## 제거
- 출역 요약/컬럼
- 일급 컬럼
- 총지급 요약/컬럼
- 수동공제 요약/컬럼
- 실지급 요약/컬럼
- 노임입력 컬럼
- 출역·노임 입력 팝업

## 유지
- 작성월/저장
- 근로자 조회
- 근로자 신규등록
- 선택 삭제
- ↑↓ 순서변경
- 공종/공종 일괄변경
- 생년월일
- 마스킹 휴대폰
- 비고
- Excel 생성 준비
- 보안 휴대폰
- 다운로드 인증 준비

## 툴바 통일
공정별 노임작성 실제 코드와 같은:
- AddCircleOutlineRoundedIcon
- RemoveCircleOutlineRoundedIcon
- ArrowUpwardRoundedIcon
- ArrowDownwardRoundedIcon

및 같은 outlined Paper 스타일을 사용합니다.

## 체크박스
헤더 체크박스 잘림 방지를 위해:
- 폭 52 고정
- overflow visible
- MUI checkbox icon 명시
- 20px 아이콘
을 적용했습니다.

## 순번
헤더 최소폭 64 + `whiteSpace: nowrap`을 적용했습니다.

## 서버 검사
Excel 준비검사에서 더 이상:
- daily_wage
- work_entries

를 요구하지 않습니다.

OTP snapshot도 출역/일급/금액 대신
근로자 선별/순서/공종/비고/개인정보 변경에 묶입니다.
