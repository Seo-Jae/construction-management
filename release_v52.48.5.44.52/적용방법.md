# v52.48.5.44.52 적용방법

프로젝트 최상위 폴더에 `release_v52.48.5.44.52` 폴더를 넣은 뒤 아래 순서로 실행합니다.

```powershell
node .\release_v52.48.5.44.52\apply-v52.48.5.44.52-guide-popup-width.cjs
npm run build
git add .
git commit -m "v52.48.5.44.52 가이드 팝업 화면 비율 개선"
git push origin main
```

`main` 브랜치 push 후 Vercel 자동배포를 확인합니다. 자동배포가 정상 동작하면 `npx vercel --prod`는 별도로 실행하지 않습니다.
