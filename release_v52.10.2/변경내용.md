# v52.10.2 변경내용

- 메신저 아이콘 클릭 시 자동으로 조용히 알림 권한을 요청하던 동작 제거
- 메신저 별도창에 알림 상태 UI 추가
- 권한이 아직 없으면 `알림 사용` 버튼 표시
- 버튼 클릭 시 `Notification.requestPermission()` 실행
- 허용 직후 Windows 테스트 알림 자동 발송
- 허용 상태에서는 `테스트 알림` 버튼 제공
- 차단 상태에서는 브라우저 사이트 설정에서 직접 허용해야 한다는 안내 표시
- 메신저창이 다시 포커스될 때 권한 상태 자동 재확인
- 사이트 내부 새 메시지 Snackbar는 다시 추가하지 않음
- 기존 별도창, 초안 유지, 글자크기, 방장위임, 이미지 붙여넣기 등 v52.10 기능 유지
