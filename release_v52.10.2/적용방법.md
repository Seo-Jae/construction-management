# v52.10.2 적용방법

## SQL
추가 SQL 없음. v52.10.1 SQL이 정상 실행된 상태를 그대로 사용합니다.

## 적용
프로젝트 최상위(package.json이 있는 위치)에 ZIP을 풀고 PowerShell에서 실행합니다.

```powershell
node .\release_v52.10.2\apply-v52.10.2-messenger-notification-permission.cjs
npm run build
```

적용 파일은 2개입니다.

- `src/components/MessengerButton.jsx`
- `src/page/MessengerWindow.jsx`

적용 전 파일은 `backup_v52.10.2_...` 폴더에 자동 백업됩니다.

## 확인 순서
1. ERP 상단 메신저 아이콘 클릭
2. 별도 메신저창 상단에 알림 상태 안내가 표시되는지 확인
3. `알림 사용` 클릭
4. Chrome/Edge 알림 권한에서 `허용`
5. 즉시 테스트 Windows 알림이 표시되는지 확인
6. 알림이 허용된 상태에서는 `테스트 알림` 버튼으로 언제든 확인
7. 다른 계정에서 새 메시지를 보내 Windows 우측 하단 알림 확인

## 이미 차단된 경우
브라우저 정책상 코드에서 다시 승인창을 강제로 띄울 수 없습니다.
주소창 왼쪽의 사이트 정보 → 사이트 설정 → 알림 → 허용으로 바꾼 뒤 메신저창으로 돌아오면 상태가 자동 갱신됩니다.
