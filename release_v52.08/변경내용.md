# v52.08 변경내용

## 기준

- v52.07 누적 상태를 기준으로 작업함.
- v52.07 이전 공사관리·안전관리·회원권한·Main·날짜 UI·지출결의서·DW 기능은 삭제하거나 재작성하지 않음.
- 기존 `Dashboard.jsx`에는 메신저 연결에 필요한 최소 코드만 추가함.

## 변경 파일

```text
src/Dashboard.jsx
src/components/MessengerButton.jsx
src/page/Messenger.jsx
src/utils/messengerFiles.js
```

## 신규 DB/Storage

```text
public.messenger_rooms
public.messenger_room_members
public.messenger_messages
public.messenger_attachments
Storage bucket: messenger-files (private, 10MB/file)
```

메신저 전용 RPC와 RLS를 함께 설치한다.

## Dashboard 변경

- 상단 접속자 정보 왼쪽에 메신저 아이콘 추가
- 전체 읽지않음 숫자 배지 표시
- 메신저는 현장 선택과 무관한 전역 화면으로 처리
- 공사관리/안전관리 어느 영역에 있어도 상단 메신저 아이콘으로 진입 가능
- 메신저 아이콘을 다시 누르면 직전에 보던 화면으로 복귀
- 메신저에서 공사관리/안전관리 영역을 변경해도 메신저에 갇히지 않도록 직전 화면으로 복귀 처리

## 기존 기능 보존

`Dashboard.jsx`의 기존 파일과 v52.08 파일을 비교하면 기존 로직 삭제 없이 다음 연결만 추가된다.

- MessengerButton import
- Messenger import
- messenger 전역 view 등록
- 상단 메신저 버튼
- 메신저 렌더링 분기
- 메신저 진입 전 화면 복귀 처리

기존 Sidebar 메뉴 구조 자체는 수정하지 않았다.
