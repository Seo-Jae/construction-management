# 메신저 v1.2 기능 범위

기준 소스: 사용자가 전달한 `new (3).zip`에 v52.07 누적배포본을 적용한 최신 로컬 상태.

## v1.0

- 상단 전역 메신저 아이콘
- 읽지 않은 전체 메시지 숫자 배지
- 활성 사내 사용자 검색
- 현장과 무관한 1:1 대화
- 여러 사용자를 선택하는 그룹 대화
- 실시간 메시지 반영
- 대화방 목록 / 마지막 메시지 / 마지막 시간
- 대화방별 읽지 않은 메시지 수
- 메시지 작성시간
- 그룹대화 발신자 이름·직급 표시
- 참여자 이름·직급·역할·회사·현장 표시
- 최근 100개 메시지 우선 조회 + 이전 메시지 추가 불러오기

## v1.1

- 사진 전송
- 일반 파일 전송
- 한 번에 최대 5개 첨부
- 파일당 최대 10MB
- 큰 일반 이미지는 브라우저에서 최대 1920px 기준으로 자동 축소 및 JPEG 압축 시도
- 2MB를 넘는 이미지의 용량을 줄여 Storage 사용량을 절약
- HEIC처럼 브라우저에서 압축할 수 없는 이미지는 10MB 이하일 경우 일반 파일로 원본 전송
- 사진 미리보기 팝업
- 사진/파일 다운로드
- 비공개 Supabase Storage bucket `messenger-files`
- 대화방 참여자만 파일 조회 가능
- 업로더 본인만 Storage 파일 삭제 가능

## v1.2

- 내 메시지 삭제
- 삭제 메시지는 대화 이력에 `삭제된 메시지입니다.`로 표시
- 첨부 메시지를 삭제하면 DB 첨부정보를 비공개 처리하고 Storage 파일도 삭제 시도
- 그룹방 이름 변경
- 그룹방 참여자 추가
- 그룹방 참여자 제외
- 그룹방 생성자만 이름/참여자 변경 가능
- 모바일/좁은 화면에서 대화방 목록 ↔ 대화창 전환형 반응형 UI
- PC 대화정보 우측 패널

## 접근권한 원칙

기존 현장업무 데이터처럼 `project_name`만으로 메신저를 분리하지 않는다.

메신저는 다음 원칙을 사용한다.

- 활성 계정만 사용 가능
- 본인이 참여한 대화방만 조회 가능
- 대화방 참여자만 메시지와 첨부파일 조회 가능
- 1:1/그룹 모두 현장 간 대화 가능
- 메시지 작성은 RPC에서 다시 참여자 여부 확인
- 그룹 관리도 RPC에서 방 생성자 여부 재검증
- 프런트 코드에 service role key를 사용하지 않음

## 현재 v1.2에서 제외한 기능

다음 기능은 첫 사용 후 필요성을 확인해서 후속 버전에서 결정한다.

- 브라우저를 완전히 닫은 상태의 OS 푸시 알림
- 동영상 전송
- 음성메시지
- 메시지 수정
- 메시지 전달/답장/인용
- 이모지 반응
- 파일 자동 만료/보관기간 정책
- 관리자 대화내용 열람 기능

특히 관리자라고 해서 다른 사용자의 대화방 내용을 자동으로 볼 수 있게 만들지 않았다.
