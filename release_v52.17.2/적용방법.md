# v52.17.2 적용방법

이번 버전은 SQL 변경이 없습니다.

프로젝트 최상위 폴더에 `release_v52.17.2` 폴더를 복사한 뒤 PowerShell에서 실행합니다.

```powershell
node .\release_v52.17.2\apply-v52.17.2-attendance-app-width-ticker.cjs
npm run build
```

빌드가 성공하면 Git에는 아래 파일 1개만 추가합니다.

```powershell
git add src/page/AttendanceWorkerPortal.jsx
git status
git commit -m "v52.17.2 attendance app width and ticker color"
git push origin main
```

`git add .`은 사용하지 않습니다.

Vercel의 운영 프로젝트 `wooklim-construction-management`에서 Production 배포가 `Ready`가 되면 실제 갤럭시 앱에서 확인합니다.
