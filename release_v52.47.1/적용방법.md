# v52.47.1 적용방법

이번 버전은 Excel 업로드에서 `소계` 행이 근로자로 인식되는 문제를 수정합니다.

## 원인

회사 양식의 마지막 소계 영역은 `A219:H220`처럼 병합되어 있습니다. ExcelJS에서는 병합영역 내부 셀을 읽을 때 병합 마스터값 `소계`가 C/D열에서도 읽힐 수 있어 기존 parser가 가짜 근로자로 인식했습니다.

## 수정 기준

근로자로 인정하려면 D열이 정규화 후 반드시 `내국인` 또는 `외국인`이어야 합니다.

추가 안전장치로 성명이 `소계 / 합계 / 총계 / 계`이면 무조건 제외합니다.

## 적용

SQL 변경은 없습니다.

```powershell
node .\release_v52.47.1\apply-v52.47.1-excel-summary-row-filter.cjs
npm run build
```

빌드 성공 후:

```powershell
git add src/utils/laborWorkerExcelImport.js
git status
git commit -m "v52.47.1 filter excel summary rows"
git push origin main
```

`git add .`은 사용하지 않습니다.
