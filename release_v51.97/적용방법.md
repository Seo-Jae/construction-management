# 사내시스템 v51.97 적용방법

프로젝트 최상위 폴더에서 PowerShell을 열고 아래 명령을 순서대로 실행합니다.

```powershell
node .\release_v51.97\apply-v51.97-dashboard-schedule-toast.cjs
npm run build
```

적용 스크립트는 기존 `src/page/AdminDashboardScheduleBoard.jsx`를 `backup_v51.97_날짜시간` 폴더에 자동 백업한 뒤 수정 파일을 반영합니다.

이번 버전은 Supabase SQL 실행이 필요하지 않습니다.

## 확인 항목

1. Dashboard에서 현장설명·입찰 현황 또는 회의 일정을 수정하고 저장합니다.
2. 저장 성공 시 화면 상단 중앙에 초록색 토스트가 표시되는지 확인합니다.
3. 토스트가 3초 후 자동으로 닫히는지 확인합니다.
4. 토스트 표시 중에도 현장설명·입찰 표와 달력의 위치가 움직이지 않는지 확인합니다.
