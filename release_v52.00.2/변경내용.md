# 사내시스템 v52.00.2 변경내용

## 회원관리 화면

- 기존 읽기 전용 직급 표시를 편집 가능한 입력란으로 변경했습니다.
- 직급 값을 회원별 수정 초안에 포함했습니다.
- 직급만 변경한 경우도 미저장 변경사항으로 감지합니다.
- 직급 입력값을 회원 권한 저장 RPC에 함께 전달합니다.
- 화면 상단 직급 표시는 저장 전 입력값도 즉시 반영합니다.

## 데이터베이스 보호

- `admin_update_user_access_v2`에 `p_position_title` 인자를 추가했습니다.
- 함수 내부의 최고관리자 검증을 통과한 경우에만 `user_profiles.position_title`을 변경합니다.
- 일반 사용자나 일반 관리자의 직접 UPDATE를 차단하는 트리거를 추가했습니다.
- SQL Editor와 서비스 역할을 통한 시스템 관리 작업은 허용합니다.
- 권한 변경 스냅샷에 `position_title`을 포함해 변경이력을 남깁니다.

## 호환성

- v52.00.1의 세부권한·특수권한·기존회원 변환·변경이력·월 한국어 표기 내용을 모두 포함합니다.
- v52.00.1이 이미 적용된 데이터베이스에서도 재실행할 수 있습니다.
- 기존 회원의 직급은 SQL 실행만으로 변경되지 않습니다.
