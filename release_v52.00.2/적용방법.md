# 사내시스템 v52.00.2 적용방법

## 적용 내용

- 회원관리의 직급 입력란을 최고관리자 전용 수정항목으로 변경
- 권한 저장 시 `position_title` 함께 저장
- 일반 사용자의 RPC 우회 변경 차단
- 일반 사용자의 `user_profiles.position_title` 직접 변경 차단
- 직급 변경 전후 값을 권한 변경이력에 포함

## 적용 순서

1. Supabase SQL Editor에서 아래 파일 전체를 실행합니다.

   `Supabase에서_실행_회원권한_2~5단계_통합_v52.00.2.sql`

   v52.00.1 SQL 실행 성공 여부와 관계없이 v52.00.2 SQL 하나만 실행하면 됩니다. 기존 v52.00 또는 v52.00.1 SQL은 다시 실행하지 않습니다.

2. ZIP을 프로젝트 최상위 폴더에 풀고 PowerShell에서 아래 명령을 실행합니다.

   ```powershell
   node .\release_v52.00.2\apply-v52.00.2-position-admin-only.cjs
   npm run build
   ```

3. 최고관리자 계정으로 회원관리 화면을 열고 회원을 선택합니다.

4. `기본정보 > 직급`을 수정한 뒤 `권한 저장` 또는 `승인 후 사용 시작`을 누릅니다.

## 확인사항

- 저장 후 회원을 다시 선택했을 때 수정한 직급이 표시되어야 합니다.
- 직급만 바꿔도 `변경사항 있음`이 표시되어야 합니다.
- 최근 변경이력의 변경항목에 프로필 변경이 기록되어야 합니다.
- 최고관리자가 아닌 계정이 데이터베이스 호출을 우회해도 직급 변경은 거부됩니다.
