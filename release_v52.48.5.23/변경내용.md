# v52.48.5.23 변경내용

## 자재 한글·영문 동의어 검색

다음 표기를 같은 검색어로 인식합니다.

- `stud` ↔ `스터드`
- `runner` ↔ `런너`, `러너`
- `AL TILE` ↔ `타일판`, `타일`
- `LOVER`, `LOUVER` ↔ `루바`, `루버`
- `BOLT` ↔ `볼트`
- `Clip-Bar` ↔ `클립바`
- `channel` ↔ `찬넬`, `채널`
- `angle` ↔ `앵글`
- `joint`, `joiner` ↔ `조인트`
- `hanger` ↔ `행거`
- `board` ↔ `보드`
- `panel` ↔ `판넬`, `패널`
- `clip` ↔ `클립`
- `pin` ↔ `핀`
- `nut` ↔ `너트`
- `spring` ↔ `스프링`
- `molding` ↔ `몰딩`
- `main`, `minor`, `cross`, `carrying` ↔ `메인`, `마이너`, `크로스`, `캐링`
- `T-Bar`, `M-Bar`, `H-Bar`, `SQ-Bar` ↔ `티바`, `엠바`, `에이치바`, `에스큐바`

## 검색 방식

- 동의어 변환 후 품명·규격·자재코드를 이어 붙여 포함 검색합니다.
- 대소문자, 공백, 하이픈, 밑줄, 괄호와 기호는 검색 결과에 영향을 주지 않습니다.
- 예: `런너50` → `C-RUNNER(50형)`, `루바` → `AL LOVER`, `클립바` → `Clip-Bar`.

## 데이터 영향

- 데이터베이스와 저장 형식은 변경하지 않았습니다.
- SQL 실행이 필요하지 않습니다.
