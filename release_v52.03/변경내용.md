# v52.03 변경내용

## 회원관리

- 최고관리자 전용 `계정 영구삭제` 버튼 추가
- 현재 로그인한 본인 계정 삭제 차단
- 최고관리자 계정 삭제 차단
- 삭제 대상 이름·이메일 표시
- 대상 이메일 재입력 확인 절차 추가
- 삭제 성공 후 회원목록 자동 갱신
- 삭제 실패 사유 화면 표시

## Supabase

- `admin_delete_user_account(uuid, text)` RPC 추가
- RPC 내부에서 현재 로그인자의 active 최고관리자 권한 재검증
- 프런트 화면을 우회한 일반 사용자 요청 차단
- 인증 계정, 회원 프로필, 회원 전용 권한 설정 정리
- 업무 문서·일보·공정 데이터는 직접 삭제하지 않음
- 계정 삭제 감사기록 보존

## 누적 포함

- v52.01 Dashboard 브라우저 alert를 토스트로 전환
- v52.02 일반 UI 글꼴을 왼쪽 메뉴 글꼴 계열로 통일
- 담당자 서명과 출력 양식 전용 글꼴 유지
