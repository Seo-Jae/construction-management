# v52.03 적용방법

이 패키지는 v52.01 Dashboard 토스트와 v52.02 전체 UI 글꼴 통일을 포함한 누적본입니다.

## 1. 프로젝트 파일 적용

프로젝트 최상위 폴더에서 실행합니다.

```powershell
node .\release_v52.03\apply-v52.03-user-account-delete.cjs
```

## 2. Supabase SQL 실행

Supabase Dashboard의 SQL Editor에서 아래 파일 내용을 전체 실행합니다.

```text
release_v52.03\Supabase에서_실행_회원계정_영구삭제_v52.03.sql
```

`Success. No rows returned`가 표시되면 정상입니다.

## 3. 빌드

```powershell
npm run build
```

## 4. 확인

- 최고관리자 계정으로 회원관리 진입
- 일반 회원 선택 시 `계정 영구삭제` 버튼 표시
- 현재 로그인 계정과 최고관리자 계정은 버튼 비활성화
- 삭제 팝업에서 대상 이메일이 일치해야 삭제 버튼 활성화
- 삭제 후 회원목록에서 계정 제거
- 삭제한 이메일·비밀번호로 로그인 불가
- 기존 업무 문서·일보·공정 데이터 유지
