# v52.48.5 적용방법

이번 버전은 단순 미세조정이 아니라 로그인 화면 구조를 다시 배치합니다.

## 핵심 원인 수정

기존 MobileShell의 앱 공통 스타일이:

- 모든 입력창 minHeight 56
- 모든 버튼 minHeight 52
- 모든 버튼 fontSize 0.96rem

을 부모 CSS로 강제하고 있었습니다.

부모 selector가 로그인 버튼 자체 sx보다 specificity가 높아
v52.48.2에서 72, 78 같은 값을 줘도 실제 화면에서는 제대로 반영되지 않았습니다.

v52.48.5부터 cleanLogin에는 이 부모 강제 스타일을 적용하지 않습니다.

## 레이아웃

네이버 참고 화면의 비율을 기준으로:

- 흰색 상태바
- 좌측 상단 뒤로가기
- W 로그인 제목을 아래쪽에 배치
- 제목과 첫 입력 사이 큰 여백
- 휴대폰 / 비밀번호 간격 확대
- 두 번째 입력 아래 충분한 여백
- 대형 로그인 버튼
- 바로 아래 대형 가입신청 버튼
- 관리자모드는 하단 링크 위치

로 재구성합니다.

기능은 우리 시스템 기능 그대로입니다.
