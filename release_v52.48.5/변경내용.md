# v52.48.5 변경내용

## 이전 버전과 가장 큰 차이

이전 버전은 위치/크기 수치만 계속 변경했습니다.

이번 버전은 크기가 실제 적용되지 않던 CSS 우선순위 문제를 먼저 제거합니다.

### 기존

MobileShell(appMode):
`& .MuiButton-root { minHeight: 52 }`
`& .MuiInputBase-root { minHeight: 56 }`

### 변경

`appMode && !cleanLogin`

즉 로그인 화면에는 위 공통 스타일을 적용하지 않습니다.

## scale 제거

v52.48.3~4의:

- width 축소
- transform scale(1.35~1.36)

방식을 완전히 제거합니다.

레이아웃 크기를 직접 지정합니다.

## 레퍼런스 위치

- 뒤로가기 영역
- 브랜드 영역
- 입력영역
- 로그인/가입 버튼 영역
- 관리자모드 영역

을 각각 분리해서 세로 간격을 다시 지정했습니다.

## 상태바

로그인 모드에서 `meta[name=theme-color]`를 흰색으로 변경합니다.
다른 모드로 이동하면 욱림 녹색으로 복원합니다.
