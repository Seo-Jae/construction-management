# 사내시스템 v51.98 변경내용

- 회원관리 화면을 `왼쪽 회원목록 + 오른쪽 상세설정` 구조로 개편
- 왼쪽 목록에 상태, 이름, 이메일, 사용자 구분, 기존 역할, 접근현장 요약 표시
- 승인대기·사용중·사용중지·전체 필터 및 이름·이메일·직책·현장 검색 유지
- 오른쪽 상세설정을 `기본정보 / 접근현장 / 권한 템플릿 / 세부권한 / 특수권한` 구조로 배치
- 기본정보의 사용자 구분·시스템 역할과 복수 접근현장은 기존 DB에 실제 저장
- 저장하지 않은 변경사항 표시 및 다른 회원 선택 시 변경 취소 확인창 추가
- 하단에 변경 취소·승인·승인거절·권한 저장·사용중지·다시 사용 버튼 고정
- 기존 회원 승인, 사용중지, 기존 계정 전체 사용중지, 접속현황 기능 유지
- 권한 DB 구성 전까지 기존 역할과 메뉴 접근권한 유지
- Supabase SQL 변경 없음
