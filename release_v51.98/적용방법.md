# 사내시스템 v51.98 적용방법

프로젝트 최상위 폴더에서 PowerShell을 열고 아래 명령을 순서대로 실행합니다.

```powershell
node .\release_v51.98\apply-v51.98-user-management-layout.cjs
npm run build
```

적용 스크립트는 기존 `src/page/UserManagement.jsx`를 `backup_v51.98_날짜시간` 폴더에 자동 백업한 뒤 수정 파일을 반영합니다.

이번 버전은 Supabase SQL 실행이 필요하지 않습니다.

## 확인 항목

1. 최고관리자 계정으로 `회원관리`를 엽니다.
2. 회원목록이 왼쪽, 선택 회원 상세설정이 오른쪽에 표시되는지 확인합니다.
3. 승인대기·사용중·사용중지·전체 필터와 검색이 정상 작동하는지 확인합니다.
4. 사용자 구분·시스템 역할·복수 접근현장을 변경한 뒤 `권한 저장`을 확인합니다.
5. 저장하지 않은 상태에서 다른 회원을 선택하면 확인창이 표시되는지 확인합니다.
6. 승인·승인거절·사용중지·다시 사용 기능을 테스트 계정으로 확인합니다.
7. `접속현황 및 기록` 화면이 기존과 동일하게 열리는지 확인합니다.

## 현재 단계 안내

`권한 템플릿`, `세부권한`, `특수권한` 영역은 화면 위치만 먼저 구성했습니다. 기존 사용자의 접근권한은 그대로 유지되며, 다음 버전의 권한 DB 구성 후 실제 설정 기능이 연결됩니다.
