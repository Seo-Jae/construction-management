# 지출결의서 작성 v51.89 적용방법

## 적용 기준

- 기준 버전: v51.88.1
- 이번 버전은 지출결의서 작성 화면의 배치, 통행료 PDF 경로 표시, 이동거리(km) 입력을 수정합니다.
- DB 변경은 없으므로 Supabase SQL을 실행하지 않습니다.
- `pdfjs-dist@5.7.284`가 없으면 적용 스크립트가 `--legacy-peer-deps` 옵션으로 자동 설치합니다.

## 1. 압축 해제

ZIP 파일을 프로젝트 최상위 폴더에 압축 해제합니다.

프로젝트 최상위 폴더 예시:

```text
C:\Users\서재형\Desktop\new
├─ package.json
├─ src
├─ public
└─ release_v51.89
```

## 2. 소스 적용

PowerShell에서 프로젝트 최상위 폴더로 이동한 후 실행합니다.

```powershell
node .\release_v51.89\apply-v51.89-expense-resolution.cjs
```

적용 스크립트가 처리하는 작업:

- 기존 파일 자동 백업
- v51.89 전체 교체 파일 복사
- `pdfjs-dist` 설치 여부 확인
- 미설치 시 `pdfjs-dist@5.7.284` 자동 설치

적용 파일:

- `src/page/ExpenseResolution.jsx`
- `src/utils/expenseResolutionExcel.js`
- `src/utils/highpassReceiptPdf.js`

## 3. 빌드 확인

```powershell
npm run build
```

`Some chunks are larger than 500 kB` 문구는 용량 경고이며 빌드 실패 원인이 아닙니다. 마지막에 `built in`이 표시되면 정상입니다.

`@mui/material`을 찾지 못한다는 오류가 발생하면 아래 명령을 먼저 실행합니다.

```powershell
npm install @mui/material @mui/icons-material @emotion/react @emotion/styled --legacy-peer-deps
npm run build
```

## 4. 화면 확인

1. `업무보고관리 > 지출결의서 작성`에서 신규 문서를 엽니다.
2. 상단에 갑지·상세내역 미리보기가 표시되는지 확인합니다.
3. 하단에 기본정보와 사용내역 목록이 표시되는지 확인합니다.
4. 사용내역 안내문이 `표시됩니다.` 뒤에서 줄바꿈되는지 확인합니다.
5. `통행료 PDF 업로드`와 `+ 내역 추가` 버튼이 아이콘 없이 한 줄로 보이는지 확인합니다.
6. 통행료 PDF를 선택합니다.
7. 팝업에서 출발지와 이동거리(km)를 일괄 입력한 뒤 `선택 항목에 적용`을 누릅니다.
8. 필요한 경우 각 행의 출발지·도착영업소·도착시간·이동거리·금액을 수정합니다.
9. `선택 내역 추가`를 누릅니다.
10. 목록 사용내용이 `서울 → 용인 35km`처럼 한 줄로 표시되는지 확인합니다.
11. 갑지에서 경로와 km는 유류대 내용칸에, 금액은 통행료 금액칸에 표시되는지 확인합니다.
12. 상세내역과 엑셀에서도 영업소·도착시간 없이 `서울→용인 35km(통행료)`로 표시되는지 확인합니다.
13. 저장 후 다시 열었을 때 이동거리와 금액이 유지되는지 확인합니다.

## PDF 자동 추출 기준

- SM하이플러스 문자형 확인증 PDF 기준입니다.
- 날짜, 도착영업소, 도착시간, 금액을 자동 추출합니다.
- 영업소 원문과 시간은 중복 판단 및 팝업 확인용으로 유지하지만 최종 사용내용에는 표시하지 않습니다.
- 스캔 이미지 PDF나 다른 카드사 양식은 자동 추출되지 않을 수 있습니다.

## 저장 방식

이동거리(km)는 기존 `description` 필드에 숫자로 저장합니다. 따라서 이번 버전도 DB 컬럼 추가와 Supabase SQL 실행이 필요하지 않습니다.
