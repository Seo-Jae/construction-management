# 지출결의서 작성 v51.89 변경내용

## 1. 사용내역 안내문 정돈

- `등록된 내역은 목록으로 표시됩니다.` 뒤에서 줄바꿈합니다.
- 다음 줄에 직접 입력과 통행료 PDF 업로드 안내를 표시합니다.

## 2. 버튼 축소

- `통행료 PDF 업로드` 버튼의 업로드 아이콘을 제거했습니다.
- `+ 내역 추가`를 아이콘 없는 작은 글자 버튼으로 변경했습니다.
- 두 버튼 모두 한 줄 표시를 유지합니다.

## 3. 통행료 PDF 이동거리(km) 입력

- PDF 확인 팝업에 `이동거리(km) 일괄 입력`을 추가했습니다.
- 선택 내역의 출발지와 km를 한 번에 적용할 수 있습니다.
- 각 행의 km도 개별 수정할 수 있습니다.
- km가 비어 있으면 목록 추가 전에 해당 행을 안내합니다.

## 4. 통행료 사용내용 표시

- 최종 사용내용에서는 도착시간을 제외합니다.
- `용인영업소`는 `용인`으로 표시합니다.
- 표시 형식은 `서울→용인 35km`입니다.
- 갑지에서는 경로·km를 유류대 내용칸에 표시하고 통행료 금액은 기존 통행료 금액칸에 유지합니다.
- 상세내역은 `서울→용인 35km(통행료)` 형식으로 표시합니다.

## 5. 화면 상하 배치

- 기존 좌측 입력·우측 미리보기 2열 구조를 제거했습니다.
- 갑지·상세내역 미리보기를 상단으로 이동했습니다.
- 기본정보와 사용내역 목록을 하단으로 이동했습니다.
- 사용내용 셀은 한 줄 말줄임으로 표시해 행 높이가 커지지 않도록 했습니다.

## 6. 적용 범위

- 기준 버전: v51.88.1
- DB 변경 없음
- Supabase SQL 없음
- 적용 스크립트: `release_v51.89/apply-v51.89-expense-resolution.cjs`
