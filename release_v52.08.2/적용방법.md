# v52.08.2 적용방법

기준: **v52.08.1 메신저 화면 깜빡임 안정화본이 적용된 프로젝트**

## 1. Supabase SQL 실행
Supabase SQL Editor에서 아래 파일 전체를 실행합니다.

`release_v52.08.2/Supabase에서_실행/00_v52.08.2_읽음_대화방나가기.sql`

이 SQL은 새 테이블을 만들지 않습니다.
- 기존 `messenger_room_members.last_read_at`을 읽음표시에 사용
- 참여자 조회 RPC에 `last_read_at` 반환 추가
- `messenger_leave_room(uuid)` RPC 추가
- 그룹 방장 탈퇴 시 남은 참여자에게 방장 자동 이전

## 2. 프로그램 파일 적용
ZIP을 `package.json`이 있는 프로젝트 최상위에 풉니다.

PowerShell:

```powershell
node .\release_v52.08.2\apply-v52.08.2-messenger-ux.cjs
npm run build
```

적용 스크립트는 현재 `src/page/Messenger.jsx`가 v52.08.1 안정화본인지 확인한 뒤에만 교체합니다.
기존 파일은 `backup_v52.08.2_날짜시간` 폴더에 자동 백업됩니다.

## 3. 확인 순서
1. 1:1 방에서 메시지 전송 → `안읽음` 표시 확인
2. 상대 계정이 해당 방을 열면 → 보낸 사람 화면에 `읽음`으로 변경되는지 확인
3. 그룹방은 현재 참여자 전원이 읽었을 때 `읽음`, 한 명이라도 안 읽었으면 `안읽음`인지 확인
4. 삭제 아이콘이 기존 크기 그대로 연한 빨강으로 보이는지 확인
5. 1:1 대화방 나가기 확인
6. 그룹 일반 참여자 나가기 확인
7. 그룹 방장 나가기 시 다른 참여자로 방장 이전 확인
8. 하단 메시지 입력칸 높이/정렬 확인
9. 화면 깜빡임이 다시 발생하지 않는지 확인

## 4. Git
