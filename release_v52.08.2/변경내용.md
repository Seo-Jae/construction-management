# v52.08.2 변경내용

## 1. 읽음 / 안읽음 표시
- 내가 보낸 메시지의 전송시간 옆에 `읽음` 또는 `안읽음` 표시
- 1:1: 상대방의 `last_read_at`이 메시지 시간 이후면 읽음
- 그룹: 현재 참여 중인 다른 참여자 전원이 읽었을 때만 읽음
- `messenger_room_members UPDATE` Realtime은 읽기 전용 참여자 재조회만 수행하여 v52.08의 반복 갱신 루프를 재발시키지 않음

## 2. 삭제 아이콘
- 기존 크기와 패딩 유지
- 기본색만 연한 빨강(`#fca5a5`)으로 변경
- 마우스 오버 시 조금 더 진한 빨강 표시

## 3. 대화방 나가기
- 1:1 / 그룹 모두 지원
- 나간 사용자는 해당 방을 더 이상 조회할 수 없음(RLS membership 기준 유지)
- 그룹 방장이 나가면 남은 참여자에게 방장 권한 자동 이전
- 방장 혼자 남은 그룹은 이전 대상이 없어 나가기 차단

## 4. 메시지 입력창
- 첨부/전송 버튼 크기는 변경하지 않음
- 입력칸 최소 높이를 42px로 조정
- 하단 3개 요소를 세로 중앙 정렬해 어정쩡한 높이 차이를 완화

## 기존 기능 보존
- v52.08.1 화면 깜빡임 안정화 유지
- 1:1/그룹 생성 유지
- 실시간 메시지 유지
- 사진/파일 유지
- 그룹명/참여자 관리 유지
- 내 메시지 삭제 기능 유지
