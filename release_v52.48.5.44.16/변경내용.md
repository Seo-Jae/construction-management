# v52.48.5.44.16 변경내용

## 우측 타입별 현황

- 해당 타입에 실제 세대가 없는 옵션 항목은 목록에서 제외합니다.
- 예: `59A` 타입에서 `중간세대`가 0세대라면 `중간세대 0세대`를 표시하지 않습니다.
- 타입 제목을 클릭하면 해당 타입 전체 세대를 골구도에 파란색으로 강조합니다.
- 펼쳐진 옵션명을 클릭하면 해당 타입 안에서 그 옵션인 세대만 노란색으로 강조합니다.
- 선택한 항목을 다시 클릭하면 강조가 해제됩니다.

## 골구도·현황 너비 조절

- 골구도와 우측 현황 사이에 마우스로 좌우 이동할 수 있는 세로 경계를 추가했습니다.
- 기본 현황 폭은 기존과 같은 270px입니다.
- 현황 최소 폭은 220px, 골구도 최소 폭은 520px로 제한했습니다.
- 세로 경계를 더블클릭하면 기본 폭으로 돌아갑니다.
- 키보드 포커스 상태에서는 좌우 방향키로 20px씩 조절할 수 있습니다.

## 상단 화면

- `측벽세대-1 376세대`처럼 나열되던 옵션명별 전체 집계 Chip을 삭제했습니다.
- `옵션 종류`, 전체 세대, 저장상태, 파일명 등 기본 상태 정보는 유지합니다.

## 데이터베이스
