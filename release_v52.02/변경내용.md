# 사내시스템 v52.02 변경내용

## 일반 화면 글꼴 규칙 확정

- 왼쪽 메뉴의 글꼴 계열을 전체 일반 화면의 공통 기준으로 지정
- MUI 컴포넌트와 일반 HTML 입력 요소에 같은 글꼴 상속
- 화면별로 따로 지정된 조직도 Pretendard, 도면분석 Arial, 작업자 코드 monospace 제거
- 글자 크기·굵기·줄 간격은 기존 값 유지

## 유지한 예외

- 담당자 서명란의 궁서체
- 출력 미리보기의 맑은 고딕
- 근로계약서 인쇄용 나눔고딕
- 엑셀·PDF 생성 코드의 출력 전용 글꼴

## 누적 포함

- v52.01 Dashboard 브라우저 alert 11곳의 중앙 상단 토스트 전환
- 확인·취소 선택이 필요한 confirm 팝업 유지
