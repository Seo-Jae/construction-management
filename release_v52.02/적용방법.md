# 사내시스템 v52.02 적용방법

이번 패키지는 v52.01 Dashboard 토스트 전환을 포함한 누적본입니다. 일반 화면 글꼴을 현재 왼쪽 메뉴와 같은 MUI 기본 글꼴 계열로 통일하며, 기존 글자 크기·굵기·줄 간격은 변경하지 않습니다. 담당자 서명란의 궁서체와 출력 양식 전용 글꼴은 그대로 유지합니다. Supabase SQL 실행은 필요하지 않습니다.

## 1. 코드 적용

ZIP을 프로젝트 최상위 폴더에 압축 해제한 뒤 PowerShell에서 아래 명령을 실행합니다.

```powershell
node .\release_v52.02\apply-v52.02-ui-font-standard.cjs
npm run build
```

적용 스크립트는 교체 대상 기존 파일을 `backup_v52.02_날짜시간` 폴더에 자동 백업한 뒤 새 파일을 적용합니다.

## 2. 적용 규칙

- 일반 화면 공통 글꼴: 왼쪽 메뉴와 같은 `Roboto → Helvetica → Arial → 시스템 sans-serif` 계열
- 기존 글자 크기·굵기·줄 간격: 유지
- 조직도 별도 Pretendard 계열: 일반 화면 공통 글꼴로 변경
- 도면분석 별도 Arial: 일반 화면 공통 글꼴로 변경
- 근로계약서 관리목록 작업자 코드 monospace: 일반 화면 공통 글꼴로 변경
- 담당자 서명란 궁서체: 유지
- 주간업무·품의·지출결의·근로계약서 등 출력 미리보기와 엑셀·PDF 전용 글꼴: 유지

## 3. 확인 순서

1. 왼쪽 메뉴와 Dashboard 본문 글꼴이 같은 느낌으로 표시되는지 확인합니다.
2. 버튼·입력칸·표·팝업의 글꼴이 같은 계열로 표시되는지 확인합니다.
3. 조직도와 도면분석 화면의 글꼴이 일반 화면과 동일한지 확인합니다.
4. 근로계약서 관리목록의 작업자 코드가 다른 고정폭 글꼴로 보이지 않는지 확인합니다.
5. 주간업무·품의·지출결의·근로계약서 출력 미리보기의 기존 글꼴이 유지되는지 확인합니다.
6. 담당자 서명 이름이 기존 궁서체로 표시되는지 확인합니다.
