# v52.48.5.44.71 변경내용

- `.70`의 잘못된 `get_my_runtime_access()` 참조를 실제 운영 함수인 `get_my_runtime_access_v2()`로 교체했습니다.
- `Dashboard.jsx`의 `.69` 규칙과 맞춰 `담당자`/`관리자`가 자신의 `user_profiles.project_name`과 동일한 현장에서는 지출결의서 저장 권한을 기본 허용합니다.
- 기존 `save_expense_resolution`, `delete_expense_resolution`의 업무 로직은 재작성하지 않고 권한 helper 참조만 유지/교체합니다.
- `.70`이 이미 적용되어 `can_access_expense_project`를 참조하는 DB에서도 재실행 가능합니다.
- 검증 SQL은 SQL Editor의 인증 컨텍스트 문제를 피하기 위해 런타임 RPC를 직접 실행하지 않습니다.
