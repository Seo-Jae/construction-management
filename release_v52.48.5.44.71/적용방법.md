# 적용방법

```powershell
node .\release_v52.48.5.44.71\apply-v52.48.5.44.71-expense-runtime-access-v2.cjs
```

Supabase SQL Editor에서 아래 파일을 **전부 실행**합니다.

```text
supabase/v52.48.5.44.71_expense_runtime_access_v2.sql
```

실행 결과 첫 검증표에서 `runtime_access_v2_exists = true`, `expense_helper_exists = true`, 다음 표에서 `helper_uses_runtime_v2 = true`를 확인합니다.

그 후 Test 담당자 계정에서 지출결의서 저장을 다시 확인합니다.

정상 확인 후:

```powershell
npm run build
git add .
git commit -m "v52.48.5.44.71 expense runtime access v2"
git push origin main
```
