# v52.48.5.44.14 적용방법

기준 버전은 `v52.48.5.44.13`입니다.

## 1. 코드 적용

프로젝트 최상위 폴더에 압축을 해제한 뒤 PowerShell에서 실행합니다.

```powershell
node release_v52.48.5.44.14/apply-v52.48.5.44.14-insulation-option-layout.cjs
```

적용 스크립트는 v52.48.5.44.13 파일 해시를 먼저 확인합니다. 다른 변경이 있으면 덮어쓰지 않고 중단하며, 기존 파일은 `backup_v52.48.5.44.14_날짜시간` 폴더에 백업합니다.

## 2. 빌드 및 배포

```powershell
npm run build
git add .
git commit -m "refactor: simplify insulation option workbook v52.48.5.44.14"
git push
```

이번 버전은 새 Supabase SQL이 없습니다. 단, v52.48.5.44.13의 SQL을 아직 실행하지 않았다면 기존 v52.48.5.44.13 패키지의 `option_status_documents` SQL은 먼저 실행해야 저장할 수 있습니다.

## 3. 확인 순서

1. `옵션관리 > 옵션현황(단열)`에서 상단 두 박스와 버튼 높이를 확인합니다.
2. `골구도 다운로드` 후 토스트가 표시되는지 확인합니다.
3. Excel의 `단열 옵션 골구도` 한 시트에 전체 동이 나오는지 확인합니다.
4. 실제 세대 셀이 빈칸이고 필로티·예외층·타입은 유지되는지 확인합니다.
5. 임의의 세대에 현장에서 사용하는 옵션명을 입력합니다.
6. 셀에 색상을 넣더라도 시스템에서는 색상이 반영되지 않는지 확인합니다.
7. `엑셀 업로드` 후 토스트와 화면 미리보기를 확인하고 저장합니다.
