# v52.48.5.44.14 변경내용

## 상단 화면

- `골구도 기준`, `단열 옵션` 박스 높이를 `골구도 다운로드` 버튼과 같은 30px로 통일했습니다.
- 골구도 다운로드·Excel 업로드 성공/실패 결과를 화면 중간 안내문 대신 하단 토스트 팝업으로 표시합니다.
- 저장 성공/실패 결과도 같은 토스트 형식으로 통일했습니다.
- 단열 화면에 표시되던 파란색 `골구도 다운로드 후...` 안내문을 삭제했습니다.

## Excel 골구도

- 동별 시트를 여러 개 만들지 않고 `단열 옵션 골구도` 한 시트에 전체 동을 나란히 배치합니다.
- 층수가 다른 동은 1층 기준으로 하단이 맞도록 정렬합니다.
- 실제 세대 셀은 빈칸으로 내려받으며 각 세대마다 표시되던 호수는 제외했습니다.
- 호 라인 구분을 위해 각 동 상단에는 `1호`, `2호` 형식의 열 제목만 유지합니다.
- 필로티, 예외층, 합쳐진 세대, 하단 기본 타입은 유지합니다.
- 저장된 옵션이 있으면 재다운로드 시 해당 옵션명만 표시합니다.

## 옵션 구분 방식

- 옵션명은 시스템이 미리 정하거나 변환하지 않고 현장 담당자가 Excel에 입력한 문자열을 그대로 사용합니다.
- Excel 셀 색상은 읽거나 저장하지 않으며 화면에서도 옵션별 자동 색상을 적용하지 않습니다.
- 옵션 데이터는 `{ value }` 객체 형태로 유지해 추후 현장별 구분 규칙·명칭 설정 기능을 확장할 수 있도록 했습니다.

## 데이터베이스

- 이번 버전에서 새로 실행할 Supabase SQL은 없습니다.
