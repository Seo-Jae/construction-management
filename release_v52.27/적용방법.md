# v52.27 적용방법

## 핵심 원인

v52.20 로그인 유지 보완 이후 `loadMe`가 `worker`를 dependency로 가지고 있었습니다.

구조:
```text
loadMe 실행
→ setWorker(new object)
→ worker 변경
→ loadMe 함수 재생성
→ [loadMe] effect 재실행
→ loadMe 재실행
→ 반복 가능
```

QR scanner effect는 `processQrToken → loadMe`에 연결되어 있고,
cleanup에서 `stopScanner()`를 실행하므로 위 반복이 발생하면
카메라 stream이 시작 직후 계속 종료될 수 있습니다.

## v52.27

- `workerRef` 추가
- `loadMe` dependency에서 `worker` 제거
- 일시 오류 시 `workerRef.current` 사용
- 로그인 성공/세션무효/로그아웃 시 ref 동기화
- scanner effect identity 안정화

## 배포 후 우선 테스트

1. 작업자 앱 완전 종료
2. 다시 실행
3. 출·퇴근 QR 촬영
4. 카메라 권한이 허용되어 있으면 즉시 후면 카메라 영상 표시 확인
5. 1분 이상 scanner를 열어두어도 검은 화면/재시작이 없는지 확인
6. 다른 앱으로 잠깐 이동 후 복귀해도 카메라가 비정상 반복 종료되지 않는지 확인

권한 테스트를 위해 Android 앱 정보의 `앱 권한` 화면에서 카메라 항목이
보이지 않는 것은 PWA/WebAPK 구조에서는 직접적인 실패 기준으로 사용하지 않습니다.
카메라 권한은 Chrome 사이트 권한과 getUserMedia 결과를 기준으로 확인합니다.
