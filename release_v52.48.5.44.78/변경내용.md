# v52.48.5.44.78 변경내용

## 자재투입현황 탭 버튼 모양 추가 보정

이전 버전에서 Excel 다운로드 문서서식은 정상 반영되었으나,
`월 원본 상세`, `업체별 월·누계`, `품목별 월·누계` 탭 중
첫 번째와 세 번째 탭을 선택했을 때 선택된 버튼 외곽 라운드가
가운데 탭보다 어색하게 보이는 문제가 남아 있었습니다.

이번 버전에서는 자재투입현황 탭 버튼의 표시를 아래처럼 추가 보정합니다.

- Tabs 컨테이너 상하/좌우 여백 추가 확대
- Tab 버튼 자체의 내부 여백 재조정
- 각 Tab 버튼에 고정 pill border-radius 강제 적용
- 첫 번째/마지막 Tab 좌우 여백 추가
- selected 탭 z-index 보정
- Tab root overflow visible 보정
- flex 정렬값 보정

목표는 1번/3번 탭 선택 시에도
2번 탭 선택과 동일하게 버튼 외곽이 자연스럽게 둥글게 보이도록 맞추는 것입니다.

추가 Supabase SQL은 없습니다.
