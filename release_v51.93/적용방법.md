# 지출결의서 작성 v51.93 적용방법

## 적용 기준

- 기준 버전: v51.92
- 엑셀 상세내역 문구와 셀 색상만 수정합니다.
- 화면, PDF 업로드, 저장 구조, 갑지 출력은 변경하지 않습니다.
- Supabase SQL을 실행하지 않습니다.

## 1. 압축 해제

ZIP 파일을 프로젝트 최상위 폴더에 압축 해제합니다.

```text
C:\Users\서재형\Desktop\new
├─ package.json
├─ src
└─ release_v51.93
```

## 2. 소스 적용

PowerShell에서 프로젝트 최상위 폴더로 이동한 후 실행합니다.

```powershell
node .\release_v51.93\apply-v51.93-expense-excel.cjs
```

수정 파일:

- `src/utils/expenseResolutionExcel.js`

기존 파일은 적용 전에 자동 백업됩니다.

## 3. 빌드 및 배포

```powershell
npm run build
```

빌드가 정상 완료되면 기존 배포 방식으로 Vercel에 반영합니다.

## 4. 확인 항목

1. 상세내역에 `서울→용인(유류비)` 형식만 표시되는지 확인합니다.
2. 상세내역에서 km, 통행료 도착지·시간이 빠졌는지 확인합니다.
3. 작성월 밖 칸이 줄마다 끊기지 않고 전체 회색인지 확인합니다.
4. 평일 흰색, 주말 연한 크림색, 제목·요일 진한 남색이 유지되는지 확인합니다.
5. 갑지에는 기존대로 경로·km, 도착지·시간, 유류비·통행료 금액이 유지되는지 확인합니다.
