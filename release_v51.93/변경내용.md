# 지출결의서 작성 v51.93 변경내용

## 1. 상세내역 문구 간소화

- PDF 통행료 행도 상세내역에는 이동 경로만 유류비로 표시합니다.
- `서울→용인 59km(유류비) / 용인 05:44(통행료)` 대신 `서울→용인(유류비)`로 표시합니다.
- 이동거리(km), 통행료 도착지·시간, 통행료 문구는 상세내역에서 제외합니다.
- 왕복 이동은 `서울→용인(유류비)`, `용인→서서울(유류비)`처럼 각각 한 줄로 표시합니다.

## 2. 상세내역 셀 색상 깨짐 수정

- 원본 양식에서 여러 셀이 공유하던 Excel style 객체를 셀마다 분리한 뒤 RGB 색상을 적용합니다.
- 작성월 밖 날짜 영역은 날짜줄과 내용 5개 줄이 모두 회색으로 통일됩니다.
- 제목·요일 머리글은 진한 남색, 평일은 흰색, 주말은 연한 크림색을 유지합니다.

## 3. 기존 기능 유지

- 갑지의 `서울→용인 59km`, `용인 05:44`, 유류비·통행료 금액은 그대로 유지합니다.
- 날짜 형식 `yyyy-mm-dd aaa`를 유지합니다.
- PDF 업로드, 유류비 입력, 셀 직접수정, 좌우 폭 조절 기능은 변경하지 않습니다.
- 수정 대상은 `src/utils/expenseResolutionExcel.js` 1개뿐입니다.
- 새 DB 컬럼 및 Supabase SQL은 없습니다.
