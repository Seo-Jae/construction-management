# v52.48.5.44.74 변경내용

품의 보고 목록에서 `상태 = 반려`인 경우 반려 Chip을 클릭할 수 있도록 변경합니다.

클릭 시 별도 팝업에서 현재 결재차수의 반려 정보를 표시합니다.

- 반려 결재자 이름
- 결재자 직책
- 반려 일시
- 결재자가 입력한 수정·보완 요청사항(comment)

기존 `report_document_approval_steps.comment` 데이터를 그대로 사용하므로 추가 Supabase SQL은 없습니다.

품의 보고의 `반려` 상태에만 클릭 기능을 적용하며 다른 상태의 동작은 변경하지 않습니다.
