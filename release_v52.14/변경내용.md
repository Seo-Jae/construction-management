# v52.14 근태관리 v1

- ERP 회원과 분리된 근로자 모바일 가입·로그인
- 3개 현장 선택, 한글명·외국인 여부·영문명·휴대폰·소속업체·직종 수집
- SMS 대신 현장담당자 대면 승인과 최초 가입 휴대폰 등록
- 근로자 1명당 휴대폰 1대, 휴대폰 1대당 근로자 1명
- 휴대폰 변경 시 담당자 승인
- 5초 동적 QR, 7초 서버 유효시간, 30초 일회용 처리 토큰
- 서버 시간·한국 날짜 기준 자동 출근/퇴근 전환
- 같은 QR의 근로자별 재사용과 하루 중복 출·퇴근 서버 차단
- 정적 앱 설치 QR 인쇄
- PWA 홈 화면 설치와 모바일 내부 카메라 QR 촬영
- 담당자용 가입승인·기기변경·일자별 근태조회·수동수정·변경이력
- 근태관리 조회/관리 권한을 기존 회원관리 권한 목록에 연결
- GPS와 위치정보는 수집하지 않음

## 휴대폰 인증 기준

내일 시범운영을 위해 외부 SMS 업체가 필요한 문자 인증은 제외했습니다. 휴대폰번호와 비밀번호로 가입한 뒤 현장담당자가 근로자 본인과 휴대폰을 대면 확인해 승인합니다. 최초 가입 휴대폰은 즉시 계정에 묶이며 다른 휴대폰 로그인은 기기변경 승인대기로 전환됩니다.
