# v52.48.3 적용방법

## 왜 다시 수정하는가

v52.48.2.1은 실제로 적용되었지만,
스크린샷 비교 결과 변경폭이 너무 작았습니다.

이번 버전은 기존처럼 8px 정도씩 키우지 않고
**설치된 근태앱의 로그인 UI 전체를 1.35배 시각 확대**합니다.

## 가로폭

단순히 1.35배 확대하면 화면 밖으로 넘어가므로:

- 원본 layout width = 74.074%
- visual scale = 1.35

로 설정합니다.

`74.074% × 1.35 ≈ 100%`

이므로 최종적으로 보이는 가로폭은 현재와 거의 같지만:

- W
- 로그인 제목
- 입력글씨
- 입력 높이
- 버튼 높이
- 버튼 글씨
- 각 요소 간격

은 실제로 35% 커져 보입니다.

## 적용 대상

`appMode + login`

일 때만 적용합니다.

따라서:
- 가입신청
- 관리자모드
- 로그인 후 근태화면
- PC 웹 근태화면

에는 전체 scale을 적용하지 않습니다.
