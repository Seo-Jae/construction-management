# v52.48.5.3 변경내용

기준 버전: v52.48.5.2

## 원인

직전 로그인 화면에는 `maxWidth: 520` 제한이 남아 있었습니다.
그래서 큰 휴대폰 화면에서도 로그인 본문이 약 500px 폭에서 멈춰,
네이버 참고 화면보다 전체 UI가 작고 가운데로 축소된 것처럼 보였습니다.

## 반영 내용

- 로그인 상단 뒤로가기 화살표와 `window.history.back()` 삭제
- 설치형 근태 앱 로그인 본문의 `maxWidth: 520` 제한 제거
- 로그인 본문 폭을 화면의 90%로 확대
- W 로고 4.5rem, 로그인 제목 3.35rem으로 확대
- 상단 위치를 참고 화면의 세로 비율에 맞춰 재배치
- 휴대폰번호와 비밀번호 글자를 2rem으로 확대
- 입력행 높이와 두 입력란 사이 간격 확대
- 로그인/가입 신청 버튼 높이를 110px으로 확대
- 로그인 버튼과 관리자 모드 글자 크기 및 간격 확대

가입 신청, 로그인, 관리자 모드의 동작은 변경하지 않았습니다.
일반 웹사이트 화면과 로그인 이후 근태 앱 화면도 변경하지 않았습니다.

SQL 변경은 없습니다.
