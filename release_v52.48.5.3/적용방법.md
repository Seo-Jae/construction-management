# v52.48.5.3 적용방법

프로젝트 최상위 폴더에 `release_v52.48.5.3` 폴더를 넣은 뒤
PowerShell에서 다음 순서대로 실행합니다.

```powershell
node .\release_v52.48.5.3\apply-v52.48.5.3-attendance-login-naver-ratio.cjs
npm run build
git add src/page/AttendanceWorkerPortal.jsx
git status
git commit -m "v52.48.5.3 match attendance login to naver ratio"
git push origin main
```

`git add .`은 사용하지 않습니다.

Vercel 배포가 `Ready`가 되면 설치된 근태 앱을 완전히 종료했다가 다시 실행합니다.
로그인 화면 UI만 변경되므로 앱 삭제와 재설치는 필요하지 않습니다.

Supabase SQL 실행도 필요하지 않습니다.
