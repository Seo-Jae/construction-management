# v52.48.5.44.77 변경내용

## 1. 자재투입현황 Excel 다운로드 문서서식 적용

현재 다운로드 구조는 유지합니다.

- 월 원본 상세 / 품목별 월·누계: 동일한 품목별 집계 Excel
- 업체별 월·누계: 업체별 월·누계 시트 + 월 원본 상세 시트

다운로드되는 각 시트를 실제 서류로 사용할 수 있도록 공통 문서서식을 적용합니다.

- 상단 문서 제목
- 현장명
- 조회기간
- 출력일시
- 헤더 진청색 배경 + 흰색 굵은 글씨
- 전체 표 테두리
- 맑은 고딕 기본 글꼴
- 숫자 오른쪽 정렬
- 금액 천단위 쉼표
- 수량 천단위 쉼표 및 소수 최대 4자리
- 건수 천단위 쉼표
- 긴 문구 자동 줄바꿈
- 자동필터
- 제목/헤더 고정
- A4 가로 출력
- 좌우 여백 축소
- 한 페이지 폭 맞춤
- 인쇄 제목행 반복
- 하단 현장명 / 자재투입현황 / 페이지 번호

업체별 다운로드에 포함되는 `월 원본 상세` 시트의 선택기간 합계행은 별도 강조합니다.

## 2. 탭 선택 버튼 잘림 수정

`월 원본 상세`, `업체별 월·누계`, `품목별 월·누계` 탭 중
첫 번째와 세 번째를 선택했을 때 양끝의 둥근 버튼/그림자가 잘려 보이는 문제를 수정합니다.

- scrollable Tabs -> standard Tabs
- 좌우/상하 내부 여백 확보
- Tabs scroller/flex 영역 overflow visible
- 기존 각 탭 색상 및 선택 스타일 유지

추가 Supabase SQL은 없습니다.
