# 사내시스템 v52.01 변경내용

## Dashboard 토스트 팝업 통일

`src/Dashboard.jsx`의 일반 브라우저 `alert()` 11곳을 기존 공정 저장 토스트와 같은 MUI 토스트로 통일했습니다.

### 성공 토스트

- 출력일보 근로자 정보 저장 완료
- 일자 마감 처리 완료
- 일자 마감 취소 완료

### 경고 토스트

- 등록 인원이 없는 날짜의 엑셀 다운로드
- 마감된 날짜 편집 시도
- 이전 작업내용 없음
- 필수 근로자 항목 누락
- 이전 근로자 또는 작업 데이터 없음

### 오류 토스트

- 마감 상태 변경 실패
- 출력일보 양식 파일 불러오기 실패
- 금월 출력일보 생성 실패

`window.confirm()`은 사용자의 확인 또는 취소 선택이 필요하므로 변경하지 않았습니다.
