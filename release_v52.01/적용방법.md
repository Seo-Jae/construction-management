# 사내시스템 v52.01 적용방법

이번 패키지는 운영 `main`의 v52.00.2를 기준으로 `Dashboard`에 남아 있던 브라우저 알림창을 중앙 상단 토스트 팝업으로 변경합니다. Supabase SQL 실행은 필요하지 않습니다.

## 1. 코드 적용

ZIP을 프로젝트 최상위 폴더에 압축 해제한 뒤 PowerShell에서 아래 명령을 실행합니다.

```powershell
node .\release_v52.01\apply-v52.01-dashboard-toast.cjs
npm run build
```

적용 스크립트는 기존 `src/Dashboard.jsx`를 `backup_v52.01_날짜시간` 폴더에 자동 백업한 뒤 교체합니다.

## 2. 확인 순서

1. 출력일보에서 근로자 정보를 저장하고 초록색 성공 토스트가 표시되는지 확인합니다.
2. 마감 처리 또는 마감 취소 후 성공 토스트가 표시되는지 확인합니다.
3. 등록 인원이 없는 날짜의 엑셀 다운로드를 눌러 노란색 경고 토스트가 표시되는지 확인합니다.
4. 마감된 날짜를 눌러 관리자 문의 경고 토스트가 표시되는지 확인합니다.
5. 이전 근로자·작업내용 불러오기에서 데이터가 없을 때 경고 토스트가 표시되는지 확인합니다.
6. 공종별 현황 저장 토스트가 기존처럼 정상 표시되는지 확인합니다.

## 적용 범위

- 토스트 위치: 화면 중앙 상단
- 자동 닫힘: 3초
- 성공: 초록색
- 경고: 노란색
- 오류: 빨간색
- 확인·취소 선택이 필요한 창: 기존 방식 유지
- 기존 Dashboard 데이터 저장·엑셀 다운로드·마감 기능: 유지
