# v52.19.1 적용방법

v52.19의 적용 스크립트에서 발생한 `dashboardStorageBase is not defined` 오류만 수정한 보완본입니다.

## 현재 상태
v52.19 실행은 적용 스크립트 자체의 `ReferenceError`로 중단되었으므로,
`src/App.jsx`, `src/Dashboard.jsx`, `src/page/Messenger.jsx`에는 v52.19 변경이 적용되지 않은 상태가 정상입니다.

## SQL
SQL 변경 없음.

## 적용

프로젝트 최상위에서:

```powershell
node .\release_v52.19.1\apply-v52.19.1-global-state-messenger-scroll-fix.cjs
```

`[v52.19.1 적용 완료]`를 확인한 뒤:

```powershell
npm run build
```

빌드 성공 후:

```powershell
git add src/App.jsx
git add src/Dashboard.jsx
git add src/page/Messenger.jsx
git status
git commit -m "v52.19 stabilize app state and messenger scroll"
git push origin main
```

`git add .`은 사용하지 않습니다.
