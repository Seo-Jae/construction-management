# v52.19.1 변경내용

## v52.19 스크립트 오류 수정
기존 적용 스크립트가 `Dashboard.jsx`에 넣어야 할 다음 텍스트:

`${dashboardStorageBase}:managementArea`
`${dashboardStorageBase}:selectedProcess`

를 적용 스크립트 자신의 JavaScript template literal로 해석해
`ReferenceError: dashboardStorageBase is not defined`가 발생했습니다.

v52.19.1에서는 해당 교체문을 문자열 배열 + `join('\n')` 방식으로 바꿔
`${dashboardStorageBase}`가 대상 `Dashboard.jsx`에 문자 그대로 들어가도록 수정했습니다.

## 실제 기능 내용
v52.19에서 계획한 기능은 그대로입니다.
- 인증/포커스 갱신 시 Dashboard 전체 unmount 방지
- 모든 권한 계정에서 현재 메뉴 및 React 작업상태 유지
- 선택 공정 sessionStorage 보존
- 메신저 이미지 로드 전 공간 확보
- 대화방 최초 진입 시 최신 메시지 bottom pin
- 사용자가 직접 위로 스크롤하면 bottom pin 해제

SQL/패키지 변경 없음.
