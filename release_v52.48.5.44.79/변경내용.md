# v52.48.5.44.79 변경내용

`자재투입현황`의 3번 탭(`품목별 월·누계`) 선택 버튼이 여전히 끝부분에서 어색하게 보이는 문제를 수정합니다.

원인을 확인한 결과 v52.48.5.44.78 적용 후 같은 `sx` 객체 안에
`'& .MuiTab-root'` 스타일이 두 번 존재하고 있었습니다.

JavaScript 객체에서는 같은 key가 두 번 있으면 뒤쪽 값이 앞쪽 값을 덮어쓰기 때문에,
v52.48.5.44.78에서 넣었던 `mx`, `overflow`, `position`, `zIndex`, `flexShrink` 등의 보정이
실제로는 대부분 무효화되고 있었습니다.

이번 수정:
- 중복 `MuiTab-root` 스타일을 하나로 통합
- 기존 글꼴/색상/transition 설정 유지
- 각 탭 pill radius 강제 유지
- overflow visible 유지
- 선택 탭 z-index 유지
- 마지막(3번) 탭 우측 여백을 별도로 확보하여 그림자와 둥근 외곽이 잘리지 않도록 수정

Excel 다운로드 관련 코드는 변경하지 않습니다.
추가 Supabase SQL도 없습니다.
