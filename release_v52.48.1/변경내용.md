# v52.48.1 변경내용

## 로그인 화면

기존:
- 초록색 근태시스템 AppBar
- 작은 흰색 카드
- 작은 제목
- 작은 outlined 입력칸
- 요소가 상단에 작게 모여 보임

변경:
- 로그인 화면에서는 AppBar 숨김
- 화면 전체 흰색
- W 로그인 브랜드 헤더
- 입력창은 큰 standard/underline 형태
- 로그인 버튼 대형화
- 가입신청은 연한 보조 버튼
- 관리자모드는 하단 text 버튼

## 다른 화면 영향

`cleanLogin`은 `mode === 'login'`일 때만 활성화됩니다.

따라서:
- 가입신청
- 관리자모드
- 로그인 후 근태화면
- QR 촬영
- 공지
- 캘린더

에는 로그인 전용 디자인이 적용되지 않습니다.
