# v52.48.1 적용방법

## 목표

근태앱 로그인 화면을 현재 작은 카드형 UI에서
모바일 로그인 앱에 가까운 큰 UI로 변경합니다.

참고한 방향:
- 흰 배경
- 상단 큰 W + 로그인
- 큰 입력칸
- 큰 초록 로그인 버튼
- 가입신청 / 관리자모드 하단 배치

네이버 UI를 그대로 복제하지 않고
욱림건설 브랜드와 기존 기능을 유지한 형태로 구성합니다.

## 유지 기능

v52.48의:
- 관리자 모드
- 통합관리시스템 아이디/비밀번호 인증
- 관리자 휴대폰 QR 표시
- 기존 근로자 로그인
- 가입신청
- 로그인상태 유지

는 그대로 유지합니다.

## SQL

변경 없습니다.

## 적용

프로젝트 최상위에서:

```powershell
node .\release_v52.48.1\apply-v52.48.1-attendance-login-mobile-redesign.cjs
npm run build
```

## 화면 확인

근태앱을 로그아웃한 상태에서 확인합니다.

로그인 화면:
- 기존 초록 헤더가 로그인 화면에서는 보이지 않음
- 흰 배경
- 큰 초록 `W`
- 큰 `로그인`
- 아래에 `욱림건설 근태시스템`
- 휴대폰번호 큰 밑줄형 입력
- 비밀번호 큰 밑줄형 입력
- 초록색 대형 로그인 버튼
- 가입신청
- 관리자 모드

가입신청 화면으로 들어가면 기존 초록 헤더와 기존 가입 UI가 다시 표시됩니다.

관리자모드로 들어가면 v52.48 관리자 QR 화면이 그대로 표시됩니다.
