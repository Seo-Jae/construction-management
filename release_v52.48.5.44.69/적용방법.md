## 확인 순서

1. 담당자 계정으로 로그인
2. 자기 소속현장 선택
3. `업무보고 > 지출결의서 작성` 메뉴가 보이는지 확인
4. 신규 작성 → 저장 → 다시 열기 → 수정 → 삭제 순으로 테스트
5. 추가 허용받지 않은 다른 현장은 접근되지 않는지 확인

## Supabase 서버 확인

프런트 적용 후 저장/삭제에서 권한 오류가 발생하거나, 서버 권한까지 확정 검증하려면 Supabase SQL Editor에서 아래 파일 내용을 실행합니다.

`release_v52.48.5.44.69/supabase_v52.48.5.44.69_expense_access_inspection.sql`

이 SQL은 DB를 수정하지 않고 현재 RPC/RLS 정의만 출력합니다. 결과를 전달하면 실제 운영 함수 정의에 맞춰 서버 권한 패치를 만들 수 있습니다.
