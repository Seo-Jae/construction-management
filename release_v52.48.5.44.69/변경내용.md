# v52.48.5.44.69 변경내용

이번 패치는 `지출결의서 작성` 메뉴의 **자기 소속현장 기본 권한**을 추가합니다.

## 적용 규칙

- `담당자`, `관리자`가 현재 선택한 현장이 본인의 `userProfile.project_name`과 같으면 `report.expense.view` ACL의 미설정/차단 여부와 관계없이 지출결의서 화면 접근을 허용합니다.
- 본인 소속현장이 아닌 추가 현장은 기존 `report.expense.view` 권한 판정을 그대로 사용합니다.
- `ExpenseResolution.jsx` 자체는 이미 현재 선택 현장(`activeUserProfile.project_name`)으로 목록/저장 대상을 제한하고 있으므로 변경하지 않습니다.
- 회원관리의 다른 메뉴/기능 권한은 변경하지 않습니다.

## 서버 권한

현재 저장소에는 `save_expense_resolution`, `delete_expense_resolution`의 실제 PostgreSQL 함수 정의가 없어서, 운영 DB의 함수를 추측해 교체하지 않았습니다. 잘못된 `SECURITY DEFINER` 또는 임의 RLS 정책을 넣으면 타 현장 접근이 열릴 수 있기 때문입니다.

`supabase_v52.48.5.44.69_expense_access_inspection.sql`은 **조회 전용**이며 운영 DB 정의를 확인하는 용도입니다. 이 결과로 서버 저장/삭제가 자기 소속현장을 허용하는지 확인한 뒤, 필요 시 다음 패치에서 정확한 서버 권한 함수만 수정하면 됩니다.
