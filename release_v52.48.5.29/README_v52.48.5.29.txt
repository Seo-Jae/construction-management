v52.48.5.29 - 일위대가작성 기술자료 이미지 관리

[중요]
이 패키지는 현재 v52.48.5.28 상태를 그대로 유지한 채 다음 기능만 추가합니다.
기존 일위대가 계산식, 문서 버전, 저장/불러오기, 자재/노무/경비, 단수정리 등 기존 기능은 되돌리거나 덮어쓰지 않습니다.

[추가 기능]
1. 일위대가작성 우측 기술자료 영역에 실제 기술자료 이미지 표시
2. 최고관리자: 업로드/교체/삭제 항상 가능
3. 최고관리자가 회원관리에서 '기술자료 이미지 추가·수정' 특수권한을 준 사용자: 업로드/교체/삭제 가능
4. 권한이 없는 사용자: 업로드 박스/교체/삭제 버튼 자체가 보이지 않으며 등록된 이미지만 조회
5. 기존 image_key 기준으로 같은 공법의 세부규격이 같은 기술자료 이미지를 공유
6. 테스트 이미지 2장 기본 연결
   - Clip_Bar천정 -> clip-bar-ceiling.png
   - Clip_Bar천정_내풍압 -> clip-bar-ceiling-wind-pressure.png

[적용 순서]
1. 현재 프로젝트 루트(new 폴더)에서 아래 실행
   node release_v52.48.5.29/apply-v52.48.5.29-unit-price-tech-images.cjs

2. Supabase > SQL Editor에서 아래 파일 전체 실행
   supabase/v52.48.5.29_unit_price_technical_images.sql

3. VS Code 터미널에서 빌드 확인
   npm.cmd run build

4. 개발서버 실행
   npm.cmd run dev

[권한 부여]
- 최고관리자는 별도 설정 없이 항상 이미지 관리 가능
- 회원관리 > 해당 사용자 권한 설정 > 특수/민감 권한에서
  '일위대가작성 · 기술자료 이미지 추가·수정'을 켜면 해당 사용자에게 관리 기능이 표시됩니다.
- 일반 사용자는 이미지 관리 UI가 전혀 보이지 않습니다.

[안전장치]
- 적용 전 src/page/UnitPriceAnalysis.jsx, src/Dashboard.jsx를 자동 백업합니다.
- 예상한 현재 코드 구조가 아니면 아무 파일도 덮어쓰지 않고 적용을 중단합니다.
- 기존 파일 전체 교체 방식이 아니라 필요한 위치에만 추가합니다.
