# 사내시스템 v52.04 적용방법

현재 적용된 v52.03.1 이후 프로젝트를 기준으로 합니다.

## 1. 압축 해제

ZIP을 프로젝트 최상위 폴더에 압축 해제합니다.

## 2. Supabase SQL 실행

Supabase SQL Editor에서 다음 파일 전체를 실행합니다.

```text
release_v52.04\Supabase에서_실행_Main_캘린더_주요이슈_v52.04.sql
```

`Success. No rows returned`가 표시되면 정상입니다.

## 3. 프런트 파일 적용

프로젝트 최상위 폴더에서 실행합니다.

```powershell
node .\release_v52.04\apply-v52.04-main-calendar-issues.cjs
npm run build
```

## 4. 개발 화면 확인

```powershell
npm run dev
```

## 5. 회원별 전체현장 공유권한 부여

1. 최고관리자로 로그인합니다.
2. 회원관리에서 대상 회원을 선택합니다.
3. 특수권한의 `캘린더 이슈 전체현장 공유`를 켭니다.
4. 저장합니다.
5. 대상 회원이 Main에서 이슈를 등록할 때 `전체현장에 공유` 체크박스가 표시되는지 확인합니다.

## 6. 운영 확인

- 공지사항 좌측 1/3, 캘린더 우측 2/3 배치
- 날짜 클릭 시 공사일보 화면으로 이동하지 않음
- 이슈 등록일의 빨간 점 표시
- 월간 이슈 날짜순 표시
- 현장 사용자의 현재 현장 이슈 등록
- 특수권한 사용자의 전체현장 공유
- 본인 이슈 수정·삭제
- 최고관리자의 전체 이슈 관리
