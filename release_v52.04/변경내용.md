# 사내시스템 v52.04 변경내용

## Main 화면 배치

- 공지사항을 좌측으로 이동하고 데스크톱 화면 너비의 1/3을 사용합니다.
- 캘린더를 우측으로 이동하고 데스크톱 화면 너비의 2/3을 사용합니다.
- 작은 화면에서는 공지사항과 캘린더가 한 줄씩 세로로 표시됩니다.
- 주요공정 영역은 이번 버전에서 변경하지 않습니다.

## 캘린더

- 날짜 클릭 시 공사일보 작성 화면으로 이동하던 기능을 제거했습니다.
- 출력일보 등록일은 기존 녹색 점으로 계속 표시합니다.
- 주요 이슈가 있는 날짜는 빨간색 점으로 함께 표시합니다.
- 캘린더 아래에 선택한 달의 주요 이슈를 날짜순 카드 형태로 표시합니다.
- 같은 날짜에 여러 이슈를 등록할 수 있습니다.

## 작성 및 권한

- 활성 사용자에게 자신이 접근할 수 있는 현장의 이슈 작성 권한을 제공합니다.
- 일반 현장 사용자는 현재 현장 이슈만 작성합니다.
- 회원관리의 특수권한에 `캘린더 이슈 전체현장 공유`가 추가됩니다.
- 해당 특수권한을 받은 사용자와 최고관리자만 `전체현장에 공유`를 선택할 수 있습니다.
- 작성자는 본인이 작성한 이슈를 수정·삭제할 수 있습니다.
- 최고관리자는 모든 이슈를 수정·삭제할 수 있습니다.
- 화면 표시뿐 아니라 Supabase 함수에서 현장 접근권한과 전체현장 공유권한을 다시 검증합니다.

## 데이터 보호

- 기존 출력일보, 공지사항, 주요공정 데이터는 변경하지 않습니다.
- 이슈 작성자의 이름은 이력 보존용으로 저장합니다.
- 회원 계정이 삭제되더라도 이슈 내용과 작성자 이름은 유지되며 인증 ID 연결만 해제됩니다.
