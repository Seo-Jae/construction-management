# v52.25 적용방법

## 변경
작업자 출·퇴근 앱의 `로그아웃` 위치를 화면 하단에서 **상단 초록색 헤더 우측 끝**으로 이동합니다.

- 로그인 완료 상태에서만 표시
- 흰색 로그아웃 아이콘 버튼
- 기존 하단 `로그아웃` 버튼 제거
- 브라우저 접속 시 `앱으로 설치` 버튼은 기존 하단 위치 유지
- 공지 티커, QR, 로그인 유지 기능 변경 없음

## SQL
SQL 변경 없음.

## 적용

프로젝트 최상위에서:

```powershell
node .\release_v52.25\apply-v52.25-worker-logout-header.cjs
```

`[v52.25 적용 완료]` 확인 후:

```powershell
npm run build
```

## Git

실제 변경 파일은 1개입니다.

```powershell
git add src/page/AttendanceWorkerPortal.jsx
git status
git commit -m "v52.25 move worker logout to header"
git push origin main
```

`git add .`은 사용하지 않습니다.

## 확인
작업자 앱 로그인 후:
1. 상단 초록색 헤더 우측 끝에 로그아웃 아이콘 표시
2. 기존 하단 로그아웃 버튼이 사라짐
3. 상단 아이콘 클릭 시 정상 로그아웃
4. 로그인 화면에서는 상단 로그아웃 아이콘이 표시되지 않음
