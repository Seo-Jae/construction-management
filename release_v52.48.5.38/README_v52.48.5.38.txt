v52.48.5.38 - 기술자료 상세보기 마우스 이동/줌

기준
- v52.48.5.37.4 기술자료 이미지 고정박스 및 자동축척 상태에서 다음 기능만 추가
- 기존 일위대가/기술자료/지시선/부속자재/편집기/권한/DB는 유지

기술자료 상세보기 VIEW
1. 마우스 휠
- 위로: 확대
- 아래로: 축소
- 확대/축소 중심은 마우스 포인터 위치
- 범위: 50% ~ 500%

2. 마우스 드래그
- 도면 빈 영역을 좌클릭한 채 드래그하면 전체 기술자료 Sheet 이동
- 이동 중 cursor는 grab -> grabbing
- 번호 원/하단 명칭을 클릭할 때는 이동모드가 개입하지 않아 기존 부속자재 선택 기능 유지

3. 초기화
- 더블클릭: 화면 맞춤 + 100% + 중앙 복귀
- 기존 '화면 맞춤' 버튼도 위치/배율까지 함께 초기화
- '원본 크기'는 기존 원본 표시 후 100%에서 시작하며 이후 마우스 줌/이동 가능

4. UI
- 상단에 현재 배율 표시(예: 100%, 175%)
- 좌측 하단에 '마우스 휠 확대/축소 · 드래그 이동 · 더블클릭 화면맞춤' 안내
- 우측 상세 부속자재 패널은 움직이지 않고 고정
