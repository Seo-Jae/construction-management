# v52.48.5.44.12 변경내용

- `공정진척관리` 하단에 새 상위 메뉴 `옵션관리`를 추가했습니다.
- `옵션현황(단열)`, `옵션현황(선택)`, `옵션별 비교` 소메뉴를 추가했습니다.
- 세 화면 모두 현장관리에서 저장한 골구도를 기본 레이아웃으로 사용합니다.
- 동 구성, 층, 호, 필로티, 예외층 및 하단 세대타입을 기존 공정진척 골구도와 동일하게 표시합니다.
- 옵션 화면에서는 아직 값이 저장되지 않도록 골구도를 읽기전용으로 표시합니다.
- `옵션별 비교`에는 다중 공종 진척 현황과 유사한 기준/비교 선택 UI 자리를 먼저 구성했습니다.
- 신규 전용 권한 SQL 없이 기존 `공정별 현황 입력` 조회 권한을 공유합니다.
- 새 Supabase SQL은 없습니다.
