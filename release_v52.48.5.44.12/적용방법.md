# v52.48.5.44.12 적용방법

기준은 `v52.48.5.44.11` 반영 완료본입니다.

1. ZIP을 프로젝트 루트(`package.json`, `src` 폴더가 있는 위치)에 풉니다.
2. PowerShell에서 실행합니다.

```powershell
node release_v52.48.5.44.12/apply-v52.48.5.44.12-option-management.cjs
npm run build
git add .
git commit -m "feat: add option management base v52.48.5.44.12"
git push
```

새 Supabase SQL은 없습니다.

## 확인방법

1. 좌측 `공정진척관리` 바로 아래에 `옵션관리`가 표시되는지 확인합니다.
2. `옵션관리`를 펼쳐 아래 3개 메뉴가 표시되는지 확인합니다.
   - 옵션현황(단열)
   - 옵션현황(선택)
   - 옵션별 비교
3. 각 화면에서 현장관리의 동 구성, 필로티, 예외층, 세대타입이 반영된 골구도가 표시되는지 확인합니다.
4. `옵션별 비교` 상단에 기준 옵션과 비교 옵션을 배치할 기본 영역이 표시되는지 확인합니다.

현재 버전은 메뉴·라우팅·골구도·상단 UI 베이스 단계입니다. 옵션 항목, 세대별 값, 색상, 저장 데이터는 다음 단계에서 연결합니다.
