# v52.08.1 적용방법

기준: v52.08 메신저 v1.2가 이미 적용되어 있고 Supabase SQL도 실행된 상태.

## 1. 압축 해제
프로젝트 최상위(package.json과 src가 있는 폴더)에 ZIP을 풉니다.

## 2. 적용
```powershell
node .\release_v52.08.1\apply-v52.08.1-messenger-stability.cjs
```

## 3. 빌드
```powershell
npm run build
```

## 4. 확인
- 메신저 대화방을 1~2분 열어두어 화면이 계속 깜빡이지 않는지 확인
- 다른 계정에서 메시지 전송 → 현재 방에 실시간 반영 확인
- 읽지않음 배지 증가/해제 확인
- 사진/파일 송수신 확인

## Supabase
추가 SQL 실행은 없습니다. v52.08에서 실행한 메신저 SQL을 그대로 사용합니다.
