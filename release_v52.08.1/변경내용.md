# v52.08.1 변경내용

## 원인
v52.08의 메신저 화면은 `messenger_room_members`의 모든 Realtime 변경(INSERT/UPDATE/DELETE)을 구독했습니다.
대화방을 읽음 처리하는 `messenger_mark_room_read()`는 `last_read_at`을 UPDATE합니다.
그 UPDATE를 메신저 화면이 다시 감지하여 `markRoomRead()`를 재호출했고, 다시 UPDATE가 발생하는 반복 구조가 생길 수 있었습니다.
또한 Realtime 갱신 때마다 메시지 영역 전체를 로딩 화면으로 바꾸어 화면이 새로고침되는 것처럼 보였습니다.

## 수정
- `messenger_room_members` Realtime 구독에서 UPDATE를 제외하고 실제 참여자 구성 변경인 INSERT/DELETE만 감지
- 메시지 Realtime 변경은 현재 대화방 메시지만 조용히(silent) 갱신
- 메시지 수신 때 참여자 목록을 불필요하게 재조회하지 않음
- 포커스 복귀 / 메시지 전송 / 파일 전송 / 메시지 삭제 후 갱신에서도 기존 메시지를 유지한 채 최신화
- 기존 1:1, 그룹, 읽지않음, 파일, 이미지, 삭제, 그룹관리 기능은 유지
